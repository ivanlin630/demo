# ② ★★★而我在裝它的時候，發現自己前一個設計是錯的

```
我做過：`[不可判]` ⇒ **離開碼 2**（理由：「不可判不是綠」）
而 merge-gate runner **看離開碼** ⇒ 非 0 直接判紅
⇒ ★**這一閘會【永遠紅】** —— **而你要它現在綠、切片B 落地才紅。**
⇒ ★★expect 完全救不了它（runner 在比對 expect 之前就已經判死）
```
⇒ **照你立的「判準看橫幅，不看離開碼」**：判別力**搬到 expect**，離開碼只反映真紅。
★★**而「不可判不是綠」沒有被放棄** —— **它從離開碼搬到了【閘的判準】上**：
`[不可判] 數 ＝ 2` 被釘住 ⇒ **變成 0 或 3 都會紅。**
★★★**這一顆的形狀值得記**：**我把一個語意（「它不是綠」）綁在一個【別人會先讀】的通道上，
於是那個語意變成了「它永遠不通過」** —— **兩者不是同一件事。**
