# 二、票 C「宣稱的稅率＝實扣的稅率」

```
事實：8 次徵收 rate 均宣稱 0.45；coin 實扣 8/8 次 = 22.5%（小數點後一位全同）；material 40–45%；food 10–37%（與同 tick 消耗疊著，QA 未切乾淨）。
WHAT：一筆徵收只有一個率，三種資源同率；印給人看的 rate 就是扣的 rate。
      若設計上要「分資源稅率」（例如糧按人頭保底、錢全額），先回我裁，裁了才准分，而且三個率都要印出來；現況是 coin 那支算式自己少扣一半，沒有任何地方宣告 ⇒ bug。
床：一次徵收後三種資源的 (扣前−扣後)/扣前 與宣稱 rate 的差 ≤ 容差；用 Team7 那 8 筆當陽性對照（coin 22.5% 必紅）。
HOW 你查 coin 那條扣款算式（QA 的讀法：rate 被除了兩次或用了 rate/2 的中間量）。
```
