```
WHAT
①例行思考：整點 pass，每隊一次（既有 CadenceStagger 錯開可留，它只影響 CPU 不影響結果）。
②狀態轉換當場釋放：抵達／完工／失敗／強制事件／遭遇邊界 ⇒ 承諾解除於該 tick（TaskArbiter 的「到目的地即釋放重評」就是這個形狀，推廣到全部轉換）。
③不得空等：被釋放的隊在下一個整點前必有一次重決策（同 tick 立即重想或排進下一整點，HOW 定；兩者都滿足 ≤1 小時）。
④遭遇戰照 1:1 時間尺：單位計時器 tick 級，與①②並存。
⑤玩家：press-is-do 不變。
床：佈置一隊於非整點抵達 ⇒ 距下一次決策 ≤ 60 tick；佈置強制事件於非整點 ⇒ 同上；反向：無轉換時兩整點之間零決策（確保不是改成每 tick 想）。
禁：為了反應快把例行 pass 改成每 tick；為了省 CPU 把釋放延到「下下個整點」。
```
