# 三、★★GDScript 差點靜默換掉我的雜湊（釘值格抓到的）

```

⇒ 寫進 GDScript 後第一次跑：★跨語言釘值 0／3，而且 2-d 的 mean ＝ 0.5920、四分位歪掉

      而且 GDScript 的分佈與 Python 鏡像【逐位吻合】（mean 0.5017／p25 0.2556／ups 26）
```
