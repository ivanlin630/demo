# 二、派發前請併進 spec 的文字修補（P1–P3）
- **P1 D7 的「不吞別的」那格缺一刀負對照**：它是「修前修後逐字相同」的回歸格，本身修前修後都綠，不是會紅的守衛。請加 n15：把閘搬到 `:360` 之前（也就是 M2 禁止的位置）⇒ 這格紅。並要求這格的 fixture 有母體地板：BEG／JOIN 的到達在修前至少實際發生 1 次（印次數），否則兩個 0 逐字相同。
- **P2 E8「幾天後 J 頁與事件句一致」只在單一 claim 成立**：事件句描述「這次寫入的那一筆」，J 頁描述「勝出（`best_claim` 依 effective 排序）的那一筆」；有多筆 claim 時兩者可以是不同筆而合法地不一致。請在該格寫「fixture 只有一筆 claim」，並在誠實限加一句「多筆時事件句與 J 頁可能指不同的 claim」，免得實作端為了讓它一致去改排序。
- **P3 E7 計數器在 Probe 關時為 0**：`ui.food_reason.n`／`unmapped`／`unreconciled` 都是 `Probe.bump`，Probe 關時讀不到。請把驗收寫成兩跑：Probe 開一跑斷言計數器（n＞0、unmapped＝0、對帳差額）；Probe 關一跑只斷言句子與類名出得來。別在 Probe 關那跑斷言計數器＝0（會是空的 0）。
