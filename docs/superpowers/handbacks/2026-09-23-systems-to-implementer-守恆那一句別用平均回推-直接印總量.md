# ★★★一、你那三組數字裡，最強的是 `376 vs 384`

```
8 勢力 × 48 小時 ＝ 384；量到 376；差【正好 8】＝ 勢力數
⇒ 每個勢力的第一次被推遲一次（§4b-1 在勢力粒度上的同一效應）
```

★**為什麼它比「2.8 倍」「42.6 倍」都強**：它是一個**可以事先算出來的差**。
⇒ 「量到的數 ＝ 我預測的數，而且連**差在哪裡**都對得上」——
★★這種吻合**沒有解釋空間**；而「快了 2.8 倍」只要有人說「本來就該快一點」就可以含混過去。

★★★**判準**：能寫成**等式**的證據，永遠優先於能寫成**倍數**的證據。

# ★★二、而「總工作量一樣」那一句，我要你換一個操作元

```
你寫：calls=547、平均批次=1.1 ⇒ 547 × 1.1 ≈ 601 ≈ 8.4 勢力工作／小時 ≈ 8 個勢力
★★問題：1.1 是【四捨五入過的】
   若真值 1.05 ⇒ 547 × 1.05 = 574（≈ 8×72−8 ＝ 568，幾乎正好守恆）
   若真值 1.10 ⇒ 601（比守恆值多 5.8%）
⇒ ★★★你要主張的正是【守恆】，而這個操作元的捨入誤差跨過了「守恆 vs 不守恆」的界線
```

★**修法（你手上就有資料）**：印**批次大小的總和**（`Σ batch.size()`），不要印平均。

```
判決行要長成：facai.calls=547  facai.faction_work_total=<整數>  hours=72  factions=8
⇒ ★然後把它跟【預測值】比：factions × hours − factions（首次推遲）
⇒ ★★這樣它就從「≈」變成一個可以對得上的【等式】，跟你 376 那一段同級
```

★★**順帶一個母體的事**：`FACDRIVE` 那一輪是 **48 小時**，呼叫次數那一輪是 **72 小時**
⇒ 兩個數字**不同母體**。各自內部自洽沒問題，但**不要把它們寫在同一個算式裡**。
