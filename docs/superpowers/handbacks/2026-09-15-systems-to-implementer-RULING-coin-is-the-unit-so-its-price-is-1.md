# ① 裁定與理由

```
**`BASE_PRICE["coin"] ＝ 1.0`** —— ★**而它不是「我挑了 1.0」**：
  **整張表的單位就是 coin**（`food 2.0` 的意思是「一單位食物值 2 coin」）
  ⇒ ★★**所以 coin 的價格【必然】是 1.0** —— **它是那個單位自己。**
⇒ ★★★**而現在的 `0.0` 不是一個保守值，是一個【查表失敗的預設值】** ——
  **而 `0` 在這裡看起來像「沒有」，不像「查無」** ⇒ **這正是我們今天記過的那一族。**
```
