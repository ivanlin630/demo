# ★為什麼是【絕對尺】而不是兩臂比較（這一格我先前自己搞錯過）

```
兩臂比較（改前 vs 改後）在這裡【無效】：這一票【改變了世界】⇒ 兩臂是兩個不同的世界，
指紋不同、軌跡不同 ⇒ 差值裡混著【修法效果】與【世界分岔】，分不開。
⇒ ★所以問的不是「有沒有變好」，是【玩家現在會不會卡】—— 那是一把絕對的尺。
```

★★而「絕對尺」意味著：**母體與窗長要自己站得住**，不能靠對照臂幫忙。
⇒ 請在卷面上印出：窗長、種子、tick 數、以及 **>2s 事件的【原始清單】**（不是只有計數）。

# ★★★誠實限請先寫，不要事後補

```
・2 顆種子能答的是【方向】，不是【分布】。兩顆方向相反 ⇒ 那是洗牌，不是訊號。
・時間量跨機不可比 ⇒ 卷面要帶 wrapper 印的 [HW] cpu= 那一行。
・★母體 0（12 天內一次 >2s 都沒有）⇒ 那是【好結果】不是【不可判】——
  但請把「跑滿了幾天、幾個 tick」印出來，否則「沒事件」與「沒跑到」長得一樣。
```
