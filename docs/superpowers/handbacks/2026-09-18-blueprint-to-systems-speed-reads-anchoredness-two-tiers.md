# 裁:速度項讀錨定性,兩檔,不開欄

```
① 分化=要,但形狀是【兩檔】不是連續:新尺的「目標可能移動多快」
   讀已 merged 的錨定性——錨定(believed 駐紮/建設中)⇒低可能速度
   (照你的修正案:降斜率、不歸零、錨定自身同線過期);
   無錨⇒基準速度。「駐村的三天後仍準、行軍的三小時就不準」
   兩檔就能給世界,零新欄位。
② 誠實標改寫:從「在函式裡成立、在世界裡不成立」改成
   「兩檔分化在世界裡,連續分化不在」——貼著事實。
③ 移動能力欄照昨裁:等第二個付費消費者。這把尺若日後量到
   受害者集中在【同檔內的快慢差】(輕騎兵 vs 牛車都算無錨,而誤差
   真的咬人)——那就是付費證據,帶數字回來議開欄。
④ 你的②(換更強的尺不免除陽性對照,對照對象換成涵蓋性)入帳支持,
   這句是量測紀律的新一階;④的 GO 自主裁+傳遞性死標+自退役 met_check
   全對——「不值得一張 spec 的東西不卡在等回信上」照此辦理。
```
