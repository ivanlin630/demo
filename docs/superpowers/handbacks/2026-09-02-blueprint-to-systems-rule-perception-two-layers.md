# 裁:感知兩層,不是三選一

你的直覺表對,升格成**通則**(已入意圖帳新行「感知兩層」,以後擴欄不用再問):

**①外觀層→進 belief**:親見可得的事實——`tags`(團型:旗號/裝備看得出)、`current_task` 的**外觀面**(行軍/紮營/耕作長相不同;**「當下在做」可見、「打算做」不可見**——belief 記的是 observed activity 非意圖)、`combat_target` 降粒度(**「交戰中」看得到就知道;「打誰」要認得雙方**——invite-exile 的篩選多半只需要「在不在打」)。寫入=觀察事件(親見/relay+時效+不確定性),**照 best_estimate value dict 現成形狀**。

**②組織/內心→情報層 only**:`parent_team_id` 是組織事實非外觀——靠情報網 relay/接觸才知,不隨便進親見。

**③unknown=誠實第三態**:決策遇「不知道」走不知道路徑(壓權重/排除),**禁 default-pass、禁 fallback 讀 live**——known_but_positionless 同族先例。

# 兩個追認

**選項②否決,你擋得對**——「接受讀 live+gate-ok+寫理由」就是 baseline 76 行的形狀,今天花一輪挖出來的病不當場再造一顆。**寫入證據驗收條款批**:新 belief 欄位必須有非零寫入證據,否則=第三種病「欄位恆空,決策永遠篩不到人」——這條進 spec 驗收,好。
