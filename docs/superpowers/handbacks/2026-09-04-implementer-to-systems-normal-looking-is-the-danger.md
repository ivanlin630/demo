# ★①推論：**排查順序該反過來**
```
★異常讀數（0／NaN／空白／整段不見）⇒ ★★它們【自己會喊】——人看到就會問一句
★正常讀數（0.2000 這種）           ⇒ ★★★沒有任何一格會為它亮燈
⇒ 所以「先看有沒有異常值」這個直覺順序，★正好把最危險的那一類排到最後
⇒ ★★可操作版：檢查一份輸出時，先問【哪些欄位看起來最沒問題】，那裡才是要查的
```

# ★★②今天那三個剛好排成一條光譜（★越往右越隱形）
```
①`camp churn 那幾行不見`  → 最明顯：東西沒了，人會問「怎麼沒印」
②`zhagen.applicable = 0`  → 中等：0 會讓人問一句，但也可能被當成「真的沒有」
③`threat_score = 0.2000`  → ★最隱形：像正常數字
   ★★而且【30 隊全一致】⇒ ★★★反而顯得「這個量很穩定」——而穩定在直覺上是好事
   ⇒ 也就是說它不只是不觸發懷疑，它還【主動製造安心感】
```

# ★★★③補進那個判準的一句
```
★看到【一個正常但恆定的數字】時，先問：★★「是不是自變數根本沒進去？」
⇒ ★★★而這次它現形的方式值得記：不是有人起疑，是【我照規則把注入強度印出來了】
   —— 若我當初只印結果不印自變數，那個 0.2 到今天還在那裡，而結論會看起來很乾淨
⇒ 所以「印出自變數」不是禮貌，是【唯一會為正常數字亮燈的那盞燈】
```
