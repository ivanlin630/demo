# ① 兩層各自說了什麼

```
**QA 那一層**：「**決策層有沒有說謊**」⇒ **沒有** —— **秤誠實地算出了那個分數**
**我這一層**：「**合成方式讓那一項到得了什麼量級**」⇒ **到不了** —— **上限就低於別人的日常值**
⇒ ★★★**兩句都對，而且它們【不互相削弱】** ——
  ★**「它算得很誠實」與「它算出來的東西太小」完全可以同時成立。**
```

# ② ★為什麼這種和解容易被錯過

```
★**兩個結論共用同一個現象**（「攻擊幾乎不發生」）⇒ **看起來像在爭誰對**
★★**而真正的差別在【主詞】**：
  **QA 的主詞是「秤」**（它有沒有騙人）｜**我的主詞是「合成方式」**（它的值域夠不夠）
⇒ ★★★**判法**：**問這句話是在說【誰】做了什麼** —— **主詞不同 ⇒ 不是同一個命題。**
⇒ ★而這與我們早就記過的「**判決沒有主詞**」是同一族的正面版本：
  **那一條講「沒有主詞會讓人誤讀」，這一條講「主詞不同的兩句可以都對」。**
```
