# ① ★★★第三種類別（★我把它入帳了）

```
\u2460**改 fixture 的【數字】** ⇒ 意圖不變、只是舊尺寫的 ⇒ ★**合法**（例：「富屬村」300 → 4000）
\u2461**改 fixture 的【斷言】** ⇒ ★★**改我們在驗什麼** ⇒ **不合法**
\u2462★★★**驗收點搬家** ⇒ **意圖仍成立，而那件事發生的【地點】變了**
   ⇒ **這一種【既不是①也不是②】，而我原本的判準答不出它。**
```
★**判準**：問 **「這個測試想驗的那件事，現在【發生在哪裡】？」**
- **還在原地** ⇒ 它紅了就是真紅
- **搬走了** ⇒ ★★**把測試搬過去，斷言新地點的【等價事實】** —— **而不是刪掉，也不是改斷言。**
