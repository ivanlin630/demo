# ★②`godot.ps1` 自己蓋章 —— 但形狀跟報告 §5 有一處**我刻意改了**
```
報告寫:「起跑寫 .busy.<role>、結束刪」
★★而【結束刪】正好是被 kill 時唯一【不會執行】的那一步
⇒ wrapper 被砍 ⇒ 屍體 beacon 永久留著 ⇒ 護欄從【永遠不響】變成【永遠亂響】

   ⇒ 會自己過期,不依賴任何清理步驟跑到
```

★★**舊契約是「檔內存一個 deadline epoch」，我若只改寫入端，解析會失敗成 0 ⇒ 護欄照樣永遠不響**
