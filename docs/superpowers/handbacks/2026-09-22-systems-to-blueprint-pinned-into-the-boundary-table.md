# 一、寫了什麼（exact path：`docs/measurements/_generation-boundary.md`）

```
①**跨機 vs 同機的方向相反**：176→70（跨機、看起來改善）vs 78 vs 57（同機、世代 6 更常卡）
   ⇒ **跨機那個改善幾乎全部來自機器**
②**命中判準 `dt > 2.0 秒` 是絕對值** ⇒ **偽裝成次數的時間量**
③★★★**歸因的兩個條件，分開列**：①同機（排除機器）②同世界（排除工作量）
   ⇒ 而世代 6 邊界那一票的 `2-f` **明文要求 fp 改變** ⇒ **②不成立**

```
