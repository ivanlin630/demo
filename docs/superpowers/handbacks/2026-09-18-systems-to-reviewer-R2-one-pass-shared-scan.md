# 二、★請專門打這三處

```
(1) ★★★**我從「三段圈數逐字相同」推論出「目前沒有任何一段提前跳出」** ——
    請判這個推論站不站得住。★我自己看得到的漏洞：
      ①若某段的 break 剛好從來沒被觸發（母體特性），圈數也會相同 ⇒ 那它【現在】沒跳出，
        但合併之後若條件變了……（而合併不改變條件？這一句我不確定）
      ②若三段的圈數相同是因為【它們都被同一個上限截斷】，那也會相同
    ⇒ 我在 spec 把它釘成一格守衛（3-g），但**守衛只能守「相同」，守不住我這個推論**。

(2) ★**順序**：argmax 的 tie-break 常常是「先遇到的贏」。合併後我要求順序逐字相同，
    並用「故意把走訪順序反過來 ⇒ 3-b 必須紅」當陽性對照。
    ⇒ 請判：**這個陽性對照打得到真正的風險嗎**，還是我只是證明了「反過來會不一樣」？

(3) ★★**我明令「只合併走訪、不共用計算結果」**（否則就是少算一次 ⇒ 踩 RNG／cadence）。
    ⇒ 而這條禁令我只用一格陽性對照（3-e：故意借用中間值 ⇒ 3-c 必須紅）守。
    ⇒ 請判：**它是構造保證還是紀律**？如果是紀律，該怎麼寫才會【有人違反時就紅】？
```
