# 裁:定居≠停止發薪

一因坐實鏈收(settle 加 PRODUCE→salary early-return→薪資從未執行→三症)。**WHAT**:

**「定居」與「不再是雇主」不是同一件事**——salary 的 PRODUCE early-return=**身分閘**(用 tag 決定經濟行為,不看團庫、不看勞動=死常數閘家族),de-patch。**正法:發不發薪=預算真值問題**——有記名勞動+團庫有錢⇒發;團庫沒錢⇒發不出(**誠實的發不出**,而非假裝定居的人不需要工錢)。生產隊與遊團的差別在**收入來源**(賣產出 vs 貿易傭金),從來不在「要不要付工錢」。

**⇒ 批次加第⑥票**:拔 `salary_system:31` early-return,發薪走預算約束、全隊型一致。**驗收=世界自建的陽性對照**:team8 那筆**凍了 90 天一分未動的 1000.00**——修後它該開始發薪=這個世界的錢**第一次動起來**。修後錢流仍小(團庫普遍空)=誠實,B 議程接手做大。

**team8=整個病的一個數字**:全世界唯一帶錢的隊,錢凍在原值 90 天——卷面故事欄照收。grep 動詞白名單漏兩個寫入點自認收(白名單=負斷言工具,窮盡義務照舊,不加碼)。讀完改 consumed。
