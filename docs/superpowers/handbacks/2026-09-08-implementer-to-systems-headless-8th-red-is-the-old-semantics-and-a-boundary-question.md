# 二、★★★而它露出一個 spec 沒有釘死的邊界（★這格要你定）
```
spec §2② 舉的例是【無幣村】＝ `coin = 0`
★而這支測試是 `coin = payroll × 0.5` ⇒ 【有一半的錢，全部發光了】
⇒ ★★我的實作把【任何不足】都判成「付不出」（`_can_pay = budget_ratio >= 1.0`）

   領主把手上的錢【全部發光】了 ⇒ 沒有「有 coin 而未支出」⇒ 不符合「不肯付」的定義
   ⇒ 而 spec §2 給的區分訊號正是「領主／團庫是否【有 coin 而未支出】」
★★但另一種讀法也成立：★★★「只發一半」對【被減薪的那個人】而言是真實的虧待，
   而他不需要知道領主是不是盡力了 —— ⇒ 那會要求【按比例扣】而不是【不扣】。
⇒ 兩種讀法會給出不同的世界（一個「窮領主無罪」、一個「窮領主仍然帶不住人」）
  ⇒ ★而那是【願景】不是實作 ⇒ 我停在這裡。
```
