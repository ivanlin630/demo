# 時間骨架 5 錨裁定

回 `time-audit-groups`。分組表漂亮。**×5 窄拆確認收下**（唯一讀站=BASE_MOVE_TICKS、food/fatigue ÷24=獨立手校痕）→ 拆=改移動格耗+重校那幾個手校下游，非全域旋鈕。重校比怕的小。

## 錨 ①：移動 1 world-hex = **240 tick = 1 天**（×1，連動值）
- 連動式直算：`BASE_ACTION_TICKS(10) × 遭遇戰地圖尺度(24) = 240`。**×5 拿掉**（48→240）。
- believable：一格=一天步行行軍（~一日路程），全世界 ~25 格=約 25 天橫跨=五代十國一國尺度合理。
- 菁英/騎兵快（→MIN）、地形/夜/疲勞慢（→MAX）。**這 240 = invariant #2 的錨，不准再塞倍率打破。**
- 連帶：一格=一天=吃一天糧 → 走遠路要備糧/補給（=錨④後勤，非瞬移）。

## 錨 ②：遭遇戰地圖尺度 = 24（MAP_DIAMETER，不變）
進連動式當基準。24×24 戰術圖尺度合理，不動。

## 錨 ③：cadence 按**決策層級**語意化（框架我給，逐條你填）
```
戰略意圖(致富/征服/建國) = 天級（決策本來就慢,一天想一次夠）
戰術任務(去哪/做啥)      = 時級（半天~數時）
反應(被襲/絕境)          = 事件觸發（即時,不等 cadence）
★行軍中隊 = 全降天級 + 事件觸發（悶頭趕路,到了或遇襲才動腦）
  = ②「移動中降思考」的具體:行軍狀態 cadence≈1天,非每tick
```
裸 720/360/240 → 3天/1.5天/1天 語意天數收編。逐條對照這框架填，邊界情況呈我。

## 錨 ④：後勤「走一格餓死」真帳 = 併三平行 measure
加「行軍糧帳」列：糧耗/格 vs carry 容量 vs 沿途補給機會——哪缺。**數據回來我裁補給機制**（帶乾糧上限/沿途 raid·買糧/糧耗率），接後勤裁定。measure-first，不預先開藥。
