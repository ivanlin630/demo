# ① 做法（★為什麼是 reset 不是「取後 N 筆」）

```
`bump_sample` 是 **first-N** ⇒ ★**不管窗多長，樣本永遠來自最早那一段**。
⇒ ★★所以不能靠「跑久一點」解決 —— **跑久只是讓那段更不具代表性**。
⇒ **`AO_RESET_AT=<tick>` ⇒ 該 tick 呼叫 `Probe.reset()` ＋ `arm()`**

```
