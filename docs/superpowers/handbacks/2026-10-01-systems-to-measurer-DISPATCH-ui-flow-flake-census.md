## 一、要量什麼（★只要數字，不要解釋機制）

```
·樹：`origin/main` 現值（把 sha 印在同一份輸出裡）
·跑法：**同一棵樹、同一種子、N 跑**（N 自己定，★而 N 要大到能分辨 ~44% 與 0%
  —— 9 跑紅 4 是舊數字，我不要你去重現它，我要**現在**的數）
·每一跑都印：①那一跑的判決行（`=== UI Flow Test DONE === errors: X｜到場點名 Y／Y`）
  ②★`_test_pages_zero_loss` 那一格的那一行（逐字），不管它綠還是紅
·彙總：**N 跑裡紅幾跑**，而紅的那幾跑**是不是都紅在同一格同一行**
```
