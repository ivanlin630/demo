# ★①blueprint 的判準（★逐字，我不改）
> **量「輪詢的獨特貢獻率」＝【週期觸發的重評】中【改變了決策】的比例 ＋ 成因分類。**
> **≈0 ⇒ 冗餘 ⇒ 退場；>0 ⇒ ★那批案例【逐個變成該補的 T0 事件型別】再退**
> **（＝用戶原令「不搞白名單挑食」的【完備化路徑】）。**

★★**這比我原本給你的三欄鋒利** —— ★★★**它把「要不要砍輪詢」變成「輪詢的殘值【就是】那份缺漏事件清單」。**

# ★★②要量的（★三欄，第三欄是我加的）
```
★①分母:【純 cadence 觸發】的重評次數（★死水三欄裡的 cadence 那欄,你已經有）
★★②分子:其中【改變了決策】的次數
   ★判準要你先定義再量,而我給邊界:「改變」= 該次重評之後,該 actor 的【選擇】與重評前不同
     ⇒ ★★不是「跑了」也不是「分數變了」,是【選出來的東西變了】
     ⇒ ★★★而若你判斷「維持原選擇」也算貢獻(確認承諾),★把它獨立成第三類,不要併進分子
★★★③成因分類:分子那批,逐個標【是什麼變化促成的】
   ⇒ 這一欄【就是】待補的 T0 kind 候選 —— ★blueprint 的完備化路徑靠它
★★★★④(我加的)延遲量:那些【沒改變】的,若當時不跑,★下一次事件喚醒在多久之後?
   ★★理由:「這次沒改變」≠「不跑也沒差」——★★★改變可能只是還沒到,而砍掉輪詢會讓它【晚很久】才發生
      ⇒ 沒有這一欄,≈0 會被讀成「可以砍」,而真相可能是「可以砍,但反應延遲會從小時級變成天級」
```

# ★★★③判準先講死（★免得事後挑）
```
①★分母 = 0 ⇒ ★★停,回報「這張床上輪詢根本沒觸發過」——不要拿 0/0 當「貢獻率 ≈ 0」
②★★分子/分母 ≈ 0 且 ④的延遲量【小】 ⇒ 冗餘,可退場
③★★★分子 > 0 ⇒ ★不退,而③那欄的清單交我 ⇒ 逐個判要不要變成新的 T0 kind
④★分子 ≈ 0 但 ④的延遲量【大】 ⇒ ★★這是第三種結論:「輪詢沒在改變決策,但它是【兜底的時效保證】」
   ⇒ ★★★那時要問的是「兜底該不該存在」,而不是「它有沒有用」——那一格交我裁,你只要把數字分開
```
