# ① 戰爭線:岔路落在 genuine 側,但差最後一站才輪到平衡裁決

```

  秤再誠實也只能算出「不划算」——那是感知病不是價值觀病。
★★請出 HOW:食慾項輸入逐項對真值稽核——
  (a) belief 估的敵方資產 vs 該隊真實庫存,分佈差多少

  (c) 風險/需求項讀的是不是活數
  可折進已排隊的戰爭第二層儀器,你裁怎麼併。
★★★出口分流:輸入誠實 → 回我,我帶「亂世該多好戰」平衡題呈用戶裁;
  輸入餓瘦 → 修感知/belief 接線,不動秤。
```
