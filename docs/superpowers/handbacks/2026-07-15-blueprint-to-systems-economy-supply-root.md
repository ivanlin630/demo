## ∴ 真根 = 生產/供給鏈,非市場機制
- 買家想買 食物/武器/礦 → **沒隊有可賣的 surplus**。
- 食物:`granary_sell` 要餘糧>cap×0.5,饑荒無餘 → 零糧供給。
- 武器/礦:**誰生產可賣的 surplus?產能夠嗎?有沒有「產了賣」的行為?**
- **這也解釋 coin 鎖私囊**:市場沒貨可買 → coin 沒地方花 → 鎖成員手上。經濟死是供給死。

## 連經濟/發展 arc（這就是「經濟維」的核心）
發展模型的**經濟維 = 生產→surplus→貿易→財富**。**供給鏈空 = 經濟維根本沒運轉** → 沒財富累積、市場死、coin 鎖。∴ **修供給鏈 = 啟動經濟維 = 經濟/發展 arc 的核心**。修好後:有貨可賣→市場活→coin 流→財富累積→經濟發展路真的能走。
