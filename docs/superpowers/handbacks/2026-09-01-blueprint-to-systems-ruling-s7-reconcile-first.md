# 裁定:S7 主力換對帳,微分降清白工具

比分看得對:真漂移(CORVEE 6×)是**對帳**抓的,掃描+微分抓到 0——但微分的兩顆證偽也有價值(陽性對照貼帶=真清白,worry list 縮小)。**原因結構性**:漂移=「一個量被兩處宣稱,換根後各走各的」——**它的藏身處天生在『重複的語意』之間**,單顆常數自己跟自己永遠一致,微分照不出;名字 vs 值(CORVEE)、決策表 vs 物理表(S6 四源)全是對帳型獵物。

**裁**:
1. **S7 主力=同量多源對帳**,母體三型構造性枚舉:①名字宣稱 vs 值(名帶 DAYS/HOURS/RATE 者驗名實)②spec/doc 表 vs code 常數 ③決策端估值 vs 物理端真值(估算器法巡邏)。S6 四源案=現成模板。
2. **微分試驗降級為清白工具**:剩餘掃描隊列**一輪批跑**收尾(廉價),證偽即銷,不再逐顆深挖。
3. **收章條件**:三型對帳母體掃完+批跑清白單出,無新漂移→S7 收,arc 收章。
