# world-gen 戲劇性尾巴 — feel 細化

承 `measurement-rulings` #0（真因＝世界沒極端值）。用戶走查逼出完整 feel。WHAT/feel 藍圖給，**分佈形狀/實作＝系統 HOW**。

## 根因（三面，同一病）

`person_generator.gd`：
1. `values[v] = randf_range(0.2, 0.8)` → 無性格極端（無 0.9 霸主/屠夫、無 0.1 懦夫）。
2. `skills base = randf_range(0.0, 0.3)` → 無技能專家（連 leader 都低）。
3. `generate_for_team`（升 named）呼 `generate()` **不看 tier** + `kill_random` 隨機抽 → **菁英 anon 升 named ＝ 隨機低技能，老兵本事蒸發**。

（註：progress.md 記 person_generator 有「tag 屬性/技能偏移」＝ **stale**，實碼無。）

## feel（五條）

### 1. 價值觀：對稱尾巴，守中位
- **非全民極端**（那是另一種假＝卡通狂熱世界）。
- 大盤守中（~0.4–0.6 凡人），**只放出尾巴** → 偶現 0.9 霸主 / 0.1 懦夫。
- 動的是**變異/尾巴，不是平均**。世界 ＝ 多數凡人 + 關鍵少數狂人，狂人驅動立國/血仇/陰謀。

### 2. 技能：多數低（留）+ 專家高尾巴 + 成長到大師
- **多數低 ＝ 對的、擬真**（農民本就不會偵查/戰術/醫療），別動。
- 缺的是**專家高尾巴**：宿將（戰術/統領）、老斥候（偵查）、老謀士（計謀）、郎中（醫療）該存在。
- **成長要能到大師**（窗口內練得出專家，非永遠封頂低）。

### 3. leader 選擇效應：抽自「野心 + 能力」尾巴
- 立國需 野心(value)高 **且** 統領(skill)高 同一人——光野心沒統領撐不起大軍。
- 兩尾巴若獨立，「又狂又能」＝ 尾巴×尾巴 ＝ 太稀有。
- → **leader 不純隨機**：偏向野心+能力端（亂世能爬到隊長者，本是狠勁+本事突出）。**狂人要有本錢**，否則空有野心的廢物。

### 4. 升 named 忠於 tier（技能尾巴的結構化來源）
- 高技能 named **就該是「被提拔的老兵」**——敘事最合理。
- 菁英 anon → 高 戰鬥/戰術/統領 named；平民 → 低。
- 修 `generate_for_team`：**讀來源 tier 設技能**；`kill_random` 改抽對應 tier（要升老兵就從老兵桶抽 + 給匹配技能）。
- **複用既有 AnonTierSystem，零新概念。**

### 5. 一致性
- 初始 leader（程序化路徑）與升階 named 都吃同套尾巴邏輯，免一邊有戲一邊平庸。

## 驗收方向（重量預設世界後）

- value/skill 分佈**有可見尾巴**（非截斷）。
- **立國 / 血仇 / 識破裁決 > 0**（狂人 + 專家出現後，戲劇行為跨閾）。
- 菁英 anon 升 named 後**技能顯著高於平民升的**。
- 大盤仍多數平庸（非全民狂人）。
