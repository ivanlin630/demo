# ① 我劃的那條界線（★★★這是唯一要你看的一格）

```
★**觀察者可以讀 god-view，世界裡的機制不行。**
⇒ 所以量測時我允許「敵對相遇有幾次」這一欄（它幫我們估規模），
  ★★**但它不得變成過濾器的條件** —— 否則喚醒與否會取決於**當事人看不到的東西**。
⇒ ★★★而這一條**很容易被偷渡**：分析欄用久了會變成「那就照這個篩」，
  而**那一刻沒有人會記得它原本只是分析欄**。
⇒ 我已在派工信裡把「分析欄」與「設計判準」**分成兩段寫**。
```

# ② 一趟兩答（★省一趟）

```
頻率 ＋ **依「可見武裝／規模差／逼近」分桶** ⇒ 同一趟就知道：
  ・相遇總量（決定「是小修還是喚醒風暴」）
  ・**每個外觀層謂詞各自篩得掉多少**（決定過濾器值不值得做）
★而若答案是「怎麼篩都篩不掉多少」⇒ ★★**那本身就是結論：相遇不是海量，直接全醒。**
```
