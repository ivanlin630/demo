# 方法
`player_command_system.gd` 的 `_action_registry` 53 個 handler ＋ 回應提案三型，逐一看函式體裡對世界的寫入（資源／任務／勢力／據點／戰鬥／情報／名聲），再 grep 它寫的欄位有沒有讀者。靜態讀：讀得出「有沒有寫入」、讀不出「寫了有沒有被蓋掉」，標了 ★ 的要床驗。

# 要修（宣稱動作必須改世界，2026-10-06 裁）
1. **調整武裝比例**（`_action_set_armed_ratio` 寫 `pt.armed_anon_ratio`）：`equipment_system.gd:67／:73` 每次結算用武器庫存重算同一欄並直寫 ⇒ 玩家設的值會被蓋回 ★（順序與頻率床驗）。WHAT：要嘛玩家設的是「目標比例」、裝備邏輯在武器夠時服從它、不夠時印「武器只夠 N%」；要嘛拿掉這個鍵。不准留一個會被靜默蓋掉的開關。這也是 2026-08-03 審出的「三個各自為政的人口比例旋鈕」之一，先修這一顆。
2. **訓練**（`_action_train`）：沒有可升階對象時照扣 `TRAIN_COST_COIN`，回「訓練（-X 幣，無可升階對象）」且 ok:true。WHAT：沒人可練＝不扣錢、回不可＋原因，且動作清單先列在不可側。
3. **重掃同格對象**（`refresh_targets`）：純介面重整，卻是一個「行動」，每按一次互動都在事件流印「指令｜重掃同格對象：已重掃同格對象」（用戶貼的每張圖都有）。WHAT：它不是世界動作，不進事件流、不占「結果」句；要重掃就靜默重掃。
4. **通商**（回應 propose_trade）：唯一效果名聲 +0.05。WHAT：空動作不留——歸深層批貿易票：通商要有實效（對方願直接交易／互通市價與糧源情報），或把這個提案從 NPC 的提案族拿掉。深層批，不插隊。
