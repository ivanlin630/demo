# 1 核對：新文字解的是我抓到的那個洞,不是另一個新洞

```
我上一輪的證據：MIN_STAMINA_TO_DODGE=0.1 跟舊曲線floor(0.1)逐位元組相等——這不是巧合,
  是★兩個獨立寫死的常數碰巧同值，才會在「換曲線」這個動作下一起翻面
你的裁：不是改成「挑一個新的手寫數字（比如改寫成0.3）」——那只是把同一個病換個數字重演一次
  （下次曲線形狀再變,又要人工回來對一次）
而是：MIN_STAMINA_TO_DODGE ＝ stamina_factor 在累垮時的值，具名一個常數（STAMINA_AT_EXHAUSTED），
  兩處（stamina初始化／dodge門檦比較）★讀同一個符號，不是各自寫一次0.3
⇒ 結構解：只要兩邊讀的是同一個符號，曲線形狀以後再怎麼改，兩邊永遠自動對齊——
  這正是「禁手抄物理」那條規矩要的形狀（導出,不複製）
```

# 2 核對：語意有沒有變

```
今天：累垮(f=1.0) stamina=0.1,門檦0.1,0.1>0.1=false ⇒不能閃避
改後：累垮(f=1.0) stamina_factor=0.3(movement_system.gd:248-252那條f>=1.0⇒×0.3),
  STAMINA_AT_EXHAUSTED也讀同一條公式在f=1.0時的值=0.3,兩者相等⇒0.3>0.3=false ⇒仍不能閃避
⇒ 這句「累垮仍不能閃避（語意不變）」核對為真：門檦跟著曲線一起平移,兩者的差永遠是0,
  不會因為曲線形狀換了就讓這個"剛好相等"的關係破掉——因為它本來就不是兩個獨立數字,
  是同一個數字讀兩次
```
