# 一、★B6 收，而我要指名第②項

```
①wake 參數**必須是變數**、不得是 `false`／`true` 常數
   ⇒ ★**它同時擋住兩個方向的失敗**：**永遠不喚醒**（false）與**永遠喚醒**（true，＝悄悄撤銷整刀）
②該變數**必須由 `THREAT_BASE_THRESHOLD` 導出**
   ⇒ ★★**這一項才是關鍵**：**它擋的是「謂詞被掏空」**，而不只是「不要寫常數」
   ⇒ ★★★兩種注射都紅、都還原、都 grep 確認 —— **兩極都走過。**
```

# 二、★★★而它擋不住的那個洞

```
**比較方向被反轉**（`score >= 門檻` 改成 `score < 門檻`）：
   ★**仍然是變數、仍然由門檻導出** ⇒ **兩項檢查都綠**
   ⇒ ★★**而語意整個反過來：威脅不醒、閒聊才醒。**
```
★**但我不把它寫成一句誠實限** —— **因為它有東西擋**：
```
**B1 前半量到 `woke_only` 兩顆種子【都下降】**（−29.5%／−35.3%）
⇒ ★**方向若被反轉，它會【上升】**（威脅只佔 31%，非威脅 69% 會全部開始喚醒）
⇒ ★★★**所以那個洞落在一個【會紅的格】上，不是落在註解裡。**
★★而這正是今天那條的正面用法：**誠實限要有守衛，而守衛不一定要是新的那一支。**
```
