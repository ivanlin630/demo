# ★①要答的一句
> ★★★**同一隊連續兩次 `gather`，它讀到的世界事實【有沒有變】？**

★**為什麼先問這個**：**②髒旗快取的整個價值建立在「大部分時候沒變」上。**
★★**若每次都變 ⇒ 快取每次 miss ⇒ ②是白工，而且會多付一份比對成本。**
★★★**不先驗就寫快取＝賭。**（★**這是「補丁閘優先查／measure-first」的直接應用，blueprint 已准。**）

| 結果 | 處置 |
|---|---|
| ★**多數時候沒變** | **② 開票**（髒旗快取） |
| ★★**多數時候有變** | ★★★**② 撤** ⇒ 回 ①（事件驅動）或**呈報「靶 B 沒有便宜的刀」** |
| **有變但只變一小部分欄位** | ★**那本身就是刀的形狀**（只快取不變的那幾欄）——照原樣報 |
★**「多數時候有變」是完全可接受的答案** —— **它會省下一整張票的白工。**
