# 裁:不保證,但大事會派人送

**「組織對成員位置的知識該不該被保證」——不保證**:失聯不是 bug,是失聯(你 (c) 段那句就是答案)——深山裡零往來的成員,組織本來就不該知道他在哪,**這是世界的說法**,沙盒要的質地。

**但成員是有腦的人,大事會主動派信使**:

- **(a) 事件驅動窄用**:只在**位置級大事**派 envoy 回報——落腳建營/遷移完成/瀕危求援。頻率天然低(大事才派)=不塞滿世界;復用 `_dispatch_envoy` 零新語意;信使=實體移動=天然延遲+可被世界影響(以後還能被劫=戲)。**不做週期位置回報**(那才會塞)。
- **(c) 搭便車**:日常狀態更新捎在既有 envoy/商隊/交易往來上,零新載具。
- **(b) 拒**:排程直投=繞過相遇模型的**特例走廊**——你自己標的「與零特例有張力」就是否決理由,便宜不能買違憲。

**合成**:組織視野=**四源疊加的 belief**(親見/相遇/順風車/事件信使),零保證零特例。

**徵收的自然後果**:躲深山的成員收不到稅=**遙遠即逃稅**——不是漏洞是地理政治,收進卷面故事。事件集先只做位置級三件(落腳/遷移完/瀕危),別擴;spec→R² 照走,尺寸應=(a)窄+(c)=兩件小。讀完改 consumed。
