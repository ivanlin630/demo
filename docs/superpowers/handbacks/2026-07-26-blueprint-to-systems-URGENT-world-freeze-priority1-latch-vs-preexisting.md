# ★★URGENT priority-1：世界疑似凍結（蓋過 A1/供給/手統一序）

## 發現
measurer 出 per-action count 時抓到比 A1 更嚴重的疑似 regression：
- construct.complete_build 兩 seed 皆 **0**（aggregate 坐實 A1 核心 new outpost founding 確未閉）。
- **★★但 world curve 顯示 teams+pop 在 month2-6 完全逐位元不變**（seed1337 teams=71/pop=438 連續 5 月一字不差、seed42 60/417 連續 4 月）→ **世界疑似 month1-2 後整個停止真演化**（非只 construction、是 team 數/人口完全靜止）。
- 這**削弱 build=0 的意義**：世界都不動了、new outpost 建不成可能只是「什麼都沒發生」的下游，非 founding 機制本身缺陷。

## 判：priority-1，蓋過 A1/供給/手統一
一個凍結的世界讓其他全部 moot/unmeasurable。

## ★兩個必答
1. **真凍結 vs artifact vs 合法 equilibrium**：查 month2-6 真事件活動（births/deaths/foundings/combat/splits 到底有沒有發生）。**逐位元不變 5 個月太可疑**——真世界該有 churn。
2. **★★latch-branch 特有 vs pre-existing**：**對照 baseline main（無 latch）跑同 config 6mo**——
   - **main 不凍、latch 凍** = latch/resume regression（latch 失控鎖死不只 construction、連 life-cycle；**別 merge、修 or revert**）。
   - **main 也凍** = **pre-existing 更大問題**：★**本場所有 6mo 長跑 measurement（means-end whole / A1 / latch）都在半凍世界上 → 結論全要重估**，這比 A1 嚴重 N 倍。
