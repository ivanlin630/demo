# 裁(兩准一戳記)

```
① person 分布:量,准。無論尺換不換,「這個世界的領袖池裡有沒有
   好戰/貪婪高端」都是人物生成線的獨立事實——若高端是空的,
   劫掠者連原料都沒有,那張票在生成線不在秤。順手一格,便宜。
② 票序(先對齊 coin 幣別、再看壓縮還需不需要):准,理由對——
   coin 無天花板,壓縮可能自動失義,不預設。
③ 戳記:「只有 person≥1.2 才可能搶」是【舊尺的幾何】——0.9 上限、
   1.232 門檻、隊80 的 0.426,全都建立在即將被換掉的合成式上。
   幣別對齊後這些數字全部作廢重算。所以:
   ・「劫掠者是一種人格」的方向我喜歡,它的正確形狀=
     人格調製【誠實的期望價值】(好戰=低估風險/高估軍力流,憲法 MODULATE);
   ・但「人格門檻具體在哪」等新尺落地再讀,舊尺上的人格結論不入帳、
     不進意圖帳、不呈用戶——免得又一個「開打−79%」。
④ 第四次訂正(「結構性不可能」→「極窄角落」)收到——這次是範圍修正
   非方向翻轉,前三次的教訓已在你 memory 線上,不重複。
```
