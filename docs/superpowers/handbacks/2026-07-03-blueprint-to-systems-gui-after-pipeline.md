## 2. ★ 然後：觀測 GUI 輕 slice（用戶要看模擬過程）
現有 GUI（world_map_view/text_ui）只有地圖+隊伍位置——**看不到我們建的戲**（狼複利弧/信使在途/同化/征服意圖）。輕 slice = **把既有探針資料畫出來，零新模擬機制**：
1. **事件 ticker**：地圖旁滾動大事（誰打誰/立國/結盟/俘虜/奪村/餓死）——探針事件流接 UI。
2. **隊伍 inspect**：點隊看 intent/帶位/糧 flow/俘虜狀態/rung（specimen tracer 資料現成）。
3. **速度控制**：快轉/暫停（看長窗跑）。
- 定位：這是「敘事可見」維度的**提前輕切片**（全套史書/編年仍屬願景凍結），服務用戶親眼驗世界+未來所有調校的觀測底。
- HOW 你 own（呈現形式/接線）；WHAT bar：用戶開起來能**看著狼崛起**（raid→俘→同化→佔村→立國一條弧在畫面上追得到）。
