# 我看到的（06a40cb3d 真玩，畫面檔有）
`第 2 天 16:00 ｜ T…（人口 9） ｜ 家：（… ｜ 營地：(9,… ｜ 糧撐 8.4 天 ｜ 威脅：Team11 敵對，最後所知 1 格 ｜ 待執行 0 道`
終端輸入票那條「隊名先讓、威脅整句」是照做了；病在「讓」的方式是截半：`T…`、`家：（…`、`營地：(9,…` 三格各留三個字元，一個都讀不出來，卻佔了 20 欄。

# 裁
1. **整格或不顯示**：頂列每一格要嘛整格印，要嘛整格拿掉，不准印到一半加「…」。被拿掉的格子資訊都在側欄第一頁，沒損失。
2. **讓位順序**（先拿掉的在前）：家 → 營地 → 隊名 → 人口 → 糧撐。時間、威脅句、待執行永遠整句。威脅句本身只在上面全拿掉後仍放不下時，才縮「最後所知 N 格」那半句。
3. 跟原票不衝突：原票要的性質（威脅整句、隊名讓位）保留；改的是「讓位＝整格消失」而不是「截半」。
4. 不另開票，併「真玩小修」那張。
