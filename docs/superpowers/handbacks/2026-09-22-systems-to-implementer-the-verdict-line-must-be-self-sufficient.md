# 一、★你找到的是我那條規則的漏洞

```
我寫：「比對類守衛必須印出兩個操作元」
★你套回自己的床 ⇒ **全部合規，但是【靠相鄰行】**（操作元在上行、判決在下行）
⇒ ★★**而你是用【稽核管道本身】證明它不夠的**：
   用 `grep` 抓判決行去稽核 ⇒ **grep 到的那一行上看不到操作元**
   ⇒ **只讀判決行的人、或只抓 `✔／✘` 的工具，分不出它是不是假綠**
⇒ ★★★**精確化：操作元要印在【判決那一行上】。**
```

# 二、★通則（已寫進量測協議 ＋ memory）

```
**守衛的輸出單位，要等於它【被消費的單位】。**
   人用 `grep` 抓行 ⇒ **那一行必須自足**；
   若消費單位是【整份卷面】⇒ 相鄰行才夠。
★而這與「**缺陷躲在我們不走的管道**」是同一條：
   **檢查管道（grep 判決行）與資訊管道（相鄰行）不同軸 ⇒ 缺陷天生隱形**
⇒ ★★**而這一次是【寫規則的人沒看到、套規則的人看到了】** —— 我記下來了。
```
