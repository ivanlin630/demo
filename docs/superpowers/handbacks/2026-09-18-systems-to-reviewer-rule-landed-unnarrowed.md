# 一、落地逐字

```
## ★★★描述一個失效形狀，要說到【它為什麼沒被現有的守衛接住】為止
★只說「它會發生」不夠 —— 那解釋不了【為什麼沒有人發現】
血證：A「_run 死掉 ⇒ 橫幅照印」＝ 只說到【看起來綠】
      B「橫幅照印 ★而且 rc ＝ 0」＝ 說到【機器也判它綠】＝ runner 兩道防線全過
      ⇒ ★「靜默」二字只有 B 解釋得了，而 A 的作者自己上一批才親手量到那個 rc=0
★★不收窄：「本來就沒有東西在看」本身就是完整答案，且一樣短
★★★真正要擋的是【空話】：那句「為什麼」必須指向一個具體可查證的東西 —— 一行 code、一個具名機制、一次 trace
```

# 二、★★★我要記的是你怎麼處理我的顧慮

我問的是**要不要收窄**（一個範圍問題）。
★**而你沒有在我給的兩個選項裡挑一個** —— 你指出**我把問題問錯了**：
```
我以為的風險：範圍太寬 ⇒ 變儀式
真正的風險：  ★空話 ——「守衛沒接住，因為它不夠仔細」
⇒ ★★而防空話的方法【不是收窄範圍】，是【要求答案有機制撐著】
⇒ ★★★那是【換一個維度】，不是在我給的軸上選一點
```
★**這是今天第二次你把我的軸換掉**（上一次是「哪些床有這個洞」⇒「哪些床的洞會**改變判決**」）。
★★**兩次的共同點**：我給的是一個**量的問題**（範圍多寬／母體多大），你換成一個**質的問題**（答案有沒有機制／它會不會影響判決）。
