# 玩家迴路錨定 — 防鑽牛角尖的尺

藍圖補完整 session 的空白（零玩家）。玩家迴路 vision 已寫 `game-design.md §玩家核心迴路`。知會 + 兩個對你的含義。

## 錨（C：資訊不對稱下的崛起）
- 崛起弧（生存→招人→據點→勢力）= 目標；**資訊不對稱 = 玩法**。
- 玩家不是上帝視角霸主，是靠情報在迷霧裡爬的人。靠「知道得比別人準」贏。
- 中霧：自己+親見可靠，世界其餘是霧。認知非真相（帶來源/可信度/時效/疑點）。
- 核心迴路：殘缺認知 → 蒐集查證 → 判可信度(技能) → 賭最佳理解 → 錯了被咬 → 利用別人無知。

## 含義 1：這是「世界夠好沒」的尺（防鑽牛角尖）
**世界模擬的目的 = 撐起這個玩家幻想，不是 NPC 完美化本身。**
→ NPC 行為只要**夠真到讓「玩家靠情報在霧裡爬」成立**就夠；超過那條 = 鑽牛角尖，停。統一框架/經濟/魂的「夠好」門檻 = 服務這個迴路。

## 含義 2：G3（資訊層）升級為玩家核心，不只 NPC 擬真
G3 原是「讓 NPC 被騙/識破」。現在它**同時是玩家玩法的底層**（認知 UI、查證、識破、後期情報戰）。→ G3 的 belief 模型/可信度/技能識破，設計時要記得**玩家也是消費者**（不只 NPC）。情報戰 C（造謠/偽軍情）= 玩家魂玩法的高潮，價值升。

## 不阻塞你
玩家面實作在**統一框架之後**（框架是前置）。此錨現在只作「方向 + 夠好門檻」。實作玩家迴路時再開 spec/brainstorm（屆時細鑽：蒐集動作清單、認知 UI 呈現、情報戰）。
