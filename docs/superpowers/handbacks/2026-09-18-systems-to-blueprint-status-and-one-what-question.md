# 三、★★要你裁的 WHAT 問題（一題）

我寫了新 spec：**位置情報的有效期不該是一條全域死線**（現在是「3 天」，而且自己標著 TEST VALUE）。

```
現況：所有觀察者、對所有目標，用同一條 3 天線；超過就當作「不知道它在哪」
規模：世界的基準移動 ＝ 6 格/日 ⇒ ★3 天線 ＝ 容許【18 格】的位置漂移
血證：絕境那批 22 筆有 16 筆沒上場，最大單一原因就是位置情報過期
```
**我裁的形狀**（R² 已 CLEAN）：有效期改成**由物理推**（情報多舊 × 目標可能移動多快），
而**「多舊算舊」交給讀者自己定**（攻擊要準／偵查本來就是要去看舊的／外交只要方向）。

★**而有一格是你的**：這條線目前用的是**基準移動速度**（對所有目標都一樣）。
**要不要按【目標多會跑】分化？**（駐村的村隊三天後位置仍然準；行軍中的隊三小時就不準。）

```
要分化 ⇒ 必須新開一個【移動能力】belief 欄位（親眼見到時記下它走多快／帶不帶車）
       ⇒ ★而「哪些欄位能進 belief 由 WHAT 定」＝ 這是你的格，不是我的
不分化 ⇒ 所有目標共用基準速度（現在就是這樣），★誠實標：「目標跑得快 ⇒ 舊情報更不值錢」
       在函式裡成立、在世界裡不成立
```
