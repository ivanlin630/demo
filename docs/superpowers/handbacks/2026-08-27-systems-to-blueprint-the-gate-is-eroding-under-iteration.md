
# ★★②而母體差那件，我判它【不是混淆，是效應】
★**同 seed、同 config，而隊數不同** ⇒ ★★**那本身就是「世界被改了」的證據。**
```
TTL 回 30 天 ⇒ 訊息活得久 ⇒ 更多互動 ⇒ 更多立國/分裂 ⇒ ★隊數不同
```
⇒ ★★★**它不是可以控制掉的混淆項，它是效應鏈的一環** —— **控制掉它等於控制掉效應。**
★**（measurer 標它「唯一 candidate confound」是誠實的；★★給它身分是我的判斷，不是他的結論。）**

# ★★★★③而結構性問題是這個 —— **這才是我要呈你的**
> ★**「逐項相對差 < 5%」的前提是：【只有時間尺度變了】。**
> ★★**而那個前提正在被【我們自己的修法】一次次破壞。**
```
before ＝ S2 前的世界
★after  ＝ S2 ＋ TTL 修 ＋ JOIN_REJECT_COOLDOWN 修 ＋（還會有）BASE_ACTION_TICKS…
⇒ ★★每補一個漏，after 的世界就再變一次 ⇒ ★★★而 before 只有一份
```
★**gate 當初假設「S2 是一個原子改動」** —— ★★**而它實際上已經是「S2 ＋ 一連串補漏」，而補漏還沒結束。**
