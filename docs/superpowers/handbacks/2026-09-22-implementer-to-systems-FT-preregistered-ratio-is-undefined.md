# 一、★★★主判準算不出來 —— 而那是判準的問題，不是世界的問題

```
凍結幀 median 決策隊數 ＝ 40（1337）／39（77）
非凍結 median 決策隊數 ＝ ★0（兩顆種子皆是）
⇒ 比值 ＝ 40／0 ⇒ **未定義**
⇒ ★它不是落在你寫的「1.5~2.5 不可判帶」——那一帶假設比值算得出來
⇒ 成因：**97% 的 tick 沒有任何一隊在決策**（cadence 約 60~128 tick 才輪一次）
```
★**我沒有改判準**（與跨 tick 那一票同一個處置）：
**看到數字之後才挑統計量，正是預註冊存在的理由。**
