# A2 補正：食物消耗也在污染面（漏綁，補上）

補 `timewave-five-rulings` A2。用戶戳出：×5→1 改的不只行軍補給，**食物「生產÷消耗」整個比例都在污染速度下校的**。我 A2 只綁「補給+gen」，漏了消耗重校。補。

## 污染面完整盤（食物三率，改速度全受影響）
```
① 生產  tile regen/harvest        每天長多少糧
② 消耗  FOOD_PER_PERSON(×5下 2.4→0.8 手校) 每人每天吃多少
③ 行軍額外  走一格 48→240tick=同段路吃 5× 糧  =餓死潮源
+ food/fatigue ÷24 手校痕（補償快移動塞的）
= 全是「×5 快世界下手動調到不崩」的值 → ×1 慢 5× → 假設全錯 → 必重校
```

## A2 綁四件（非三件，修正）
```
A2 = ×5→1
   + 沿途補給（③行軍解：覓食/raid搶糧/買糧）
   + ★FOOD 消耗重校（②：×5 下手校的 0.8 + ÷24 痕 必重驗）
   + gen 承載力重校（①÷②比例配新時間節奏）
四件一個 landing,缺一=餓死潮 or 爆倉
```

## ④ 糧帳 measure 擴成「完整食物收支重驗」（一次量清，不逐個猜）
```
量（×1 下、A1 骨架後）：
  駐紮隊：生產①/消耗②/淨值 → 承載力對不對(餓死潮? 爆倉?)
  行軍隊：行軍額外消耗③/沿途補給/淨值 → 走遠路撐幾格
  + 揪出所有手校值(0.8/÷24/其他)哪些 ×1 下假設錯
產出「×1 食物收支表」→ 據表重校 ②+gen(①)+定補給③,一次校對
```
= 走裁定分兩層：measure 揭真帳、我裁補給機制+承載力目標、系統校值。**不憑推理綁數值。**

## 藍圖自檢（連上一條升格）
上輪剛立「凡速度/尺度變更,先問下游哪些量隱含舊值」——**這次自己第一個違反**（A2 漏掉食物消耗）。用戶又補了我一個。→ 強化該紀律：**速度/尺度變更時,列出「所有隱含該尺度的下游量」成清單再改**，食物收支表就是移動速度的下游清單。這清單化該進 checklist（同時間常數污染防線）。
