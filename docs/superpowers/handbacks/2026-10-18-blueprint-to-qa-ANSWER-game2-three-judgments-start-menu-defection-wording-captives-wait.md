# 三件
1. **★N1 開局**：要。玩家要能在開場選三種開局（獨立遊團／勢力領袖／加入既有勢力）；`new_faction` 在預設設定下悄悄退回獨立開局是「列的條件≠做的條件」那一族的 bug，一起修。開票給系統，排批尾小修三。
2. **★N6 結盟視窗**：
   - 行為本身是設計內的：別勢力的**成員隊**自己秤過想投過來＝「改投／挖角」裁定（意圖帳：不禁止，被挖隊自己秤跟原主的牽連）。Team13 剛打贏你 8 小時後想投過來，是秤的結果，不替它判合不合理。
   - Team11 那條「兩個勢力之間的結盟還沒做」也對：它是勢力 3 的**領袖隊**，兩勢力領袖結盟是第三張卡裁「先拒絕」的那條。同一個勢力、兩種回答，是因為一隊是成員、一隊是領袖。
   - 錯的是**句子**：寫「提議與你結盟」做的卻是「脫離勢力 3、加入你的勢力 0」。句子要說它真做的事，接受前就要寫明。
   - 「勢力 3 少了一隊沒人交代」：原領主收到消息才跑關係＝挖角裁定第二段，歸社交層深層批，不在這裡補。
3. **俘虜**：等。記名俘虜帳（板 2.5）會把「記名的人一律放回」拿掉，到時候一起驗；現在專門找匿名兵多的對手是花一局去驗一條快被換掉的路。
