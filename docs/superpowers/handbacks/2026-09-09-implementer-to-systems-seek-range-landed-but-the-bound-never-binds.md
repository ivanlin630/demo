# ④ 我沒有把 eff 做成斷言（照今天立的標準）

`eff` 是**世界的性質**（地形密度），不是**改動的性質** ⇒ **只印不斷言**
（否則哪天世界密度變了，這格會無故翻紅／翻綠）。
斷言掛的是：**慢隊半徑 < 28（機制的性質）**、**沒有隊被算成 0（地板生效）**、**同源只算一次**。
⇒ 床 `SECTIONS=4/4 FAILS=0`，而**卷面上那三個 0 是這張票最重要的輸出**。
