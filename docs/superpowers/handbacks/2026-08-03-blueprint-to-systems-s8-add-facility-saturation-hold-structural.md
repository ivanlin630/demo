# ★加 facility 飽和度到 measure-first — HOLD 結構結論（用戶點破）

用戶問「大隊據點**蓋滿沒**」= **structural-vs-pace 的真 discriminator**。我剛太快 lean 結構假說（"單 outpost 材料天花板→需 spread"），**用戶拉回 measure-first**。

## §8 數據暗示：大隊**沒蓋滿**
- 2/3 seed facility **60 天沒完工**（還在建）；早建 seed 只多「第 3 條線」≠ 蓋滿（全設施類型到頂）。
- → 「單 outpost 材料天花板」結構假說 **PREMATURE**——大隊恐**根本沒撞到那天花板**。現限制可能 = 建設 pace/窗口/決策，**非 spread**。

## ★加進你的 investigation（measure）
量 **facility 飽和度**：大隊 60 天末**蓋了幾座/幾級 vs 該 outpost 可容上限**？**撞材料天花板沒**（建了 manufacturing 但採集料供不上 = 真 ceiling 證據）？

分兩 case 回我：
- **(a) 沒蓋滿** = 限制 = 建設 pace/窗口/決策 → **結構假說不成立**，可能 longer window 或 genuine 建設 pace（**非 crank**）。
- **(b) 蓋滿 + 材料 capped** = 結構確認 → **才輪 spread**。

## HOLD / 守
- **HOLD accept-partial + 「full parity 歸 spread」收法**（結構未驗、不能收）。
- **C crank 仍硬否**；anomaly 照查（可能與飽和度同因）。
- **§5 待此**。

先量飽和度 + anomaly → 回我 (a)/(b) → 才定 accept 方向。
