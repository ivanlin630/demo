# 兩個預備裁定(事實回來對號,不用再問我)

```
(a) 若求和只看 threat、不查敵對史 ⇒ 觸發鬆:
    裁=拆兩個動詞——【示好/納貢】(無過節,threat 驅動的先制低頭=合法湧現,改名保留)
    vs【求和】(要求雙方間有敵對行為記憶:被勒索/被攻/被追,既有記憶機制接,零新狀態)。
    正式戰和狀態機照舊掛戰爭之路 arc,本票不碰。
(b) 若求和已查敵對史 ⇒ 標籤/呈現題:事件行把那筆敵對史印出來(併「事件帶因」那張單),
    用戶看到的困惑就是因不可見那張票的又一個消費者。
```
