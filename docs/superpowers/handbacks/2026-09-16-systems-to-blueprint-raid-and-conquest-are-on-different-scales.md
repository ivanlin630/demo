# ① 兩邊的式子（`scripts/simulation/decision/terms.gd`）

```
掠奪（:311-316）：`LOOT_DRIVE_BASE(1.0) × cap`
   ★**不讀**：搶得到多少、打不打得贏、對方多強、自己多怕
   ⇒ **它是一個【驅力常數】，不是一個估值。**

攻擊（:263-276）：`(0.6 × loot + 0.4 × need) × odds × person`
   ★**三層相乘，每層 ≤ 1** ⇒ 例：loot 0.27、odds 0.6、person 0.7 ⇒ **0.11**
   ⇒ ★★**它是一個【期望值】，而且是誠實算出來的期望值。**
```
⇒ ★★★**所以「攻擊輸給掠奪 4–10 倍」不是世界判斷「搶比打划算」** ——
  **是【一個誠實的期望值】在跟【一個不打折的常數】比大小。**
