# 完整沙盒願景定稿（知會，對齊終點）

藍圖×用戶願景討論定稿。落 `game-design.md`「完整沙盒願景」段。**知會你對齊終點**——燒地基時照這張圖，缺料回頭補。無待辦，除一條升不變量（見下）。

## 一句靈魂 + 設定
- **五代十國亂世 / 1-2 代尺度 / 沙盒優先玩家最後貼**。
- **「軍事易得，正統難守，傳承更難。」** = 那時代的戲、也是現在最缺的一半。

## 七維度 + 五底線（現況分界）
- **在飛**：經濟✓/征服(差capture)/資訊 + AI深度 + 統一架構 + per-tick。
- **未開大塊**：4 正統宗教文化 / 5 關係聯姻 / 6 繼承爭位性別 / 7 天災 / 敘事可見 / 玩家面。
- 靈魂組 = 4/5/6（正統/聯姻/繼承），接既有 belief/Pattern B/受控人力/RelationGraph，**非新爐灶**。

## ★ 一條升硬不變量（該納 invariants）
**per-tick 成本早晚期無延遲差 = 硬不變量**（玩家會直接感受；perf 倒推出 1-2 代尺度）。推論：
- 世界大小**全程有界**（就算 1-2 代內累積也要 bound）。
- **die-off erase spike 從「另案」升為必收**——正是「大戲時刻（滅團潮）最會爆」那個，直接違反此不變量。長跑滅團潮量到 freeze 前該修。
- 請納 invariants.md（per-tick 有界）+ die-off spike 重排（不再純 backlog）。

## 燒序方向（大方向，非鎖死你的 HOW 序）
```
現在: 燒完統一矩陣(1/2/3+單寫者/互動) = 地基
  → 正統宗教文化(接G3) → 關係聯姻(RelationGraph接線)
  → 繼承爭位性別(1-2代鉸鏈) → 天災(危機引擎,可早插便宜加戲)
  → 敘事可見(讓戲看得到) → 玩家面(最後薄鏡頭) ‖ 地理/河流(征服深做時)
```
