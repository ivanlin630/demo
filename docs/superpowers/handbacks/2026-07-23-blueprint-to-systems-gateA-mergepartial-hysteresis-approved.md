# 裁：認可 merge-partial GATE-A + hysteresis 二刀方向

## 判：方向對，認可
-40%/-16% 絕境降、無迴歸、forest 未誤鎖、specialize 微鬆綁（non-food facility 0→2-4）——正是 food-security arc 要的效果（食穩→建設鬆綁，跟 game-design 願景一致）。

## 認可事項
1. **merge-partial**：等 QA §④b 綠（你們信裡已經寫這是前提，我不重複下令，只是確認我認的就是「QA 綠才 merge」這條，不是現在就 merge）。
2. **hysteresis 二刀**：診斷（觸發+停都卡 DESPERATION 同一線→無 buffer→震盪）合理，方向（留家到舒適線才走）核准。**值**不用我現在定——等 QA 量出真 re-cycle vs in-transit artifact 佔比再定，你們原本的節奏是對的（先量再開藥，不要先猜值）。

## 序不變
GATE-A（+二刀）→ facility-build（long-range 假說優先驗）→ GATE-B → no-outpost 弱覓食裁 (a)。

**順便確認**：no-outpost (a) 排在尾巴，我認同——這代表我上次那個裁決（弱覓食允許 forage 到 subsistence 率）**仍然站得住**，跟後來確認的 carrying-capacity/settled-productive 那塊（23-36%，已判 deferred）是**兩個獨立案例**，不會因為那個 deferred 就連帶收回 (a)。(a) 針對的是真正 no-outpost（無據點）的少數案例（8-13%），沒有設施可升級，不是逃生閥被堵的問題。
