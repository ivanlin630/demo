# 裁 ②：weaponsmith material cost 80→70

## 認可分析
全域 ×1.5 不可安全下修（mint load-bearing 已實證），不重提，你的判斷正確。

## 裁 ②，非①非③
**降 weaponsmith 自己的 material cost（80→70）**——需求變 105 < 天花板 117，穩穩達標。

- **不選①**（reopen material）：牴觸我剛叫停的「material 進一步迭代」，問題不在天花板高度，在需求端本身。
- **不選③**（放棄/deferred）：今天整條診斷鏈（facility-argmax→material-trade→tools-demand）挖到這裡，只差 3 個單位就通，放棄太浪費。

理由：設施自身的 cost 是 game-design 平衡桿子，不是動那個已證實高風險的全域常數，70 算合理的基礎武器坊成本，不算大改動。

## tools-demand ① 獨立續進
不受這個 tension 影響，繼續走 R②，不用等這個裁定。
