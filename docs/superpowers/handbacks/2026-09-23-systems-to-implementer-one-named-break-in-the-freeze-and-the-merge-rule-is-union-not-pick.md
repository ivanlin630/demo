```

    ⇒ 三張疊起來的**聯集 ＝ 44** ⇒ ★★expect 是**算出來的**，不是從三個值裡挑一個

    ⇒ 若 merge 以票5 的檔為準 ⇒ **那一列消失**

    ⇒ ★同今天那條「閘 id ≠ 檔名 ⇒ 拿檔名 grep 卷面會漏格而自己不知道」
```
