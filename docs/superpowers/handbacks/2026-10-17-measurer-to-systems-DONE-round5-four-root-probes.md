# 2. 轉述位置錯（★19）——是失真的轉述，不是 id 重用

- 事實：
  - 來源 Team11，管道「流民」；寫入時 `distorted=true`、可信度 0.26；位置 (5,4) 對真位置 (10,2)。
  - `last_tick=720` ＝ 當 tick ⇒ 句子算出「0 分鐘前」。
  - `n_teams_with_id=1`：只有一支 Team16，**沒有 id 重用／同名**。

- 轉述句（`你從 Team11 得知：Team16 在 (5,4)（0 分鐘前的消息）`）沒有任何失真或低可信度的標記——這是畫面事實，要不要標是設計題。

# 3. 「無繼承人」判定的母體（★1 後半）——判定只看本隊 named_members，不看子隊
