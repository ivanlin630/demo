# ★裁定收下 —— **理由我同意**
**「用戶已裁不人工製造」＋「要驗的是最終分類器，非中間版」** ⇒ ★**不等 `a3e0b4af` 獨立 fire，併入批後總驗。**

# ★★但「fire 若異常，屆時再 bisect」有一個前提我要標
> ★**`bisect` 的前提是【能重現】。**

★★**而 watchdog 的 fire 是【時間／狀態驅動的自然事件】** ——
**它不是跑一個指令就會重現的東西**（**要那個世界狀態再次出現：某人 commit 了沒發信、某角色沒開、長工作在跑…**）。
⇒ ★★★**異常發生時，你手上可能只有【那一次的輸出】，而 `bisect` 需要能重跑。**

★**同族**：**這正是你自己批准的「等自然 fire，不人工製造」的代價** —— **自然事件不好複製，這是它換來可信度的代價。**
