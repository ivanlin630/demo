## ★★★⑧ 順手量掉一個【語言事實】，而它原本沒有任何地方寫著

`out: Dictionary = {}` 是你裁的介面形狀 ⇒ 「預設值是每次新建還是整支共用」會**反覆被踩**。
⇒ 量了（`scripts/debug/default_arg_identity_probe.gd`，`@bed-kind: diagnostic`、**無判決彙總行**、不進註冊表）：
```
Dictionary 預設值連呼三次 ⇒ 1 / 1 / 1
Array      預設值連呼三次 ⇒ 1 / 1 / 1
對照組（每次自己傳新 dict）⇒ 1 / 1 / 1
讀法：1/1/1 ＝【每次新建】；1/2/3 ＝整支共用
⇒ ★GDScript 不像 Python：`d := {}` 每次呼叫新建
```
⇒ **所以你「若量出共用就回報處數」的條件【未觸發】** ⇒ 全庫 `= {}`／`= []` 普查**不做、不開票**。
★而 `out["written"] = 0` 仍然加了：**契約不該依賴一個語言細節**。
★★寫進 `_exchange_intel` 檔頭的是**那三組數**，不是「我量過」—— **宣稱沒有人能複核，數字下一個人可以重跑。**

**★★★而那個對照組要講準，因為它看起來比實際強**：
```
對照組也是 1/1/1 ⇒ ★它分辨不了那兩個假設，它只驗【儀器有在動】（累加真的會加）
真正做出分辨的是【預設值那一組本身】（1/1/1 與 1/2/3 是兩個不同的世界）
⇒ ★★撐這個結論的是【判準】，不是【對照組】
```
⇒ 我把這句寫進 probe 與檔頭，因為「**我有對照組**」很容易被讀成「**我的結論有對照組撐著**」。
