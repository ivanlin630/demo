# 一、要你裁的一句

**NPC 主動說「要向你進貢」而玩家接受之後，那個 NPC 對玩家的感覺應該是什麼？**

# 二、★為什麼這是一個問題（R② 查到的，我核過）

```
轉帳那支既有函式（`diplomatic_ai_system.gd:244 apply_tribute_accept`）在 `:254-258`
會寫一筆 NPC 記憶 `"tributed"`；而 `npc_ai_system.gd:117` 把 `"tributed"` 歸在
**betrayal／looted／special_taxed／rejected_aid** 同一組 ⇒ 走 **`form_feud`（結仇邊）**。
★而它原本的語境是**兩個強制情境**：`demand_tribute`（遠程索貢）與 `resolve_extortion`（同格勒索）。
⇒ ★★直接重用在**NPC 主動送禮**上 ⇒ 語意變成
  「**NPC 主動示好，而這個動作本身讓它對玩家結仇**」⇒ **方向是反的**。
★★★嚴重度也量過：`FEUD_SEVERITY` 刻意不收 `"tributed"`、用 intensity（≈0.1）當嚴重度、
  `FEUD_MIN = 0.30` ⇒ **多半不會跨門檻**，★但**人格乘子極端時還是可能**
  ⇒ 那時玩家會看到「**剛送我東西的 NPC 突然對我有仇恨值**」。
```

# 三、★我已經裁掉的那一半（HOW，所以我不丟給你）

```
**accept 路徑只重用「轉帳」那一半，不連帶寫那筆記憶。**
理由：**同一支函式同時做「轉帳」與「寫關係」，而那兩件事的方向在不同情境下不同**
⇒ 一個函式承擔了兩個語意 ⇒ 重用它 ＝ 把**強制情境**的關係語意**偷渡**到**自願情境**。
★而它是**不表態的安全底**：零關係寫入 ⇒ 不會製造一個反方向的效果。
```

# 四、★★所以要你裁的只剩一句：**要不要【正面】寫一筆**

```
(甲)【現在就是這樣】**不寫** —— NPC 送了貢，而它對玩家的感覺**不變**
   ⇒ 便宜、不會錯，★但「主動送禮」這件事在關係帳上**沒有任何痕跡**
(乙)**寫一筆正面的** —— `npc_ai_system.gd:126-128` 已有
   `kindness／aided_in_battle／benefactor` 走 **gratitude** 的形狀可以參考
   ⇒ ★語意上更對（它主動示好 ⇒ 它對玩家的好感／期待應該有痕跡）
   ⇒ ★★而要你定的是**強度與方向的意思**：它是「我對你示好」還是「我在買保險」？
     （後者在世界觀上可能**不該**加好感 —— 而那正是我不能替你裁的部分）
```

★**而它不擋本票**：裁定甲已經讓本票可以做完；乙 可以日後作為一個**刻意的 WHAT 決定**加上去。
★★而本票會加一格地板（＋它的反向走法）把這件事釘住：
**accept 之後 `"tributed"` 類記憶 ＝ 0 筆**，★而**`demand_tribute` 那條路必須寫得出它**
—— 否則那個 0 分不出「accept 不寫」與「**那個記憶機制整個壞了**」。
