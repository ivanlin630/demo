# 裁：coin liquidity WHAT = de-patch extraction gate（need-driven）

## ① 認可 root = illiquidity 非 shortage
守恆坐實：coin 在 anon_treasury 取不回，**非世界沒 coin**。confirm。

## ★② 我兩假說皆 refuted——老實收
- **① mil-loot→anon_treasury**：假說**原型不成立**（conquest-loot 零事件、機制沒 fire）。
- **② civ-dealflow/GATE-B**：真但比 salary **小一個數量級** = 次要。
- ∴ **GATE-B 非 coin 引擎**，維持排後獨立——我上封「GATE-B 可能重框成 coin 引擎」的 hypothesis **也 refuted**，收。這輪我一個裁決裡押了兩個假說、兩個都被 measure 打回。**教訓不是別假說（假說便宜），是 measure 才是真、never spec on 未量假說**——新 R① 正是強制這個，這次又救了。

## ★③ WHAT 裁：fix 方向 = de-patch extraction gate（非 tune）
**root = extraction gate `greed-prudence×0.5 > 0.4`（`faction_ai:2365`）結構性排除中位人格**（greed .5/prud .5 = 0.25 < 0.4 → 永不 extract → coin 永鎖）。

**fix 方向 = de-patch，不是把 0.4 調低**（那是 tune 壞閘 = band-aid）：
- **extraction 決策應 need-driven（utility 秤）**：隊有 spendable coin 的**真用途**（想建設 / 買糧 / 買料 afford）→ extract 回 spendable。
- **人格當 texture**：貪婪領袖 extract 更 aggressive + 留少 buffer；慎重領袖 extract 夠用 + 留厚 buffer——但**都會 extract**（差在量與 buffer），不是中位人格結構性零 extract。
- **三線交會**：本場整條 arc（flat 常數 gate → 交 utility/need 湧現）+ 憲法「utility 餵 utility 非 scripted」+ **死常數人格化**（0.4 這死常數排除中位人格 → 人格化成 need-weighed 決策）。這是 de-patch，跟這場其他補丁閘同一治法。

## ④ salary rate 本身非 fix
coin **沒丟**（salary → 隊自己 anon_treasury），是**鎖在 illiquid pool 取不回**——降 salary 只少轉一點進去，**鎖住的還是鎖住**，治症不治根。fix 標的 = **liquidity（extract gate）非 salary rate**。salary drain vs income 你要再精算就 measure，但別把降 salary 當 fix。

## ★⑤ 一個 WHAT-relevant 前置問（決定 HOW 難度）
`_consider_extraction` 現在**讀不讀得到 need signal**（coin-need / build-need）？
- **若既有 need 基建**（食 urgency / material need 那套）**有 coin-need 分量** → 直接 wire extraction 到它。
- **若無** → 那是 **means-end 延伸**（extraction target 由「我要花 coin 做 X」推導）= 可能接上今天已做的 material means-end 架構（設施慾望→resource need 那套，延伸到 coin）。
- 這決定是「簡單 rewire」還是「補 need 基建」，你 scope。

## ⑥ texture 守護（de-patch 別 overswing）
de-patch 後**別 swing 到「always extract all」**——prudent 領袖要留 buffer（extract = 補到夠用 + 人格 margin，**非清空 treasury**）。flat 排除 → need-driven，但保留人格對 buffer 厚度的 texture。

## ⑦ R① 第 4 擋
你兩 coin-cause（其實是我兩假說）measure 前沒 spec = 對，**兩個都次要、salary/illiquidity 才是**，救了兩個白 spec（尤其 mil-loot 那個機制根本沒 fire，spec 下去純浪費）。R① 第 4 個攔截，這次一次擋兩個。
