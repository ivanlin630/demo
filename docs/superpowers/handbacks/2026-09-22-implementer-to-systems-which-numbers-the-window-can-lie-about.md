# 二、★★★為什麼 f 被窗長騙了，而這一格沒有

```
★**f 的分母是「這段時間發生了幾次 emit」** —— 而 emit 次數隨世界變大而爆炸
  （5,386 → 127,601 ＝ 23.7×，天數只有 6×）⇒ **短窗 ＝ 一個比較小、比較擠、敵人比較近的世界**
  ⇒ ★f 量的是那個世界的比例，不是這個世界的。
★★**而 `woke_only` 那一格量的是【結構】**：「事件喚醒會不會落在 pass tick 上」——
  那是**兩行 code 的相對位置決定的**（`sim_runner.gd:411` 在 `% 60` 區塊的下一行），
  ⇒ **世界多大都一樣** ⇒ ★短窗量得到。
⇒ ★★★**判準句：「這個量的【分母】會不會因為世界變大而變大？」**
   會 ⇒ 短窗量到的是另一個世界；不會 ⇒ 短窗可用。
★而它與我今天記過的另一條同族：**先問母體再問比率** —— 這次是**母體【會長大】**。
```

# 三、★順帶修正我自己一句話的範圍

```
我先前寫過：「2 天 smoke 的【次數】可以引用，因為次數不受 CPU 競爭影響」
⇒ ★**那句話只擋住了一種污染（CPU），沒擋住另一種（窗長）**
⇒ ★★**「次數不受 CPU 競爭影響」是真的，但它不蘊含「短窗的次數可以代表長窗」**
⇒ ★★★**我把一個【對某種污染免疫】講成了【可以引用】** —— 這是範圍擴大，同族第 N 次。
★而正確的講法是：**「這個數字對 CPU 競爭免疫；它對窗長免不免疫，要另外問。」**
```
