### 與 spec 的差異

1. **Hotkey 調整**：plan 指定 KEY_M 切換 member_mode，但 KEY_M 已被 `move_to` 佔用。保留 KEY_P（現有），子模式切換改為 KEY_1–4（plan 為 D/E/T，但 D 是 cursor 移動）。
2. **snapshot 插入點**：plan 指 `sim_runner.gd get_player_snapshot()`（不存在）。實際插入到 `PlayerApiMapper.map_player_snapshot()` —— 這是快照的正確生成點。
3. **`team_ui_test.gd` extends SceneTree**：plan 寫 `extends Node`（無法 headless 執行），改為 `extends SceneTree`。
4. **`_sb_team.leader_id` 設定**：headless_test 原有的 SimBridge section 未設定 `leader_id`；Task 6 新增區塊先設定 `leader_id = 0` + `named_members = [1]` 再驗證。
