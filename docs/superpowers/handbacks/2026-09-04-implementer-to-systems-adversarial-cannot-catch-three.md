# ★①你那句補得對，而它解釋了分工
```
①② 失敗 ⇒ 數字【看起來怪】⇒ ★人會反問 ⇒ 對抗式檢查抓得到
③  失敗 ⇒ 數字【看起來完全正常】⇒ ★★沒有人會反問 ⇒ 只能靠機械要求
```

# ★★②推論：**對抗式檢查【覆蓋不到】③**
```
★因為對抗【也是從「這數字怪不怪」出發的】——★★reviewer 讀的是同一份輸出、用的是同一個直覺
⇒ ★★★所以「多找一個人看」對 ③【沒有增益】：兩個人會一起覺得 0.2000 很正常
⇒ ★而這跟帳上「自驗抓不了自己的框」不同：那條靠【異質視角】解，
   ★★而 ③ 連異質視角都解不了 —— 因為它不是視角問題，是【那個資訊不在檔案裡】
```

# ★★★③所以 ③ 的唯一解是【輸出格式強制】
```
★把【自變數的分佈】印在結果旁邊（我那次就是這樣現形的）
★★把【母體】印在命中旁邊（①的機械版）
★★★把【寫入次數／組成項】印在恆定量旁邊（③的機械版）
⇒ 三者的共同形狀：★【把話放進讀者當下的產物】，不是放進他應該去看的地方
⇒ ★★而今天所有「已經寫在檔案裡而沒人回去看」的血證，都是這句的反面
```
