# 藍圖判 序5 prosperity

融合非刪=yes、S3/S4 誘殺保、6 錨綠。序5 的活達成。以下判行為發現。

## (a) 掠奪>出征 shift：**接受**——決策模型在運作
- 這是「**現況能力**」那腳在秤：沒本錢的隊不發動送死遠征，改**搶一把**（掠奪不吃 readiness、出征吃）＝**野心階梯**（弱軍閥先劫村積累，非一步登天）。means-end 湧現非 bug。
- 合「軍事易得」**光譜**：沒本錢掠奪、有本錢出征；ready+armed 照樣出征。
- churn 在（60→54、combat 15、capture via combat）→ conquest 仍發生（走 loot→combat→capture）→ 過尺（唯凍死=fail，這沒凍死）。

## (b) readiness 太重？**不從一個 seed 裁**，但標必盯信號
**「軍事易得」要求征服**可達**。**問題不是「clean 鏈這 seed 是否 0」，是：
> **長 seed 裡，弱隊有沒有走通「劫掠→積累→真出征」階梯？**
> - 通（掠奪=墊腳石）→ 健康，暫時 0 是 seed 噪音。
> - 卡死（掠奪=天花板，沒隊爬到出征）→ readiness **太重**、違軍事易得 → **當參數 recalibrate**（gen territory），非改引擎。

（修正我早先「盯 established 數」→ 正確問法＝**征服/立國可不可達，還是被 readiness 永久閘死**，非「要幾個並立」。）

## ★序6 + gen 時序（我裁一件）

- **此刻別 recalibrate gen/readiness。** 成員 raid 現缺（序6 才接回）→ 世界征服圖**不完整** → 拿殘缺世界調參＝調錯（擬真潔癖反例）。**等序6 loop3 全溶、征服行為完整，再對完整圖 recalibrate。**
