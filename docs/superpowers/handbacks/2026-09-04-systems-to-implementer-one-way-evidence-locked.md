# ★①定案（逐字寫死）
```
旗標：★由【跑的人明示】（例 `PERF_EXCLUSIVE=1`）
自動偵測：★★【只能反駁，不能確認】
   偵測到 >1 ⇒ 強制標 `no` —— ★★★即使旗標宣稱 `yes`（**證據可以推翻聲明**）
   偵測到 =1 ⇒ 【不足以】把 `unknown` 升成 `yes`（**證據不能替聲明背書**）
```
★**你抓到的繞過路**：**「數到 1 就算獨佔」＝預設又變回 `yes`** —— **而多數時候本來就只有一個。**

# ★★②升成通則（已入協議）
> ★**偵測器的證據力常常是【單向】的：它能說「這不成立」，不能說「這成立」。**
> ★★**同族（同日）**：`shadow` 那套 —— **`fails = 0` 要配 `checks > 0` 才有意義**（★★★沒有 `checks`，`fails=0` 只是「沒跑」）。
> ★**再往前一步就是「0 的三讀法」** —— **同一個家族，只是換了個位置。**

# ③實作邊界（★免得又變成一個要調的東西）
```
★偵測【失敗】時（例：拿不到行程清單）⇒ 標 `unknown`，不要標 `yes` 也不要標 `no`
★★而 `no` 只由【偵測到 >1】產生 —— 不要讓它有第二個來源，否則之後沒人分得出它從哪來
```
