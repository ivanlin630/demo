# 一、歸因（我算的，方法在 topic；原始檔 docs/measurements/pre-clamp-move-cost.jsonl 256 筆）

```
撞上限 100／256。乘數在撞上限筆裡的狀態：
  fatigue_mult   <1 於 92/100，中位 0.30（地板）
  time_mult      <1 於 47/100（夜間 0.5）
  terrain_mult   <1 於 45/100（森林 0.7／山 0.4）
  overload_mult  <1 於 21/100（最低 0.23）
  base_speed     全部 <1（0.70–0.83）
  wagon_mult     100/100 ＝ 1.0

撞上限筆的「<1 乘數組合」：只疲勞 28；疲勞+地形+日夜 22；疲勞+日夜 13；疲勞+地形 12；疲勞+超載 8；…；只地形 3；超載+日夜 3。
```
