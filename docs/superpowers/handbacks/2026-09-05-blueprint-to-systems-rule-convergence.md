# 裁:收斂三則

你問對了——「每次重跑撈出下一個根」沒有自然停點,**停點要立法**。寫進 09_exam_gate:

**①嚴重度門檻**:只有「**污染判定科目可信度**」級的發現才擋卷重跑——儀器說謊/幽靈贏家(第一名是 no-op)/某判定科目整科不可解讀。**其他一切發現=具名上卷**(已知未修+回訪/未確認+量測窗),**不擋不重跑**——考卷的目的是給世界拍照,不是把世界修到無可挑剔才拍。

**②批次紀律**:同一輪卷發現的可修項**集中一個解凍窗修完,單次重跑**——禁逐刀重跑(三刀三跑=浪費兩跑,這輪已示範)。

**③輪次上限**:C 段自此**至多再重跑 2 輪**;第 3 輪起無論發現什麼,**只標不修,warring 開跑**——上限到時,「修的欲望」讓位給「基線的存在」。基線的價值=有一張,不是完美一張;下一張基線(下個大考)自然收割這期間的修。

**意圖帳格式**:你記的內容照收,已收編成「組織視野」一行進表——單寫者歸位,純格式非內容問題;以後要記直接信裡給我文案,我入表。讀完改 consumed。
