# emergence multi-seed：混合結果 + tune 前提變了（呈報，非自作主張）

measurer multi-seed（8 seed×4 月，N=127 settled 隊）——你委「弱則 tune 人格權重」，但**tune 的前提變了**，呈報你裁。

## 數字
- **★好戰→軍事 outpost 強烈坐實**：military 隊好戰均值 **0.80 vs 非 military 0.44（Δ+0.36）**、野心同向（Δ+0.24）。**真 emergence。**
- **貪婪→工坊 不成立且反向**：manu 隊貪婪 0.42 vs 非 manu 0.50（Δ**-0.085**）；野心 Δ-0.060（n=10 偏小）。
- **慎重→farming 幾乎零**（Δ-0.018）。

## ★系統分析（mechanism-first：2/3 弱 = 框架 need-first 設計的可預期後果，非 tuning 漏）
1. **farming 零相關 = 正確**：S2 survival-crush（食急迫）**刻意讓餓隊 farming 主導**（食安地基願景）→ 人人餓了都建農，慎重 term（1+0.3×值≈±0.15）被量級輾壓。**這正是我們設計要的**——食安不該因人格打折。
2. **workshop 弱/反向**：workshop 由 **deficit（goods/tools 缺）主導**（缺什麼建什麼），貪婪 term（±0.2×值≈±0.1）微弱被 deficit×terrain 蓋。反向可能是**貪婪 leader → 貿易/掠奪（roam）而非 settle 建廠** → 工坊實由 settled need-driven 隊建 → **leader_pref「工坊=貪婪 0.2」映射本身可疑**。
3. **好戰→軍事 work 因軍事 discretionary**：weaponsmith 只在 `_threat_recent` 才建（need-gated），且好戰 pref 0.4 較強 → 受威脅的好戰隊在同級選項間人格勝出。**討 discretionary 設施人格才顯。**

## ★呈報：盲 tune 有風險（前提變了）
你委「弱則 tune 人格權重」假設「弱=權重太小，調大即可」。但實測顯示**弱是 need 主導（正確），非權重漏**：
- 調大 farming 慎重 / workshop 貪婪 → **打架 need-correctness**（慎重 leader 食安夠仍過度建農？非貪婪 leader goods 缺卻不建工坊？）→ **可能傷剛拿下的供給側成功**（need-driven build-what-you-lack 是供給破的機制）。
- 且「工坊=貪婪」trait 映射可疑（貪婪像 → 商/掠奪非工匠）→ 調大錯映射只放大噪音。

## ★觸 WHAT（你裁，非我地盤）
- **願景 archetype 模型**：「工匠」對應哪個 trait？（現 leader_pref 工坊=貪婪 0.2 似錯映射）「農夫」該人格驅動、還是 need 驅動就好（食安本就人人要）？
- **多強 personality-driven vs need-driven**？好戰→軍事已達成 discretionary 人格分化；farming/workshop need-driven 是否**已符願景**（食安地基+建你所缺，人格是 texture 非 override）？

## systems 建議
- **傾向接受現狀**：好戰→軍事=真 emergence；farming/workshop need-driven=架構正確（供給破的機制），非 bug。人格在 discretionary 設施顯、在 survival/need 設施讓位=**合理分層**。
- 若你要更顯的工匠/農夫分化：給 archetype trait 映射（工匠=?）+ 想要強度 → systems mild-tune（只在同級 need 打平時人格破 tie，不 override need）+ re-measure。**但認知這與 need-correctness 有張力。**
