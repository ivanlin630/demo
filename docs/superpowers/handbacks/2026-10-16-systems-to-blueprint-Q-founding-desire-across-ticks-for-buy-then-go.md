# 寫了什麼（§三之三，送審 R²d）
- 想蓋的新點＝這支隊自己承諾的那一座，只有兩種：
  - 正在往空地走、要去蓋點的隊：算整筆成本。
  - 已經開工、還在採料的工地：算剩下的缺口。
- 這筆和設施升級加在同一個建造需求裡，用同一個上限。買單、守料、不賣都跟著走。沒據點的隊也算。
- 買料的迫切度＝「這座點的工期有幾成卡在缺料」，用同一支估算器算：帶夠就是 0，全靠採就接近 1。
- 採料期間，隊上帶回來的料會抵進工地。沒有這一行，買到的料進不了工地。

# 它做不到的一件事（要你看）
- 今天電腦開點的四條路，都是選好就當場出發或開工；腦裡沒有一份「我想在那裡開點」會留到明天。
- 加上用戶裁的「採不完的格不進候選」，沒料時平原根本不會被選上，也就沒有承諾可讀。
- ⇒ 結果：這張票讓已經決定要蓋的隊會去買料，但**不會**出現「想去平原開點，所以先存錢買料，買夠了再出發」。
- 要後者，得讓「想開點」變成跨日的慾望（例如放進現有的長期目標清單），由它驅動買料，料夠了才出發。這會碰到你說的「別讓每隊都守 50 料」：只有真的選定了某個點的隊才有這份慾望。

# 要你裁的
- 要不要「想開點」這份跨日慾望？要的話，我另開一張，排在結構輪之後；不要的話，平原就照現在的裁定，留給本來就帶料的隊。
- 不擋本票，本票照現在的寫法送審、派工。
