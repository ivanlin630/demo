# 敗北模型願景裁定（藍圖 owner）

## 1. 殲滅-heavy = 塌陷，非世界本該如此
- 違背 game-design line 1130 敗北模型（損耗/俘虜/潰散＝同模型三端）。塌成殲滅-only = 三端只剩一端 = **degradation**。
- **現實檢驗**：2 人隊掉 1 = 50% 傷亡在一擊 → 現實上他們**逃/散**，不是打到剩 1。絕對殲滅線 ≤1 對小隊**不現實**。
- ∴ 判：**bug/塌陷**。小隊該有逃生/潰散出路。

## 2. 敗北三端配比意圖（我 owner 定）
- **潰散/逃 = 劣勢方常態**（尤其小隊，能散能逃）——服務絕境願景（弱隊倖存→絕境階梯）+ 現實。
- **俘虜 = 中頻**（逃不掉但沒被殺）。
- **殲滅 = 稀**（只在**逃不掉**：被圍/無退路/或狂者憑膽量血戰到死）。
- **不消滅殲滅**——保留「逃不掉才死」，別矯枉過正變成人人不死。

## 3. 藥方向 = (a)，但做成憲法版（關鍵）
**(a) 敗北出路前置**：逃/潰散/投降決策**在絕對殲滅線之前 fire**——但**不是硬寫「小隊必逃」**，是：
- **逃 vs 戰是引擎/人格決策**（膽量：勇者血戰、怯者早逃＝**正是照妖鏡 #1 的 courage 門檻**）。
- 現在的病 = 絕對殲滅線 **pre-empt 掉這決策**（隊還沒機會決定逃就死了）。
- **修 = 讓引擎的逃/潰散決策有機會在殲滅線前觸發** → 照妖鏡 #1 的膽量門檻**自動啟動**（勇者撐、怯者逃）。**一石多鳥**：敗北模型復活 + 照妖鏡 #1 開始 fire + 絕境 flight 湧現。
- **這是憲法一致的 (a)**：不硬塞逃生，是給「引擎的逃決策」優先於「機械殲滅線」。**seam 你定**（如殲滅線只在 FLEE/rout 決策已評估且選了戰、或無退路時才套用）。

## (c) consolidation 腿 = 記，非本 slice
- 你的跨切信號對：combat 都在小隊間 ← 隊不整併（merge food-blind，A2c-1）維持小 pop。隊變大 → combat 有長度撐到三端。
- 但 (c) 是**另一條腿**（大隊也該能潰退，不只靠變大）→ **記為 consolidation arc 的絕境腿**，非此 slice。(a) 先修，直接給小隊逃生窗。
