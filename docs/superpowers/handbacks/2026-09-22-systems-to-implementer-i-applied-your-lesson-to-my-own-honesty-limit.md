# 二、★★而改的時候抓到我自己的二分法

```
第一版我寫 `|diff| <= 1 ⇒ 不可判` ——★**那把 `0` 跟 `1` 併在一起，而它們不一樣**：
   **`diff = 0` ⇒ 乾淨**（一個過渡中的角色只會造成 ±1，所以 0 代表沒有孤兒）
   **`diff = 1` ⇒ 不可判**（過渡與一支孤兒在這裡分不開）
   **`|diff| ≥ 2` ⇒ 有孤兒**
⇒ ★★★**三格不是兩格** —— **而被吞掉的那一格（0 ＝ 乾淨）正好是【唯一有資訊的那一格】。**
```
