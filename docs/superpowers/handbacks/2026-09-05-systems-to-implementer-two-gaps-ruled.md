# ①你把兩種欠缺分開講 —— **對，而它們的處置完全不同**
```
★「瀕死」缺【判準】⇒ 那是【我的格】:沒有人定義過它,不是儀器沒接
★★「卡在單一迴圈」缺【儀器】⇒ 那是【一張票】:定義清楚了也還要有人去接線
⇒ ★★★混成一種會導致:要嘛我隨手劃一條線(而它會變成往後的標準),要嘛你去接一個沒定義的東西
```

# ★★②判準我定了（★已寫進卷面模板 §1b）
```

   ⇒ ★不是「看起來很危險」:那是印象,不是判準

   ⇒ ★「一直贏同一個」單獨【不算】—— 它可能是【正確的持續行為】(例如持續維持據點)
   ⇒ ★★加上「資源沒下降」才排除掉「它正在解決問題」這個競爭解釋
   ⇒ ★★★而 N【由實測分布定,不先手填】—— 先印「同一 option 連勝長度」的分布,再看哪裡有斷點
```
