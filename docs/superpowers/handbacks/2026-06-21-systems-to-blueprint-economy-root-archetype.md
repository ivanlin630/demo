# 經濟真根 = 目標錨矛盾，不是市集模型。要你裁 tag-vs-人格

**取代 `economy-depth`（status: superseded）**。那封的「撲空 92% / 市集模型 A/B」框架經完整生命週期 trace **推翻**。先道歉繞路——我中途憑零散探針下了兩次錯結論。這封是拿到**硬 trace 後的定論**。

## 真根（商隊全生命週期 trace，硬證據）
T1「友軍商隊」2 年 23 個任務轉換點，關鍵段：
```
d0  被派 貿易(prio50) → 出發去市集
d2  貿易 → 建設            ← 貿易被「建設」蓋掉
d3  又派 貿易 → d4 又被 建設 蓋
d8  人在 T0 的市集(4,4)、arb_empty=FALSE(有單可做)、task=生產  ← 走到了、有生意、卻在生產不交易！
d11~ 在家 建設/生產，糧倉漲到 1605→1994
```
**貿易任務每 ~2 天被 建設/生產 搶走 → 商隊震盪 → 永遠走不完一趟完整貿易。** d8 是鐵證：商隊**真的走到別人市集、真的有 arb**，但當下在「生產」→ 交易擦身而過。

| 系統 | 依據 | 命令 T1 |

## 要你裁（WHAT：「商隊」由 tag-角色定義，還是人格定義）
- **(a) tag 硬鎖**：商隊 tag → 強制 `ARCHETYPE_TRADE`，人格不覆寫。T1 目標錨變貿易，衝突消失，商隊以貿易為業。
  - 優：直接治本、商隊真會貿易、世界看得到跑單幫。缺：人格與職業可脫節（貪婪低的人也當稱職商隊頭）。
- **(b) tag 偏置**：商隊 tag 給貪婪軸加權（如 +0.3），但極端人格仍可翻。T1 這種中庸人格會被推成 TRADE，真正非商人格（高義氣低貪婪極端）仍可能偏定居。
  - 優：擬真、tag 與人格協商。缺：要調 bias 權重、邊界 case 仍可能矛盾、較難預測。
- 我（系統）傾向 **(a)**（最直接破矛盾、商隊就該以貿易為業；config 已用 tag 宣告意圖）。但這碰「職業 vs 人格」的世界觀，是你 WHAT。
