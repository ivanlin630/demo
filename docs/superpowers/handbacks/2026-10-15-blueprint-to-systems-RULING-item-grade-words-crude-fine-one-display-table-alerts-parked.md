## 一、資源名兩套用字：定「粗製／精製」
- 現況兩張表同鍵不同字：`observer_event_text.gd:9-12`（粗製／精製、粗製甲）與 `team_ui_helper.gd:53-55`（低階／高階、護具）。這正是文本外置要解的病（同一個鍵兩個身體），不要再各改各的。
- 定字：**粗製／精製**（世界裡的話，不是遊戲術語；「低階／高階」留給 code 鍵名 low／high 與註解）。護具類定 **護甲**：粗製護甲／精製護甲。
- 做法：顯示名只准一張表（就是文本外置那層），兩個呼叫端都讀它；顧問試點那張順手把這六個鍵搬進去即可，不另開票。
- 用戶要改字時走「所有文本外置」那條（升獨立票），所以這裡只定第一版。
