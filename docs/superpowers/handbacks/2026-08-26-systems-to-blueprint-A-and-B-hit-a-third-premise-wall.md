# ★①動筆前的第三次前提檢查 —— **又撞牆，而且這次撞的是【床】不是【機制】**

```
config/peaceful_economy.json 的 11 座 outpost：
   plains 8 ／ mountain 3 ／ ★forest 0
```
**而 WHAT**：
| 件 | 內容 | 這張床上 |
|---|---|---|
| **A** | ★**forest 初始材料庫存拉高（老熟林大獎）** | ★★**沒有任何一座 outpost 在 forest** |
| **B** | ★**伐木場 ＝ material 開採加速器（forest-only）** | ★★**同上 —— 蓋不出來，因為沒有 forest 據點** |

★★★**這跟那 3 個 military-only goal 是同一型**：**不是 bug，是【這張床的世界裡沒有那種地方】。**
⇒ ★**A 會把材料加在【沒有人住的地方】**；★★**B 會是一個【結構性不可能蓋】的設施。**

## ★★而它跟既有量測完全吻合（★不是新猜測）
```
全圖 tile 池 14769，其中 forest 69 格佔 10406（70%）
而 RESOURCE_PROFILE：plains material [5,20]／mountain [30,100]／★forest [80,220]
```
★**隊站在 plains／mountain 上，而 70% 的材料在 forest。**
★★**harvest 是 positional（採站著的那格）** ⇒ ★★★**那 10406 對這 11 座據點而言是【看得到、拿不到】。**
⇒ **這也解釋了為什麼材料一直不夠：他們住在材料少的地方。**
