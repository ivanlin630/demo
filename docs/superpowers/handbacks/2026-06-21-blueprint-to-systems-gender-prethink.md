# 性別 WHAT（預想，範圍 a：資料 + 生育，不建 Trait 相容機器）

藍圖預想。**澄清定位**：性別是 ④Trait 縫的**第一筆資料**，但它**不示範 Trait 縫的「相容性修正」機器**（那等文化/宗教 content）。性別主效果是**人口機制**（生育），走的不是態度/情報/限制三通道。本預想 = 純「加性別資料 + 修無性別繁衍」。

## 好性質：獨立、不卡框架
生育是**自動人口過程**（reaction BREED_BASE_CHANCE），**非 team 決策** → **不經統一決策框架** → 這條是**獨立小改，隨時可做**（不必等框架，不像 Trait 縫本體）。

## 1. 資料
- `PersonData` 加 `sex`（male/female）—— named 個體。
- anon **cohort/team 帶性別比**（每 cohort 或 team-level 男女 ratio）= HOW（資料結構你定）。
- 生成（world-gen / cohort / named）出生 ≈ 均衡，後續被事件（戰爭）扭斜。

## 2. 生育改成「需兩性」
- 現：無性別 cohort roll（單一性別也繁衍 = 不擬真）。
- 新：**成長率受兩性平衡限制**（如 ∝ min(男,女) 或按 balance 縮放；嚴/軟 = TEST VALUE）。
- **emergent 後果（這才是價值）**：
  - **全男戰幫 → 內部不繁衍**，只能招募/吸收成長（war band 人口不可持續）。
  - **戰爭殺光男丁 → 人口無法恢復 → 人口崩**（真實的人口傷疤）。
  - **定居有家庭的隊 → 自然成長**。
  - 接敗北模型：戰損(多在戰鬥 cohort)扭斜存活性別比 → 戰爭耗竭打仗那性別 → 恢復更難。

## 3. 範圍邊界（OUT / 等別的 content）
性別有趣的效果**全卡別系統，本預想不做**，只**埋資料**等它們來讀：
- **禁女性參戰 / 性別戰鬥角色** → 法律/習俗 content（④ 後）。
- **世襲/繼承 父系/母系** → Graph 血緣圖/家族樹（死亡繼承，卡血緣）。
- **性別社會角色/態度** → 文化/身份 content（④ 後）。
- 多元性別 → 不做。

## 4. 驗收方向
- 均衡 pop 成長、單一性別隊**內部 0 繁衍**（靠招募）、戰爭扭斜性別比 → 恢復變慢。
- anon cohort 性別維度不破既有 cohort/pop 守恆。
- 數值（平衡嚴/軟）= TEST VALUE。

## 5. 定位提醒
這是 ④Trait 縫的**前置資料**，**不是** Trait 縫本體。Trait 縫的相容機器（態度/情報/限制 + 框架輸入）等文化/宗教那種 content + 統一框架。性別此階只管「有這個欄位 + 生育要兩性」。
