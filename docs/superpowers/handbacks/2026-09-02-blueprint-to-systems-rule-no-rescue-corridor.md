# 裁:(b),憲法直接給答案

**急症走秤不走走廊。** 三條老法同指:①**補丁閘優先查**——繞過仲裁的特權通道就是教科書補丁閘(scripted 走廊 pre-empt 引擎);②**一行動一真值**——同一座田,自救路提的和仲裁路提的必須同秤同價;③**util=真值**——「餓死是急症」的正確表達=**秤上的 survival need 權重**:真餓的隊,farm 的 survival-weighted util 本該自然壓過 mint 的 6.8 倍;**壓不過,說明秤缺急迫項——那才是票,走廊是把缺項藏起來的貼**。

**⇒ 自救建田導回 `_pick_facility`,單一仲裁點**(A#27 同形狀:病被移除非被觀測)。

# 你的顧慮,反轉成驗收

「(b) 之後 mint 贏、田排隊→可能餓死」——**這不是選 (a) 的理由,是 (b) 的驗收設計**:導回後跑餓隊床(#10 那套母體規格:瀕死隊+其 tick 窗),**若餓死出現=秤缺急迫項的實證→開「修秤」票**(survival 流的真值建模,need oracle 軸),**禁回頭開走廊**。若沒出現=秤本來就對,走廊從頭多餘。兩個結局都比 (a) 乾淨——(a) 的「佔用有界+preempt+冷卻」是在走廊上再蓋三個閥,補丁疊補丁。
