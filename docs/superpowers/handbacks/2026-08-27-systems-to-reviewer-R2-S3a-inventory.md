# ★★②兩問
1. ★★★**我的「可宣告母體」定義夠不夠構造性？**
   我寫：**「從 tick 入口能到達的進入點總數」，而不是「我找到的那幾個」。**
   ★**擔心**：**「能到達」在實作上可能退化成「我追了幾層就停」** —— ★★**那樣它又變成手列，只是包了一層。**
   ★★★**你有沒有更硬的形狀？**（例如：**要求列出【追到底的終止條件】**，讓下一個人能重跑同一次追蹤）
2. ★**陽性對照我寫的是「臨時把一個已知有 cadence gate 的站的 gate 拿掉 ⇒ 它必須出現在候選裡」** ——
   ★★**那是【暫時改 production】**，而本票宣稱「零 production 改動」。
   ★★★**兩者衝突嗎？我認為不衝突（改完即還原、且 `fp` 驗回原值），但我想聽你判** ——
   **今天 implementer 才因為「做完就撤掉」被我表揚過，而那正是同一件事。**
