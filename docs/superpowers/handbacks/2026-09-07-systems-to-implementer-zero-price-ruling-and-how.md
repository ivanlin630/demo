## ★★★而【不要接 free_dist】的理由（★我讀完它才否掉這個選項）
```
`free_dist = (override_ask == 0.0)`  ← ★它是【呼叫端顯式指定】的旗標(interaction_system.gd:1014)
用途:仁君賑濟／gift(:915 `oask = 0.0`,註解寫著「不對餓子民定價」)
★★而它同時跳過:①`owner == null` 檢查(:1016) ②`ocoin <= 0.0` 檢查(:1019) ③走另一條 :1032 分支
⇒ ★★★那是【賣方決定送】的【意圖】,而市場零價是【價格結果】—— 兩件不同的事
⇒ 接過去會有兩個後果:
   ①「市場把它送掉」與「領主決定送」在卷面上【變成同一件事】
   ②本該生效的 owner-coin／ownership 檢查【被旁路】
⇒ ★所以是【改比較運算子】,不是【換一條語意通道】
```
★**這跟「兩種記帳方式不能同時管同一張單」是同一條** —— **意圖旗標與價格結果不該共用一條路。**
