# ① 陰性對照（在 HEAD 的暫時樹上把接線弄壞，`BED_DAYS=1`）

弄壞方式（落在修法真正改變行為的區間）：
  c.material_need_total = 80.0     ← 分母換回固定常數
  c.home_restock_min    = 10.0     ← 門檻換回固定常數
```

|---|---|---|
| `restock_min_from_burn_bed` | **紅** `FAILS=1` | ★**該紅那格**：跨隊門檻 `min=10 median=10 max=10 相異值 1` |
| `material_shortfall_scale_bed` | **紅** `FAILS=1` | ★**紅錯格**：④（`_msf > 1` 的隊 4）紅了，而 **②「跨隊 _msf 有變異」照樣綠（相異 12）** |

# ② ★★所以弱點不在窗長，在我那格測錯東西

★**固定分母 80 之下，`_msf` 照樣有 12 個相異值** —— 因為**分子（缺口）本來就跨隊變異**。
⇒ ★★**我那格量的是「世界有變異」，不是「分母是逐隊的」** ——
而後者才是這張票改的東西。**這正是你說的：相異數是代理量。**

**已改**（`fc4565bf`）：②改成斷言**分母本身**跨隊變異 —— 陰性對照重跑：
```
壞掉的樹  分母 material_need_total 相異值 1  ⇒ ②紅（＋④紅）  FAILS=2
工作樹    分母 material_need_total 相異值 2  ⇒ ②綠            FAILS=0
```

# ③ ★★★而真正該回報你的數：**窗長對這一格完全沒有影響**

```
BED_DAYS=1   母體 15 隊｜_msf 相異 12｜★分母相異 2
BED_DAYS=2   母體 16 隊｜_msf 相異 14｜★分母相異 2

⇒ ★**我上一封拿來當降窗理由的那兩個數（母體、_msf 相異）確實是代理量**，
★★**而真正有鑑別力的那一格（分母相異）在三種窗長下【完全相同】** ——
**窗長從來不是這支床的弱點，它買到的只是時間。**

⇒ **降窗成立**：陰性對照在 1 天窗紅、且紅在該紅那格（補強後）。

# ⑤ ★一件我沒有掩蓋的薄弱處

**分母相異值 ＝ 2**（不是 12、不是 10）。**這格是【險過】的**：
它只需要世界裡有兩種 `need_keep(material)` 值就會綠。
⇒ ★**這代表 `need_keep(material)` 在這個 scenario 裡只生得出兩種值** ——
可能是 construction need 撞到 CAP、或設施組合單一。
★★**我沒有去查那是為什麼**（超出本票），但**它是一個值得看的訊號**：
如果真實需求只有兩種形狀，那「逐隊分母」買到的差異也就只有兩級。
⇒ 要不要開票查，你裁。
