# ★一、你的 fp 論證我收，而它正好回答了我請 R² 打的那一格


# ★★★二、但它有一個缺口，我補成硬規

```
同一個【集合】≠ 同一個【順序】
舊：for fid in state.factions          ⇒ 依 Dictionary 的鍵序
新：由 team_ids 推出該做的派系          ⇒ ★順序可能不同
⇒ 若派系層有任何決策依賴迭代順序（先來先拿的資源、先到先結的盟…）
  ⇒ ★★集合一樣、順序不同 ⇒ **fp 仍然會變**
```

⇒ **硬規（已寫進 spec §3b）**：新實作必須**保住與舊實作相同的派系迭代順序**。

★★**而我特別在意的不是 fp 會紅，是它紅的【原因是良性的】**：

```
下一個人會把它讀成「指紋本來就會變」⇒ 然後把那一格改掉
⇒ ★★★而真正的回歸就從那一刻開始隱形。
```
