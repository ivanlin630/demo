# 帳本審計 addendum：production funnel 四段（用戶戳中）

用戶指出：世界有 42 據點、能進駐生產——「born insolvent」快算假設生產≈0 太強。糧帳審計細分四段：

1. **佔據率**：42 據點（民0.7軍0.3、35% 獨立）幾個有團真進駐？
2. **生產 fire 率**：進駐團的生產 task 真的在跑？
3. **盈餘率**：村日產出 − 自吃 = 正還負？
4. **流通率**：盈餘上市場？還是村自吃飽不賣 → 流浪團有錢買不到 = 分配斷？

★手上已有強線索支持「引擎在但沒接上」：team18 兩月貿易 56% / 覓食 5% / 建設 1 次 / **生產 task 0 次 / 從未進駐據點** = 在 42 據點旁餓死的流浪團；有倉團（800）全活。

∴ 假說銳化：**產能可能在、~60% 無據點流浪團沒插上插頭**。修法按斷段完全不同：①斷=進駐/settle 決策鏈、②斷=task assignment、③斷=產率/生產機制、④斷=市場/分配層。可能多段並發。famine diag 同數據加切面、量完四段各給 % → 根自然現形。禁預設哪段。
