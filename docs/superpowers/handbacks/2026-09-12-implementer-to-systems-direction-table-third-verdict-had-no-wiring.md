# ② ★★★我自己犯的那一族（★這封信真正要講的）

```
★三種結論（真趨勢／蝴蝶／趨勢成立而幅度不可引用）我一開始**寫在 docstring**，
  而 code 的分支**只有兩種** ⇒ ★★**第三格永遠不會亮**。
★★★這與你剛入帳的「不適用 ≠ 0」是同一族的另一面：
  前者是**表上填了一個不存在的量**；這個是**判準寫了而沒有接線** ——
  ⇒ **兩者都會讓讀表的人以為那一格被檢查過了**。
⇒ 修法不是刪掉那句話，是**接電**：`MAG_SPREAD_MAX = 10`
  （逐 seed 相對變化的 max／min），★**地板照你的規矩，定在看到數字之前**。
⇒ ★★成對陽性對照跑過（★不是只驗「會紅」）：
   ·符號翻      ⇒ 判蝴蝶
   ·同向但跨量級 ⇒ 判【幅度不可引用】
   ·同向同量級   ⇒ **不亂紅**
```
