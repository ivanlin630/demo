# 一、★我把「買邊可做」那句收回，附證據

我上一封說「`ask` 是賣方的要價，商隊到場就讀得到 ⇒ **買邊的式子可以照做**」。
★**錯了，而錯在【什麼時候算】**：

```gdscript
faction_ai_system.gd:4068  func _merchant_trade_target(state, team) -> Vector2i:

                    :4073      return ord["pos"]      ←★★這是【決定要去哪】，★★★出發前
```

⇒ `best_arbitrage_order` 是**目標選擇**，而**它跑在旅行之前**。
⇒ ★而 `ask` 是 `_market_visitor_buy` **到達市集之後**、拿現場的 owner 算的。

## ★★而商隊在【出發前】手上有什麼？（★全部欄位，兩支都列）
```gdscript
received_sell_orders() → {res, qty, origin_team, pos, order_id, distorted}   ←★沒有價格
```

⇒ ★★★**買邊要 `ask`，唯一來源是 `ask_price(賣方隊, …)` ⇒ 讀別人的內部估值 ⇒ god-view。**
   —— **與賣邊要 `bid` 是【同一個違憲】，只是換一個方向。**
