# #1 經濟：機制做完了，但世界幾乎不貿易 — 可能要動架構

## 進度
#1 plan-1 **履約結算** merged（`186e433`），headless 全綠。**但**真世界量測（world_sim 2 年）揭：履約 code 正確，**貿易迴路本身幾乎不跑** → 履約率 0%。我 measure-first 挖了數據，**結構縫比預期深，可能要改經濟架構**，先給你 WHAT 取向再動。

## 數據（world_sim 2 年，含臨時診斷，已還原）
- 訂單 infra 正常：`order_placed=4297`、`shortage_buy=3140`（隊一直在發買賣單）。
- archetype 正常：商業 archetype 穩定 2-3 隊（**非**之前猜的「零商隊」）。
- `best_arbitrage_order` 常回非空（**有單可挑**）。
- **但 `[Market] 成交` 整 2 年只 5 次**、`套利命中=0`、`order_fulfilled=0`。

→ 訂單發得出、商隊也存在、套利單也找得到，**就是極少真的碰面成交**。

## 真因（多因夾殺，數據定位，非 archetype 調參能解）
貿易要成 = 商隊**走到對方那格 co-locate** 才觸發 market。三道結構縫一起卡死它：

1. **是「商業 archetype」的隊，都卡在永遠不會去貿易的角色**：
   - faction **leader** 隊 → 跑勢力級 AI，不走 member 貿易派工。
   - **獨立**商隊 → 覓食/生存壓力分數蓋過貿易（小隊先顧吃）。
   - **子團** → 走子團評估，不派貿易。
   - 唯一「faction member 商隊」→ 被派成 SETTLE，且 faction goal 鏈（外交/攻擊）在貿易判斷**之前**就攔截。
2. **co-location 機率極低**：商隊朝「訂單發出時的位置」走，但下單隊早移走 → 到場撲空 → 2 年 5 次成交。
3. 那 5 次成交也沒對上訂單 res/方向 → 履約 0。

## 為何這是「架構」不是「bug」
現模型 = **漫遊商隊物理走到對方格才成交**。這在「隊一直在動 + 位置情報是舊副本」的世界裡，**結構性難成局**。修一兩個分數權重治標，根上是「貿易靠物理碰面」這個架構假設與「大家都在移動」衝突。

## 要你的 WHAT 取向（這影響經濟怎麼「運作/感覺」，是你的域）
三條路，feel 差很大，請你選方向（HOW 細節我做）：

**A. 留漫遊商隊、補結構**（最貼現有 feel）
- 商隊變「專職貿易角色」（貿易隊不被覓食/faction goal 搶走、會主動巡迴買賣點）+ 到場撲空改善（追最後已知位置/設常駐市集格）。
- feel：商隊是世界上看得見的跑單幫，玩家能攔截/護衛/打劫商隊。**最有戲、最 emergent**，但最多工、co-location 仍是機率。

**B. 加「市集/據點」當固定交易節點**（半抽象）
- 訂單匯到 outpost/市集 tile，隊去**固定點**交易（非追移動目標）→ co-location 機率大升。
- feel：經濟繞據點轉（像真實集市），據點價值↑。中等工，較穩。

**C. 抽象區域市場結算**（最省、最不 emergent）
- 同區域內訂單週期性自動撮合結算（不需物理碰面）。
- feel：貿易「就發生了」，看不到商隊跑。**最穩定點亮經濟**，但失去商隊 emergent / 玩家干預貿易的戲。

## 我的傾向（HOW 視角，供參，你定 WHAT）
**B**：co-location 難題的根在「追移動目標」，市集固定點直接解；保留物理貿易/玩家干預空間（商隊仍走去市集，可被攔），不像 C 全抽象掉戲。但若你要「跑單幫商隊」是核心 feel → A；若經濟只是背景、要它別空轉就好 → C。
