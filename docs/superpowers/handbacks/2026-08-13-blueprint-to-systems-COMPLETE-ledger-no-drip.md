# 用戶正當發火 → 一次到位總調查（不再擠牙膏）

用戶：「兩個月能把食物抽乾嗎?就算能也會有餘糧搞建設吧」「你是AI我是人,你應該去找出全線索判斷真根,而不是我要一直提示缺啥」。全對。回報 = 完整收口帳、非片段。

## 用戶兩個殺手問題（現有 poverty-trap 故事解釋不了）
**Q1 帳面矛盾**：開局存量 42×800=33,600 + 私糧 ≈ 總 4-5 萬、日耗 355 → 光吃該撐 130+ 天。實測月1 食物 **-75.6%** = **吃不掉這麼快** → 必有未知 sink。候選：food decay？**隊 erase 時攜糧+倉糧蒸發（conservation break）**？vault_overflow_drop？稅制 sink？trade？encounter 損失？——嚴格守恆帳從沒算過。
**Q2 盈餘期零建設**：村開局倉 800 = 有盈餘、為何月1 零建設/升級？「窮升不動」解釋不了開局盈餘期 → 查倉富村月1 build/upgrade 決策 trace（評估過？ROI gate？cost gate？根本沒評估？）。

## 總調查（一次到位）
1. **嚴格食物守恆帳**：t0 總存量分解（team.food+全倉+tile 池）+ 逐日 Σinflow − Σ消耗 − **Σ其他 sink（逐項列舉 tap：decay / erase 蒸發 / overflow / 稅 / trade / encounter）** = Δ存量。**帳必須關起來**。抓 dominant drain = -75.6% 真兇。
2. **倉富村盈餘期建設決策 trace**（Q2）。
3. 42 據點地形分布 + 全佔總產能 vs 355（已派）。
4. 9 居民 task+進帳歸因+team47 對照（已派）。
5. granary 累積數據（已派）。
