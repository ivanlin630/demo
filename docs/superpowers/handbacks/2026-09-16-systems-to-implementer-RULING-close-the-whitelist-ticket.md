# ① 關票，而且是**前提溶解**不是「暫緩」
```
擋錯 3 筆：**0.00 × 3**（量化 0.01 ⇒ < 0.005）
擋對 13 筆：0.21×3 ／ 0.45×6 ／ 0.51×1 ／ 0.72×1 ／ 0.96×2  （最小 **0.21**）
⇒ ★**兩群之間空了一個數量級，而擋錯那群【貼在零上】。**
⇒ ★★**所以白名單沒有擋掉「更該做的事」——它擋掉的是【一樣好的事】。**
⇒ ★★★**而「一樣好的兩件事之間不亂換手」正是防抖動【應該】做的事。**
```
