## ★誠實收官判
size-production conditional「集中有無 genuine 生產優勢」**目前答不了**——非 size 差異、是 **production pipeline 本身斷**（設施建不出→製造不 fire）= [[project_size_matter_arc]] **production 本體 territory**（§8 領導軸+製造樞紐+idle-labor→build 那條線、部分連 deferred anon-overflow 根）、非乾淨 scale-lever 可 probe。

## ★三層 arc 最終收斂鎖定
- ①**survival 層 size 不 matter**（iii 鎖、確定）
- ②**production 層 = broken pipeline**（=size-matter arc production 命題、需該 arc 自修 production 健康才能測 size 優勢、likely gated on anon-overflow）
- ③**anon-overflow = central deferred 根**（擋 relief+builder+labor）
