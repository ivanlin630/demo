# ★HOLD L1「直掃」做法 — 用戶否定 bypass、要「資訊永遠傳播」

## 用戶否定
用戶**否定** intra-faction direct-scan bypass（我上一封 ratify 的做法）。**用戶原則：資訊永遠傳播**——不開特例後門給領主；饑荒消息**經 belief/carrier 系統擴散傳到領主**，領主**依 belief 行動**。

## 更正感知鐵律解讀
- **我原 ratify**（intra-faction 直接 perceive = 合法 bypass）→ **錯方向**。
- **正解**：**資訊 always 傳播（擴散、不 dead-end）+ 帶延遲/decay**（遠/敵 = 舊/模糊）→ **戰爭迷霧靠延遲衰減保、非硬擋、也非開特例**。intra-faction 傳播**快、reliably**；cross-faction **慢、decay** → fog 保住。
- 接 `game-design:590` belief 模型（遠方經斥候/逃難者/商旅傳落 belief）。

## L1 修法改向
- **非**領主直掃自家居民（特例後門）。
- **是**修**訊息傳播**：讓居民饑荒**經 belief 傳達領主**（延遲但**不 dead-end**）→ 領主**依 belief 賑濟**。**一個資訊模型、零特例。**
- 執行（送糧 convoy）不變。
