# ★guardrail 收進資訊網 WHAT：info-決策跑人格、禁死常數

用戶命門鐵律：**資訊網所有決策 = 人格秤 util，禁死常數門檻**（照妖鏡「死常數人格化」用到資訊層）。

## 每個 info-決策 = 人格湧現、非常數
- **求援?**：傲村莊硬撐不開口（可能撐到死）/ 務實早求 / 依附·忠信任勢力求 / 孤高自恃不求 = **人格秤**，**非**「runway<X → 自動求救」常數。
- **領主派信使查?**：關切/責任感盯著自家 / 野心擴張疏忽 / 多疑過度監控 = **人格**，**非**「沉默>N tick → 自動派」常數。
- **資訊值不值得知道** = 好奇/謹慎/情報意識人格。
→ **零死常數門檻，傾向從人格湧現。**

## 連饑荒-flee 同理（診斷分類用）
逃不逃 = 人格（勇/固執撐、務實早跑）；絕境逃**已人格化**（照妖鏡#1 done）。∴ 診斷分：居民餓死 = **人格真選擇撐**（罕見、合理、非 bug）vs **根本沒 flee 決策**（bug）。

## HOW 時守
- info-decision util **吃 personality modulate**、非 hardcode threshold。
- **genuine 非 crank**（人格 MODULATE 真 value、非 arbitrary boost 常數——同 [[feedback_genuine_value_not_crank]]）。

仍 **WHAT-first shaping、HOLD build**。地基 KEEP。
