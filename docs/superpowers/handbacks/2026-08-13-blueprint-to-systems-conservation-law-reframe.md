# 根本層 reframe：三條守恆律審計 + 「世界無盈餘引擎」統一假說

用戶要求更根本視角。逐機制 genuine-vs-bug 是機制層；根本層是守恆律。

## 統一假說（待帳本坐實、禁預設）
**饑荒非六症之一，是基底，使其他五症必然。**
快算：全世界糧本 ~2.5-3萬（38% 團有倉 ~1300、餘私糧 250/180）、日燒 444×0.8≈355/天 → **零生產跑道 ~80 天**、多數團 **31 天倒數**。production=broken-pipeline 已是 scale-econ 量測結論（no_facility / farming 五層雞生蛋）→ 這 2 月 = 沒引擎的世界吃老本、準時餓死。
負和世界結構上不可能出：有大有小（累積需盈餘、scale-econ「size 不 matter」同根）/ 戰爭（投資、付不起 readiness）/ 合併（host 無餘糧 82% 拒）/ 立國（全下游）。**分裂力無條件 vs 合併力被盈餘 gate = 單向原子化棘輪。**

## 三審計（measurer 轉向、同數據加切面、不用重跑）
1. **世界糧帳**：總生產/日 vs 總消耗/日逐日曲線（diag bed `daily_curve` `total_food` 已在收！）。一條線判生死：單調下滑 = 世界生成違反生存預算 → 修創世/生產端、非機制。
2. **力平衡**：分裂事件數 vs 成功合併數/月（unrest tap 補後可量）。
3. **時鐘比**：餓死時鐘（私糧 250÷8=31 天）vs 行動完成時鐘（`join.order_set` 有 **dist 樣本**！算 travel time 分布 vs order 時 food_days）→ 若中位 travel ≥ 中位剩糧 = **空間策略結構性完不成** = merge 4.8% / migrant / relief 三症一根。

## blueprint 補血（我的失職我補）
從沒給「健康世界生命體徵」參照系 → 我寫 **vitals spec** 初稿（和平期人口±% / 糧比 / 團規模分布 / 戰國戰死>0），以後 audit 有尺、genuine-vs-bug 有參照。

## 序
measurer 三切面出 → 若坐實資不抵債 → 根修 = **生存經濟基座 arc（生產/盈餘引擎）先於一切故事 arc** → 我帶用戶。地基 KEEP。
