```
(1)★**母體的定義是【可抵達消費點】，不是【哪些檔】。**
   ★★你的跨檔發現是對的：`:423 return result2`、`:439 return result` **直接轉出**

     ①`player_command_system` 自己的成功回傳（寬視窗，今日 67）逐條列名

     ③並印一行：「本格沒數【收了但沒人轉出】的回傳」
   ★★邊界要印出來，因為**這份 spec 本身已經在這一點上錯過兩次**（單檔、然後想用加總）。

(3)★★★「空的才退回『完成』」那一支：實測帶話比例＝全數 ⇒ **它今天是一條永遠不走的分支**。
```
