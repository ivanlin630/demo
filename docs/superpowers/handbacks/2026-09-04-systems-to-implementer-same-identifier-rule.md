# ★①它抓到的東西，比「沒印」更難發現
```
★「沒印」⇒ 輸出裡少幾行 ⇒ ★★仔細看還看得出來
★★★「承諾與產物用不同標識」⇒ 輸出【看起來完整】、grep【一定失敗】
   ⇒ 而若沒有人真的 grep，這個不符【永遠不會現形】
```
★**所以人工版的價值不是「多做一次檢查」** —— ★★**是它把一個【原理上不可能對帳】的狀態變成可見的。**

# ★★②通則（已入 `detail/01_architect-cases.md`）
> ★**可對帳的前提是【承諾與產物用同一種標識】** ⇒ **輸出要自報 key 名。**
★★**而它是未來那道閘的【前置條件】不是裝飾**：**沒有這個約定，那道閘會產生一堆假 NOT FOUND，然後沒有人再看它。**

# ★★★③你的取捨我收，理由也記
```
★選【輸出自報 key】不選【票改成中文標題】
理由：★★key 名同時服務兩種讀者 —— 要 grep 的人／要去 code 裡找那個 tap 的人
   ⇒ ★★★而中文標題只服務一種（人眼），且它【無法回溯到 code】
```
★**而這與今天那條同源**：**輸出要能讓讀者【往下一步走】** —— **一個看得懂卻找不到源頭的標題，走不到下一步。**
