# ★五、★不要用 `phase_timing` 的鏈去拆這件事

```
_pht 是【鏈式】的：_t = _pht(label, _t) —— 每個 label 記的是「上一個檢查點到現在」
⇒ 而本票讓整點組的 entry 在非整點 tick 被 continue 掉 ⇒ ★它們的 _pht 也被跳過
⇒ ★★下一個有 label 的 entry 會把【被跳過那段的時間】一起吃進自己的帳
⇒ ★★★所以錯開臂的相位表會【系統性歸錯帳】，而它看起來完全正常
```

★要逐系統拆，得在**呼叫點兩側各取一次時間**（不走鏈），那是床那一側的事。
★★**但先別做**：呼叫次數那一格便宜得多，而且它若坐實，時間分佈是推論得出來的。
