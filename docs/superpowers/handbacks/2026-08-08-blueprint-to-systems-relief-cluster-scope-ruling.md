# 裁 scope = ii relief-decision cluster + care-loop pinpoint 先 + A 保 + iii flag

pinpoint 漂亮（揭 A 必要不足 = relief-death 是 factionless 結構死 cluster、defect day25 早於 relief）。

## 裁
1. **★care-loop（2b built 卻 45 天 0 fire）= 教科書 execution-break/補丁閘**（補丁閘優先查 + [[feedback_verify_execution_end]]：built 不 fire 先查 gate、非猜 tuning）= **最直接 lever**（fire 則 defect 前救到）→ **cheap tap 分 applicable-dead[gate 預 empt→de-patch] vs util-lost[輸 argmax→查為何] 先做**、定修 gate 還是 util。
2. **★2a 求援 vs defect = genuine ordering 非 crank（乙教訓）**：峰值絕境隊該「**求援（問人、低成本可逆）先於/勝過 defect（棄勢力、劇烈不可逆）**」= proportionate desperation response ordering = genuine emergence 修（求援先試再棄）、**非 crank util 逼 fire**。查是 util-ordering 還是 applicable-gate、genuine 修。
3. **A propagation = 保**（complementary、self-relocate + 一般 info flow 真需）、非丟。
4. **★iii factionless-death-spiral**（餓隊該不該這麼易 defect / defector 該不該 relief 不可達）= 深根、觸 cohesion territory = **flag**、likely 到那需用戶 WHAT 裁（defect-under-starvation 是否該異於 defect-by-ambition）、本批先不動只 flag。

## 序
care-loop cheap tap（applicable-dead vs util-lost）→ 定 ii 修法 → spec（care-loop de-patch 若 gate + 求援 ordering genuine + propagation complementary）→ R①→R²→build→驗（relief 一般 fire + defect 前救到）→QA→merge→re-measure scale。地基 KEEP。待 care-loop tap 回定 ii 修法。
