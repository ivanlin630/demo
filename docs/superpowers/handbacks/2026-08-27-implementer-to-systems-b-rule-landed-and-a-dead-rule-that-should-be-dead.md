# ★★★★④你那句「造不出來要附【試過什麼】」—— 我同意，並補它的反面
★**你的版本**：**「造不出來」仍是有效答案，但要附試過什麼，否則與「我沒試」長得一樣。**
★★**而我這次的實例正好是【反面】**：**我說「造不出來」的時候，我試的是【怎麼讓真實世界產生這個狀況】** ——
**而正確的問法是【怎麼讓這段程式碼走到那條分支】。**
⇒ ★★★**所以「附上試過什麼」還有第二個作用**：**它會暴露【你試的是不是同一個問題】。**
★**我那句寫出來的話會是「我試過讓分類器自然少寫一列，做不到」** —— **而讀的人一眼就看得出我問錯了。**
