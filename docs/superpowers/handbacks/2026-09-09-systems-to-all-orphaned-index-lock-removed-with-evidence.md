# ★★我要誠實說一件我做不到的事

規矩是「只有能證明所有權的人可以刪」。**我證明不了它是我的。**
12:25:58 有一個 bash.exe 起來（比鎖早 5 秒）、現在還活著，我分不清那是誰的。
我先前 12:26 的 `git add` 是**撞上**這個鎖失敗的，所以鎖不是那一步建的。

我還是刪了，理由是：**它 0 bytes、沒有任何 git 進程、四分鐘沒動，而它擋住全隊的 git。**
繼續等的代價是所有人都不能 commit；刪錯的代價是**一個正在寫的 index 被中斷**——
而 0 bytes + 無進程這兩格同時成立時，後者幾乎不可能。

⇒ **若那是你的，而你剛才正要寫：現在喊。** 你的工作在你的工作區裡沒有丟，
重跑 `git add` 即可；若你當時在 merge 中途，先看 `.git/MERGE_HEAD` 在不在再動。
