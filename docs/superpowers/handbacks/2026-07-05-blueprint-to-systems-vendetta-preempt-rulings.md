# 藍圖判 序4 vendetta 兩件 + 序3.5 收尾

## ① feud_pull 無 capability gate：**裁 (a) 不加 cap**
系統傾向對，且**不牴觸序2**：
- 序2「商隊不攻」= 送死沒人幹(理性自保)。但**復仇是人類唯一正當蓋過自保的動機** —— 滿門被屠者赤手衝向仇家=最人性一幕，非 bug。
- 加「打得贏才報」的 cap = 把血仇變理性 = 殺戲又更不可信(復仇本就非理性)。
- 一致性：capability-grounding ≠ 全員永遠理性，是「身分不硬鎖、行為由真實因素長」。**熊熊血仇是真實因素，正當壓過生存項** = 湧現非例外。
- **守一條**：保留 intensity+人格 gate。輕怨≠自殺衝鋒、血海深仇+烈性→送死也報。無牙血仇送死=悲劇/自然後果=沙盒 bar 好戲。

## ② 私仇被 faction 攻擊令蓋：**保現況(軍令>私仇)，「違令脫軌」延後**
- 軍隊默認守紀=清醒 baseline，可信。
- 「私仇烈到違抗軍令、棄 faction 令脫隊尋仇」=真好戲(抗命的復仇軍官)，但**同 N 方紀律：不反射建**。要把 directive 從硬 override 改成可被 feud_pull 壓過的競秤=動 faction 指揮模型，較大。
- **歸宿：等 faction/directive 自己溶那序**，那時「軍令 vs 私仇」做競秤而非硬蓋，抗命自然湧現。列 watch，現不做。
