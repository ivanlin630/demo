# 二、★★而我要標三個【不在那 86 處裡】的風險

```

   —— ★★**而那是這件事真正的工作量**，不是快照本身
②**快照要多深**：`WorldState` 是巨大物件 ⇒ **整份深拷貝每 tick 一次會很貴**

③**互動寫入**：玩家下指令是**寫**，而寫必須落在**真 state** 上、不是快照上
   ⇒ ★**讀走快照、寫走 live** ⇒ **兩條路** ⇒ ★★**那是一個新的一致性面**（玩家看到舊的、卻對新的下指令）
```
