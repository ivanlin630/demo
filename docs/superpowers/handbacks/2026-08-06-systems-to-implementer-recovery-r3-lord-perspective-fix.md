## ★真根（systems 診斷 + blueprint 升級）
`_try_relocate_order:1871` 領主令 gate 用 `relocate_value(subj_est, target_est, sunk=PersistStrength.compute(村))` = 村戀土-weighted →
- (1)領主永不令會抗命的村（低戀土自願遷先走 / 高戀土領主不下令）→ **兩層對抗 dead**；
- (2)★**領主讀村內在戀土 = god-view 後門**（領主哪知村民多戀土=村內心；fix 清一殘留閘、合框架收尾精神）。

## ★fix
領主令改**領主自己視角 genuine util** = `_inflow_est(target) − _inflow_est(current)`（村壞地經濟損失、領主 belief 可見 terrain）+ 整併戰略 benefit − order-cost；**★不減村戀土 sunk**（可含領主 belief 可見的**棄置 outpost 基建損失**=領主自家領土基建、非村內心）；乘領主人格（規劃整併/仁君→高、放任→低）。
- 村保留戀土自秤 obey/resist（`_deliver_relocate_order` 現 `obey=義氣+懼−傲−戀土` **不動**）。
- ★**anti-crank 牙**：領主非被迫下令（被動領主不下=分化）；壞地村領主也可能不下（genuine 差異非全序）；村 genuine（有從有抗）。

- 守：god-view（領主**不讀村 PersistStrength/戀土**；self-relocate 讀自己 sunk 合法）/ 零死常數（領主令 util 真值）/ determinism byte-identical / constitution（現 75、不新增 site）。
- 測試跑**真全 advance_tick pipeline** 驗 `relocate.ordered>0`（領主令真 fire）+ comply/resist 分化（忠村從/傲戀土村抗）+ 怨→叛/起義劇情鏈 + ★**回歸①④未破**（爛地村真遷走+三態）。
- 完成 → handback `to:systems`（R²、merge-gate 核領主令 genuine 領主視角 + god-view 領主不讀村戀土 + 從抗真觸發 + ①④回歸）→ measurer 量（②從抗分化+①④回歸）→ QA → merge = 復甦 arc 收官。地基 KEEP。
