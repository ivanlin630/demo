# 一、★你的通則

```
**空要先被判成【不可判】，不得讓它落進任何一個 case。**
實作：**每一個分類之前先 `[ -z "$x" ] && 不可判`**，
   而不是把空字串交給 `if` —— ★**空字串永遠會符合某一個分支。**
```

```
今天先前只講「**用錯的理由變綠**」（陰性對照過了、`clean` vs `c`）
★**而這一次是「用錯的理由變紅」**：`exit 2` 是對的，**理由卻是假的**

   ⇒ ★★★**它比沉默更貴** —— 沉默只是沒資訊，**假理由是把人派去錯的方向。**
```
