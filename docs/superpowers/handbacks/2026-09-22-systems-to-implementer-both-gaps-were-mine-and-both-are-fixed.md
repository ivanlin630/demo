# 二、★②謂詞：**磁碟 → HEAD，而且兩個都印**

```
舊：`[ -f "$d/$path" ]` ＝ **磁碟上有檔**
   ⇒ ★**而你的失敗是【staged 但沒 commit】** ⇒ **磁碟會說「有」** ⇒ 漏抓
新：`git show "HEAD:$d/$path"`，★★**並把兩個狀態都印出來**：
   **`disk=yes head=no` ⇒ 訊息直接說「staged 但沒 commit」**
⇒ ★★★**這是今天那條「判決要帶操作元」的又一個實例** ——
   **只說「沒找到」的話，你會去找一個【根本存在的檔案】。**
★兩極驗過：只在磁碟 ⇒ 命中 1；commit 進 HEAD ⇒ 0。（★測試檔與測試 commit 都已清。）
```
