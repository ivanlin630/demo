# 藍圖裁 序2 tag-gating + 序1 收尾

## 序2 tag 叉：**選 (a) 軟傾向，但有一條關鍵修正**

不硬鎖 tag。但「商隊不攻」**不該**只是純人格 weight 弱——那會讓沒牙商隊隨機揮刀=劫匪化。

**憲法分辨線套用**：問「商隊不可攻」是世界規則還行為規則——
- 若當**性情**(商隊選擇不打) → 行為規則 → 硬鎖=腳本=違憲。
- 若當**編成/戰力事實**(商隊沒戰兵、揮刀送死) → 世界事實 → 合憲(像「無糧不能行軍」)。

**裁定：「不攻」由真實戰力/編成湧現，非 tag label、非純人格 weight。**
- 商隊沒戰兵 → attack option eval **自然趨 0**(自身戰力弱、划不來) → 常態不攻。**不是被禁，是送死沒人幹。**
- 商隊有重甲護衛 → 絕境揮刀能成立。
- → 「商隊天生不打仗」保住，但鎖來自世界(戰力)非 label = 湧現非腳本。硬 tag-gate 是「不准」；戰力歸零是「送死」——後者對。

**這卡一個 HOW 你要落實：attack eval 須 capability-grounded**——吃自身戰力/編成，弱商隊 attack eval 才自然趨 0。若引擎現 attack option 只看人格 weight 不看自身能不能打 → 純軟版會劫匪化。防線=**eval 吃自身戰力**，非只調 weight。若引擎已有自身 power 項套進 attack eval → 確認即可；若無 → 這是序2 該補的。

## 其餘 WHAT（納入驗收）
- tag→context weight 仍可**明顯偏向**(商隊性情不好戰)，但那是次要層；主鎖是戰力。
- 融合驗「該出現還出現」含反向：**商隊沒變隨機劫匪、軍隊沒變雜貨商**。常態不越界、只絕境/機會+有本錢才越界。率表看得出。
- unified 側**不改**(已軟)；只讓 solo 對齊 + attack eval 補戰力項(若缺)。
