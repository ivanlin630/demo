# ★一、先講最要緊的：那條規矩不受這個矛盾影響

```
(甲) assert 臂  ⇒ 98、★無 DONE   ⇒ 規矩判【真缺陷】 ✓ 對
(乙) headless   ⇒ 跑完了、有 DONE、閘讀到 HARD-FAILS 並做了清單比對
                 ⇒ 規矩判【測試失敗】 ✓ 也對
```

⇒ ★★**不論兩者為什麼不同，「看有沒有印出 DONE」在兩邊都給出正確答案。**
所以協議那一條**不用改、也不用等真相**。★這一句現在就成立，不是等出來的。

# ★★二、我的假說（★標明是假說，不是結論）

線索是**你今天自己量過的另一件事**：

> 「注射打死了前面一格 ⇒ ★assert 會【中止執行】⇒ 後面所有格根本沒開始」

**假說**：`assert` 失敗會**中止當前的執行流**，而行程會不會結束，取決於
**還有沒有別的地方會呼叫 `quit()`**。

```
(甲) 你的探針：print → assert(false) → quit()   ← ★三句在【同一條流】裡
     ⇒ assert 中止那條流 ⇒ ★★`quit()` 【永遠跑不到】 ⇒ 行程活著 ⇒ 卡住 ⇒ wrapper 給 98
(乙) headless_test：assert 埋在某支測試函式深處，而 `quit()` 在【別的地方】
     ⇒ 那條流被中止，但 quit 仍然會被跑到 ⇒ 行程正常結束 ⇒ 卷面完整
```

# ★★★三、一個實驗就能定案（而它便宜）

```
探針 A（複製你 (甲) 的形狀）：func _initialize(): print(...); assert(false); quit()
探針 B（把 quit 移出那條流）：func _run(): assert(false)
                              func _initialize(): _run(); quit()
⇒ ★若 B 正常結束（rc=0 或有 DONE）而 A 卡住 ⇒ 假說成立
⇒ ★★若 B 也卡住 ⇒ 假說【被推翻】，那就是別的東西，而我們會知道不是這個
```

★★**兩種結果都有資訊**，所以這個實驗值得做；而它是秒級、不建世界。
★★★**但我不要你現在做**：機器要留給相位拆解那一輪（天花板那個數），那是擋著 spec 的東西。
⇒ 排在它後面；若你想先做，跟量測員對一下機器，**不要兩邊同時跑**。
