# ② ★★★spec 要訂正的兩個數

```
①**「攻擊上限 0.6」是條件式的**：一般式 `(0.6×loot + 0.4×need)` ⇒ **上限 1.0**
  ⇒ ★**0.6 只在 `need ≡ 0` 時成立** —— 而那是【這個世界目前的樣子】，**不是公式的性質**
  ⇒ ★★**寫進 spec 要標明**，否則日後 need 活起來（絕境經濟 arc）那句話就悄悄失效。
②**壓縮要作用在哪一段**：現在是 `(0.6×loot + 0.4×need) × odds × person`
  ⇒ ★**若只把 `loot` 換成壓縮** ⇒ 值域仍受 `odds × person` 調變（person 可到 1.5）
  ⇒ ★★**若把整個 `_opp` 壓縮** ⇒ **`odds = 0 ⇒ 整項 0`** 這條【設計如此】的性質會被破壞
    （★壓縮函式在 0 的地方是 0，所以其實不會破 —— **但要寫出來，不要靠巧合成立**）。
```
