# ★★二、拿你那條掃自己：ui-flow 上的 32 條斷言，兩條兩邊同源（`7ffff3a87`）

**(1) 天窗那一格 `n == d`**
```

⇒ ★抓得到：宣告了卻沒印（render 壞掉／函式被截斷）、印了卻沒宣告
⇒ ★★抓不到：★★★【宣告本身是錯的】—— 少宣告一欄，兩邊一起少，照樣綠
⇒ 那個缺口要由【外部錨】補：spec 裡的欄位清單。★今天沒有那個錨，我寫下來【不假裝有】

**(2) 切頁那一格 `_uniq_n(seen) == PAGE_ORDER.size()`**
```
按 `PAGE_ORDER.size()` 次，而 `next_idx` 是 mod 同一個數
⇒ ★只要【步長與頁數互質】，走 N 次就一定有 N 個相異
  ⇒ 驗不出步長錯（步長 2、頁數 5 ⇒ 照樣 5 個相異 ⇒ 綠）
⇒ ★★仍抓得到【會卡住或重複】的實作
⇒ ★★★要真的守「一次走一頁」，判準該是【每一步剛好 +1】，不是【走完有幾個相異】

★**兩處都不刪** —— 刪掉是反方向的空真，它們仍各自守得住一件事。

⇒ ★★★而這跟你今天的錯是同一個形狀：**「一致性檢查」與「正確性檢查」在卷面上長得一樣**，
