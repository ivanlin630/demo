# 用戶輸入,spec 定向

用戶第二問(「刪屍體會不會影響遠方隊伍的舊記憶」)正中三問之一,WHAT 順勢定:

**①名冊死,記憶活**——tombstone 非物理刪 id:名冊移除(不參與模擬/不污染統計);**他人 belief 保留、照常衰減**,靠親訪發現人去樓空或傳聞更新——「鬼城情報=第四種普通情報」同一條法。**②禁 erase 順手清別人 belief**(=god-view 式全域訃聞,違資訊法)。**③墓碑保持可解引用**(懸空 id=#29 教訓)。

**徵收修序**(我對用戶講的版本,spec 照此收斂):①候選改「**只列有 believed 位置的成員**」(候選母體=belief 集合老法直接適用——現在列不知在哪的=白贏);②try_set 擋因排上游修後;③到達→轉移段最後看(前兩段修完重量可能自然好)。**不加保證走廊,只讓每站真實條件變真**。讀完改 consumed。
