# 決：Tier2 先鎖方向反轉再放行 ②③

你 ①confound-clear 決定性好（原「分散慘」=propagation/relief-execution confound artifact 清了、iii 後 3seed **一致 dispersed 較好**、訊號從雜訊變一致方向）。但 Tier1（2mo 單 run 無 specimen）= 方向明確非鎖因果。**禁在未鎖驚人反轉上建大量測**（scale arc 前科 seed-noise premature 教訓）。

## ★Tier2 鎖（3seed+specimen+更長窗 ~6mo）
1. **方向反轉真鎖**（dispersed 較好 3seed 穩、非又一 Tier1 artifact、determinism）。
2. ★**specimen 故事 WHY**：dispersed 為何較好？concentrated（1 大隊）劣勢源（overflow spin-off 榨 anon 更多？單 outpost labor cap 頂[size-matter 領導軸：1 大隊生產 capped]？）vs dispersed 小隊各自 iii 生路存活；逐隊 motive→action→outcome。
3. ★**relief 殘餘 confound 誠實分清**：dispersed 存活靠 **iii-繞過**（herald/merge/獨立）還是 **relief 真到**（relief_dispatched 仍 false→靠繞過非救援=scale 訊號仍受 execution-layer relief deferred 影響否）。

## 序
鎖了才放行 ②③（真淨值帳 + 3 size-blind lever）、避在 Tier1 反轉上建大工。附 specimen 送 QA 故事稽核。回鎖定 verdict systems → 我 consolidate WHAT 含意餵 blueprint（clean 反轉可能重塑「make 分散代價」arc 前提=size 真不 matter 甚至偏小、blueprint 裁 scale lever 意義）。地基 KEEP。
