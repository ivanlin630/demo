# ★means-end whole 驗收判準（藍圖定）+ 派 measurer/QA

恭喜 whole-done，漂亮一條 arc（117 誤植 → 挖到 means-end 缺口 → 全系統 S1-S7 建完）。驗收判準我定如下。

## A. 核心必過（基礎經濟活起來 via means-end）
- **A1 ★means-end 鏈真被走**（arc 原始動機）：material-short 隊 → 去 forest → 建 forest 據點 → 採 material → 蓋想要的設施，**整鏈走通**。隊還卡平原缺料坐著 = **FAIL**。
- **A2 多線平行**：隊同時追 ≥2 目標、經委派小隊平行（非單線）。
- **A3 ★人格差異化投資**（折現驗證）：穩定隊遠視投資發展 vs 絕境/餓隊短視求生——折現**真分化行為**。
- **A4 近零指標脫離**：EXPAND / harvest / facility-build / deal 從 race-collapsed baseline（0 事件 / harvest 0.5-4.8%）**明顯升**。

## B. 下游驗證（根修好、下游自消）
parked 症狀**自然消退**：material 缺口 / coin liquidity（extract flat 0.4 被 means-end「需 spendable coin → 需 extract」取代）/ 掛單噪音（hollow-economy）。**不消退 = 根理論不完整、要 followup。**

## C. ★★QA 故事稽核（強制閘，本場血證紀律）
不只看聚合數字——QA **逐 tick 故事驗證**隊**真的走 means-end 鏈發展**（動機→行動→結果），不是數字碰巧動。本驗收 = 本場最大聚合結論 → **QA 故事稽核強制**（threat-oracle 創始血證的應用）。

## D. 憲法檢查
確認**無 bespoke 硬掛 goal-hook 殘留**（S7 該把最小-hardcode scaffolding 泛化成 util-門檻掛）。constitution_gate 74-removed=0 已示乾淨，但確認 goal 生成是 **util-門檻驅動、非寫死**。

## E. Watch-items（已知次優、非 blocker）
S3 unowned-forest 優選 / S4 facility-type-mismatch / S5 residency 手評未退 / S7 stale-satisfied 反向 staleness（3 天窗）。QA 記錄若哪個**實質扭曲核心故事**。
