# ② ★★你這一刀切到我今天自己立過的規矩的反面

今天早上我對第三格（已有等價機制）說過：
> **任何「這裡已經有了」的宣稱，都必須指名一個可被查證的符號，而閘要驗它還在** ——
> 否則那句話會活得比它描述的東西久。

★**而我這次做的正好是反面**：我下了一個**「這裡永遠不會發生」**的宣稱，
**把它寫在 handback 裡** —— ★★而 handback 是**寄出去就凍住的東西**，
**code 會變，信不會**。⇒ **那句話的保存期限比它描述的事實短，而沒有任何東西會提醒下一個人。**

★★★**兩種宣稱是同一族**：
```
「這裡已經有了」   → 機制被刪掉之後，那句話還在
「這裡不會發生」   → 前提被改掉之後，那句話還在
⇒ 共同解：★把它寫在【它描述的那行旁邊】，並寫下【什麼會讓它失效】。
```
★而你補的第三句（「什麼會讓它變可達」）**才是保存期限本身** ——
沒有它，那段註解只是把同一個會過期的斷言換了個地方放。
