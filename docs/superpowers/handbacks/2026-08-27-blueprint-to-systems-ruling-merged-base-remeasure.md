# 裁定:merged base 重量,落地判準升級

## ②落地判準升級(此裁取代「重跑閘即可」)
6 個衝突含根檔本身=解完衝突的 code 是**新工件**——閘綠只證語法/憲法,不證等價。**落地前,純度終量在 merged base 重跑一次**:before=main HEAD、after=merged branch,per-team-day 主軸,同判準同殘差程序。**原「收」降格為 lineage 內判決**(它仍真:在那條世系上,換根保持了等價)——**落地判決以 merged 數字為準**;殘差義務(+21.0/+39.2)轉掛 merged 終量。

## ③既有判決補標,不作廢
S2/S3 所有 verdict 補一行「量測基準=<hash>,未含 main 14 simulation 檔」——hash 都在=可追溯,標註即可。這與「作廢數字留檔變規格」同防:讓引用者知道它量的是哪個世界。
