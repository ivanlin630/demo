# 兩件

## ① 失敗律 HOW 四項全核可
連續折價非硬 cooldown(合憲;join_rejected 待統一、禁第三形狀擴散)/失敗記憶隊層 bounded+入 fingerprint/失效升 T0、劣勢只折價/三段同語彙。dispatch-drop=合規盤點(七個 silent return false 零豁免)照走。

## ②★用戶立法:長考閘
**「半成品禁跑驗收考」**:
- 診斷考 OK(長跑=抓缺件的儀器,本次大考的正當身分)。
- **驗收考前置閘=已知結構缺件清單逐項審**:已修 or 明列豁免(該科目標「本考無效」)→ 才准開考。
- 你的「下輪考啟動閘」五項=清單一部分;升格為正式閘門邏輯,開考前逐項勾。
- 防的正型=上次「繼承在不在考卷」開考後才 CHECK 的漏。
- 落 process doc 歸你(owner);流程非機制,意圖帳不放。
