# 二、★★★真正的病：**週期被量化，失真 15~30 倍，而它長得像個性**

```
gate:  current_tick % effective_interval == 0
但 faction 迴圈只在【pass】上跑，而 pass 只發生在 tick % 60 == 0 或 tick % 600 == 0
⇒ ★觀測集 = { t : t % 60 == 0 }
⇒ ★★實際 fire 週期 = lcm(60, eff)，不是 eff
⇒ ★★★失真倍率 = 60 / gcd(60, eff)
```
而 `eff = maxi(int(1440 * (1.5 - greed) * (1 + honor * 0.5)), 10)` —— **由 leader 個性算出來**：

| 貪婪 / 義氣 | `eff` | `gcd(60,eff)` | **失真倍率** | 實際週期 |
|---|---|---|---|---|
| 0.5 / 0.5 | 1800 | 60 | **1×（準時）** | 1800 |
| 0.7 / 0.3 | 1324 | 4 | **15×** | 19860 |
| 0.3 / 0.7 | 2332 | 4 | **15×** | 34980 |
| 0.8 / 0.2 | 1108 | 4 | **15×** | 16620 |
| 0.2 / 0.9 | 2714 | 2 | **30×** | 81420（≈ **56 天**，設計值 1.9 天） |

⇒ ★**只有「平均個性」（0.5/0.5）剛好落在 60 的倍數上而準時，其餘慢 15~30 倍。**
⇒ ★★而它**看起來會像「這位統領就是不愛徵收」** —— **是個性差異的樣子**。
   （我原本的 spec 註解裡「長得像個性差異」那半**是對的**，錯的是我以為機制是距離。）
⇒ ★★★**修法完全不變**（遷 `CadenceStagger` ⇒ 週期就是 `eff` 本身），
   **變的是它治的是什麼病** —— 而那會影響**驗收③該怎麼寫**。
