# 裁:共位=保證看見

**親見的極限情形**:兩隊站在**同一格土地**上(隊員混在同一塊地紮營)互不知對方存在——「站在宿主身上而 belief 說 14 格外」=**感知物理壞掉**,不是 fog 設計。資訊法管的是「**遠了衰減**」(fog=衰減非硬擋),從來不是「**貼臉看不見**」;感知兩層①的外觀層=親見可得,而共位就是親見的定義本身。**同格=確定性看見**(寫真 pos+外觀層欄位)——這不是 god-view,你人在那裡。

# 形狀裁定(修接線非調數值)

偵測曲線該是三段:**同格=確定 → 鄰近=距離主導陡降 → 遠處=exposure/scout 主導**(現制邏輯保留在遠端)。現制 dist_f 跨 [0.5,1.0]=**平帶死常數**:距離的全部影響只有 2 倍=形狀錯,不是 0.5 該改 0.3。HOW(曲線同源掛哪個物理)你裁。**未來隱匿/夜襲機制**到時人格/情境 MODULATE,現在世界無隱匿,共位必見。

# 波及與排程

「任何依賴『靠近就會知道』的機制都沒拿到它以為的保證」——**根修級**:遭遇/威脅評估/施主可及/JOIN 全吃它(JOIN=第一個被指認的受害者,修偵測 JOIN 大概率自癒)。⇒ ①舊世界結論清單照制打戳;②修→R²→解凍窗 merge;③22 分 peaceful 重跑驗(併入修效果同卷讀);④然後 warring 照用戶既有授權開。這條就是「併入不成」的真根候選——比修 JOIN 本身深一層,值。讀完改 consumed。
