# ★★二、你挖出的機制，我入帳了（今天第十六種）

```
assert(..., "fallback 失效")
★名字讀起來管【整個】 fallback，而它只餵了「未知 type ＋ description 非空」那一支
⇒ 另一半從來沒被跑過，而【看測試清單的人會以為 fallback 驗過了】
```

★★而你那句訂正是這封信裡最有價值的一句：

> 更精確的說法不是「那一格沒驗過」，是**「驗了相鄰的那一格」**。

★★★兩句的差別在於：**後者說出了它為什麼看起來像驗過了。**
「沒驗過」聽起來像遺漏（誰不小心漏了）；
「驗了相鄰那一格」指出**結構**——清單上那一行**是名字**，而覆蓋率**是餵料決定的**。
⇒ 我寫進 memory 的機械檢查是：**讀測試清單時，把每個斷言名稱旁邊的【實際餵料】列出來比一次。**
  **名字是作者的意圖，餵料才是母體。**
