# 裁定：經濟死的真根 = AI 決策框架不統一 → 做框架統一，別再 patch

回應 `economy-root-archetype`。用戶與藍圖討論定論：(a)/(b) tag-vs-人格只是**一個症狀**；真病更深，**取代 (a)/(b) 框架**。

## 真根
目標錨 / faction AI / solo AI / subteam / 商隊 hoist / survival …… **每個子系統各自對隊伍 latch task、用 ad-hoc `TaskArbiter` 優先序互搏**。沒有「一隊一個連貫決策」。

- tag-vs-人格(商隊精神分裂)= 這架構的**必然產物**之一。
- = 你 memory 早記的框架債（`project_framework_seams`：缺 pipeline/所有權圖縫、「加東西=大改」）。**經濟只是讓它現形。**
- WS-2/2b 的商隊 hoist 是貼 tag 那面 OK 繃、跟目標錨打架 → (a)/(b) 會是**第 7 層 OK 繃**。

## 決定（用戶定，路線2）
**做「統一決策框架」當下一個大 arc。(a)/(b)、經濟局部 patch 全不做，fold 進框架。**

理由：病在**所有 NPC 行為類型**(戰鬥/外交/遷徙/貿易 = 同一個破碎決策)。修經濟一處 = 浪費 + debt 續長。一次在框架層修好 = 惠及全部。

## believability bar（WHAT，藍圖定；框架形狀=你 HOW）

1. **一隊一個連貫決策**：survival / 野心 / archetype / tag / faction / 私人目標(feud等) / 經濟狀態 **全是輸入**，weigh 成**一個**選擇。不再靠優先序互搏。
2. **加行為 = 加一個 term，不是加吵架子系統**（治本「加東西=大改」）。
3. **服務全行為類型**：不是經濟專用，是 team 的通用 macro 決策（戰鬥/外交/遷徙/貿易/生產/survival 同框架）。
4. ⚠ **連貫 ≠ 同質**：人格/archetype 必須產生**分歧**的權重 → 軍閥、商人、定居者、狂人、懦夫**該長不一樣、該做不同選擇**。統一框架**嚴禁把行為抹平成一個樣**。這條是硬約束——之前「戲劇尾巴」的成果(立國/識破冒出)不能被框架統一洗掉。
5. **看任一隊在幹嘛，都該講得出「因為它所有驅力綜合起來，此刻最該做這個」。**

## fold 進框架的舊問題
- **tag vs 人格**：兩者都是決策的**輸入**(tag=當前角色/職業、人格=傾向/野心)，由一個 weighing 協商，非二選一。持久矛盾可走既有 `tag_shift` 漂移收斂(掌權者本性改變組織)。
- **商隊 hoist**：不是獨立 latch，是「貿易」這個選項的 utility 一個 term。
- **survival/絕境**：不是 override latch，是高權重輸入(快餓死 → survival term 壓倒一切，emergent 而非硬閘)。
- **經濟 = 第一個驗證案例**：框架對了 → 商隊不再被生產搶走 → 走完貿易 → 6 層 plumbing 被 exercise → 履約脫 0。**框架 arc 須含「重量經濟驗證」當驗收。**

## 不浪費
WS-2/1/3/2b/2c/2d 六層 plumbing 全有效 = 貿易的**執行層**，只是被破碎決策擋在門外。決策一連貫即被觸發。

## HOW（你的域，需自己 spec/brainstorm）
- 統一決策的**形狀**（utility-based 評分？其他？）。
- 從現有 N 子系統(目標錨/faction/solo/subteam/hoist/survival)**遷移/收斂**的路徑(de-risk，別大爆炸；可能 seam-first like G3 accessor)。
- 各驅力 term 的權重(TEST VALUE)。
- 保留人格分歧(bar #4)的機制。

## 序 / 預期
這是 **foundational arc，比經濟大**，惠及全 NPC 行為。經濟會等它，但這才是「加東西=大改 / 行為精神分裂 / 魂行為偶發」一系列病的共同根。
建議你開「統一決策框架」spec/brainstorm（HOW），有 WHAT/believability 疑義回呈本 channel。
