# QA 故事稽核：死因/崩潰隊 — 正式判決

讀完 team5/10/11 全部決策（做什麼）entry（含 candidates 全陣列），逐隊核對到崩潰後（pop=1）的完整尾段軌跡。**跟 measurer 的聚合判讀有重大分歧，不是全盤確認**。

## ★核心發現：崩潰後的命運，三隊並不一樣

**人口崩潰（5-6人→1人）本身是 genuine**——這點 measurer 判對，我沒有推翻的證據：task 正常輪替（覓食/貿易/治理/建設/return_home），從未卡死單一 task，是真的在嘗試多種手段而非決策盲派。

**但崩潰之後（剩1人）的故事，三隊分岔了**：

### team10 / team11 ＝ 崩潰後暴力回彈，不是「還在流血」

**team10**：剩1人後 `effective_food` 在 tick16840 起持續攀升——`100.52 → 172.40 → 226.63 → 269.50 → 310.02 → 340.81 → 368.93`（tick16840→21160，共 4320 tick ≈ 18 天，`task=貿易 winner=build_workshop:resource` 反覆進行）。

**team11**：剩1人後更誇張——`11.29 → 22.10 → 32.48 → …一路爬升到 448.42`（tick11100→21370，共 10270 tick ≈ 43 天，同款 `貿易/build_workshop:resource` 持續進行）。

**這兩隊在最後 40-50 天完全脫離飢餓**，`effective_food` 從 0 一路漲到 3-4 百，**跟 measurer 判讀的「數值縮小只因人少了少吃、不是流入轉正」正相反**——這不是「流量變小」，是**真正的淨流入轉正、而且持續累積**。

### team5 ＝ 真的還在流血（knife-edge 生存）

**team5** 尾段（tick16000→21600，共5600 tick ≈ 23 天）完全不同：`effective_food` 呈現週期性鋸齒——每隔約 800 tick 拿到一次固定約 `+3.67` 的注入（`food_private` 直接從 0 跳到 3.67），然後**每個心跳穩定衰減約 -0.33～-0.34**，耗到 0 才等下一次注入。**這隊確實是「還在流血」的知刃邊緣生存**，`coin=747.53`（比 team10/11 的 `coin=200` 多得多）也沒能買到穩定糧食——coin 不是瓶頸，值得另查是不是地形/可及資源的真差異（**genuine depletion 對 team5 成立，但對 team10/11 不成立**）。

## ★對 measurer Q1 的回答：food_flow_avg 為何「從未轉正」——這句話對 team10/11 是誤導

聚合面看 `food_flow_avg`（EMA）可能真的全程掛負，但**逐 tick 讀 `effective_food`（真實庫存）明明在暴漲**——這是同一個「EMA 落後瞬時值」的家族問題（跟我前輪 labor-v2 accepted cost 稽核抓到的 `food_flow_avg` 5日EMA 落後現象同款：`resource_system.gd:20/230-243`，另外該檔案自己的註解也提到「離開自家糧倉→effective_food 跌→一次負脈衝壓低 flow」——這兩隊持續 `貿易` 任務，若這個 task 讓 EMA 取樣點落在「離開糧倉」的判定上，EMA 可能被結構性鎖負，即使真實庫存已經在漲）。**「food_flow_avg 從未轉正」不能直接讀成「這些隊還在流血」——至少 team10/11 不是，需要 team5 才是**。

## ★對 measurer Q2 的回答：team11「投靠」嘗試發生了什麼

抓到 tick10700/10900/10910 三筆完整 candidates：`併入`（投靠/求收容）util **2.90-2.91**，遠遠壓過第二名 `備戰`(0.76)——**util 算對，飢餓時投靠正確地變成壓倒性首選，不是決策盲派或算錯**。`result=committed`（真的選了，不是算出來沒真切換）。但**投靠沒有成功脫險**——tick10900 起 task 掉回 `紮營`，pop 停在 1 未再變化——目標(可投靠對象)可能真的不存在/搆不到，屬於執行完成度問題，不是 util 計算問題。這跟我在 convoy slice 抓到的「決策對、執行完成度斷」是同一家族的症狀模式，但這裡我沒有更深的軌跡可以確認根因是否相同，只能指出相似性、不能斷言同源。

## 建議

1. **不建議把「food_flow_avg 全程負」當作這4隊仍處於危機的證據**——至少 team10/11 明確反例，需要換用 `effective_food`（真實庫存）而非 EMA 來判斷「還在不在流血」。
2. **team5 才是真正值得深挖的案例**——coin 充裕(747)卻食物卡在 knife-edge，跟 team10/11(coin僅200卻食物暴漲) 形成強烈對照，值得查兩者的地形/可及資源差異是不是真根因。
3. **不建議把「投靠」歸類為決策失敗**——util 對、committed 對，只是沒有可投靠對象或執行完成度斷，跟 convoy slice 那類「決策對、最後一步沒接上」的家族值得一起追。
