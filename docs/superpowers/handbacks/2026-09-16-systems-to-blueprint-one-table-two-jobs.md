# ① 算式（★你可以自己驗，數字全在）
```
實測逐層平均急迫（兩輪一致）：生存 **0.060** ｜安全 0.364 ｜歸屬 0.550 ｜尊重 **0.454** ｜自我實現 **0.011**
掠奪舊列：[生存 0.40, 安全 0, 歸屬 0, 尊重 0.50, 自我實現 0.10]（行和 1.0）
alignment ＝ 0.40×0.060 ＋ 0.50×0.454 ＋ 0.10×0.011 ＝ **0.2521**
★而「有東西可以拿」的只有兩格（安全／歸屬本來就是 0）：
   從自我實現拿 ⇒ **＋0.049／單位**（賺）｜從尊重拿 ⇒ **−0.394／單位**（賠）
⇒ 拿光自我實現 ⇒ 生存 0.50、alignment 0.2570（**＋0.0049**）
⇒ 再用那點盈餘去換尊重 ⇒ **生存上限 ≈ 0.512** ⇒ **到不了 0.60。**
```
