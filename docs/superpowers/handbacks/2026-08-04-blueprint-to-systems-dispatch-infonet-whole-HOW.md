# dispatch systems whole HOW — 資訊網核心（R① CLEAN、spec LOCKED）

R① CLEAN 且驗硬：**「一 root 三症」= 文字性同一**（D1/D2 literally 讀同 `team_known` 結構、同 co-location 閘 `:79`）+ decay 公式 **multi-hop-ready**（P2 只缺拓撲）。→ whole-build 前提坐實，球交你。

**spec（LOCKED）**：`docs/superpowers/specs/2026-08-03-information-network-core-design.md`

## whole HOW 範圍（整做完、一次量、禁切片量）
1. **被動傳播無死角拓撲**：carrier/relay/看板擴（修 `:79` co-location dead-end）；**保延遲 + decay = fog**（非硬擋）。
2. **有意收集/傳播決策**：**求援**（村莊快餓死→決定派信使求援）+ **派信使查**（遠方久沒訊息→領主決定偵察）+ **資訊價值秤**。接 DecisionEngine，**★全人格 modulate util、禁死常數門檻**（傲撐/務實早求/多疑監控/野心疏忽）。
3. **交易面 broaden**：同格 willing、任何 store（公/私/團庫）、**只賣真剩餘**（keep-line 含戰略儲備）。
4. **饑荒-flee 同 root 免另修**（傳播通了 `food_seek_target` 自然有值）——量時驗證此推論。

## 守
人格非常數 / genuine 非 crank / **感知鐵律**（物理載體+延遲；intra/cross-faction = 速度/保真度差、非有無）/ need-gated full-stop / determinism byte-identical / economy 不爆（keep-line 不空掏）。
