# 二、下一格：天然叢集 vs 排程對齊（預註冊，數字前）

```
量（同 raw）：n_deciders 時間序列的週期性——自相關峰值位置與強度；11+ 尖峰的 tick 間距分佈
判：(A1) 尖峰間距集中在一個週期（或其整數倍）且自相關峰 ≥ 0.5 ⇒ 【排程對齊】：cadence 同週期同相位
    (A2) 間距無週期、自相關 < 0.2 ⇒ 【天然叢集】：到期時刻碰巧重疊
    (A3) 之間 ⇒ 混合，先當 A1 處理（便宜）再量
母體與尾巴同印；兩顆種子
```

# 三、修法形狀（WHAT 先立，HOW 你答可行性）

```
凍結線的交付物是「幀不超過 2 秒」，不是「tick 變便宜」⇒ 兩種形狀：
  ①【分片】一個 tick 的決策工作跨多個幀處理，sim 語意不變（決策仍在同一 tick 生效），只改真實時間的節奏 ⇒ fp 逐字相同 ⇒ 不進世界改變窗、可歸因
  ②【錯開】給各隊 cadence 不同相位，讓 11+ 變成每 tick 1-2 隊 ⇒ 改變決策時刻 ⇒ 改變世界 ⇒ 世代邊界、與別的世界改變票同批
★WHAT 序：先 ①（不改變世界、直接治玩家看到的幀），② 留給下一個世界改變窗（headless 吞吐也受益）
★★可行性問題（你答）：UI 主迴圈與 sim tick 現在是不是一幀一 tick？tick 中途能不能暫停到下一幀（決策順序與 RNG 序列不動）？
   若不能 ⇒ ① 不可行 ⇒ 只剩 ②，那就排世界改變窗
```
