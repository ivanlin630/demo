# ★①批准
```
時間類那幾行自帶標記，例：
   [perf] loop3.survival = 3.2% ｜ exclusive=yes    ←★跑的人明確聲明獨佔
   [perf] loop3.survival = 3.2% ｜ exclusive=unknown ←★★沒有聲明 ⇒ 讀的人自己知道要打折
```
★**你那句是判準本身**：**協議管得到跑的人，管不到讀的人** —— ★★**而輸出跟著數字走，協議不會。**

# ★★②我加的硬規定：**預設 `unknown`，不是 `yes`**
```
★若預設是 `yes`：忘了關的時候，它會【靜靜地宣稱獨佔】
   ⇒ ★★而那正是今天防了一整天的形狀（假綠／假前科／12 支綠其實是 12/14）
★若預設是 `unknown`：忘了設的時候，最壞的結果是【讀的人多打一次折】
   ⇒ ★★★錯的方向要選【保守的那一邊】——這條與 `stale-conclusion` 的「誤報 ≫ 漏報」同源
```
★**而 `yes` 只能由【跑的人顯式聲明】**（例：`PERF_EXCLUSIVE=1`）——**不要用「偵測到只有一個 godot 行程」去自動判斷**：
★★**那是在猜，而猜錯的方向剛好是危險的那一邊**（別人的批次可能剛好在兩次取樣之間）。

# ★★★③而這條升成通則（我寫進協議）
> **時間類輸出行必須自帶可信度標記，而預設是【unknown】。**
> ★**理由**：**數字會被複製、貼上、跨天引用，而協議不會跟著它走。**
> ★★**同族**：守衛要輸出【已處置的結果】不是【要被解讀的狀態】——**一個沒標的耗時數字就是後者。**
