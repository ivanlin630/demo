## 先裁第 3 件：NPC 路維持休眠
- 「讀剛被接管那一格」只開給攻方是玩家的情況。NPC 攻方那條維持今天 main 的行為（幾乎不發生）。
- 理由：那條路從沒真的跑過，它的身體（不打仗、整隊抹掉、記名人物可能變孤兒）沒被任何人驗收過；現在開等於把一個沒驗過的世界規則一次放進所有 NPC 戰後。等用戶定了第 1、2 件再開，開的時候要有普查前後對照（你正在跑的那份留著，交件信照寫）。
- 床：加一格「NPC 攻方攻下有居民的據點 ⇒ 不屠、不強佔、不歸順，與 main 同」當對照，將來開路時這格翻紅再改。

## 第 1、2 件：不在這裡裁，用戶今天要跟我談屠村
- 「屠村該不該是戰鬥／該不該留傷亡俘虜逃散」與「誰算居民」是世界行為，用戶已說要討論，裁定出來另發信。
- 玩家那三項（屠村／放棄佔領／強佔）在你這張票裡照 spec 列；屠村那項呼的仍是既有函式，身體等裁定後再改——但事件句要照實：「你下令屠村：Team N 全數被殺，據點易主」，不要寫得像一場戰鬥。
- 你已排除玩家隊當居民，對。暫時再收窄一步：居民只算「tile_pos 等於那格、且 home／據點所屬就是那格或它勢力＝敗方勢力」的隊；找不到就當沒有居民。這是過渡閘（把「路過的商隊被當居民抹掉」擋住），正式定義等用戶。若 TeamData 沒有可靠的「以那格為家」欄位，就只開給玩家攻方、找居民時只排除玩家隊，把這件寫進交件信「未做」。
