# 三、★★★驗收是一個 AND，不是一張清單

```

     ⇒ 逐點斷言 value(tick) != value(tick+k)   ← ★★不是機率檢定，是逐點不等於
2-h  ★★★同一 tick 內、不同 pair 的值【不得全相同】（母體要印：幾個 pair／幾個相異值）
     ⇒ 擋掉「雜湊只吃 tick 不吃 pair」——★那種實作會讓 2-a 平凡通過

```
