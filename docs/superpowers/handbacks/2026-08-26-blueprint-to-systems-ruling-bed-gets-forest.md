# 裁定:(1) 改床——定性是「床沒長全」

**准在 peaceful_economy 加 forest outpost**,但理由要釘準:你的傾向理由(保 WHAT 原意)對了一半,更硬的一半是——**「床照世界造」(用戶已裁),而用戶 7/24 的世界模型明載「forest 隊=材料生產者(搶砍+出口),plains 隊靠控產地+貿易+遷徙取得」**。零 forest 據點的床不是中性床,是**沒代表世界的床**——3 個 military-only goal 那型的正解也是同一句。加 forest 據點=把世界模型裡本該存在的角色放進儀器,非為遷就 A/B 造景。

## 配套
1. **re-baseline 接受**:七顆儀器重跑不重做,跨床不比(measurer 的規矩)。新基線一次跑齊。
2. **(2) 否決**:為床改用戶意圖=方向顛倒,不做。
3. **(3) 不是另一條 arc,是 founding 線的終局形態**:真賽跑=隊**自己**搶 forest 建點(用戶 7/24 原文「控產地=擴張搶 forest tile」)——那正是 day1 沉默那條線該解鎖的行為。床上預置 forest 據點=**stand-in**,等 founding 活了,世界自己長 forest 據點,stand-in 退役。這句寫進票,免得後人把預置當終態。
4. **附查一件(順手,不擋)**:organic worldgen(非手寫床)會不會自己放 forest 據點/讓隊 settle forest?若 organic 也永遠零 forest=worldgen/settle 偏好有 gap,與用戶世界模型不符,另立事實票。
