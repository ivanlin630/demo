# commander-v2 落地 — 統領會思考了

照你 means-end 核心 WHAT + 裁 A（只真 affordance）。統領層從「多閾值憑空跳令」升到「手段-目的推理」。

## 達標（你的驗收：可解釋 + viability，非跟戰數）

- **可解釋（北極星）**：每個派系令都追得回意圖——measure 重跑 `無因令 = 0`（硬 assert）。好戰霸主→意圖「征服X」+ 令[攻擊X(why:主手段) / 外交(why:補力結盟) / 徵收(why:籌餉)]，每令 driver={intent,why,mode}。
- **viability（真實打、輔助從餘裕）**：征服只在「湊得出實打力」才選；敵 belief 顯強→不選征服、不發攻擊令（退守成/致富）。軍力**獨力**足→單令攻擊；獨力不足但有救兵餘裕→主令攻擊 + **補力肢**（結盟 vs 徵收 util 比較選）。**不發打不贏的攻擊令。**
- **真思考非查表**：補力肢是「主行動 force 前提現算不足 → 開補力 need → filler 按 affordance∩need×人格 匹配」算出來的，不是寫死清單。加新意圖=寫一句 predicate，自動用既有行動 schema 分解。

## means-end 機器跑通（含欺敵孤兒洞處理）

- 意圖集{征服/致富/防衛/守成}、行動集{攻擊/徵收/外交}（真 affordance）、深度1。
- **欺敵孤兒洞**：征服的「擋敵盟」子需求需欺敵 affordance（孤兒）→ **該 need 不開、不假塞**（守你 affordance 真實性 invariant）。**欺敵 arc 建好後此 need 自動有 filler 插回機器**（affordance 由孤兒轉真）。

## ⚠ 一個 believability 窗口疑慮（誠實講，待你判要不要 tune）

湧現的**協同多肢 scheme**（攻擊+補力肢）只在**「軍力獨力不足、但有救兵餘裕」**這個窗口出現：
- 獨力就夠 → 單令攻擊（不需補力肢）。
- 力差太遠 → 退守成（不發征服）。

= 正確 means-end（你只在需要時招盟友）。但**這窗口在真實長跑多不多、玩家看不看得到「召盟攻 X」的協同戲，world_sim 該 seed 沒捕捉到**（派系太少/短命，多數守成）。靠 unit + P3 場景證機制活。

**問你**：要不要排一個「多派系戰國 seed」驗協同 scheme 真湧現頻率？還是先信機制、等真人玩測？（viability 偏保守[補力餘裕只算已在攻擊的 member]可能使征服過稀有，是 TEST VALUE 可放寬。）

## 統一 arc 里程碑

**隊層（早）+ 統領層（本塊）= 統一決策 arc 兩半全收編。** 「決策不統一/latch 互搏/憑空跳令」這隻病——arc 從頭在殺的——**真根全清**。

## 下一塊（照你時序）
**欺敵 sim arc（anchored-pre-player）**：假和/斷供-貿易戰/離間/緩兵 sim 機制 → 建好插回 commander 既有 means-end 機器（孤兒 affordance 轉真、自動進匹配）。= 玩家錨 C 欺敵層落地。其餘孤兒（壓迫 cascade/城防/戰俘…）排其後 by player-visibility。

待你：①協同窗口要不要 seed 驗 ②欺敵 arc 開工（要我先 brainstorm/spec 嗎，還是你先給欺敵的 believability 願景細節）。
