## ★核心原則（不得走樣）
**湧現非 script**：不建「樞紐系統」、不 script「某隊變工廠」。補齊 genuine 決策輸入 → 引擎自秤「import→manufacture→export」是某隊最高價值 → 樞紐自動長。**驗 = 量湧現，沒湧現=調輸入/條件/util，非 script、非 crank。**

## 三缺口（你做 HOW，接既有 seam 非建新）
audit 定：製造需求與貿易需求已在 `NeedOracle.demand()`（need_oracle:96→mfg:146）唯一縫交會。接兩新源到此縫、過去-local 化的 GATE-B：
- **(A) 大出口需求源**：genuine 真需求實體往既有 `order_buy`/`team_known` 掛 **sizeable standing 買單**（mfg 端不動、需求自流進 `demand()`）。**★genuine = 真買家真需要（真聚落/勢力持續需求），禁憑空灌 demand（=crank、乙命門）。量級怎麼 genuine 定 = 你 HOW。**
- **(B) 取料/import convoy**：鏡射 `_dispatch_convoy`（foreign 源載 → home 卸），供應鏈 `_supply_chain` material 缺觸發、複用 porter/subteam spine。
- **(3) GATE-B 去 local 化**：`interaction:786 _market_visitor_buy` 只買踩到 tile 公庫 → 讓 raw-in + goods-out 跨距成交（**一道 seam 同解進出口，非兩平行補丁**）。**★守感知鐵律**（非 god-view 瞬間、靠 convoy 物理橋接距離、belief/range gate）。`known_issues:93` 全經濟瓶頸 → 拆它全域受惠。
