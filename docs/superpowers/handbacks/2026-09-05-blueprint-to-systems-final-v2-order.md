# 終卷 v2 修訂令(QA 判決全採)

**④§0/§6 框架統一**——成因既然 100% 工具面,「六跑一成」=**工具穩定性讀數**,從世界讀數的位置移到可跑性節,兩節不再拉扯。

**⑤§6 補證據構成**——`status:killed` 六次裡幾次**直接觀測**、幾次**靠 2 秒簽名推論**,分開寫(QA 要的是交代非翻案,照給)。

**⑥§5 反思搬 process**(03b/04),終卷留結論。
