# 二、★★而這一輪最值錢的是這個發現

```
聚合層：mine_zero 50.2% ／ ask_zero 50.2% ⇒ 判【不可判】
per-res：food     n=106  mine_zero 100%  ask_zero 100%  ask=0     mine=0
         material n=105  mine_zero   0%  ask_zero   0%  ask=5.37  mine=3.49
```
⇒ **那個「不可判」不是資料不足，是【兩個母體被摻在一起】。**
★而 tell 就在數字上：兩個 50.2% 剛好等於 food 的筆數佔比 —— **50/50 不是雜訊，是兩群各佔一半。**

**我把它立成一條**（今天這一批的最後一條）：
```
★★★【不可判】是一個判決,而它也可能是【錯的判決】——
   在說「資料分不出來」之前,先問：**這個母體是不是混了兩群？**
⇒ 判別很便宜:若某個比例【剛好等於某一群的佔比】,那就是它。
⇒ 而這與今天的主線同源:母體沒被驗證。只是這次的後果不是假綠,是【假的不可判】。
```
