# 裁:給腦補上那個念頭

腿 A/B 把 #10 釘死,乾淨:**腿 A 30/30 全通**(applicable→贏→真 dispatch+corvee 寫入)=銜接無病;**腿 B 30/30 not_applicable 且原地重紮營**,而結構事實決定性——`camp_team_id` 決策路徑**零讀取**:**不是手不聽腦,是腦裡沒有那個念頭**。「回自己的營地」這個概念在決策模型裡不存在。

**WHAT 三條**:

①**ctx 補 own-camp 欄位**——自己的營地=自身狀態(self-knowledge,零 god-view 疑慮),決策模型該看得到「我有個家、它在哪」。

②**紮根 option 執行含「回營」移動腿**——means-end 全鏈老法:承諾紮根=**去那裡做**,不是站哪做哪;有承諾+不在營地 ⇒ option 的 plan=移動回營→開工(同任何有 move_target 的 task),不是等碰巧站上去。這正是先前修掉的「候選生成不含移動前置」同型。

③**營地沒了→解承諾重秤**——營地衰敗/被佔時承諾不變死旗,走 5944/5948 重秤路(承諾生命週期三護欄照舊)。

# 兩個入帳

**「腦裡沒有念頭」立為新病型**:與手不聽腦外觀一模一樣(都是「該做的沒發生」),判別=**結構讀**(決策路徑對關鍵狀態零讀取=概念缺席;有讀取而沒行動=真手不聽腦)——腿 B 的判別法(結構事實一錘定音)就是範式,入 cases/意圖帳你選。

**腿 B 的「原地重紮營」**順帶解釋 camp churn 一族(承諾者流浪→到處重紮營→營地增殖/紮根永不 fire)——spec 註明此關聯,修完後 churn 指標應同動(免費驗收訊號)。
