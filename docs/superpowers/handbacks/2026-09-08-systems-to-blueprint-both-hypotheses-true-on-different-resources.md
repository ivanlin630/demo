# 一、★結果（3 日窗首跑，★驗 tap 用，非結論；30 日窗以 measurer 那輪為準）

```
聚合：mine_zero 50.2% ／ ask_zero 50.2%  ⇒ 判【不可判】
per-res：
  food     n=106  mine_zero 100%  ask_zero 100%  平均 ask=0.00  平均 mine=0.00
  material n=105  mine_zero   0%  ask_zero   0%  平均 ask=5.37  平均 mine=3.49
```
```
★food     ＝【全員過剩、誰都不要】（兩邊都趴 0）——你的假說 A
★★material ＝【賣家開價脫離行情】（ask 5.37 ≫ mine 3.49，而兩邊都不是 0）——你的假說 B
⇒ ★★★兩個都成立,只是在不同資源上 ⇒ **下一刀要分資源出,不是二選一。**
```

# 二、★而「不可判」是假的 —— 那是聚合造成的

```
兩個 50.2% 剛好等於 food 的筆數佔比 ⇒ 不是雜訊,是【兩群各佔一半】。
⇒ ★在說「資料分不出來」之前,要先問【母體是不是混了兩群】。
   （這與今天的主線同源:母體沒被驗證。只是後果不是假綠,是【假的不可判】。）
```

# 三、★★而三症一根要換一個資源

```
你的假說鏈掛在 **material**：「material 深過剩 → 估值趨零 → 倒掛 → 殺單」
而數據：★material 的 ask/mine 都【不是 0】—— 它不是「估值趨零」,是【開價高於買方估值】。
        ★★「估值趨零」那個形狀出現在 **food**（兩邊 100% 趴 0）。
⇒ ★★★所以不是假說錯,是【它指錯了資源】。
   ⇒ 若把鏈改掛 food:「food 深過剩 → 全員估值趨零 → 買賣兩端都是 0 → 拒買」——形狀吻合。
   ⇒ 而 material 需要另一條解釋:**賣家憑什麼開 5.37 而買方只值 3.49?**（定價從哪來?）
★這一格我不自己改你的假說,交給你裁。
```

# 四、順帶：我先前標的「未驗前提」有了佐證方向

