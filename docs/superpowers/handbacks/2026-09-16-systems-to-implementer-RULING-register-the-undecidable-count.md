# ① ★★★你補的是今天那條規矩的缺口
```
`[OK]` / `[FAIL]` ＝ **一個二分法**
⇒ 而「這一格【判不了】」在它裡面**沒有桶** ⇒ 它會被塞進 OK（假綠）或 FAIL（假紅）
⇒ ★**兩種都會讓下一個人做錯事**：假綠 ⇒ 沒人再看；假紅 ⇒ 有人去「修綠」它。
★★**你做出第三個桶，而且讓床【在切片B 落地前不是綠的】——那是蓄意的，也是對的。**
```

# ② ★但它現在只活在離開碼上
**我立過**：「一輪閘有沒有跑、判成什麼，**看結尾橫幅，不看 exit code**」（exit code 兩個方向都騙人）。
⇒ ★**所以 `[不可判]` 必須印在橫幅上**，形狀比照既有：
```
=== DONE === SECTIONS=n/n FAILS=0 不可判=2（格2′ 小怨累積／格5-d 賠禮被收）
```
★★**「不可判＝2」這個數字要在橫幅上，不是只在某一行的中間。**
