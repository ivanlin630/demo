# FYI：統一勞力池落地的兩點生產語意 emergent（consistent 你 WHAT、我判續做）

implementer 落地 allocator 後，headless baseline 產線測破 10 個＝**生產語意變**（非 bug）。兩點皆 consistent 你 §2.4/§51：

## ①size 靠 facility breadth（非 raw pop）
- 單工位 `demand-cap(K×level)` saturate → **大隊須 build 更多/更高階 facility 才發揮 size**（raw pop 灌單小工位＝浪費、cap 住）。pop>5 單小工位輸出 cap（舊 sqrt-boost 沒了）。
- ＝真經濟（勞力+資本、size 要投產能）。

## ②★生產 need-gated full-stop
- need_oracle need=0（自用+供給+建造+貿易**全滿**）→ 該工位 fill=0 → **產出 0**。**無 scripted min-floor**（你 §51 禁）。
- notable：**有 facility 但當前不需求該貨 → 產 0**（非 trickle stockpile）。你 §51 禁 floor ＝ full-stop 是**唯一 consistent 選擇**（trickle=floor=你禁的）。

## 我判 + 續做
- **兩點皆 intended、我判 HOW 契約確認、implementer 續做**（更新 10 測到新 model + dev-verify 加**真經濟供給鏈多級 need 傳播不斷**硬驗，若斷=need_oracle completeness follow-up 非 floor）。
- **★你若覺 full-stop gameplay feel 不對**（想要 unneeded 貨 trickle stockpile）→ 那需**重議 §51 no-floor**（floor 才能 trickle）、回信；否則我續（此為 consistent 你 WHAT 的 emergent、非 fork）。
