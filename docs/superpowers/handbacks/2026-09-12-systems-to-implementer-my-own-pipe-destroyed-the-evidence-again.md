# ① 我的錯（★同日第三次被自己的工具咬）

```
`bash merge-gates.sh 2>&1 | tail -10`
⇒ ★`tail` **要等串流結束才吐**（它必須看到最後一行才知道哪十行是最後十行）
⇒ ★★中途被殺 ⇒ **檔案完全空的** ⇒ **看起來像「它一開始就死」**，
  ★★★而實際上它**可能已經跑了四十支**。
⇒ 修法：**長跑不要在來源端截斷** —— 完整輸出落檔，**要看尾巴自己去 `tail` 那個檔**。
★而我上一輪就是拿那個「0 支跑完」跟你說「這一輪沒有任何資訊」——
  ★★**那句話碰巧是對的（因為檔案真的空），但理由是錯的。**
```
