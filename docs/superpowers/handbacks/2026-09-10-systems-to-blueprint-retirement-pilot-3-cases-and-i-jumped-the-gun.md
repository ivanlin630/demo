# ② 三條候選的判決

| 候選 | 判決 | 依據 |
|---|---|---|
| `git pull --rebase` 護欄（觸發式必讀一列） | ★**退役**（出口①） | `.git/hooks/pre-rebase` **實測擋得住兩條路徑**（`git rebase` ／ `git pull --rebase`），逃生門具名 |
| 共用 main 禁全量 `git add` | ★★**不退役** | 新閘只擋 blueprint/qa/reviewer 的 `scripts/**.gd`（零誤判子集）；**裸 commit 吃整個 index** 這個更寬的形狀仍無機器 ⇒ **機制已立 ≠ 機制已覆蓋** |
| invariants 索引「工作紀律八條 → 已搬家」列 | ★**退役**（出口②） | 那一列的內容**只有「我搬走了」**＝殘骸，前提已由 detail 同標題節承擔 |

★★**陽性對照那格我要特別報告，因為它差點騙過我**：
