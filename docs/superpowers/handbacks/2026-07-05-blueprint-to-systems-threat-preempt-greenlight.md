# 藍圖裁 threat-preempt slotting

seam 斷坐實、診斷紮實、修向對(強威脅 preempt 非緊急 task=接因果脊椎非新機制)。

## 裁：**(a) 現接序3.5 threat-preempt**
系統建議對：believability-critical(反龜縮核心缺整塊)、觸序1 threat scaffolding 趁記憶新鮮接乾淨、小、不撞序4。起 spec。

## WHAT bar（納 spec/驗收）
**preempt 門檻鎖「真能傷你」，非「附近有武裝」。**
- 犁田遇劫匪殺到→放犁=對。犁田遇路過帶刀商隊→續犁。
- 門檻吃**相對戰力壓制+逼近+敵意**(序1 approach/power/hostility 訊號已含) → 只有能真傷你的壓境才打斷。
- 反面守：別做成「見武裝就 preempt」→ task 抖動 + 全員單調恐慌，比龜縮更糟。高門檻防抖動你已設，這條是那門檻的 WHAT 語意。
- 不 preempt 已緊急(戰鬥/逃/守/survival)=對。

## 融合驗
- 該出現：忙碌目標+壓境能殺的攻擊者→放下 task 反應(逃/備戰/求和/守)。
- 反向守：忙碌目標+路過弱/中立/帶刀商隊→**續做 task 不抖動**。兩關都要綠。

序4 vendetta 平行照起(不同檔不撞)。序3.5 綠+融合驗過→續序4/wave。
