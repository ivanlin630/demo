# default 組成/健康 measure — 裁生成參數

管線推進報告+裁定請求。量測:gen 普查床（10 seeds×兩 config,gen-time 零 sim）+ 軌3 輸出挖掘。

## 量測結果

**① 狼候選荒（軌3「FORCE 狼=0」root）**
```
狼候選(獨立+武力+野心≥0.5)/seed: default 0.40 | warring 1.60
獨立隊 archetype: default 武5/商33/定13（65% 商業） | warring 武17/商65/定44
全 leader FORCE 佔比: 16-23%（R2 義氣負項後 disposition 分佈,商業 50-53% 常勝）
```
- default 開局 roving 獨立僅 2-4 隻 → **~半數世界抽不到一隻狼主角**。沙盒無 protagonist=大戲無從長。

**② 開局大饑荒=結構性（兩 config 同病）**
```
6 月 pop 收斂: default 197→83（42%） | warring 615→266（43%）
```
- **兩 config 收斂到同比例 ≈42-43%** = gen 初始 pop ≈ **承載力 2.3×**,前 3-4 月必大規模餓死潮（default 月 5-6 已穩=到承載力後健康）。非個別隊病、非 default 特有——**生成播了世界養不起的人口**。

## 待你裁（WHAT,生成參數）

**裁① 狼密度**:
- a) `roving_count_range` 拉高（default 2-4→6-10;warring 同步微調）——最小改,樂透票變多。
- b) 人格生成分佈調（野心/好戰右移 or disposition 權重）——影響全域 believability,動作大。
- c) 不調 gen,狼靠 runtime 湧現（succession/成長/爭位——但維度 6 未開,現實上狼只能靠 gen 抽）。
- 我傾向 **a**（局部旋鈕,不動人格 believability;b 動搖 R2 剛統一的分佈,c 現無管道）。

**裁② 開局饑荒**:
- a) 保留=「亂世開場,天下大餓」敘事（believable 但每局開場都是滅團潮;玩家/觀測者看到的前 3 月=死亡潮）。
- b) gen 初始 pop 調至承載力 ~1.2×（開局緊但不屠;die-off 改由戰爭/事件驅動非餓死潮）。
- c) 折中:pop 略降+開局糧倉 buffer（餓死潮延後變緩坡）。
- 這是開場體驗 WHAT,你裁。量測基礎:2.3× 是實測係數,調參我 seeded 校。
