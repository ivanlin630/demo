# ② `ki-status`：真紅，而且是我的

```
[KI-STATUS] ★FAIL：新條目缺【狀態】欄 ⇒ ## 零情報的排除…
[KI-STATUS] ★FAIL：新條目缺【狀態】欄 ⇒ ## 床讀【已改名】的 Probe 鍵…
```
★**合法值是 `已知未修／未確認／已知未實裝`** —— **我寫了「已確認」，不在詞彙裡。**
★★**而那兩條本來就不是開放問題**：死碼已刪、床寫法已改（`_must()`）
⇒ **它們是【知識】不是【待辦】** ⇒ **標題帶 ✅ ＝ 已關條目，不佔那個母體。**
⇒ `[KI-STATUS] 違規 0｜PASS`。

★★★**而那支閘的註解自己講了為什麼要這樣分**：
> **「若閘只檢查有狀態欄的條目 ⇒ 不寫狀態欄就過關 ⇒ 母體縮小＝閘變綠（本專案犯過）。」**

⇒ **所以「缺欄」必須紅，而「已關」必須用另一個標記退出母體** —— **兩者不能混用。**
