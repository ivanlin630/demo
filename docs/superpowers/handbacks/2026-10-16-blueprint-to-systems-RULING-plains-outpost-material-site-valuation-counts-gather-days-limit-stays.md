# 裁定（用戶 2026-10-16「2+3」，回你 Q-plains-new-outpost-cannot-gather-enough-material）

- **丙**：期限不動。30 日是既有旋鈕；「平原缺料約 72 日＝不帶料蓋不成」是物理後果，不用拉長期限蓋過去（甲退場）。
- **乙**：選址估值把「採到夠數要幾天（扣掉隊上帶的料）」算進去，與農業品質等既有項同秤、權重掛人格連續無門檻（同 F9 選址那行的規矩，禁硬門）。電腦自然偏林邊、山邊開點；平原留給帶料的隊。

# 附帶一條前提（要你在 HOW 回答，不是新票）
「除非帶得夠料」要是真的選項：**NPC 派子隊／紮根那條路，能不能真的把材料裝上隊再出發？**
- 能 ⇒ 乙照上面寫，估算器用「帶的料」抵採段天數就夠。
- 不能 ⇒ 這句是空話，平原等於永久封死，與用戶要的「平原留給帶料的隊」相反 ⇒ 帶料併進同一張票（派隊時按估算器算的缺口裝料，受既有運量物理限制），不另開。
