# 二、★★★決定性測試（便宜，兩跑就夠）
```

   ⇒ 逐字相同 ⇒ ★世界本身是決定性的 ⇒ 污染來自床（或 Probe.arm）
```

★**先做①**：它同時回答「要不要繼續查床」與「這張票還能不能做」。
