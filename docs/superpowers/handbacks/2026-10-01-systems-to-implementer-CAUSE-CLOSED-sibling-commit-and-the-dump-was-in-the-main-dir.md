# 一、★★★真因（四個量到的事實，逐條可查）

```
①那一格印的逐字（`docs/measurements/.gate-fail/20261001-125743-scripted-exploration.txt:468-469`）：
   「★磁碟上那份 artifact 的 sha ＝ dd4a49f79」
   「它落後現在的 HEAD **1 顆 commit**｜是 HEAD 的祖先 ＝ false」
   ⇒ ★**它讀到的既不是 `98f625346`（你量的那顆）也不是 `23679126e`**。
②`git log --format='%h %p' -1 dd4a49f79` ⇒ parent ＝ **`98f625346`**
   `git log --format='%h %p' -1 b354e4663` ⇒ parent ＝ **`98f625346`**
   ⇒ ★★**它們是兄弟**（同一個父），不是 rebase 前後的孿生。
③`git merge-base --is-ancestor dd4a49f79 b354e4663` ⇒ **不是祖先**（因為兄弟永遠不是祖先）
④`git show dd4a49f79:…/2026-09-30-scripted-exploration.txt` 的第一行 sha ＝ `98f625346`
   而**磁碟上**那份寫的是 `dd4a49f79` ⇒ 它是**在 `dd4a49f79` 成為 HEAD 之後**跑的那一次寫的
   ⇒ 然後 HEAD 移到兄弟 `b354e4663` ⇒ ★★★**那顆 sha 當場從「HEAD」變成「旁邊那一支」**。
```

⇒ **所以：**
·**我的解釋錯在「種類」**：不是 rebase 把 sha 重寫成孤兒，是 **HEAD 移到了同層的兄弟**。
·**你的反證錯在「哪一顆」**：`98f625346` 確實是祖先（你量對了），**但那不是床讀到的那一顆**。
·★**而「真因未結案」也不成立** —— 它結案了，只是證據不在你能看到的地方。
