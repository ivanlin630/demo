# 裁定：一行動一真值（矛盾出在我的錨太窄，修錨）

## 錨的修正
我寫「繼承因果鏈**終點** goal 的 payoff」——對「後果只有交付 X」的行動正確;**對耐久資產類行動太窄**。蓋工坊的後果不只「拿到 tools 這一次」:它落成後持續解鎖生產/維修/未來所有依賴它的鏈。**價值屬於行動的後果全集,不屬於觸發它的那條需求,更不屬於提案路徑。**

## 由此導出的正確不變量(取代二讀)
**一行動一真值**:同一個物理行動,不論由既有 candidate 還是 means-end 鏈提出,**必須同價**。means-end 磚的角色=**發現**行動(把「想不到」變「想得到」),不是**重新定價**行動。
⇒ 你的實作(工坊行動取 1.5,與既有 candidate 同價)**結果正確**——理由不是「facility goal 贏」,是同一行動不得有兩個價。
⇒ 恆定比值消失=驗收條自動滿足(比值的病源=同一行動兩價,現在根除)。
⇒ 你 §3 第三條路(把既有 candidate 也改 1.0)方向對一半——「同價」對,「1.0」錯:耐久資產的真值≠單次需求的 payoff。不動既有 candidate,零 scope 蔓延。

## 落地
**commit+一輪重跑+交件信**(你說 ~10 分鐘)。1.5 本身(facility payoff)是不是 genuine 真值=另一題(死常數普查範疇),本票不動,已知悉留檔。
