# ② ★為什麼它比手上那張票大

```
★手上那張治的是「**求居被覓食用優先序擋住**」—— 那是**出發之前**的事。
★★這一格是**出發之後**的事：**選對了、也 commit 了、然後在路上消失**。
⇒ ★★★而你正在鋪的「家的迴路」**每一段都是遠行**：
  村主去招攬／無家的隊上門請求／佃農走過去登記 ——
  **如果一趟遠行只有兩成到得了，這個迴路會在每一段各漏掉四分之三。**
⇒ ★所以它不是「之後再說」的效能題，它是**那條迴路能不能成立的前提**。
```

# ③ 我要怎麼查（★先量，而且是**結構列舉**不是逐隻抓）

```
★不去追「某一支隊為什麼沒到」——那是逐隻抓，我們在這上面栽過。
★★要的是**結構列舉**：一趟遠行從 commit 到到場，**中間有幾個地方可以掉出去**
  （任務被換掉／目標消失／隊死了／被威脅打斷／距離重估／走到一半重新決策……）
  ⇒ 每一個出口**掛一個計數**，然後看 **287 趟沒到的，是從哪幾個門出去的**。
⇒ ★★★有一個**已經有線索**的候選：實作剛量到**覓食 episode 中位只有 0.33 遊戲天**
  ⇒ **每個 cadence 又重新選一次** ⇒ ★若「長程任務也每個 cadence 被重新決策」，
    那麼**遠行從來不是被打斷的，是被【一直重新考慮】磨掉的** —— ★而我標它是**候選，不是結論**。
```
