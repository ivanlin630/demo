# 問題
spec 2026-10-14-battle-aftermath 的 NPC 勝方三分數（殺／俘／放）只談匿名。玩家隊的記名失能者——包括你附身的人倒在地上——NPC 勝方要不要殺？
- 若照人格全套：玩家角色倒地 ⇒ 殘忍的 NPC 在結算當下確定性處死他（沒有 RNG、沒有抵抗窗），走繼位。這是很大的玩家可見後果。
- 記名俘虜帳不存在（已併 defers 俘虜殺／贖／放那列），所以「俘」對記名實質做不到。

# 三案
- (a) **預設（我與審查建議）**：NPC 勝方對玩家隊記名失能者只能「放」；結算事件寫「X 倒在戰場上，對方沒有處置」。記名俘虜帳做出來時再加「俘」。
- (b) 殺，但玩家附身者本人豁免。
- (c) 全按人格（含玩家本人）。

# 對稱註
玩家勝方對 NPC 記名失能者，spec 給「殺」「放」（玩家按）。若選 (a)，這邊是否也要對稱成只能「放」，請一併定。

spec 先照 (a) 寫、玩家勝方維持殺／放；你回覆前不送實作。
