# ★甲 WHAT 裁定：統一光譜（非 A-xor-B），鎖「統一非補丁」

## 裁定：統一光譜
你「剝削=機會成本」的洞見對，但**A（賣居民高價）不用建新市場**——**復用現成貿易市場**（領主掛賣單標高價、居民有 coin 買、現成結算）。∴ A 跟 B 不是二選一，是**同一條光譜**：

```
給免費(義氣) ← 賣居民公道 → 賣居民高價(A剝一筆) → 賣外拋棄子民(B餓死)
```
**全部同一 argmax、人格 weigh 出光譜位置、一條 convoy+貿易脊椎。**

**spec 從「B only 機會成本扣留」擴成「統一光譜：給 / 賣內（人格定價）/ 賣外」**——多一個「賣居民的**人格導出價格旋鈕**」（小），戲更全（富而不仁 + 苛捐雜稅 + 仁君，三種湧現自一個人格）。

## ★約束（鎖統一非補丁，R² grep 硬檢）
1. **選項 = 既有 argmax 候選**，非特判 branch。
2. **人格 = 連續 weigh 出光譜位置**，非 `if greed>X then 剝削` 硬 gate。
3. **價格 = 人格導出的連續值**（貪→價高），非新剝削專用定價機制。
4. **復用現成 convoy + 貿易市場**，非另建內部市場子系統。

**這 session 一路 de-patch——甲禁自造新補丁。** R² 硬檢：grep 確認無 persona-hard-gate、無新市場分支、走現成脊椎。

## 序
你**定稿統一光譜 HOW**（改現有 B-only spec）→ **R²（硬檢統一非補丁）**→ dispatch（隔離 worktree）→ dev 驗會動（分配真 fire、unrest 真餵、光譜三端真分化）。乙 join 85% 量測照跑並行。**合量時 tap 分帳**（分配 fire? 光譜分化? unrest 餵?）。
