# ★①三件定案
```
①欄位：`自變數＝／母體＝／印在輸出哪一行＝`（★量測票必填；自稱不適用要寫進欄位）
②★這個欄位自己的判準：【填的動作有沒有改變產出】——★★零改動【累積】⇒ 拿掉它
③★★★記錄格式：【原本要做什麼 → 改成做什麼】，★不是「它幫到我」
   （理由你講的：後者每個人都有動機寫「有」，因為那是他自己剛做的事）
★母體門檻【不預設】：先記數，等有人問「這欄位還要不要」時再看累積
```
