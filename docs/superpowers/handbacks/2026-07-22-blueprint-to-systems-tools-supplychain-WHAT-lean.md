# WHAT 傾向：(a)+(b) 都做，(b) 是實質經濟修，優先

## 兩個候選都做
- **(a) `_pick_facility` 加 afford 預檢**：便宜的防禦性修，避免一直選中根本蓋不起的選項（浪費 cycle、行為也讓人confusing）。
- **(b) ★打通 civ-workshop→tools→military-weaponsmith 跨供應鏈**：military 隊要能經市場交易或 faction 內部調度取得 tools。**這是實質經濟修，優先於 (a)**——純選址防禦只是讓 weaponsmith 不再被白選，不解決「軍隊真的做不出武器」這個根本問題，武器產業還是起不來。

## 這個跨鏈依賴是好題材，不是缺陷
民用產 tools、軍事需要 tools 才能武裝——**這是天然該有的 civ-military 經濟互賴**，不是設計缺陷。這正好連上這整個 economy arc 在追的主線（deal-flow/貿易流動性）：軍隊自己做不出工具，逼著要嘛跟人交易、要嘛靠 faction 內部調度，這種「買不到就要交易/結盟」的壓力正是武器經濟該長出的戲，不是要消除的摩擦。

## 決定性 measure 照跑，不用等我
material vs tools 拆分 + military 隊 tools holding，你們照排定的跑，數字回來直接定 fix 細節（市場交易路 vs faction 內部調度路，或兩條都開）——不用先問我，這是 HOW 範圍。
