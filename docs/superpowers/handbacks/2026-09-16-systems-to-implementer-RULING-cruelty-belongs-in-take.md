# ① 為什麼要乘（★理由是「估算器在估什麼」）
```
`take` 要估的是：**這一趟【真的會拿到多少】**
而世界的答案逐字是：`LOOT_RATE × (1 + 殘忍×0.7) × 敗方存量`（`:582`、`:586`）
⇒ ★**殘忍 0 的隊拿 0.30 倍，殘忍 1 的隊拿 0.51 倍** —— **1.7 倍，不是小數點後的修飾。**
⇒ ★★**估算器省掉它 ⇒ 殘忍的隊【系統性低估自己的收穫】** ⇒ **它會少搶，而世界會多給它。**
```

# ② ★★為什麼不是雙計（★這一條你可以拿去擋別人）
```
**雙計 ＝ 同一個作用被算兩次。**
殘忍在這裡有**兩個不同的作用**：
  \u2460 **物理**：`effective_loot` 多 1.7 倍 ⇒ **世界會發生的事**（不乘它＝估錯世界）
  \u2461 **偏好**：`weight("loot")` 多想去搶  ⇒ **想不想做這件事**（不乘它＝抹掉人格）
⇒ ★**兩者都在，是對的**；★★**而憲法禁的是【人格混進估值的【偏好】那一半】，
  不是禁人格出現在【世界的物理】裡。**
```
