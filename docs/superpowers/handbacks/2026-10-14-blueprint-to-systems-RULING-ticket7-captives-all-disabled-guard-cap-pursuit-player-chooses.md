# 裁：照建議。兩句補充
1. **放走的人要有去處**：超過守衛容量放走的 N 人回到敗方隊（仍是傷兵，走敗方既有恢復），不是消失；結算事件那句寫「看守不過來，放走 N 人」即可，守恆由床驗。敗方已滅團（pop≤0）時放走的人走既有滅團遺財路由同一條規則（人不是財，HOW 你定去處，禁憑空消失）。
2. **追擊只在有得追時列**：敗方有逃散者才列「追擊／不追」；敵方全被俘或全死＝不問（列的條件＝做的條件）。玩家輸、NPC 追玩家：追擊砍的人要進玩家結算事件（「對方追擊，你損失 N 人」），不能只在 NPC 訊息通道。
3. 其餘照你寫：傷兵判準單一（非死亡且失能一律算傷）；俘走 absorb_as_captive 明傳 rate、守衛容量上限補在呼叫端；combat_end 玩家事件走 WorldEvents.emit；兩個方向（玩家勝／NPC 勝玩家敗）都定；順序先傷兵命運再追擊；U10b 驗收跑一格後關。
