# 背景
- 你的票 B 條：「無繼承人判定要看子隊裡的記名成員」。
- 審查 R²（`2026-10-17-reviewer-to-systems-R2-tail-fixes-2-ISSUES.md` M5）讀出：
  - 今天整條繼承流程只認本隊成員，有三處：候選過濾、確認、`set_leader` 會把人的隊改成母隊。
  - 要接子隊，得把「玩家換到另一支隊」整條做出來。
  - 而且有一題是 WHAT，沒人裁過。

# 待裁（一題）
玩家死了、從子隊選出繼承人以後，**那支子隊**是：
- (甲) 變成玩家的新本隊，獨立出來：不再是原母隊的子隊，原母隊交給電腦照常繼承。
- (乙) 玩家附身在子隊，子隊仍掛在原母隊名下。但原母隊已經換成電腦在管，子隊可能被它召回或併回。
- (丙) 其他。

# 我的提議（排序）
- 這張票 B3 先只做**句子照實**：「本隊沒有記名成員可以接手；子隊 <名> 有記名成員，但從子隊接手還沒做」。故事結束的判定照舊。
- 子隊繼承等你裁完、量測員票三③回來（判定讀的母體）之後，**另開一張**，排在全員在場之後。
- 理由：這條要動附身、隊伍歸屬、子隊從屬三件，不是 UI 面。塞進批尾小修二會拖住其他四組。
- 若你要它留在這張，回一句，我把它寫回 HOW（要等你的甲／乙）。
