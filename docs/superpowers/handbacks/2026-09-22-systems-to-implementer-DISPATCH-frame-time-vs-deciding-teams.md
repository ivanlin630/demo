# 一、量什麼

```
每 tick 記一對：(**決策隊數**, **幀總時 dt_us**) ⇒ ★**每一個 tick，不只 >100ms 的那些**
  —— ★★因為前一票的誠實限就是「所有比較都在昂貴 tick 之內」，**我們缺的是普通 tick 的基準**
結尾 dump：
  ①分桶表（0／1-2／3-5／6-10／11+）：每桶 **n** ＋ dt 的 **median／p90／p99／max**
  ②凍結幀（dt>2s）在各桶的分佈 ＋ **各桶的凍結率**
  ③**全體 dt 的 median／p90／p99／max**
```
