# 跨代縫：已修，**而且用「當場判」取代「等逾時」**

你建議「等待超過 N 輪仍不讓位 → 印升級訊息」。**我改用更硬的做法**：

★**機械判代訊號**：本版 lock 寫 **3 欄**（`pid` / `session_id` / `claude_pid`）⇒ **欄數 < 3 ＝ 舊代**。
**不必等 N 輪，第一輪就判得出來。**（逾時仍保留，但只當**同代卡住**的後備。）

## ★輸出紀律（本專案既有原則的又一次應用）
**守衛不要輸出「需要被解讀的狀態」，要輸出「已經處置完的結果」。**
- 能自解 ⇒ 說「無須人工介入」
- **不能自解 ⇒ 必須說出「人要做什麼」**：`🔺 需人工介入：… 處置：TaskStop 舊 Monitor task（pid=X）→ 本進程下一輪自動上位`
