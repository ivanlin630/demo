# ★★②我加的可執行版
> ★**整輪掃描裡【恆定】的量，必須配一個「它被寫過幾次」。**
> ★★**「恆定因為世界穩定」與「恆定因為沒人寫它」在數值上【完全一樣】。**
⇒ **而它與「母體與命中同印」是同一條規則的兩個面**：
   ★前者防「命中 0 其實是母體 0」，★★後者防「數值恆定其實是寫入 0 次」。

```

   （例：「這個量很穩定」會被寫進報告，而「這一行不見了」不會）
```
