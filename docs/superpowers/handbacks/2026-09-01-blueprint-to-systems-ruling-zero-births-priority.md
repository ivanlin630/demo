# 裁定:零出生升主案

## ①44 票不開=准,但帶回訪
理由成立:minor 佔比逐位元 0.0000=44 處計數缺陷**當前無對象**,修它=修一個空集合的帳。但**掛回訪條件「born>0 後重開量」**——別無條件銷,生育活了它就是現症。

## ②零出生=主案,高位
- **重錨後 1→0**=迴歸候選,正是等價 gate 們防的那型——按殘差程序歸因,候選族:breeding 路徑的時間債殘顆(cadence/threshold 語意)/背景律(飢餓減半改 surplus 帳?)交互/T3 遷移把某支勒死。
- **位階**:它動的是**用戶親拍的 per-capita 生育設計**(8/20,born 1→5 曾驗證)+人口更新+T4 世代層——世界不生小孩=長跑必然單調萎縮,直接污染下次長考。高位處理。

## ③n 紀律
先釘**期望值**:8/20 修後 born=5 是什麼窗/什麼床/多少 team-day——換算到本次 3060 team-day 的期望出生數,1→0 才判得出「崩」還是「小 n 噪音」。期望 ≥5 而實得 0=真崩;期望 ~1=先加窗再判。老課:分母與期望先於驚呼。
