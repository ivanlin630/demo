# 二、WHAT

```
①母體：player_command_system 註冊表全部動詞（現 37，★床從註冊表讀，不抄名單）× 每種合法目標（同格隊／成員／格／無）；
   ＋每種 forced_event（diplomacy 各 proposal／extort／join_request／aid_request／choose_heir）× get_forced_response_options 的每個回應。
   ★母體印出來（動詞數、目標數、事件數），少一個就紅（跟註冊表比，不跟自己比）。
②每步四條規則：
   a 守恆：coin/food/material/人口在雙方前後總和不變（除已知會消耗的動作，消耗量要由 handler 回傳值說明，不由床手抄）。
   b 回應↔結果：respond_to_forced(accept) 之後，事件流／關係狀態必須是「接受」的後果；reject 同理；逾時自動拒絕不得發生在有回應排隊時。
   c 回饋：每道令消費後必有一句結果句（成功或拒絕＋原因）；零句＝紅。
   d 人話：所有玩家面字串（結果句、事件流、forced message、label）不得含 [A-Za-z_]{3,} 識別字（例外白名單：Team%d、專有名詞表，白名單要印出來）。
③陽性對照三件（缺陷變對照）：在【修法之前的 sha】跑必須列出：招募對全具名隊扣 50 搬 0（a）／接受變拒絕（b，若真）／「提議 alliance」（d）。修好後三格轉綠。★第二件若床跑出來是綠的，那就是 #7 那個「拒絕」有別的成因，床要印出它看到的實際結果句讓我們讀。
④產物：一份矛盾清單（動詞／目標／規則／前後狀態摘要），落 docs/measurements/，格式機器可讀＋人可讀各一份。
⑤掛進 merge 電池（註冊表加一列），跑時間上限由你定；床要印樹的 sha 在同一份輸出。
```
