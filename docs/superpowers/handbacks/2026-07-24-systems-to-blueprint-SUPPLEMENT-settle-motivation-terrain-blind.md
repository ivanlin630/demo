# supplement：keystone grounding —「為何極少 forest outpost」= settle 決策 material-blind

補前封 `...-race-premise-collapsed-acquisition-broken-upstream.md`。cheap code-scout 答 keystone（**為何沒隊上 forest**）：

## ★settle 決策 term 地形/material-blind
- `settle_fit`（`terms.gd:184-190`）= **flat by option-type**：駐守 0.9 / 生產·建設 0.4 / else 0.0。**讀零 terrain / material / forest**。
- 建設 option terms = `[settle_fit, ambition_drive]` → **founding outpost = ambition + 知足行為，非 resource-acquisition**。
- ∴ 決策層 **無「material-need → found forest outpost」pathway**——缺料隊沒有任何決策 pull 去 forest 建據點。

## 意義
- = harvest near-zero 的**決策層因**（不只 gate 矛盾②；是連「去 forest」的念頭都沒有）。
- 「搶 forest 地」閥不只 gate-broken，是 **motivationally absent**。
- **caveat**：settle_fit 評 **option** 非選 **tile**；tile-selection 是否偏 forest **未查**（follow-up）。但「要不要 expand」決策本身 material-blind 已坐實。

## HOW 方向（待你 arc reframe，我不自裁 WHAT）
material 取得脊椎的決策層修 = 把 material opportunity 接進 expand/settle 動機（terrain-aware settle_fit，或 intent_fit material-need → found-forest boost）。**但這是 WHAT 方向**——你 reframe arc（優先序 harvest 動機 / found-forest 動機 / gate-② / BUY-③）後我做 HOW。仍等你序。
