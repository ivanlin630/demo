# 一、怎麼走到這一格的（30 秒）

絕境 22 筆機會裡 16 筆沒上場，**最大單一原因＝位置情報過期**（`no_belief_pos` 6/10）。
那一票的修法是：位置改吃 last-known ＋ 年齡，**年齡進【價值】不進【門】**（舊情報打折，不是直接丟掉）。

折扣的分母是「它三天能跑多遠」。**我 spec 寫成「傳目標的 team 去算速度」——被 implementer 抓到那會讀 god-view**
（那支函式內部讀目標 live 的地形/疲勞/載重）⇒ 已撤回，改成**不讀任何隊狀態的基準旅行者**。

# 二、★★★你要裁的那一句

現在世界裡：**所有目標同一個速度** ⇒
> 「目標跑得快 ⇒ 舊情報更不值錢」在**函式裡成立、在世界裡不成立**。

★**具體差別**（這是我認為你會在意的）：
- **不開** ⇒ 一支**駐村不動的村隊**和一支**行軍中的商隊**，它們的舊位置情報**掉價一樣快**。
- **開** ⇒ 偵查會自然偏向「情報容易過期的目標」，而定居目標的舊情報可以長期沿用。
  ★而它連帶解鎖另一格：`BELIEF_STALE_TICKS = 3 天`（自己標著 `TEST VALUE`）現在是**全域死常數**，
  我已裁「該物理化」，**而物理化的分母正好卡在這裡**（不能用目標 live，只能用 belief）。
