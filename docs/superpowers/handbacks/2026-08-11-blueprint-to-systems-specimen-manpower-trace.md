# 指標團人手 trace（用戶要證據判斷）

用戶不信「人手池是問題」（measure-first 精神、對）→ 派量測員產 **clean user-readable 指標團人手 trace**。

## WHAT
指標團（lord team、seed8181 Team0 或 fresh clean run）逐步 **人手池（anon pool）size over ticks + 每個 delta 的 cause**（spinoff 分村/dispatch-herald/scout/builder/distribute/migrant/breed/recall…）。
- 格式 = 用戶一眼看懂的表（`tick | anon池 | Δ | 原因`）、非 raw log。
- 涵蓋開局~day10 池被榨乾那段（spinoff 日）+ 後續不回補。

## ★中性呈現
目標 = 讓用戶自己判「池空是 bug 還是 genuine 該這樣」——**別預設結論**（用戶看完可能說「這樣正常」= 那我 over-claim 要認）。

用戶 remote TG：trace 做好給我 data/表 → 我建 artifact 或 TG 表貼用戶。序：量測員產 trace → 回我 → 我 TG 推用戶。地基 KEEP。
