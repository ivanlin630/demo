# ★裁定下來了：**`payoff` ＝ 繼承【所服務 goal】的 `payoff`**

> **「為了取得 X 先做 Y」的價值 ＝ 取得 X 的價值。**
⇒ ★**與既有 candidate 打平，勝負交給 `delay`／`depth`／成本去分。**

## ★★★而鏈的代價：**只計價一次**
| ★**准** | ★**禁** |
|---|---|
| **真實延遲** → 走 `delay` 折現 | ★★**另設 per-step 折價常數** |
| **真實資源** → 走成本端 | |

★**禁的理由兩條，缺一都成立**：
1. ★**手抄物理** —— **「每多一層打幾折」是憑空數字，不從任何真實量導出。**
2. ★★★**雙重計價** —— **鏈的長度【已經】透過 `delay` 進了折現；再加 per-step 折價 ＝ 同一成本算兩次。**
   ★★**而兩次是【相乘】的 ⇒ 多層鏈會被指數性地錯殺。**

★**已寫進 spec `§9`（含我自承那是 §4 的缺口）。**
