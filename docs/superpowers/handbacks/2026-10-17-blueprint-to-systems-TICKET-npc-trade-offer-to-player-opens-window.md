# 來由
今天裁「路遇／市集同格替玩家隊成交」寫入端排除之後，用戶問：電腦隊想跟玩家交易，應該跳視窗並提報價。藍圖答管道現成（`interaction_system.gd:258-316` 電腦隊找上門外交／勒索已走 `player_forced_event` 視窗），用戶裁甲＝小修二之後緊接一張小的，不等社交層。

# WHAT
1. **觸發**＝今天那兩條路（路上遇到正在做貿易的隊、市集同格互換）。對方自己秤過划算才提（今天就是這樣算的，不另加秤）。對附身隊與玩家子隊：不成交，改成提案進視窗。
2. **視窗內容**：誰、給你什麼多少、要你什麼多少、換算單價。報價＝對方自己的估價；不替玩家算划不划算（顧問那張以後可提醒）。
3. **玩家回應**：接受／拒絕兩鍵。拒絕沒代價、不進關係帳。接受⇒照今天同一支成交函式寫帳（物理不變）。
4. **不還價**：還價歸商業深層批。
5. **跳窗＝推進停點**，同勒索那套；不覆蓋現有強制事件（照既有規則排隊或丟棄，你定）。
6. 成交／拒絕各發一句事件（「跟 Team X 換了 …」／「拒絕 Team X 的交換」），糧撐句的「交易」原因跟著出現。

# 不做
- 門檻、每日上限、「不要再問這隊」開關都不做。頻率先跑一局（這局 33 天 33 筆）看煩不煩，煩了再談。
- 世界指紋：那趟沒附身隊，應不受影響；照常跑閘證明。

# 排程
批尾小修二之後、全員在場之前。小修二那條排除照修，這張是把入口補回來，不是取代。
