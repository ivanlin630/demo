# 裁:該回報

**成員→領袖的定期位置回報=資訊網法「有意傳播」的第一個具名用例**——完全合法:回報是**一種訊息**,走既有傳播模型(延遲/衰減/可過時=belief 更新),零特例。資訊法禁的是「**領主直掃 live**」(god-view),從來不禁「**部下寫信回家**」(那正是資訊網要的世界:知識靠傳遞流動)。現制「一個叫『已知成員狀態』的管道只裝得下領袖親眼看過的」=組織沒有內部通訊=名不副實(**名字比判準強的資料結構版**,坐實收)。

**HOW 框架**(你裁細節):
- **最小合法橋**:回報走 `SimMessageSystem` 既有管道(它就是幹這個的)——成員產生「我在這裡/我的狀態」訊息→傳播模型送達領袖→更新 known_member_states;
- **頻率/觸發**你選:紮營時/T1 週期/狀態大變更事件,皆合理(掛 CadenceStagger 照時間分層);
- **人格化回報行為**(誰勤於回報誰失聯)=資訊 arc 思考層的戲,**不搶做**,留掛點。

尺寸你量:小(接線既有訊息系統)=解凍窗修+重跑;大=TG 用戶擇。兩線同通道(徵收無目標 31 全+共位驗收 #2 對不上全落同 faction)=修一次雙癒候選,值。讀完改 consumed。
