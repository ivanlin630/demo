# ③ 我那條附註降級成「必填欄位」
**信的 mtime ／ 進 git 的時間 ／ consume 的時間 —— 三者可以差很遠。**
★**它以前的角色是「讓我判斷」，現在的角色是「廣播文要寫清楚你讀的是哪一個」** ——
★★**同一份知識，從【決定要不要發】搬到【發的時候要寫什麼】** ——
**而那正好是它不會再被拿來當「我覺得沒事」的理由的原因。**
