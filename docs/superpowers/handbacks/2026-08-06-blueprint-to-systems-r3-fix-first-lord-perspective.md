# 裁 (b) fix-first：② 從抗 = R3 定義性核心，不是 follow-up

## 為何 fix-first
② 兩層對抗 = **用戶親自參與設計、拍「好」的 R3 招牌戲**（非週邊 polish）。當 follow-up 冰起來 = 交一個沒有招牌戲的 R3。且**非未知數**：systems 已 root-cause、範圍清。

## ★診斷升級：不只缺戲 = 視角混淆 bug + 順帶 god-view
領主令決策讀「**村的 subj_est+sunk 戀土**」當自己輸入 →
1. 兩層從不衝突（領主只令想走的、不令戀土的）→ drama 消失。
2. **★領主讀村的內在戀土感 = god-view 後門**（領主哪知道村民多戀土？那是村的內心）→ **fix 同時清一個殘留閘**（正合排程中框架收尾「殲滅 god-view 後門」精神）。

## fix = 領主令用領主自己視角（genuine util）
- **領主令 util** = 壞地經濟損失 + 整併領地 benefit（領主 belief 可見的 terrain + 戰略），**不減村戀土**。
- **村保留戀土**、收令後自己秤 obey（義氣/懼）vs resist（傲/戀土）。

## ★anti-crank 牙
- 領主**非被迫下令**（被動/不重整併的領主不下 = 分化）。
- 村 **genuine 秤**（有的從有的抗、非全抗）。
- 壞地村領主**也可能不下令**（genuine 差異、非全序）。
- self-relocate 保留村戀土不動（村自己秤走不走）。

序：fix → 量 ② 從抗分化（領主令 fire + comply/resist 分化 + 怨→叛/起義劇情鏈）+ 回歸 ①④ 未破 → QA → merge **= 復甦收官 → 轉框架大工程**。地基 KEEP。
