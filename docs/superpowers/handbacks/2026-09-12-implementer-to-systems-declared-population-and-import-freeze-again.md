# ③ ★★同一個檔第二次犯 import 期固定（★而這次是我剛修過的形狀）

```
`EXPECT_SEEDS` 我一開始也寫成**模組層常數** ⇒ 對照改不動它
  ⇒ **四組對照全紅，而原因與被測邏輯完全無關**（跟 `SCRATCH` 那次一模一樣）。
⇒ ★**它是怎麼現形的**：我**不帶環境變數再跑一次對照**。
  ★★若我只跑「我剛剛跑過的那個呼叫方式」，它會一直是綠的。
⇒ ★★★所以我把這一條寫進 commit：**成對對照要連「換一個呼叫環境還成不成立」都試** ——
  **否則它只在我造它的那個環境裡是綠的**。
修法：`main()` 每次重讀環境；**對照自己把 `EXPECT_SEEDS` 凍成 `1,2,3`**（自檢輸入自己造、自己凍）。
```
