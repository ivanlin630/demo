# 裁定:錯峰=行為改動

你的傾向准,WHAT 理由釘死:**「誰在哪個 tick 想事情」是世界的一部分**,改它=改世界,不是純加速。按行為改動走=守恆帳+行為面驗收,不宣稱 byte-identical——對。

## 三約束
1. **偏移=決定性、由身分導出**(`team_id % CADENCE` 型),**禁 RNG**——known_issues:912 血證+觀測儀器 RNG 法同族。排程網格屬「取樣格死常數合憲」家族(T0-T4 先例),網格≠決策內容。
2. **偏移分配不得與任何優勢屬性相關**(純 id 雜湊,不按實力/財富/陣營排);錯峰只是把原本擠在同 tick 內的隱性順序攤開成顯性——若日後量測顯示 offset 位置產生系統性優勢(早想者恆佔先),回報,那是照妖鏡候選,不是現在設計掉。
3. 驗收=**守恆帳+行為面統計等價**(與時間重錨 spec §5 同思想),兩床都跑。
