# 定位釘清：空間=新維度 / 頻率=既有不變量的閘

補 `tick-resolution-60`。用戶要分清剛提的兩件事在統一框架的定位，免誤解。

## ① 空間尺度 = 矩陣新維度（升格，非一次性調參）
- 病：「一格多大」散三處各自定義（遭遇戰 24 格內切 / 據點間距 2 / 移動 240tick）= **空間版「時間常數污染」**（同概念多處各寫）。
- **矩陣加第二個新維度「空間尺度」**（配「時間尺度」那格）：
  - **單一來源**：遭遇戰動作粒度=錨 → 一格真實距離 → 據點密度/min_spacing/地圖 radius 全連動導出。
  - **空間不變量**（同時間 family，納 invariants）：凡空間量必從遭遇戰錨導出，不各自硬編。
  - **強制閘**：掃裸硬編的地圖大小/據點間距/移動成本（繞骨架）= fail。
- → **永久統一格**，這次 TICKS_PER_HOUR 調 + 據點反推只是它的首次落地，非結束。

## ② 運算頻率 = 非維度，是既有兩不變量的強制閘檢查
- 「頻率」不是散在各處的概念，沒有「頻率維度」要統一。它是**既有硬不變量的驗證面**：
  - **per-tick 有界不變量**（引擎契約）：60 會不會讓某些東西 ×6 運算撞有界線。
  - **時間量必導出不變量**（時間三不變量之一）：裸 tick 常數（PRISONER_CHECK=5）繞了 cadence 導出 = **本就是這條不變量的違反者**。
- → **不開新維度**，歸強制閘：
  - 裸 tick 常數導出 = 時間強制閘的直接應用（掃它=閘生效）。
  - 每 tick 無條件迴圈 = per-tick 有界的守門對象。
- 「運算頻率安全證」= 這兩條既有不變量的聯合執行，非新工程概念。

## 一句
```
空間尺度 = 新維度,進矩陣（時間的空間孿生:單一來源+不變量+閘,永久）
運算頻率 = 非維度,是 per-tick有界 + 時間量必導出 兩既有不變量的閘檢查
         裸tick常數 = 時間閘該抓的違規,掃它=閘生效,不是開新格
```

## 對系統的意涵（避免兩種誤解）
- **別**把空間尺度當「這次調完就算」——它是矩陣永久格，強制閘要立起來擋未來裸硬編。
- **別**把運算頻率當「要統一的新維度」——它沒有維度，就是跑既有兩不變量的閘。省得多開一格空轉。

矩陣維度更新：實體×領域 + **時間尺度**（前補）+ **空間尺度**（本封）。這兩個是「跨切」維度（不綁單一實體），跟意圖/belief/state/人力/互動那些領域同級。

其餘照 tick-resolution handback（全 tick 表 + 頻率安全掃 + 裸常數導出 + 取整驗 + 據點反推）+ 眼前 A2/carrier/QA 不擋。
