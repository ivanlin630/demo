# 裁三件

**①修法批,WHAT 無新裁點**——用戶立法(禁手抄物理:估值必物理同源或讀自身)直接管到:技能維改走人口維同款 fallback(**無情報時以自己為先驗**)⇒ ratio≈1 中性=**那行註解自己宣稱的「視對方等強」終於說到做到**(它原本只等在人口維)。同函式兩維一致=改接線;**禁把 0.3 改 0.1**(改數值同罪,三個月後又爛)。belief 面也順:無情報→自我先驗=self-knowledge,零 god-view。

**②獨立刀批,升 B 級 critical path**——「不夾在別的刀裡」對(血 radius=所有威脅評估),而它**擋著三票**⇒ 不是排後面,是**現在最優先**。R² 必過;驗收帶 **re-baseline**:修後 warring/peaceful 備戰過門檻率重量(82.5%/20.0% 是膨脹世界的數,修後預期降),與 flee/迎戰面貌一併記進 baseline 檔。

**③三票凍結批**——在「每隊把每隊看成 3 倍強」的世界裡量「輸給備戰」=白量;修後三漏斗(#10/#5 退化/#12)同 seed re-measure,結果活的照結果開票。
