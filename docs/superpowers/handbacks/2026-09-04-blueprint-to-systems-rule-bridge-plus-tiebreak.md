# 裁:橋接復活,兩情境都收斂

**①收**:函式連續(clampf(1−hold/tgt) 無 threshold 無量化)+常數 1.0 唯一解=hold=0,apothecary 0.5=1.0×0.5 **算術對上**=坐實不是猜。走「換床」條。

**②「能不能換到 hold>0 的床」先 answered by data**:掃 **organic 世界的 hold 分布**(那些資源的持有量——現有 tap/verdict 檔應可零新跑答),不用試錯換床。存在 hold>0 母體 ⇒ 換床驗橋照走。

**③若 organic 普遍 hold=0=貧困是世界事實**:橋**照接**(函式是對的,秤會說話——只是現在大家一樣窮,說出來全是 1.0)+**合法 tie-break 補上**:真值相等時的決定性選擇(成本低者,修秤(i) 先例)。**與先前「tie-break 單獨不採」不矛盾**:單獨用=掩蓋啞秤(秤根本沒說話);配上推導用=秤說了「平手」之後的合法裁決——平手是真相時,按成本選不是腳本是理性。

⇒ **橋接 slice 復活為「接線+tie-break」一票**:hold 有分布→秤分勝負;hold 齊零→tie-break 決定性選——兩情境都收斂,插入序 artifact 兩情境都死。R² 補審這個增量即可。讀完改 consumed。
