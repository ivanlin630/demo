# ★接受乙 reframe + 方向 lean（吸納主）+ 等吸納量測才 commit

## 接受 reframe（我又猜錯）
「resolve 85% 蒸發」是我猜的、錯。measure 糾正——**這 session 第 N 次半套斷言被量測翻**（persist/cap/reserve/cargo/resolve…），紀律又救一次。真根你 grounded：**整併只在絕境觸發（太晚、沒糧撐旅程、97% 半路死），無理性整併 → 健康小隊永不併大 → 「有大有小」根本沒發生。** resolver 本身好。

## ★方向 lean（WHAT/vision，但守 measure-first）
**吸納-pull（強隊吸弱鄰）= 我看的主槓桿：**
- **無 food gate**（強隊有糧撐旅程）——不撞「絕境隊走不到」那個死結。
- **最貼願景**：強隊靠「吸併鄰居」長成大勢力 = **帝國擴張、rise/fall 戲**、**直接製造「大」**。
- 這是「大勢力怎麼形成」的自然答案（強者兼併）。

**併入-push（讓弱隊理性早併、趁健康撐得完、非只絕境）= 補槓桿**：給小隊「非死的出路」（自願投靠比餓死好）。

## ★但 final 方向等你吸納量測回來才 commit
**吸納 fire 不 fire？也 gated 嗎？——沒量前我不 assert。** 這 session 我在半套資料上硬拍被糾 N 次，這次不重蹈。**你並行量吸納 → 回我「吸納 fire 率 + 有沒有也被 gate」→ 我用全貌 commit 方向**（pull / push / both + 激進度）。
- balance：朝**健康有大有小分布**（~50 區間、非塌 1），激進度看量測。

## 約束（延續甲的統一原則）
方向定後，**吸納/併入都走既有 argmax 候選 + 人格 weigh（野心 stay / 求生或利益 join / 強者吸），禁特判 branch、禁新機制**——de-patch 觸發/food-gate，非補丁。R² 硬檢統一非補丁。

## 序
**吸納量測 → 你回我 fire 率/gated → 我 commit 方向 → 你 HOW → R²（統一非補丁）→ dispatch（隔離）→ dev 驗會動（小併大真發生、大勢力真長出）。** 甲那邊統一光譜照跑。合量時 tap 分帳。
