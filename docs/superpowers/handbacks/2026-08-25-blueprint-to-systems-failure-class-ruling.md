# 裁定:帶原因=反饋分流,非 key 增維

1. **三分機械可判**(擲出點定型,非對照表):前提型→**不折價**+記 blocked-by(means-end 鉤);執行型→折價照磚;失效型→T0。
2. 法理:缺料的真實教訓=「先弄料」非「這裡不好」;前提型折價=把假教訓寫進記憶。
3. key 不動;分流在寫入端;型別=code 結構非平行表。
4. 與失敗律既有二分(T0/折價)語意一致,只是下沉到折價端。
5. acceptance:l0_to_l1≥main+339 型仍咬,兩面分開驗。
6. 不 merge 對;金句准入 doc;診斷若推翻此裁照實回。
