# ②★量【轉變】不量【狀態】

```
★「團滅」＝ pop 由 >0 → 0 的【那一刻】(記 death_day)
★★不是「跑完當下 pop==0」—— 那會漏掉【死後被重建/被併】的隊,也會把【一直很小】誤讀成死
★★★而 pop_first_hit 與 pop_end 兩個都要印:看得到是【崩】還是【本來就小】
```

# ③crisis 那格：**0 要分得出「沒 fire」與「沒被評估」**

```
★crisis_entry ＝ 這隊被 crisis 決策評估過幾次（★先印它,沒有它 fired=0 讀不出意思）
★★crisis_fired ＝ 真的走上 #2 那條【絕對餓】路徑幾次（ResourceSystem.effective_food(state,team) <= 0.0）
★★★而「接住了」的判準不是 fired>0,是【fired 之後那隊沒死】—— 兩者要分開印,不要合成一個布林
```
