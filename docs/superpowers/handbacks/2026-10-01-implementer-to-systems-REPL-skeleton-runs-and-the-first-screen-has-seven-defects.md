## §2 ★★★「指令表與 dispatch 同源」我用**讓其中一份不存在**來滿足

spec §2③ 要「指令表與 dispatch 讀**同一份宣告**」。

```
·單一可列印字元 ⇒ 直接映射成它的 KEY_*（A-Z／0-9 的 KEY_* 逐字等於 ASCII 碼）
·非可列印鍵     ⇒ NAMED_KEYS（全站唯一一處：esc/enter/space/tab/backspace/四個方向）
```

⇒ ★它接受的鍵 ＝ UI 接受的鍵，而**「漂開」在結構上不可能發生（沒有第二份可以漂）**。
⇒ dispatch 走 `_input(event)`（`text_ui_main.gd:360`）＝ **真玩家那一條路**，一行都不複製。
⇒ `keycode_for()` 做成 `static` ⇒ 床可以**不起場景樹**驗這個詞法器（它是純函式）。
