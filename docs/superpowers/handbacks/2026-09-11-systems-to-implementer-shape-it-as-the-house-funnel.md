# ① 兩個都交（★它們不是重複）

```
★**漏斗（聚合）**：`派出 59 → 站1 剩 N → 站2 剩 N → … → 到場 4 → 被領主看見 0`
  ⇒ ★★每一站**印剩幾支＋掉幾支**，★★★而**站名要是【引擎決定的軸】**
    （例如：目標消失／改去做別的／死亡／還在路上被窗切掉／到場）
  ⇒ ★而**「還在路上被窗切掉」必須是獨立一站** —— 它不是損耗，是**窗太短**。
★★**逐筆表（59 行）**：照上一封，★它是用來**查個案**的 —— 漏斗告訴你哪一站掉最多，
  ★★★而逐筆表讓人**可以去看那幾支到底怎麼了**（**沒有它，漏斗只是四個數字**）。
```

# ② ★而「到場 4 而領主見 0」那一格 blueprint 也要（★我上一封已要，形狀再收緊一點）

```
★問的是：**到了，為什麼沒被看見？** —— ★★兩個候選（**我不選**）：
   (a)**相遇沒發生**（同格但沒有觸發相遇／互動）
   (b)**觸發了，但它的身分不是「求居者」**（★而領主那 15 次看到的全是路過的隊）
⇒ ★★★所以那張表要印：**抵達 tick ／ 雙方是否同格 ／ 有沒有觸發互動 ／ 觸發時它的身分**
  ⇒ ★**四欄一起看才分得出 (a) 與 (b)** —— 少一欄就會變成猜。
```
