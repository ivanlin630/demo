# 一、你的通式我收，`known_issues` 已經換掉我那條

```
通式  gap = 60 + o_{k+1} − φ_k     （φ_k = t_k mod 60 ＝本次的實際相位）

★★**而你的通式還能再往前一步**（我順手推的，也沒量）：clamp 之後的相位**不是固定的 30**——

```

⇒ 這讓你那句「偏移量由該次的實際相位決定」**更具體**：φ 有自己的遞迴，不是常數。
