# ★架構裁：(b) 系統性 de-patch — economy 決策條件化於真實威脅

## 認錯 + 讚 R²
我 spec §4「pull-convoy util 最穩」= **空斷言、沒接真公式**（跟 trade-trip/founding 同款「斷言 util 夠高但沒接公式」）。**make-or-break R² 親驗接住、逼出 meta-root——這關值得。** 我認。

## 裁：(b) 系統性，非 (a) per-case
- **(a) per-case 打地鼠**你我用戶都拒（「de-patch 非補償補丁」「系統性非 piecemeal」「架構已定別打補丁」）——補 convoy 一案，trade-trip/founding/未來每 economy 決策還是輸。
- **∴ (b) 系統性 de-patch**——**這是整 session 的鑽石**：`goal-util cap 1.5 < survival 2.5` = economy 結構永輸絕境 = **trade-trip/founding/convoy 三案 + construction + 未來全家同一根**。修這一根 = 解全家。

## ★WHAT shape（核心，架構方向；公式 HOW 你 own）
**問題不是「survival 該不該贏 economy」——是「survival 無條件永遠贏」。**
- 真餓時：survival 該贏（別餓著肚子搞建設）。✓
- **吃飽時**：fed 隊還去覓食-求更多、而不做 economy＝**bug**。

**∴ survival 的 dominance 要「條件化於真實威脅」，非無條件常數壓死 economy：**
- **fed 隊（食物健康）→ survival boost 低 → economy(capped)能贏 → economy 真 fire。**
- **starving 隊 → survival boost 高 → survival 贏 →（保命對）。**

**★runway 食物 sense 正是這個 modulator**——「我多餓/食物趨勢」就是該調 survival-vs-economy 天平的信號。**banked 的 runway work 正好餵這個 meta-fix、沒白做**（食物 sense → 天平權重）。

## 順帶修 systems 找的兩個結構 bug（同屬 (b)、通用非 per-case）
1. **距離 discount 對 logistics 倒扣**：remote surplus/遠市場是 economy 的**賣點**，不該純拉低 util（至少 logistics/trade 這類「去遠處取」的 goal，距離不該一律懲罰）。
2. **加「guaranteed-own-supply 可靠性」當通用維度**：拿自己 guaranteed 的 vs 覓食/買 uncertain 的優勢，要在公式有著力點——**做成 goal-util 的通用維度（三案共用），非 convoy-only**（那才不是 per-case）。

## 護欄
- **保 must-fix① 本意**（goal 不得無腦 override survival）：我的 shape **保留「survival 真受威脅時仍贏」**，只是拿掉「無條件」——是**把護欄條件化/修正**，非拆護欄。你確認這個 reconcile 站得住（威脅時 survival 照贏）。
- **非 scripted、util-weigh 保留**：天平權重由食物狀態連續調，非硬 gate。

## ★這是 session 最高槓桿 fix
一根解 **trade + founding + convoy + construction 全家**。∴ **① meta-fix 先做（prerequisite）**，②③④ plumbing 建其上（不然修好 plumbing、dispatch 決策還是輸＝第三個 trade-trip）。

## 驗（make-or-break，從嚴）
這觸核心 argmax，**heavy 驗**：
- 隊**仍 survive**（不因 economy 天平放寬而餓死）。
- **世界不 destabilize**（不 over-economy/不凍）。
- **全家真 fire**（trade/founding/convoy/construction 在 fed 時真的贏、真執行到手）。
- R² 從嚴複驗①。

## 序
- **你並行 ②③④ plumbing**（TASK_CONVOY + 專屬 lifecycle 分支 + 撤 persist-hold——④reviewer 洞：子隊非IDLE已sticky、fragile只在dispatch，persist-hold 是錯工具，撤對）。
- **① meta-fix rework SLICE A HOW**（survival 條件化 + 距離 + 可靠性維度，真公式非斷言）→ R² 從嚴 → measurer/QA 驗全家 fire + survive + 不凍。
- HOW 公式細節你 own，要 WHAT 拍板回我。
