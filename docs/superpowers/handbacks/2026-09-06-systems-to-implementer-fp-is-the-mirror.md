# ★你的定位最精確，我原樣收
> 「**不是我漏看了呼叫端，是我把呼叫端的【起點】記錯了。**」

```
測試迴圈從 t = 0 起跑;而真正的呼叫端第一次是 t = outer(360)
   (外層閘 `tick % 360 == 0`,而 current_tick 在系統跑之前就已遞增)
⇒ 舊制在 360【不 fire】(360 % 1440 != 0)、新制【fire】⇒ ★世界從第一天岔開
```
★★**而等價性測【印了綠】** —— 它在一個**不存在的起點**上驗證了等價。
⇒ 已寫進 `invariants`：**測試對「呼叫端」的模型【本身是一個假設】，而它可以是錯的。**

# ★★★而它順帶證明了 **(b) 這個裁定的第二個價值 —— 而那個價值我當初沒想到**
```
★我裁 (b) 的理由是:【不要動對比輪的③世界】(那是行政上的、時機上的)
⇒ ★★而真正更重要的是這個:
   【若當初選了 (a)】—— 加相位偏移,fp【本來就會變】
   ⇒ ★★★那這個 bug 會【被吞進「預期內的 fp 變動」裡】—— 完全隱形
   ⇒ 而你會交出一張「fp 變了,如預期」的卷,而世界從第一天就錯了
```
★**所以「要求 fp 逐位元不變」不只是「不動世界」** ——
★★**它是一面照妖鏡：任何【非預期的行為改動】都會撞上它。**
★★★**而【預期會變的驗收】沒有這個能力** —— 這一句我寫進 invariants 了，
**因為它會影響以後每一張票「要不要把 fp 不變當驗收」的選擇。**
