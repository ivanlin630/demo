# 稽核判準修正：可解釋性，非量級

用戶 WHAT 級修正（QA/稽核開跑前必須進 spec）：**這是世界模擬器，不是單一功能模擬器。只要有合理解釋，貿易可以為 0、任何反應都可以為 0。不准專搞貿易把其他弄壞。**

## 判準（廢量級 bar，立可解釋 bar）
- **廢**：「貿易 ≥X/月才健康」式功能配額——逼子系統表演 → 為達標灌 util → 扭壞人格/稀缺邏輯 = 功能模擬器化。
- **立**：**每個率（含 0）必須能從世界狀態解釋**。
  - **合理的 0 = 健康**：村子真自足、無稀缺 → 貿易 0 = 世界誠實。
  - **矛盾才是病**：世界自己聲明想要（幾百條訂單）+ 供給在 + 雙方要 + **沒發生** = 自我矛盾 = 斷鏈。
- = 北極星的稽核形式：**凡結果（含 0）必有可解釋原因**。
- 貿易案照此仍是真 bug（病在「數百想要 vs 6 發生」的矛盾，不在 6 小）——續走，framing 改。

## 判決表類別（改）
```
可解釋   健康,含合理的0——附解釋句（「無稀缺故無貿易」）
矛盾     想要+可行+沒發生 = 斷鏈 → 修這種
未知     查不出因 = 觀測缺 → 補探針,非直接修
```
充足性閾值（R1 的①）重定義：**不是量的地板，是「矛盾=0」**。世界句子審計（R4）的問句從「多不多」改「**說得通說不通**」。

## 修理協議（防「專搞貿易弄壞別的」）
1. **治矛盾不追配額**：修=接通斷鏈（想要的能發生）；**禁**=灌權重讓數字達標（扭曲全世界）。
2. **修一環、全環對照**：任何單環修 → 率表**全環回歸**（seeded diff + 全率表前後對照）。貿易修好但掠奪率/人格分流/知足者行為變形 = **fail**。QA 判決看整張表，不看單列。

- 充足性稽核 spec / QA 判決模板照此改（開跑前）。
- R1-R6 對應更新：①充足性閾值→矛盾=0；④世界句子→說得通否。
