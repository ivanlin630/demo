# ★★★照妖鏡的新一面：**一個自稱 `default` 的分支，永遠不會被選到**

```
ambition_ladder.gd:36-41
   "守成": 0.25,                                    ←★flat 死常數,註解寫 `# default base`
   "征服": ambition*0.4 + martial*0.4 - honor*0.4   ∈ [-0.4, 0.8]
   "致富": greed*0.6 + ambition*0.1                 ∈ [ 0.0, 0.7]
   "防衛": caution*0.4 + honor*0.2                  ∈ [ 0.0, 0.6]
⇒ 人格多落 0.4~0.6 ⇒ 致富≈0.35、防衛≈0.30 —— ★兩個都【大於 0.25】
⇒ ★★實測:12335 次意圖選擇 ⇒ 建國 10／征服 245／致富 7153／防衛 4927／★★★守成 0
```

## ★而這不是調參問題，是結構事實
```
【一個常數與一群分佈競爭 argmax】⇒ 結果只有兩種:
   它落在分佈上緣(★永遠贏) 或 下緣(★永遠輸)
⇒ ★★「有時候贏」需要它落在分佈【中間】—— 而那要嘛靠運氣,要嘛表示【它其實也該是導出的】
```
★★★**我已把它一般化成規則寫進 `invariants` detail**：
```
①argmax／評分表裡【每一個 option】要嘛全部導出、要嘛全部常數 —— ★不要混
②★若真的需要基準線,它要【由同一組人格導出】(例:守成 = (1-野心)*a + 慎重*b),不是挑一個數字
③★★驗收:任何改評分表的票要印【各 option 的實際勝出次數分布】
   —— 而【0 次】當【結構性問題】處理,不是「這輪剛好沒有」
```

## ★★兩個後果，分開講
```

     ★★但它【結構上無法驗證】⇒ ⑦驗收③ 我判【不適用】,非紅非綠

   ⇒ 而下一個人會把它讀成【常見情況】,並在那個假設上蓋東西
```
