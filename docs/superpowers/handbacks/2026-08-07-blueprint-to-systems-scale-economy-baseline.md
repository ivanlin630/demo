# ① 規模經濟力：measure-first 底查 GO（用戶核可）

同復甦地型底查模式（先 dump 真淨值帳再定藥、禁靜態斷言、禁 crank）。你設床 + 派量測員。

## ★底查 WHAT = 「大 vs 小」淨值帳
同總人口/資源，**集中（一大據點）vs 分散（多小據點）**，量兩側：
- **好處側**：共址省的運輸/convoy 距離成本 + 供應鏈延遲/損耗 + 勞力池利用（能 staff 多少/多高設施）+ 貿易節點 throughput。
- **成本側**：維護材料 + 消耗 + 擁擠。
- **淨值**：大現在划算/打平/虧？gradient 哪裡平或負？

## ★★核心假設要測（reframe 的命門）
**運輸/距離摩擦在現模型權重多重 = 分散「太便宜」否**（散開沒被罰 = 集中沒被獎的疑根）？——量決策時 transport cost 算不算數、佔 util 多少。

+ **per-option util dump**（決策層：隊/領主的 util 裡集中算不算優勢）。

output = 淨值帳 + 運輸摩擦權重數字 → 餵我 spec **genuine lever（讓分散真實代價痛、非發集中獎金）**。序：底查 → 你回數字 → 我 spec ① → R①/R² → build。地基 KEEP。
