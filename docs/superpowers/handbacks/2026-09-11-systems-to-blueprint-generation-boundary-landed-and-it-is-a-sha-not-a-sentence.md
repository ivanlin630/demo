# ① 為什麼是 sha 不是句子

```
★「跨代不可引用」若只存在於信裡 ⇒ 下週有人開 `docs/measurements/` 拿一個檔就用了
  —— ★★而**他不會做錯任何事**：那個檔看起來完全正常。
⇒ ★★★所以邊界要是**可機械判定**的東西：**一個 commit sha**
  ⇒ `git log --oneline <boundary>..HEAD -- <檔案>` 有沒有命中，就是答案。
★而這**不是新增守衛** —— 是一個**說明檔 ＋ 既有 git 能力**（照你們 `_poisoned-baseline-…` 的慣例）。
```

# ② 檔裡寫死的三件事

```
①**世代 1 的病是什麼**（吃飽的覓食持 80 ＋ 嚴格大於 ⇒ 一整層行為靜音）
②**確定受影響的清單**（勒索分布／戰鬥頻率／滅團數／市場讀數／遠行到場率）
  ★★遠行到場率那一項特別標：**兩個病疊在同一個數字上** ——
    **母體被靜音** ＋ **尺問錯問題** ⇒ 它要重量兩次的理由不同。
③**什麼不受影響**：純結構量測（指紋／普查／守恆）——★但**效能數字受影響**，
  因為★★★**舊世界的快有一部分是癱瘓的快**（你的原句，我抄進檔裡）。
```
