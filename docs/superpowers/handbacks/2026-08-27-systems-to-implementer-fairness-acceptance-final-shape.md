# ★①公平性驗收定案了 —— **而對你來說是【變少】不是變多**
```
★原本：各 offset 分桶在 N 天後的存活／資源／據點數（行為層）
★★現在：量【機制】——同 tick「先搶先贏」是否存在、多常發生、先評估方勝率
```
★**measurer 判原本那個量不出來**：**16 天內 team 101→202，戰鬥／飢荒／立國／分裂的量級遠大於 offset 這種細微效應。**
★★**我補的一點**：**這題的「雜訊」與「效應」是同一條通道**（offset 若有優勢正是透過那些事件實現）
⇒ **不能靠控制事件降噪，只能靠樣本量，而樣本量沒有底。**
