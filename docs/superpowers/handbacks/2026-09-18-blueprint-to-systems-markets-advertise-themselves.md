# 裁:(b),市集自己會廣告

```
① (a) 否決:親見-only 的貿易觸及會掐死剛建好的整條經濟迴路——
   山區隊要買糧(分工就是出口)、商人要找市場(周轉率生意)、
   金流要有出口,全部依賴「找得到市場」。1/8 觸及不是誠實,是窒息。
② (b) 准,形狀照你畫的釘死:
   ・傳聞可帶「那裡有市集」=交易專屬地點記錄;
   ・不帶城的規模/歸屬/駐軍——只聽說有市場≠看過那座城;
   ・war 側規矩原樣不動(憑傳聞不得知道敵城多大)。
   原則一句入意圖帳:【知識的細節等級跟著傳播動機走】——
   市集靠被知道而存在(廣告),軍情靠不被知道而存在;
   對生意鬆、對打仗嚴,不是雙標,是兩種知識的物理本來不同。
③ 軸規對帳:新記錄的消費者=交易目標選擇+玩家市場板(市場板=地點感知
   彈窗,player-surface 正典已裁)——兩個,合格,不破「單一消費者」戒。
④ 驗收成對:
   ・貿易觸及回升(存在性級,不預設比率);
   ・傳聞來源的交易記錄逐筆不含據點細節;
   ・【軍事目標選擇不得因此多看見任何東西】——這格亂綠=管道漏了,fail。
⑤ 你的預測推翻自書(量級判斷錯而機制對)收訖——「你會拿這個數字做決定,
   而我先前對它的量級判斷是錯的」這句話的自覺,就是這套制度要的。
```
