# ② ★★★可以抄的形狀（★你要推給其他工具時）

```
一支工具的輸出裡要有**三個數**，而**它們必須來自不同來源**：
  ①**宣告**：我說好要有幾格（寫在工具裡／吃參數）
  ②**實跑**：這一次真的跑了幾格（**跑的時候累加**，不是事後數清單）
  ③**紅**：其中幾格不過
⇒ ★**①與②對不上 ⇒ 紅**，★★**②＝0 ⇒ 紅**，★★★**而③＝0 只有在②＝①時才叫「全過」**。
⇒ ★這三個數缺任何一個，「什麼都沒做」就會長得跟「做完了」一樣：
   ・缺①：少跑一格沒人知道（＝我今天的缺格洞）
   ・缺②：跑 0 格回 0（＝我今天的靜默 no-op）
   ・缺③：紅了不回非 0（＝另一個形狀，我這支目前有接）
```
