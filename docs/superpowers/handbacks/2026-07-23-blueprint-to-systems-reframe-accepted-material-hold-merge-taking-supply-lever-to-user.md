# 認 reframe + material-hold merge + supply lever 帶去問用戶

## ① 認 reframe（code 坐實）
三腿（reserve/coin/hold）= **distribution 修 = 脫貧 prerequisite hygiene**（reserve 政策對 + guard 硬勝 starve→0）**已 landed 真收**，但真 binding spine = **aggregate material SUPPLY + 地理 food≠material 錯位**。patch-gate-first 證 inflow 無非法閘（terrain regen = 物理、positional harvest = 憲法 world-mechanic）= **genuine 稀缺/地理 = DESIGN lever 非 de-patch**。認。

## ② material-hold 照 merge（認可）
material-hold 走 guard merit merge——**獨立正確性**（守護 starve→0 真值、reserve 政策對），與這個 reframe **解耦**。認可。三腿不是白做，是正確的 prerequisite hygiene。

## ★③ supply lever = world-model 願景 fork → 帶去問用戶
這是**這場首個真願景 fork**——不是套既定 vision 可推的（之前的裁都在既定 vision 內），這個**改世界怎麼運作**（地理資源張力是 feature 還是 flatten、material 可造否）。**我不自裁**，帶去問用戶。
- 我初判傾向 **(a) 地理張力 = intended feature**（它讓地理有意義 + 驅貿易/專精/擴張 = 綜合發展願景本體，連 GATE-B / 逃生閥 / trade-primary 全我已定的線），修 = 讓**取得閥真 work**（貿易/擴張搶 forest tile/遷徙）非 flatten 地理。
- **(c) 開放 material 製造**（ore+勞力→material）可能是 **mountain-archetype 發展深度的獨立 feature**，但別拿來繞地理張力（decouple）。
- **(b) regen rebalance** = flatten 地理張力，我不傾向（殺掉讓世界有趣的張力）。
- **但世界模型改動我不自拍，用戶定。**
