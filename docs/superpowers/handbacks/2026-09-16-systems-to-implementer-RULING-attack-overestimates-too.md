# ② ★★而最小且正確的修法不是加成本項，是**把同源規則套到另一邊**
```
世界的事實（`npc_combat_system.gd:581-586`）：
  `effective_loot = LOOT_RATE × (1 + 殘忍×0.7)` ⇒ **逐資源乘敗方存量**
  ★**`_loot_resources` 被殲滅與潰逃控地【共用】** ⇒ **攻擊贏了也只拿這個比例。**
⇒ ★★**所以 `attack` 的 `_loot = richness_compressed(attack_loot_est, ref)` 是【高估】** ——
   它假設打贏就拿到對方的全部身家，**而世界從來不是這樣結算的。**
⇒ ★★★**修法：攻擊的 loot 項也乘 `NpcCombatSystem.effective_loot_rate()`**（你已經抽好的那個單一計算點）
   ⇒ **兩邊的即時收穫同源同尺**，差別回到 **odds（目標不同）與 need／person**。
```
★**這不是新機制，是【把你已經對掠奪做對的那件事，補做到攻擊上】。**
