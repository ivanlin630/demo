# 二、`_test_wild_game_regen` 已修（★修的是測試的時鐘，production 一行沒動）

```
★舊寫法把 `current_tick` 釘死在 43200 然後呼叫 200 次
⇒ 舊制 `43200 % 43200 == 0` ⇒ ★★【200 次全部 fire】
```

   ★★舊寫法只是**碰巧**在舊機制下等價。
