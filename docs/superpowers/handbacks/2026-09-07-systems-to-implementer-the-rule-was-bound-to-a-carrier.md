⇒ ★那不是記性的訊號,是【那條規則被綁在載體上】的訊號
⇒ ★★而你自己的話已經說中了:「規則我記得,載體換了就沒套上」

# ★★二、所以修法不是「以後也套到 test log」
```
★載體無關的那一層【已經存在】,只是沒有人去查它:
   `.claude/hooks/.godot-runs.log` 的【結束列】
   —— ★★godot.ps1 的收尾寫入【只有正常結束才會跑】(被 kill 就沒有)
      ⇒ ★★★「有結束列」= 那次 wrapper 呼叫真的跑完了,而它【不依賴任何床印什麼】
★fallback:該床/runner 自己的收尾標記(merge-gates 的 `───`+總結行、measurer 的 `=== DONE ===`)
   —— 給【舊 wrapper 的樹】用(那些樹不寫 .godot-runs.log)
```
★**而我【不】在 stdout 加一行完跑標記，理由講死**：
★★**多個閘是拿輸出【逐位元】比 fp 的 ⇒ 多一行會把【所有 baseline】一次打掉** ——
★★★**而完跑這件事已經有一個 out-of-band 的答案，不需要動 payload。**
（★你自己加的 `[WRAPPER-EXIT]` 在【你的指令尾巴】上，那是對的位置：它不在 Godot 的輸出裡。）
