# ★訂正：A 家族「coherence 分辨」作廢——硬 persona-gate 一律違憲 de-patch

## 用戶重申憲法（我上封漂了）
人格驅動**自由發展 = 核心**，商隊/軍閥/工匠**非硬需求、非盒子 = 湧現描述**，人格 **WEIGH 行為傾向、不 GATE 可用選項**。這條 game-design:224「穿人格秤非硬寫」**早就有**，我上封還是漂了。

## ★作廢我上封的 coherence 分辨
我上封說「保護 coherent 的人格硬閘（掠奪/戰爭基金慎重不做合理 → 別碰）」——**這本身就是開了個不該存在的違憲例外口子 = rationalization**。憲法（utility 餵 utility 非 scripted）**沒有「personality-appropriate 的硬閘可以留」這種例外**。

## A 家族判準翻轉
- **舊（作廢）**：universal-need → 修 / personality-expression → 留。
- **新**：**決策上是不是硬 yes/no 卡人格類別？是 → 違憲 → de-patch 成 soft 權重。** 不問 coherent 與否。
- 找到硬 persona-gate 一律 de-patch（人格移傾向、人人 CAN、utility 可翻盤）。

## 差異化零損失
和平領袖掠奪 utility 趨 0（幾乎不做，但情境 compelling 仍可、可被 utility 翻盤）；軍閥愛擴張靠**強權重**非硬牆。要多強調多強——只是**不准變硬類別**。

## ★邊界（保留）
結構約束（軍設施不能蓋 civilian 據點、stable 限 plains、terrain 產量）**≠ 人格閘 = 世界物理，留**。憲法管**決策邏輯**（隊怎麼選），不管世界結構（物理能不能）。

## ★AmbitionLadder 本身也是標的
`derive_archetype` argmax → 離散 archetype 標籤 → 用標籤 gate 行為（`faction_ai:973` 擴張限 FORCE、`_militancy` force_arch）= **離散化硬閘 = 違憲同族**，也是 de-patch 標的。**archetype 當 weight context OK，當 gate 不 OK。**

## 結構稽核性質校正
= **憲法合規掃描**（抓 scripted 決策閘），是 `constitution_gate.gd`（抓 scripted task 指派）的**姊妹**。

## 序
- 不變：三腿 landed、material 供給 lever 等用戶方向、A 家族續 queue（判準已翻）。
- 每筆仍 measure-convict 照 R①，**但 convict 標準 = 是否硬 gate 違憲，非 coherence**。
- game-design:226 後已 folds 此願景訂正（archetype = 湧現描述非硬類別 + WEIGH 不 GATE + 硬 persona-gate 違憲 + 結構約束邊界）。
