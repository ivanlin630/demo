## 裁 ①：c（長窗 6-12 月），複利弧 = 真驗收
- 三帶設計本質是**複利**（raid→糧→盈餘→更頻 raid→擴張），2 月窗看不到，現在裁量級=盲調。
- **真驗收 = 「同一隻狼的 raid 頻率隨糧積累上升」（複利成立）+ 沙盒層戲夠看，非固定條數。10 降回 TEST VALUE，非硬 bar。**
- (a) 狼稀有=believable 有理、(b) disposition 平衡 pass=R2 剛統一就轉旋鈕，**兩者都等長窗數據**。長窗後 FORCE 16% 若證實餓死複利 → 才開 (b)。

## 裁 ②：assimilate 隨長窗量測，數據分流（不預先開藥）
預測命中（搶糧吸不到人）但先別修——長窗一次量清哪種：
- **慢但會完成**（25 天太長但同化得完）→ cadence TEST VALUE 小調。
- **結構性跑不完**（churn 下隊 25 天內死/散/移 → 永不完成）→ **結構修下一燒**（同化改綁餵養/相處等 means-end 因子，非 flat cadence）。
- 與長窗同跑零額外成本。裁定分兩層紀律：數據分流，非預先猜。

## cadence spike：認可你 HOW 排程 + 優先序加持
per-tick = **硬不變量**且 1.2-1.6s spike 玩家直接感受。優先序按「**長跑驗收前必收**」——長窗 6-12 月正好會撞它，別讓量測床自己 freeze 污染複利數據。

## ★ 長窗探針規格（用戶要求:過程可見,非 end-state）
複利弧是**時間序列**,end-state tally 不夠：
1. **per-wolf 複利 timeline**：每隻狼（FORCE 餬口帶隊）逐月記 糧積累/raid 次數/pop/rung/faction——「raid 頻率隨糧積累上升」要**曲線**證。specimen tracer 擴到多 wolf 並行（挑 3-5 隻代表:狼性餬口/絕境/知足對照）。
2. **assimilate 生命週期探針**：每個 captive group 從建立→morale 軌跡→completed/interrupted(隊死/散/移)/escaped——裁②分流靠這（慢 vs 結構性一眼分）。
3. **tick-time 早晚曲線**：per-tick 不變量長跑首驗＋cadence spike 頻率/分佈（收 spike 後驗證）。
4. 照舊：漏斗全階（intent→prosperity→combat→capture→assimilate→growth→found→conquer）一張表——**一次看全鏈轉化率**，別再一輪揭一個瓶頸。
