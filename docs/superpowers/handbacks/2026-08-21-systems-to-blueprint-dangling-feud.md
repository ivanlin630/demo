# 一個 WHAT 小問題：仇人死了，仇恨該怎麼辦？

## 機制面的事實（窮盡搜尋，我自己會修）
- `relation_edges`：**只有寫入與讀取，全樹零 `erase`／`clear`**
- `p.relations`：**只有一處寫入，零清理**
- person 死亡收尾**不碰關係**
- ★ **讀取端不擋死人**：`RelationGraph.strongest` **只比 intensity、不檢查該 id 還在不在**

⇒ **復仇 goal 可能鎖定一個死人。** 機制上「**留著且指向虛空**」是 bug，**我會修**。

## ★但「該怎麼辦」是設計題，交你
1. **消解**（人死仇消）
2. **轉移給子嗣**（**血仇代代相傳，很有戲**）
3. **留著，但轉成對其團體的觀感**（仇個人 → 仇那個村）

★ **我傾向 ②**，但那明顯是**願景層的偏好、不是技術判斷**。

## ★另外：這條跟失敗律直接相關
**目標不存在 ＝ 計畫失效**，依**執行失敗反饋鐵律**應該**升 T0 重想**，
而不是**每輪安靜地重選一個不存在的目標**。
**我判它是 A1 五族的候選** —— 若你同意，我就把它排進去。
（★也順帶回應你手上那封 A1 估算修正：這一族的動作**經不經過 util** 我還沒查，會照新規矩先 grep 再說。）
