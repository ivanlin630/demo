# 裁序 A：先修 propagation 死角、規模經濟 re-measure 後置

## 底查大結論收（紀律教科書）
measure-first 三重接住 premature（confound→seed-noise→propagation artifact）、QA specimen 故事稽核 gate 守。結論：**找不到 genuine 分散代價**；表面「分散慘」= propagation 死角（:79 共位才傳）artifact、非規模經濟;且死角 size-relevant（越散越觸發）= **跨 3 arc 共根**（info-net①natural + cohesion①natural + scale-econ 乾淨訊號）。

## 裁 A 理由
1. **measure-first**：confounded base 上量不出/立不了 genuine 分散代價 lever。
2. **一根多症**：修 :79 死角 = info-net①natural（lord 聽到 distress 派救濟）+ cohesion①natural（自然床分化）+ scale 乾淨量、三解。
3. **結構稽核互補**：同型死角跨 3 arc 復發 = 架構信號非巧合（[[feedback_structural_audit_complement]]）。
4. **★非新 WHAT**：修 = 把 :79 propagation 做到 info-network core spec「兩層被動傳播 + delay/decay 無死角」**already-LOCKED 設計**（co-location-only → multi-hop/relay/carrier）= 實作既定設計、非新 arc。

## 3 size-blind 機制 = 後置
transport-util / cohesion-distance / relief-gap = 候選分散代價 lever，但**全待死角修完乾淨 re-measure 才定哪個 genuine 當 lever** → 後置。

## 序
你 spec propagation 死角修（對 info-net LOCKED spec、:79 multi-hop 無死角、守感知鐵律 delay/decay 非 god-view）→ R①（死角現況 QA 已 file:line confirm=輕）→ R² → build → 驗（info-net①natural relief 真 fire + co-location-independent 傳播）→ QA → merge → **re-measure scale 淨值（乾淨 base）→ 我 spec scale lever**。★連 phase3：死角=村 silent 餓死/lord 沒聽到 = 長期故事不合理源、修它也服務 ③。地基 KEEP。
