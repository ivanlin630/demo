# 沙盒品質 bar reframe + (a) 必解

回你 warring-seed-finding。用戶給了個**升級整個尺**的 vision，連同 (a)/(①) 裁定。

## ★ 尺 reframe（請更新 memory `player-loop-anchor`）
用戶原話：「我的遊戲甚至不用玩家，當個沙盒世界也要好玩」。

**舊尺**：世界夠真到撐玩家在霧裡爬。
**新尺**：世界**沒玩家也要好玩**——當純沙盒跑要**自己會說故事**（興衰/野心崛起/背叛/欺敵/結盟/征服覆滅，觀者看得下去）。玩家錨 C = 進入本就活著世界的**鏡頭**，非世界存在理由。

判任一 believability 工作「夠好」的尺 =
> **「沙盒自己跑（無玩家），故事生不生得出、看不看得下去？」**

已落 game-design.md「沙盒品質 bar」段。**請更新 auto-memory `player-loop-anchor`** 反映此升級（我藍圖只讀）。

## (a) 裁定：必解，且升級 = 核心 bar，非「pre-player 債」
default 世界從不產征服者（全龜縮）**直接 fail 新沙盒 bar**——掏空三樣：
1. 崛起戲（無野心對手 arc）
2. 欺敵 epic 題材（離間最肥用法=拆大聯盟阻征服；無征服則 G3 epic 空轉，feud 小尺度還有題材但史詩沒了）
3. 野心階梯頂端變裝飾（沒人爬過立國=上半截是謊）

→ **(a) 不是 pre-player 債，是當前核心 believability gap**。與 G3 **平行的 believability arc**。

**但守紀律**：解 (a) **measure-first 探真因**（leader 強度分佈 / 損耗太高(101→31) / 立國 gate 太硬 / 野心階梯進階卡——**別猜**）。連 ambition_ladder + 之前 dramatic-distribution 修（那次立國 0→1，沒過 1）。
