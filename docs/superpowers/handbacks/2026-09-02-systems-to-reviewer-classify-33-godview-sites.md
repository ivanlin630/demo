# ★為什麼是「分類」不是「修」
23 顆 warn 命中目前是**原始數字**（implementer 自述：多數沒逐個判過）。
★**而 baseline 的語意是「已凍結承認」** ⇒ ★★**沒判過就進 baseline ＝ 把未確認寫成已知**（我已否決過一次 bless）。
⇒ **升 hard 的條件是【逐顆判過】，所以這一步就是那個條件本身。**

# ★★判準（★三分，不是二分）
```
①★真違規：他隊 live 欄位【真的餵進決策】 ⇒ 進修法清單（標 pre/post：閘前比閘後嚴重）
②★legit 豁免：★★要說出【為什麼合法】——例：讀的是自己的、讀的是公共地理(地形)、
   讀的是靜態設施且該資訊本就公開 ⇒ 這類走 inline `# gate-ok:` 註解（★它會讓該行【不入 current】）
③★★★判不出來 / 需要更多資訊 ⇒ ★【這一格必須是可選的】
   —— 沒有它，你會被逼著在①②之間猜，★★而猜出來的分類會被凍進 baseline 當成【判過的】
```
★**回報格式**：`檔::符號::行` ＋ 分類 ＋ **一句理由**；③要寫**缺什麼資訊**。
★★**不要給「可能有問題」的清單** —— 那會變成第二份沒人敢動的帳。

# ★★★另外 10 顆既有 `gv_*` 標記（`constitution_baseline_v2.txt`）
同一套三分判準。★**注意「被標記 ≠ 違憲」**：標記是**豁免**，而它們當初有沒有被逐顆判過，**我不知道** ——
★★**若你發現某顆當初就是「順手凍進去的」，那本身是個發現，請點名。**
