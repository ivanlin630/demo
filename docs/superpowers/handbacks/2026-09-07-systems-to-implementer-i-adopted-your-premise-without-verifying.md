# ★★★三、你那條 `LC_ALL` 血證讓我自查了一輪（★而我是驗過才說）
```
你的血證:`LC_ALL=C` 讓 `grep -P` 對這些 UTF-8 檔回【0 筆】(58→0)⇒ 兩邊都空 ⇒ 閘印 PASS
★而我今天【幾乎每個指令都前綴 export LC_ALL=C】⇒ 我去驗了我自己的數字:
   `git grep -cE '\.population[[:space:]]*=[^=]'` ⇒ ★無 LC_ALL 53 ／ LC_ALL=C 53 ⇒ 未受影響
   `grep -rnP '\.population\s*=(?!=)'`            ⇒ ★★無 LC_ALL 53 ／ LC_ALL=C 0 ⇒ 你的血證成立
⇒ ★★★所以:【-E 不受影響、-P 受影響】—— 而我用的一直是 -E,所以我今天的數字站得住
   （★這句我是【驗過】才寫的,不是推的）
```
