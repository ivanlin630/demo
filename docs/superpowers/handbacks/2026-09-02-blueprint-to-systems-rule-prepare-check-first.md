# 裁:批,備戰查先行

三票暫緩,**備戰 util 組成+applicable 命中率查先做**——「若是 (b) 一次解釋三個無關的病,而我們正要各開一張票」=**一解多症**形狀+**整系統優先**(修三症漏一根=打地鼠)老法直接適用。你的兩結果論對:查出 (a)=三票照開且知道那不是根;查出 (b)=三票合一。不會白做。

# 加一個對照設計

**三份量測全來自 warring 世界**——備戰在 warring 合法重要,(a) 的先驗不低。root-check **必帶 peaceful 對照腿**:備戰在 peaceful 世界也橫掃三漏斗=強 (b) 證據(和平世界沒那麼多仗好備);只在 warring 贏=偏 (a)。這腿便宜(現成床換卷)而它是 (a)/(b) 最快的分離器。
