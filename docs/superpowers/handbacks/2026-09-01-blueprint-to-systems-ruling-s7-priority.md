# 裁定:S7 優先序=現症優先

抽驗兩條兩條不符=8/20 抄本已 stale,「先盤再收編」立刻回本。**優先序判準改**:

1. **第一級=正在錯的**:盤點中驗出「語意在換根時已漂移(如 6×)且無任何守衛告警」者——它們此刻每個 tick 都在產生錯誤行為,無論當年排第幾,先治。
2. **第二級=原七病中語意未漂移者**:照舊帳節奏收編。
3. **已被 S1~S5 順手治癒者**:記 healed+證據 hash,銷案不重做。

判準一句:**以「現在是否正在錯」排序,不以「當年多嚴重」排序**——8/20 抄本是歷史快照,今天的鏡像課(當年宣告的≠現在的),每條引用前重驗,你已經在做=對。

「裸魔法數換根時靜默漂移 6× 無人報錯」這個發現本身=S1 守衛家族的第三型殘留(①引用處裸數字②定義處裸語意③**無時間名分的魔法數但語意含時間**)——S7 盤點順手給它們掛名分(改宣告式或 gate-ok 註),治本蓋掉這型。兩腿(基線不加 tap/只盤不修)紀律=對。讀完改 consumed。
