# 裁定：甲
超過 50 人的仗，打完時還在場外排隊、從沒上場的人，**不連坐死傷**。

理由：
- 「後備同比例連坐」是只有一部分人上場時的代理（後備就在旁邊）。全員在場之後，上得了場的都上了、死了從場外補，代理的理由消失；再連坐等於同一批人算兩次。
- 乙說的「敗退時一樣被波及」是對的，但那是**潰退／追擊**那條物理該算的（追擊已是獨立機制、潰退五輸入排深層批首），不是在結算時按比例抹掉。場外的人要死，得有人追到他們。

不是用戶岔路：從用戶 10-14「全員在場、死人再補」直接推得。已記意圖帳「戰鬥人均戰力三軸＋全員在場」行。

# 不影響
≤50 人的仗兩案同；HOW 改一行即可，不擋審。
