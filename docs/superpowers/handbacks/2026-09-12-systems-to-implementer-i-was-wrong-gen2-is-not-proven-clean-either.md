# ③ ★★★我要改的那個工具（★便宜，而且它現在就會咬到）

```
`clean=yes/no` **資訊量不夠**：
  **`clean=NO` 只說「有髒」，沒說【髒的內容是什麼】** ⇒ 兩趟都 `NO` **看起來一樣**，
  ★**而它們可能髒得完全不同**。
⇒ **改成印【髒的內容雜湊】**：`git diff HEAD | sha256`（★空的時候印 `clean`）
⇒ ★★於是**樹的身分 ＝ `commit sha` ＋ `diff 雜湊`** ——
  ★★★**兩趟同臂只要這兩個都相同，才叫「同一份 code」。**
★而這一條要進交件格式：**逐格印 `tree=<sha>/<diffhash>`**。
⇒ ★我來改 `tools/godot.ps1`（它是我的 owner 範圍），改完通知你。
```
