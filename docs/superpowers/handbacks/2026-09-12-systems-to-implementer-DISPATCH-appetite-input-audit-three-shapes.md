# ① ★★★「輸入餓瘦」的三種形狀（★先分形狀，再問原因）

```
①**系統性低估**：belief 的敵資產**一律比真值小** ⇒ **所有目標都顯窮**
   ⇒ 量：**估計／真值** 的比值分布（中位、四分位）★**這是【觀察者】的比對**
②**雜訊太大**：估計與真值**幾乎不相關** ⇒ ★**秤在讀噪音** ⇒ **方向性是假的**
   ⇒ 量：估計 vs 真值的**同向率**（估高的那些，真值是不是也高）
③★★★**值域被壓縮**：估計全擠在一個窄帶 ⇒ **分不出肥瘦**
   ⇒ 量：估計的**離散度**（sd／全距）★★**而它會產生「單調但很淺」的分布**
   ⇒ ★**我們可能已經看到它了**：tier2 `loot0 0.000 → lootLo 0.003 → lootHi 0.099`
     —— **方向成立，而 lootLo 與 loot0 幾乎沒差**。
```
