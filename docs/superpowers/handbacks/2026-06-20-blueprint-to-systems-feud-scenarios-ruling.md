# 裁定：剩餘 5 魂（feud WHAT / 場景 / #1 時機）

#0 戲劇尾巴重量證實 root（立國 0→1、識破裁決 0→7）。漂亮。逐一裁。

## A 類 feud（血仇）→ YES 放寬成因，但別變噪音

現模型「敗方被搶卻存活」太窄 → 滅團仇隨死者消、不決無 loot → feud≈0。**放寬，方向：**

1. **血仇由「被侵害」本身形成**，不限倖存被搶：**被劫掠 / 被吞併臣服 / 被屠 / 被背叛** → feud。
2. **滅族不該消仇，該擴散**：受害方**未在場的同夥 / 同 faction 餘部**繼承血仇（滅團 → 餘部記恨，非歸零）。
   - ⚠ **血親(parent/kin)傳播暫做不到**——G2 只建 feud/protect/gratitude 邊，**血緣邊在 ④Trait/家族樹才有**。現階先做**同夥/餘部(team/faction 可查)傳播**，血親傳播留家族樹上線後。
3. **嚴重度 × 個性 gate，避免每場小衝突都結世仇**（= 噪音）：
   - 屠族/背叛 = 深仇；例行劫掠 = 淺。複用 **G2d 私驅動(intensity×個性)**。
   - 受害方個性:義氣/好戰高 → 記恨;寬厚 → 放下。
   - **不是「被攻擊即永世仇」**——公平交手雙方全身而退可不結仇(武人相惜)。

→ 這把 G2 §5「血仇傳播」真正做實。要件:被侵害(非只倖存被搶)+ 餘部繼承(非血親,暫)+ 嚴重度/個性 gate。

## B 類場景 → 分流，不要一起排

- **scout / ambush（誘殺）→ 現在排驗證場景。** 這對局（偽裝低報 armed 的假弱餌 + 莽者不確定攻擊）**不會自己長出來**（即使有狂人/謀士），且 G3d 碼建了**從沒被看著 fire**。= 必要 QA，de-risk 魂的招牌機制。world_sim 台現成。
- **mint（鑄幣）→ 等 #1，先別建場景。** 立國已 fire（faction 開始成形）+ #1 經濟壓力上線後，**控金礦的野心 faction 可能自己蓋鑄幣廠鑄幣**（自湧現）。先 #1 重量看 mint 自不自冒，仍 0 才建場景。**別速建。**

## #3 #1 經濟閉環（履約 + 腐壞）→ 盡快開，這是剩下的大根

#0 解了戲劇魂；**經濟仍半空轉**（履約 0%、食物囤 4-5萬）。#1 是世界另一半活起來,且 **mint + 更多衝突(經濟壓力→搶資源→更多被侵害→更多 feud)** 都搭它。
→ **#1 升為下一個大實作**。可與 A類 feud 放寬(小改)並行。
