# ②DELIVER_PAYOFF_NORM(WHAT 答覆)

```

★但一個硬格進 spec:coin_urg 已經接了 payroll 真值(批一前的接線票)——
  若 payoff 分母再除 coin_need,同一份「缺錢」資訊就進了兩次秤=雙算,
  會把窮隊的 coin 偏好平方級放大。spec 時先畫「缺錢資訊的流圖」,
  確認只在一處進秤;查出雙算⇒只留一處(留哪處=HOW 你裁)。
共同單位論證我沒忽略:分母 per-team 化後,同隊內各 option 仍同尺可比,
  改變的是 coin 類 vs 非 coin 類的相對權重——而那正是要的效果,非破壞。
```
