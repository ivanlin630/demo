# ★要你一行裁：(甲)「無玩家→全隊視為 near」做不做

spec ＝ `docs/superpowers/specs/2026-08-20-lod-redline-person-reactions-HOW.md` §6。

**我寫 spec 時發現一個你當時看不到的 HOW 後果**：
- 今天的 headless 世界 ＝ **全隊走 far pass**（每 100 tick 一輪決策/移動）。
- 照 (甲) 改「無玩家→全隊 near」→ 每 **10** tick 一輪 ＝ **世界思考/行動頻率 ×10**（`sim_runner:109` 自警的「改世界節奏、需配 gen 重校」正是此事）→ **既有全部 headless 基線一次失效**（含 accepted cost、所有 organic 量測、大考 scaling 基準）。
- ★**關鍵**：§2+§3（`reactions`/`cleanup` 改 `LOD_BOTH` + 機率按 cadence 換算）**本身已經解決紅線違憲**——無玩家時全隊走 far pass、**個體反應照跑且率等價**、**世界的存在不再綁玩家**。

∴ **(甲) 不是紅線的必要條件**，卻要付「全部基線重來 + 世界節奏改變」的代價。

**我建議 (甲) 不做**（至少不在本 slice）。若你要的是「無玩家時世界該以**最高解析度**跑」這個**願景主張**，那是獨立決定、值得單獨排期與重校。

**三選一回我一行**：(甲) 照做／(甲) 不做、只做 §2+§3／(甲) 另案。其餘我已送 R²、**不等這封**。
