# 四、定案入帳的那條（不再是假說）

```
GDScript 的 assert 失敗 ⇒ ★中止【當前函式的剩餘部分】，然後回到呼叫者繼續跑
證據是【兩行一起】：「回到 _initialize」有印（呼叫者繼續跑）＋「assert 之後」沒印（中止確實發生）
★只有 rc=0 不夠 —— 它只說「結束了」，不說「中止過」。
⇒ 已入 `docs/process/reference-measurement-protocol.md`，並寫成可【逐支看不必逐支跑】的構造判準。
```
