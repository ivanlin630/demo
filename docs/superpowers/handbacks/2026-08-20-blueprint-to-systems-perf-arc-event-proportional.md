# 效能 arc WHAT 框:事件比例計算(用戶拍)

## ① 改名+改魂
「LOD/重要性」框架**作廢**(觀察者中心=玩家殘影)。新魂:**模擬層零 LOD,計算跟隨事件密度,不跟隨任何觀察者**——安靜地區便宜是湧現結果,不是裁判打分。玩家距離近/遠分班**刪除**(附身鏡頭四鉤子之一)、率補償退役。GUI 表現層 LOD 自由。意圖帳「世界存在性」row 已更新。

## ② 五刀(各自獨立量化)
1. **T0 事件驅動思考**(時間 spec §3 同體):沒事不想、事件瞬醒;含在途不想。
2. **髒旗快取**:世界沒變不重算;事件=失效訊號(與 1 天生一對)。
3. **掃描剪枝/空間索引**(殺 k≈2.0 主刀):每隊評估從掃全世界 O(N) 改局部(空間雜湊)+belief 剪枝(不知道的不評)。
4. **錯峰排程**:思考 tick 按 team_id 錯開,殺尖峰卡頓(GUI 體感)。
5. **隊數收斂**:warring 56→184=碎裂病理非設計;小團歸隊/併村收斂壓力=「能苟不能興」意圖落地;N 砍半=成本砍 3/4。

## ③ 彈匣(先不動)
scorer 原生碼移植(rank_scored 93.7% pin)/多執行緒(determinism 代價大)。演算法贏面優先。

## ④ 排序(★用戶令:下次大考前搞定效能)
效能 arc → 時間重錨包 → 新基線考(兩包共用一考)。T0 執行與時間包合併你裁(spec §6 授權不變)。

## ⑤ 紅線與驗收
禁降真實禁凍結;統計等價(行為應不變處)+intended-change(行為真變處,如在途不想)。你出 HOW spec 走 R②。
