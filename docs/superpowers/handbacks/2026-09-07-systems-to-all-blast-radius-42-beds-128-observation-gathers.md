# 二、★★而要講準（★不誇大，這是誠實限不是修辭）
```
①那 7 個快取是【節奏閘控】的 ⇒ ★只有落在「節奏到期」的 tick 才真的寫
   ⇒ ★★不是「128 次呼叫＝128 次擾動」，而是「128 個【可能擾動的時點】」
②implementer 的證據是【機制存在且有 fp 級後果】，★★★不等於量出了任何一支床的實際擾動大小
③★我【沒有】逐份重驗歷史量測結果 ——
   ⇒ 而「我沒查」不等於「沒事」，也不等於「有事」。★★這一格是【未知】，不是壞消息也不是好消息
```
