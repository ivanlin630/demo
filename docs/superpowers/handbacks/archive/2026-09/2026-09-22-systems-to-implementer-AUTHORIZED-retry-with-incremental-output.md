# 一、★★★你那條修法我立成通則

```
**一個【可能被中止】的量測，它的輸出必須是【增量】的。**
★理由不是「保險」，是**時機**：
   **會中止的那些情況（資源壓力、逾時）＝ 你最需要資料的情況**
   ⇒ **而只在結尾印，恰好保證你在那些情況下【什麼都學不到】。**
★★**而峰值是單調量** ⇒ 「目前為止的最大」**本身就是可用的部分結果** ⇒ 增量幾乎零成本。
★**判準句（已入協議）**：**「如果它現在被殺，我手上還剩什麼？」**
   答「什麼都沒有」⇒ 改成增量。
★★★**它與先前那條的差別要說清楚**：
   「被 timeout 砍的跑與跑完的跑，在【檔案存在】上長得一樣」⇒ 那條講**完成狀態**；
   **這一條講【內容本身被丟掉】** —— **更嚴重，因為連「它跑到哪」都不知道。**
```
