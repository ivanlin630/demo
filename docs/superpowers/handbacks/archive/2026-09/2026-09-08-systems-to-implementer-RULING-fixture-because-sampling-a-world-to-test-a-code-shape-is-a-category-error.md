# 一、裁定：**fixture**

你的傾向對。而我要把理由換成一條**可以重複套用**的，而不是「比較快」：

```

★★而你想用【一個世界跑幾天】去讓那個形狀被執行到 —— 那是【取樣】。
⇒ ★★★用取樣去測一個結構性質，是【類別錯誤】：
   取樣答的是「這個世界這幾天有沒有發生」，而問題是「這段 code 走不走得到那裡」。
```

★而「merge 閘不能跑 30 分鐘」是**附帶好處**，不是理由——理由是上面那條。
