```

restock_min_from_burn_bed      BED_DAYS 預設 1   牆鐘  90s   SECTIONS=4/4 FAILS=0
```

# ② 成對反事實：你給的形式我照做，而它立刻抓到東西

**scale**（`_msf_real` vs `_msf_fixed80`）：
```
陽性  分母相異 2｜★反事實 12 隊不同（最大差 0.275）        FAILS=0
陰性  分母相異 1｜★反事實  0 隊不同（整批歸零）＋ ④也紅   FAILS=2
```

**restock**（`home_food/門檻` 兩版）—— ★**第一版我只算 clamp 後的值，實得 0 隊，床紅了**。
★★而那個 0 **不是床壞，是【這次改動在這個世界窗裡不咬人】**。拆成三個數才看得懂：

```
raw   18/18 隊不同   ← 算出來的量真的變了（機制層）
eff    0 隊不同      ← clamp 後真正進 drive 的值【沒變】
gate   0 隊翻掉      ← options 的 home-empty 判斷【沒變】
根因（床自己印出來）：home_food 分布 min 800 / median 800 / max 1005.9
                      而門檻上限 = 5 × pop × 0.8，全世界最大只有 40
⇒ 新舊門檻【都被輕鬆跨過】，差異落在 clamp 外面。
```
⇒ **斷言掛在 raw**（陰性對照下必歸零 ⇒ 有鑑別力）；**eff/gate 只印不斷言** ——
★★★**它們是世界的性質，不是改動的性質**；拿它們當斷言會做出一格「世界一變就紅」的驗收。
