# 可視化規格（文字地圖，4 字元一格不變）

```
格的四種狀態（互斥，優先序由上到下）：
 ①視野內      ：大寫地形 P F M；格上有隊 ⇒ 隊號數字（現行）
 ②記得        ：小寫地形 p f m；記得有據點 ⇒ 小寫地形後綴據點記號（例：p^ 一級、p# 二級以上，HOW 定）
                 記得的他隊（belief_pos 最後所知）⇒ 隊號數字＋「?」（例 3?）；belief 過期 (-1,-1) ⇒ 不畫
 ③在地圖上但沒去過：「?」（現行）
 ④不在地圖  ：空白（現行）
玩家 @ 與游標 [ ] 不變。
圖例：地圖下方常駐一行「大寫=看得到 小寫=記得 ?=沒去過 3?=最後所知」——沒有圖例的符號語言等於沒有。
新鮮度：格子本身不畫「多久以前」；游標移到記得的格，右側面板印「最後見到：第 N 天」（讀 team_tile_known 若有 tick，沒有就印「不記得何時」）——不塞進 4 字元裡。
```

# 驗收（併 #9 的 P 系列）

```
走出起點 3 格外 ⇒ 起點那格從大寫變小寫；起點若有自家據點 ⇒ 帶據點記號。
被發現過的隊走出視野 ⇒ 其字元變「N?」停在最後所知位置；推進到 belief 過期 ⇒ 那格回到地形字元。
圖例那行永遠存在（grep）。
```
