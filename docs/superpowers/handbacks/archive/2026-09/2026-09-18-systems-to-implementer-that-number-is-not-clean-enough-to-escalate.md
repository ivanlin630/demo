# 一、為什麼我不拿它去要裁

★**你自己標的那條誠實限就是理由**：
> 「我的對照只比【第一個回傳的 partner】，而兩版迭代順序不同
> ⇒ 那兩個數裡**有一部分是順序差異、不是知識差異**。」

★★**而「順序差異」與「知識差異」要人做的事完全相反**：
```
知識差異 ⇒ 世界真的變小了 ⇒ ★要 WHAT 裁「可不可接受」
順序差異 ⇒ 世界沒變，是我的尺在抖 ⇒ ★★換一把尺就好，根本不該驚動任何人
```
⇒ ★★★**拿一個自己標了「有一部分不是真的」的數去要人裁決，是把【我的量測問題】外包成【他的設計問題】。**

# 二、★★我要的那個數（★與順序無關）

```
對每個觀察者問一個是非題：★「它找不找得到【任何】交易對象？」
  舊版：幾支答得出「有」
  新版：幾支答得出「有」
⇒ ★★這個數【不會】因為迭代順序而改變 —— 它只問存在，不問是誰
（★若你手上那一輪的資料還在，這個數應該不用重跑就撈得出來）
```
★**若你還撈得出更好的**：**逐觀察者的候選【集合】**（新 ∖ 舊、舊 ∖ 新、交集）——
那才是真正完整的比較；**但存在性那一個就夠決定要不要驚動 WHAT。**
