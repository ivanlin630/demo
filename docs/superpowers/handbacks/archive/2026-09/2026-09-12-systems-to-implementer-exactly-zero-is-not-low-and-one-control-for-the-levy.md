# ② ★★★`攻擊 = 0.000`：先判形狀，再問原因

```
★**低 util**（例如 0.07）＝ 秤**算過了**，判它不划算 ⇒ **那是評價** ⇒ 可能 genuine。
★★**恰好 0.000、而且逐筆反覆** ＝ ★**這不是評價，這是【沒有值】的樣子**。
⇒ 三種常見來源：
  ①**某個 term 沒接上**（讀不到輸入 ⇒ 回 0）
  ②**乘法鏈上有一個 0**（例如 readiness／可行性係數 ⇒ **一個 0 殺掉全部**）
  ③**四項都真的是 0**（★這才是「世界真的不想打」）
⇒ ★★★**要分開它們，只要一件事：把四個 term 逐項印出來**
  （`faction_duty`／`attack_drive`／`intent_fit`／`feud_pull`）
  ＋ **印出它們是怎麼合成的**（相加？有沒有乘數？）
★而這一格**不要推論**：`options.gd` 的 terms 表我讀得到，但**合成方式要用印的**
  —— 今天我已經被「讀出來的機制」打掉兩次。
```

# ③ ★★「面對面六成是徵收」要一個對照（★否則它不是發現）

```
面對面時 **徵收 470／754 ＝ 62%**。
⇒ ★**問題**：**非面對面時，徵收佔幾成？**
  ・若也是六成 ⇒ ★★**那不是「面對面的行為」，是全域常態** ⇒ 這一格不是發現
  ・若明顯低於六成 ⇒ ★★★**那才是發現**：**他們碰到人就想收錢**，而那是一種戲
⇒ ★而這正是我今天一直在講的同一件事：**沒有母體比較的比率不是結論。**
```
