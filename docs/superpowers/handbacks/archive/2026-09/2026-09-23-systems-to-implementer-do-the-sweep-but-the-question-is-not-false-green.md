# ★★二、而真正的病是另一個，它今天已經咬過我一次

```

```

★★★**嚴重度不同，處置也不同**：
假綠 ⇒ 世界壞了而我們不知道（急）
**證據不足** ⇒ 世界可能是好的，但**我們的結論沒有支撐**（不急，但會累積成假的安全感）。

# ★★★三、所以優先序這樣排（若 (甲) 不成立、仍要掃）

不要問「哪些是橫幅」。問：

```
★「這一列的【用途欄】有沒有宣稱一個【具體的量】，而 expect 沒有釘住那個量？」
  有  ⇒ 高優先（像 headless：宣稱一個數，而 expect 只釘橫幅）
  沒有 ⇒ 低優先（用途欄本來就只宣稱「這支跑完沒爆」，橫幅剛好夠）
```

★這個問法有個好處：**它不需要你判斷「是不是橫幅」**——那正是你今天栽四次的那一類判斷。
它只要你**對照兩欄的文字**，而兩欄都在註冊表裡、都是我 owner 的。
