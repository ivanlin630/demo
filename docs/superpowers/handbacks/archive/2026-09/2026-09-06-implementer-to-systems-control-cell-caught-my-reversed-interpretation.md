# 一、我寫了什麼

⑨ 的驗收④要量 coin 月週轉。我在「逐 reason 流量為空」時**預寫**了解讀：
```
逐 reason：（空 ⇒ ★儀器沒開，不是沒有流動）
```
★而 2 日短跑實測：
```
coin 流量總額 = 0.0 ｜ 筆數 = 0
★★對照格：bank.writes.n = 658   ←【ResourceBank 被寫了 658 次】
⇒ ★★★儀器【有開】，coin 【真的沒動】
   —— 薪資每 7 日、鑄幣要有 ore ⇒ 兩天內零 coin 流動【是正常的】
```
⇒ ★**我那句預寫解讀是【寫反的】**：它把一個**正常的世界事實**宣告成**儀器故障**。

# 二、★★這是同一條規則的第二個實例，而**方向相反**

```
上一次（⑩ 的 A/B）：預寫解讀 = 「§2 推導錯了」 ⇒ ★把【腳本 bug】說成【深刻的發現】
這一次（⑨ 的床）  ：預寫解讀 = 「儀器沒開」   ⇒ ★★把【正常的世界】說成【儀器故障】
⇒ ★★★兩次都是【預寫的解讀在證據到達之前就決定了結論】，而兩次的方向【相反】
   —— 一次高估發現、一次高估故障
```
★**而預寫失敗語意仍然是對的做法**（它讓紅燈可讀）——
★★**配套是：預寫的每一句都必須有一個【能把它否證的對照格】**，
   而**不是**只把「這個 0 有兩種意思」寫在註解裡（★我上一輪就是只寫了註解）。

# 三、★對照格長什麼樣（★而它很便宜）
```gdscript
// ResourceBank 的唯一寫入口：
Probe.bump("bank.writes.n")        // ★所有 res 的寫入次數 —— 與 coin 無關
if res != "coin" or delta == 0.0: return
Probe.add_amount("coin.flow.abs", absf(delta))
```
```
coin.flow.n == 0 且 bank.writes.n == 0 ⇒【儀器沒開】（Bank 一次都沒被寫過，不可能是世界事實）
coin.flow.n == 0 而 bank.writes.n > 0  ⇒【儀器有開，coin 真的沒動】
```
⇒ ★**一個與被觀測量【無關但共用同一條路徑】的計數器**，就足以把那兩種意思分開。
★★而它比「檢查 Probe.enabled」強：**`Probe.enabled` 只證旗標，不證那條路徑真的被走過。**
