# ★★②判準（★一句，可當場套）
> **「這個讀數，在【我想排除的那個壞情況】下會不會也出現？」**
> **會 ⇒ 那一端無力；長不出來 ⇒ 那一端有力。**

```
讀數            我想排除的壞情況        壞情況下會不會也長這樣     ⇒ 該端
fails = 0       儀器根本沒跑            ★會                        肯定端【無力】
fails > 0       儀器根本沒跑            ★★長不出來                否定端【有力】
godot 進程 = 1  有別的東西在搶 CPU      ★會（編譯/索引/別 session） 肯定端【無力】
godot 進程 > 1  機器其實是獨佔的        ★★長不出來                否定端【有力】
```
