## 切法

```
票A ＝ 五分頁的【框】：右欄 團│據點│人│核心│事件 五個分頁 ＋ 常駐狀態列
       判準＝【切得過去、每頁有標題、空的地方印具名天窗】
       ★這張票【刻意允許大部分格子是天窗】

票B ＝ 把欄位【餵進去】：走查腳本今天印得出來的值，搬進對應分頁
       判準＝【某一欄在走查印得出來 ⇒ 它在畫面上也看得到】（逐欄對照，非人工目視）
```

★**為什麼不合成一張**：

```
票A 的失敗模式 ＝「找不到／切不過去／狀態列不見了」  ← 結構
票B 的失敗模式 ＝「這一格是空的」                    ← 資料接線
⇒ ★★合成一張時，一個空格子有兩種解釋（框沒做好／沒接出），
   而【判不出是哪一種】的紅燈，歷史上都變成「再看看」。
★★★而票A 先落地還有一個實際好處：它一落地，用戶就能【切五頁看天窗】
   —— 那張天窗清單就是票B 的母體，而它是【畫面上長出來的】不是我們列的。
```
