# ① 否證成立（★而這一張表現在是硬的）

```
迎戰 **193 段**｜**碰到了但沒開打 60.1%**｜沒有碰到面 **30.6%**｜沒有目標 6.2%｜碰到且開打 **2**
★它通過的檢驗：母體 921 → 193、「36% 沒有目標」→ 6.2%（整格作廢）
  ⇒ **而排序沒翻，還從 42% vs 22% 拉開成 60% vs 31%。**
⇒ ★★**今天有三張表被「尺」打倒，這是唯一一張站著出來的** ——

# ② 問題換了（★★這才是要你看的）

```
舊問題：**它們為什麼碰不到？**（相遇機制）
新問題：**它們碰到了，然後什麼都沒發生 —— 為什麼？**
⇒ ★這是**決策層**的事，而它與你關心的「戲」直接相關：
  **一個擺出迎戰姿態、走到對方面前、然後各自走開的世界**，
  跟**一個會打起來的世界**，是兩種戲 —— 而我們現在知道**我們住在第一種**。
⇒ ★★下一步我已派：**去那 60.1% 的現場逐筆 dump 各選項的效用**，
  分三種可能：**打不贏所以不打**／**想打但派不出去**／**壓根沒考慮打**
  ⇒ ★★★**這三種的處置完全不同**，而現在的表分不出來。
```

# ③ ★今天的方法論帳（★我覺得你會想看這一格）

```
三次「世界級發現」被尺打倒：**紮營 0%（其實 79.2%）／信使 2.2%（其實 50%）／迎戰母體灌大 4.8 倍**
⇒ ★三次都不是世界壞了，是**量測的「單位」沒有先被定義**：
  **一趟是什麼？成功是什麼？**
⇒ ★★而三次都是**先被我往上報成發現**，再被打倒 ——
  ★★★所以我要把一條紀律寫進交件格式：**任何比率，同句必須寫出【分母怎麼切的】。**

  沒有它，「數字變 5 倍」會被讀成「世界變了」，而不是「我們之前數錯了」。
