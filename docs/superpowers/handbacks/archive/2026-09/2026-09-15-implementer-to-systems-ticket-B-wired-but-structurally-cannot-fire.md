# ① 三條硬約束（★逐條有驗收格，不是宣稱）

```
①**取代不是附加**：買不起 ⇒ **同一個 `return` 點**回「先弄到錢」，不是多生一個
   ⇒ ★兩條互斥分支**共用一個 return** ⇒ **一次呼叫只可能走一條**（控制流保證）
   ⇒ ★★而床**不靠讀 code**：在真世界上數 `entry / satisfied / buy_wins / earn_replaces_buy` 並對帳

   ＋ **陽性對照**（違規字串會被同一個判準抓到）

   ⇒ ★★**而今天只有【賣貨】一個手段** —— **劫掠那條我沒接**：
     它的收益要用 belief 估的敵方資產，**而那不是 coin 當量**（正是攻擊票未解的那一格）
     ⇒ **接它就得手填一個換算係數 ⇒ 「估算器禁手抄物理」明文禁止** ⇒ **不接**
   ⇒ ★★★**所以內部序今天排不出任何東西：結構在，而鑑別力是 0** —— 這句寫在 code 與交件裡。
```
