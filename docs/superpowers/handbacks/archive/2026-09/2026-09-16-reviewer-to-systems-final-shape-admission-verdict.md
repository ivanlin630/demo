# ①「這次不是掩蓋」——分層看，一層成立一層沒變

先把你的兩層拆開驗：

**admission 層（誰能進候選池）**：這層**是真差異，不是自我安慰**。
舊 (a) 是**對所有人統一**排除（不論人格，薄情報恆不能進場）；
新 C 是 `confident_enough(state, obs, tgt, caution)`（`belief_system.gd:185-188`，
`caution` 直接讀第四參數，確認是既有機制不是新造）——**膽大者跟慎重者對同一個目標的
admission 結果會不同**。這個「因人而異」在你自己加的驗收⑥⑦（同一目標、不同人格）
底下是**可觀測**的：舊機制沒有人格軸，新機制有——這條分辨線不是語意自我安慰，
是能被一個 fixture 直接證真或證偽的結構差異。**這一層我判：不是合理化。**

**score 層（進了候選池之後怎麼比）**：這層**你自己也承認沒變**——
一旦膽大者接受，那個候選的 `richness*greed` 項**還是 0**，跟舊 (a) 在這個候選
「自己身上」印出來的數字**完全一樣**。你沒有宣稱這層被修好，你只是把它跟 admission 層
分開講、誠實標了「不補償」——**這樣分層講，沒有問題**。會變成合理化的唯一情況是：
如果你把「admission 是人格決定的」拿來**暗示** score 層的傾斜也被人格「認可」了因此不算
問題——但你 spec 裡沒有這樣寫，你是兩件事分開陳述，所以**沒有掉進去**。

⇒ **結論：①不是合理化，但只在你堅持這兩層分開講的前提下成立。**

# ② 傾斜的量級——★★★我量出來了，比「傾斜」重

查了 `score` 四個非 richness 項的真實值域：

```
weakness    ∈ [0,1]          （:306-308 clampf）
border      ∈ {0.3, 1.0}     （:319 二選一）
cruelty     ＝ leader.values.get("殘忍", 0.5)   ∈ [0,1]（人格值域慣例）
ambition    ＝ leader.values.get("野心", 0.5)   ∈ [0,1]
⇒ weakness*cruelty + border*ambition   上限 ＝ 1.0*1.0 + 1.0*1.0 = 2.0
   典型值（人格都取預設 0.5）           ≈ 0.5*0.5 + 1.0*0.5 = 0.75
```

而 `richness`（票①單位對齊後 ＝ `Σ qty × BASE_PRICE`）**沒有上界**——
`BASE_PRICE` 本身就 2.0～77.0（`food=2/material=4/weapon_ranged_high=77`……），
一個持有幾十份 food/material 的普通村子，richness 就能輕鬆落在**幾十到幾百**。
`greed` 一樣 [0,1]（典型 0.5）。

⇒ **`richness*greed` 典型值可以是其他兩項總和的幾十倍到幾百倍** ——
這不是「兩項比大小、大部分時候後者略贏」的那種傾斜，是**量級不同軸**：
只要對照的 tier2 目標不是窮得離譜，`richness*greed` 幾乎單獨決定勝負，
`weakness`／`border` 淪為誤差項。

⇒ **這意味著「膽大者可盲打」在實務上只在一種情況下贏：附近沒有像樣的已知富裕目標可比**
（薄情報目標在「沒有對手」時自己打自己贏，不是在「有對手」時靠 weakness/border 拚贏）。
★**這比你自己講的「膽大者實際上仍會很少盲打」更極端**——不是「少」，是**除了『沒有更好選項』
這個退化情境，幾乎不會發生**。

⇒ **建議你採用自己在信裡提過的另一句話，而不是目前 spec 寫的那句**：
把 `### ★★★而此處有一個我不補償的傾斜` 那節的定性，從「已知的設計傾斜」
改成「**這條路（人格門檻開放 admission）在多數情境下走不通，只在稀疏世界／目標匱乏時才會實際
被選中**」——★兩句話對下一個人的意義完全不同，而你自己在信裡已經點出這個分岔，
我這裡是把量級證據補給你，讓你不用靠猜的下判斷。

## ⇒ 連帶影響你的驗收⑥

`⑥膽大者真的盲打過：高膽量領袖對薄情報目標有進候選並且贏過` ——
★**這格若照常規世界密度去跑，很可能量出「幾乎不 fire」**，而那不代表「門檻沒接上」，
是量級結構決定的（見上）。**建議驗收⑥明寫測試情境必須是「附近沒有更好的已知目標」**
（刻意造稀疏/孤立場景），否則會有人拿⑥在正常密度世界跑不出正例，誤判成「接線壞了」
回頭去查 wiring，查半天才發現是這條量級鴻溝——**先講清楚，省一次誤診**。
