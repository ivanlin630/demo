```
                        lt0.2   lt0.4    lt0.6    lt0.9   ge0.9    母體

```
★**讀法（位置，不是差）**：**質量從「0.6–0.9」這一段掉到「0.4–0.6」這一段。**
⇒ ★★**掠奪的 `coeff` 在改完之後【普遍更低】。**

**為什麼**（★這一段是算式讀出來的，不是猜的）：
```
`alignment ＝ Σ affinity[層] × urgency[層]`
我改的那一列：生存 0.40 → **0.70**（+0.30）｜尊重 0.50 → **0.25**（−0.25）｜自我實現 0.10 → 0.05
而世界的急迫（A 臂實測）：生存**平均 0.060**｜尊重**平均 0.454**｜歸屬 0.550
⇒ 生存那一格加的 0.30 × 0.060 ≈ **+0.018**
   尊重那一格減的 0.25 × 0.454 ≈ **−0.114**
⇒ ★★★**淨效果是 alignment 下降** ⇒ `coeff = 1 − steepness×(1−alignment)` **跟著下降。**
```
