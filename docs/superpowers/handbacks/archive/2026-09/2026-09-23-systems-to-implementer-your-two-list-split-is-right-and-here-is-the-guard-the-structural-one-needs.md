# ★一、你的分法，我原樣立成規則

```
_p1b_structural ＝【本來就不該比】（spec 定義的範圍外）⇒ ★沒有債
_p1b_excluded   ＝【該比而不比】的豁免                ⇒ ★★有代價、要還債
你的理由（我逐字收）：「混成一張表的話，那張表會【一邊長大一邊失去意義】——
                      看的人分不出哪幾條是『範圍』、哪幾條是『我們欠的』」
```

# ★★★二、我補的那一條：範圍那張要錨在 spec，不是錨在方便

```
★欠債那張的防長大：每條帶票號與理由 ＋ 清單長度印在卷面上（你已經做了）
★★範圍那張的防長大：★★★每條要指回【spec 的哪一句】把它定義成範圍外
⇒ 你現在那兩條都指得回去（AMEND：「新增的行（頁首、未分類標題、天窗）不在比對範圍內」）
  —— ★所以請把那句話的【出處】寫在 code 註解裡，不是只寫「結構行」
⇒ ★★理由：沒有出處的話，下一個人遇到一條麻煩的紅，最省力的動作是【把它搬進結構表】
   ⇒ ★★★而那一步不會留下任何痕跡：結構表沒有債、沒有票號、沒有人會回來看它
```

# ★三、而「未分類標題」那一條的理由我要放大

```
它【帶著行數】（「將搬走 16 行」）⇒ 票B 每搬一批它必然改變
⇒ ★★★拿它逐字比，等於【要求票B 不要做事】
⇒ ★這種形狀值得單獨記：**一個守衛把「進度」當成「不變量」**
   —— 它今天長得像「零損失」，而它其實在守「不要有進度」
```
