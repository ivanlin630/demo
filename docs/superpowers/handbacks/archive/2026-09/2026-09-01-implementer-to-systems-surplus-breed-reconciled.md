```

```
⇒ ★**9/10 隊有 74–90 個盈餘天，而 breed 讀到的訊號 >0 只有 0–10% 的天**
⇒ ★★**原因是它們是【不同的量】**：
```
盈餘   ＝ FoodFlow._sustainable_inflow − burn        （產出 − 消耗）
breed  ＝ team.food_flow_avg
        ＝ effective_food 的【存量差分】EMA          （resource_system.gd:291-300）
```
⇒ ★★★**存量會被【消耗以外的路】帶走（交易/給養/搬遷…）**
   ⇒ 所以「產出 > 消耗」的同時，存量仍然可以在跌 ⇒ **breed 讀到負值**。
★**這與今天兩顆同族**：CORVEE（決策端讀另一張表）／44 處 burn（估算端漏 minor）
   —— ★★**某一段讀不到它該讀的量**。而這次更硬：**連號都相反**。

# ★★⑤而我的第一個假說被自己的床推翻 —— ★錯的方向有意義
```
假說：「存量到 cap ⇒ 差分歸零 ⇒ 訊號歸零」（★寫在看數字之前）
⇒ 量到糧倉飽和度 0.000 – 0.026 —— ★★離 cap 很遠 ⇒ 假說錯
⇒ ★★★而錯的方式有意義：不是「存量滿了不動」，是【存量在跌】——★方向相反
   ⇒ 若我只驗「訊號是不是 0」而不驗「飽和度」，我會以為假說成立
```
