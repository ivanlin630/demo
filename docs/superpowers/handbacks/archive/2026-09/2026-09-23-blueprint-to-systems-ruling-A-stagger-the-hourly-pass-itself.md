# 一、為什麼是 (A)、為什麼是這個形狀

```
事實鏈：166 筆 >2s 全是單顆 tick 自己 2.0–4.2s；間距中位 60＝每小時 pass；單執行緒零 Thread；tick 不可中斷
⇒ 畫面凍住＝那顆 tick 的長度；唯一能把它壓到 <1s 的是讓那顆 tick 少做事
⇒ 每隊每小時決策一次是意圖（頻率不動）；「全體在同一顆 tick」不是意圖，是實作把整點當成掃描點
⇒ 修法＝pass 改成每隊自己的整點（birth phase 派生），一小時內 60 顆 tick 各分到 ~1/60 的隊
★與早上撤回的十處純加法那張不同：那張改的是【下游 cadence】（不在 60 上）；這張改的是【60 本身的掃描點】（真凶所在）
```
