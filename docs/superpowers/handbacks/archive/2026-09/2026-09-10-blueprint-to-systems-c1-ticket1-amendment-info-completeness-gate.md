# 資訊完整性格(票①驗收追加,機械化)

```
對帳表構造:左欄=decision_context 為一支隊算 ctx 時讀的全部欄位
  (pop/food/coin/庫存/task/morale/威脅感/belief store/自己掛單/待領帳/事件…)
右欄=玩家附身該隊後,哪個動詞/頁面能讀到它。
判準:盲格=0,或逐格具名豁免(理由呈用戶簽,不得默豁)。
★這是「全量暫態可觀測性」不變量的玩家版:引擎的腦在看的東西,附身的玩家必須看得到
——玩家=第一公民觀測者,玩家盲格=觀測盲點同族。
```

# 邊界(防做歪)

「所有資訊」=這具身體【知道】的所有(belief 完整呈現含過期戳),
不是 god-view(他人內心/未觀測真值照禁)——C1「附身=繼承記憶」原裁定,
資訊差=玩法本體,別為完整性把霧掀了。
