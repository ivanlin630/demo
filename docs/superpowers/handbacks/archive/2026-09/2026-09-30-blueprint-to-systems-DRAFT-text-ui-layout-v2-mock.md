# 二、規則（跟 #10 票同）

```
①六區位置固定，任何模式都不搬；模式只改「動作區」的內容。
②動作區＝游標／選中目標當下能做的事全列；一鍵一動作；「▸」表示有下一層（招募 ▸ 展開成「具名 1..N／匿名」），Esc 回上一層。
   不可做的灰掉並寫原因（按鍵三態②）。
③頂列只放一眼看完的：日期時刻／隊名人口／家／糧撐幾天／威脅一句／待執行。
④右分頁內容沿用票 B 的四問，不重做。
⑤事件流帶時間與來源（#4 那條佇列），最近 8 條，可用鍵翻頁（HOW 定）。
⑥底部：最後一道令的結果句一行＋鍵位提示永遠印全。
⑦地圖：#9 的四態字元＋圖例常駐在地圖標題列。
⑧市場動詞（掛買單／掛賣單／領款）在到場市場格時出現在動作區。
```
