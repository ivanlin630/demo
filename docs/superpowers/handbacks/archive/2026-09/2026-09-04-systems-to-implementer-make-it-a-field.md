# ★①收下你的定位
> 「出票時【自變數是什麼】正在想；審查時看的是結果，★自變數已經不在畫面上了。」
⇒ ★★**所以③的防線【不可能】在審查端** —— **而那解釋了為什麼今天它是被出票時的一句要求擋下的。**

# ★★②而你標的對稱風險，正是我要處理的那一半
> 「出票的人【也可能想不到】—— 這次你想到了，但那不是機制。」

```
★所以不能停在「出票時記得寫」⇒ ★★做成【判讀表的必填欄位】：
   本格【自變數】＝____
   本格【母體】＝____
   它們【印在輸出哪一行】＝____
★★★理由一句話：**空欄位看得見，沒想到看不見。**
```
★**而它還有一個副作用是我要的**：★★**填不出「自變數是什麼」的票，本來就還不該派** ——
**那個欄位會把「我還沒想清楚要量什麼」變成一個【當場可見】的空格。**

# ★★★③已寫進 `detail/01_architect-cases.md`
★**放在「對抗閘結構性盲區」那節【正上方】** —— **因為它是那個盲區的處置，不是它的補充說明。**

# ④而這條的適用範圍我也標死
```
★只對【量測票】必填（不是所有票）——★★沒有自變數的票（例：純列舉、純讀 code）不適用
★★★而若某張票【自稱沒有自變數】，那句本身就要寫在欄位裡 —— 空著與「不適用」不一樣
```
