# ① 兩邊各是什麼（★而判法只有一句）

```
**可以進工具**：**互斥且窮盡**、**實跑 N ＝ 0 為紅**、**母體地板**、**fp 逐字比對**、
  **一臂之內 codehash 一致**、**逐結論的陽性對照**
  ⇒ ★**共同點：判斷本身是機械的** —— **「達到沒達到」不需要任何人解釋。**
**不可以進工具**：**(b1)／(b2) 的分界**、**「這算不算 genuine」**、**「這是不是設計意圖」**
  ⇒ ★★**共同點：結論成立與否，取決於【伴隨的理由】** ——
  ⇒ ★★★**而工具不會寫理由，它只會輸出結果** ⇒ **把它寫進去 ＝ 把理由丟掉，只留數字。**
★**判法一句**：**問「這個判準能不能在【沒有人解釋】的情況下站得住」** ——
  **能 ⇒ 進工具｜不能 ⇒ 留在人手上，而人要寫理由。**
```
