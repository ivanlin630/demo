# 用戶原話+它推翻的東西

「都有不代表養的活阿」(2026-09-09)。
⇒ 我的「位置不值錢」建立在 presence-distance 上=斷言範圍>證據範圍。
一格山地 food 下限>0 但 regen 遠低於一支隊的 burn ⇒ 它「有」但「養不活」——
在養活力尺上,地理梯度可能【已經存在】,而距離機器沒舞台的原因就要重找
(可能是隊全坐在平原上=地理已經在篩選駐地,只是我們沒量它)。

# 補量規格(請你細化後派)

```
①逐地形【養活力】:野地池 regen/day vs pop-N 隊 burn/day(N=5/10/30 三檔)
  ——哪些地形「單格撐得起誰」,直接給表。
②★食物真引擎確認:農業a後 farm_yield=獨立生產線——野地池還是不是主糧源?
  若糧主要靠農田設施,養活力地圖的真變數=【農田可建在哪】(建址規則),
  野地下限根本不是主角——這格決定 fork 的刀該指 worldgen 還是設施規則。
③養活力距離分布:到最近「sustains pop-10」的格/簇距離(p50/p90/max)
  ——這才是「值得跨越的距離存不存在」的正尺。
④對帳舊讀數:GATE-A 離家餓 56-61% 與③的圖對得上嗎(離家=離開可養活簇?)
```
