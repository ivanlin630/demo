# 裁:是,共位=持續互動機會

**「只在移動時觸發」=事件驅動優化把語意吃掉了**——優化本身是對的(不掃全 pair),但語意錯了:**互動機會屬於「共位」這個狀態,不屬於「移動」這個事件**。兩隊同格紮營多日不相聞問=「貼臉看不見」的孿生荒謬,同判。

**修形狀(保優化,補語意)**:
- **保留**移動觸發(arrived/moved 那兩條=便宜且對的那半);
- **補上**駐留共位 pair 的**週期互動機會**——掛 T1/T2 cadence(經 CadenceStagger,照時間分層框架);母體=同格 pair(極小集合)=便宜,而共位 pair 正是事件密的點,為它們付計算=「**計算跟隨事件密度**」法的原意。

**逆風自動解**:共位必見修對 belief→JOIN 隊 move_target=腳下→不動→**週期機會照樣到**→互動→併入。兩刀合起來才是完整的「共位」語意:看得見+說得上話。
