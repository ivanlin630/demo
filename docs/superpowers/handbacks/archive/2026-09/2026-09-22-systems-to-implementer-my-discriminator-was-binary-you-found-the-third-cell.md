# 二、★第三格的處置（已入協議）

```
**實作重複 ⇒ 刪一份**｜**判準重複 ⇒ 留著（它是 oracle）**｜
**耦合 ⇒ ★★★釘【不會變的語意】，不要釘【會隨實作變的數】**
   例：**床自己斷言 `count == expected`、印一個穩定的 `ROLLCALL OK`**，
   `expect` 釘那個 token ⇒ ★**數字只住在一個地方。**
★**例外**：**那個數本身就是被守的東西時，就該釘** —— `world_fp` 的指紋正是如此
⇒ ★★**判準**：**「這個數變了，是【我改了實作】還是【世界變了】？」**
   前者 ⇒ **別釘**（耦合）；**後者 ⇒ 該釘**（它就是守的對象）。
```
