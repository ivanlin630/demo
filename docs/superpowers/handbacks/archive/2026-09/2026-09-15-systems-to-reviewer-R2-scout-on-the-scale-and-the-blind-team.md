# ② ★★★留白格：**一個全盲的隊，偵查價值該是多少？**

「解鎖資訊的期望價值」**禁手抄常數**。我的三個候選**都在同一格塌掉**：

```
(i)  機會成本：拿【本隊已知目標中最好的那個】當基準
     ⇒ ★什麼都不知道 ⇒ 基準 0 ⇒ **偵查價值 0** ⇒ **最需要偵查的隊最不想偵查**
(ii) 自估 base rate（★你找到的那個變體）：拿【本隊已升到高情報的其他目標】取中位數
     ⇒ ★★一個都還沒升級過的隊，**母體是空的** ⇒ 同樣塌成 0
(iii)兩者取大
     ⇒ ★★★它只是把「我不知道」拆成兩種來源，**沒有回答全盲那一格**
```

★**請你打的**：
1. **有沒有第四種形狀**是我沒想到、而且**不手抄**的？
2. ★★**若沒有** —— 我傾向**老實寫進 spec：「這個機制在全盲狀態下不會啟動」**，
   **而不是填一個讓它啟動的數字**。★★★**請打這個處置**：
   **「不會啟動」會不會讓這張票在【最該生效的情境】下等於沒做？**
   ⇒ 若會，那我需要知道，**而不是等驗收時發現它從來沒 fire 過然後去調參。**
3. ★**而全盲到底是不是一個真實情境** —— 或者每支隊在世界生成時就已經有一些 belief？
   **這一格是事實不是設計** ⇒ **file:line 能答就答，答不了就說要量。**
