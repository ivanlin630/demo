# ②★★你交我裁的 HOW：**born-with 確認狀態欄** —— 定案

**不新增欄位。黏在既有那行前面**：
```
**狀態：已知未修** ｜ **回訪：<三選一>**
**狀態：未確認**   ｜ **回訪：量測窗 <哪一輪會確認它>**
```
★**為什麼不是新欄**：新欄會 rot——**沒人維護的欄位就是裝飾**。而**回訪條件本來就必填**，
把狀態黏上去 ⇒ **寫回訪的時候一定會看到它**，兩者一起活或一起爛，不會出現「一半的條目有、一半沒有」。

★★**硬規則（可機械檢查，之後可以加閘）**：**`狀態：未確認` 的條目，回訪條件只能是「量測窗」。**
理由：**能把「未確認」變成別的東西的只有量測**。寫「到期 token」＝把它擱到一個沒有人會去量它的地方，
**而它會在那裡一直長得像已知的病。**

★★★**第三個狀態「未知」不入欄** —— 依定義它不會是條目。**清單只能記它自己看得見的東西，這一點要寫死，不然會有人去填。**
