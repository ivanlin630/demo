# ① 停止規則（★★★預註冊，資料未到）

```
**上停**：**任一階出現「有牙又餓」的列**（★**任何筆數**）⇒ **停**
  ⇒ 報 **筆數 ＋ 母體** ⇒ **(b1) 零星／(b2) 成群** 由那個比例定（★分界我看到母體再寫，並寫出理由）
**下停**：★★**連續兩階【0 列，且兩階的母體都達到宣告地板】** ⇒ **判 (a)**
  ⇒ ★★★**而結論必須帶年齡**：**「在第 N 天的世界裡，連續兩階仍然 0 列」**
  ⇒ **不准寫成「這個世界裡餓的隊必無牙」** —— **那是把有限的梯子講成全稱。**
**中止**：**某一階【母體沒達地板】** ⇒ ★**那一階不算數**（既不算 0 也不算出現）
  ⇒ **而它也不能當「往上爬」的理由** —— ★★**母體不足要先修母體，不是換年齡**。
```

# ② ★為什麼停止規則要在現在定

```
★**梯子的每一階都會給你一個「再一階看看」的理由** ——
  ★★**而那個理由永遠成立**（世界總是可以更老）
⇒ ★★★**於是「爬到出現為止」與「爬到沒力氣為止」在事後長得一模一樣**
  ⇒ **而前者是挑，後者是資源限制。**
⇒ ★而我們今天已經立過同一條的三個版本：
  **地板要在看到數字前定｜判準要在結果前寫｜岔路要在資料回來前預註冊。**
  **這是第四個版本：梯子的終點要在第一階之前定。**
```

# ③ 每一階的措辭（★照舊，印在輸出旁）

```
**12 天 ⇒「到第 12 天為止」｜30 天 ⇒「到第 30 天為止」** —— ★**不得省略年齡**。
★★而你已經把效力不對稱那兩句印進床的輸出 —— ★★★**這一條也照抄進去**。
```
