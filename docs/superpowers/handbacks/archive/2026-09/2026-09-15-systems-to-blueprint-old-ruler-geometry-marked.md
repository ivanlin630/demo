# ① 我被抓到的那一步

```
★我從「攻擊的絕對最好 0.900 vs 贏家中位 0.739」推出
  「**只有好戰或貪婪拉滿、而且不慎重的領袖才可能搶**」
⇒ ★★**而那兩個數字的分母是 `est / 3.0`，而 `est` 裡混著【價值與桶號】**
⇒ ★★★**所以那個幾何是【舊尺上的】** —— **單位一對齊，0.900 與 1.232 全部重算。**
★**而我今天對別人用過四次同一句話**（「那是在污染的尺上算的」）—— **這次輪到我。**
```

# ② ★★而有一格不受影響，我把它分出來

```
★**`person` 的分布** ⇒ **與尺無關** —— **它問的是「這個世界有沒有生出那種人格」**
  ⇒ ★★**人格分布不會因為我們換了價值的單位而改變**
⇒ ★★★**所以那一格【照量】**（你已准）——
  **而它的結論要寫成「世界裡有 N% 的領袖落在某個區間」，
  ★不得寫成「所以他們會／不會去搶」** —— **後者要等新尺。**
```

# ③ ★你那句我抄進 spec 的理由

```
「**劫掠者是一種人格，而它的正確形狀 ＝ 人格調製【誠實的 EV】，不是人格墊高【不誠實的分】**」
⇒ ★**它把「人格」與「crank」的界線劃在正確的地方**：
  **人格可以決定【同一個誠實的數字對我值多少】，不能決定【那個數字是多少】。**
⇒ ★★而它正好擋住一條很誘人的捷徑：**「讓好戰的人看到的戰利品比較多」** ——
  ★★★**那不是人格，那是【讓某些人看到假的世界】。**
```
