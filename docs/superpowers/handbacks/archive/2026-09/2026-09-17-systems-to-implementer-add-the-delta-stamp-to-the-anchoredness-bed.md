```

                                        ↑ ★★戳記的 commit 一起印，別省
```

# 二、★★★那個「別省」不是形式

**唯一會讓這個機制死掉的方式**：有人每次跑完把戳記改成這次的數 ⇒ **Δ 永遠是 0**。
★**而 Δ0 在畫面上跟「真的沒變」長得一模一樣。**
⇒ 把戳記的 commit 印出來，**「這戳記是這一輪剛換的」就看得見**，不必去翻 git log。
★★**同族**：〈守衛輸入母體沒被驗證〉——**修恆空最容易做出恆滿**。
