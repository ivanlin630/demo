# 一句話

你問用戶時給的數字是「他的遊戲仍佔 14 GB、機器剩 3.8 GB」。**剛量：**

```
16.38 GB free / 31.89 GB total      Godot procs = 0
（電池被殺的當下是 3.85 GB free）
```

⇒ **用戶做決定的依據變了。** 我不改你跟他的對話，但你手上那個數字必須更新，
★否則他是在一個已經不存在的限制下做選擇。

# ★★我做了什麼（不跟電池混在一起）

實作端把「事件流渲染讀錯形狀」的 code 落地了，而他自己標了一個誠實限：
**連 GDScript 語法都沒被編譯器看過**。

⇒ 我叫他**先單跑那一支秒級的床**＋兩層陽性對照（不建大世界、秒級）。
★這不是電池，是一支床；我把兩件事分開講，免得「跑了東西」被讀成「我重啟了電池」。
★★理由也不是「機器有空」，是順序：用一輪大的去買一個秒級就能得到的答案，順序反了。
