# R² 判決：`2026-09-10-observer-inspect-depth-HOW.md`

## 判決：非 CLEAN——(1)(3) 各要補一格，(2) 方向對只要小修

## (1) 覆蓋率守衛：你的直覺對——不是同一種腐爛，需要另一種驗法

讀了 `.claude/hooks/failure-feedback-coverage.sh` 的 `_dead_equivalents`（:42-63）——
它驗的腐爛是【**宣稱引用的東西消失了**】（symbol 被刪掉，但宣稱文字還在）,
用「grep 這個符號還在不在」抓。

**你這張票的豁免腐爛是另一種形狀**：豁免理由本身沒變、被豁免的欄位也沒被刪
——腐爛的是【**這欄位開始被別的消費者讀走**】（本來零語意的中間量，
被新加的某個 UI/查詢動詞接上了，豁免的前提就不成立了，但豁免清單上那一行完全不會顯示任何變化）。
這是【引用消失】跟【引用的東西被別處接走】兩種不同方向的腐爛，`_dead_equivalents`
抓不到後者，不是照抄就會自動涵蓋。

**具體形狀（比照 `_dead_equivalents` 的做法，反過來查）**：
```
對每一個標「豁免」的欄位名 F：
  grep -F "F" scripts/simulation/player_query_api.gd scripts/simulation/player_api_mapper.gd \
              scripts/simulation/observer_query_api.gd
  ⇒ 若命中（F 出現在任一個玩家可見查詢面）⇒ ★這格豁免已經腐爛，具名紅
  ⇒ 沒命中 ⇒ 豁免依然成立
```
這個驗法跟 `_dead_equivalents` 同一個精神（把「宣稱」變成「可證偽」），
只是查的方向相反（查【沒有】被接走，不是查【還存在】）——加進你 HOW③ 那格，
「形狀完全比照」這句話要拆成兩半：陽性對照的**骨架**（selftest／空母體 abort／
假紅陽性對照）照抄沒問題，但**腐爛判定的邏輯本身**要另外寫這一段，不是照搬。

## (2) 分頁單一真源：方向對，一個小修正——欄位可能屬於【多頁】不是【一頁】

沒找到「分頁該由 UI 端決定」這條路的漏洞——blueprint 已經把五個分頁名字定了
（生存/經濟/威脅/社交/記憶），這已經是資料導向的分類，不是任務導向的分類，
這格不用你重新論證,blueprint 已經替你定了。

**真的反例是**：有些欄位天生就屬於不只一頁。比如 `strongest_feud`/`feud_target_id`——
它同時是【社交】（誰跟誰結仇）也是【威脅】（今天攻擊那張票就是拿它接威脅反應）。
若表格結構是「一欄對一頁」（scalar），這種欄位會被逼著只能選一邊，
玩家在另一頁找不到它。**修法很小**：把 field→page 的表改成 field→{pages}
（一欄可以掛多頁），「單一真源」照樣成立——只要這張表還是唯一入口，
UI 讀表產生五頁,一欄出現在兩頁不違反「單一真源」，只是它的值是集合不是純量。
這個修正成本低，不影響你原本的設計理由。
