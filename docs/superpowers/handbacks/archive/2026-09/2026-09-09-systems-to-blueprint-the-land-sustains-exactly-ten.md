# ① 數字

```
pop = 3   ⇒ ★到處都活
pop = 10  ⇒ ★★剛好卡邊界（plains regen 8.0 == burn 8.0）
pop = 30  ⇒ ★★★100% 無解（4 種圖尺寸 × 2 seed）——【整張圖沒有一格養得活它】
```

# ② ★★而「地理稀缺」的形狀被換掉了

```
上一卷（存在性距離）  到最近有食物的格 p50 0-1、>5 格 0.00%  ⇒ 「哪裡都有」
本卷（養活力距離）    pop > 10                              ⇒ 「哪裡都不夠」
⇒ ★★★同一張圖、兩個 predicate、兩個【相反】的結論 —— 而問題問的是後者。
```
★**用戶那句「都有不代表養得活」不是一個補充，是【換了一個量】** ——
而換完之後**答案從「沒有地理」變成「有地理，只是它長在規模軸上而不是距離軸上」**。

# ③ ★★★而上限是【剛好 10】，那是兩個常數的乘積

```
resource_system.gd:56   "plains": { "food": 8.0, ... }
resource_system.gd:3    const FOOD_PER_PERSON_PER_DAY: float = 0.8
⇒ 8.0 / 0.8 = 10.0
```
★★**這兩個常數看起來是各自獨立設的**（一個是地形產出、一個是每人日耗），
⇒ ★★★**這個世界「一塊地養得起幾個人」是一個【沒有人寫下來的設計上限】，而它是 10。**
★而它是**承重的**：它決定了「一支隊能不能靠地活」，而那件事**沒有任何 spec 提過**。

# ④ ★★它 bound 住的東西（我認為比本條本身重要）

```
有大有小 arc     ★規模不是優勢，是【負債】——每多一個人就更不可能自給
人口 arc         ★★人口成長在【地形上沒有出路】：長大只能靠 granary 存量／貿易／掠奪
opening_granary_food = 800
                 ★★★這解釋了它為什麼那麼大：它是【唯一能養大隊的東西】
                 ⇒ 而今天早上「被初始參數凍結的閘」那條也連上了 ——
                   ★空家門檻永遠不咬，正是因為 800 這個【必需品】而不是一個隨手的數
後勤／貿易       ★它們不是「效率選項」，是【大隊存在的前提】
```

★★**而這也回答了今天一直懸著的那句**：「我們讓移速差 6 倍，而這世界有沒有值得跨越的距離？」
⇒ **距離軸上沒有；規模軸上有一堵牆。** ⇒ 移速的舞台仍然小，**但大隊【必須】移動去取得食物**
—— ★**那才是 convoy／貿易的真正存在理由，而它不是「效率」，是「活著」。**

# ⑤ 誠實限（照 measurer，我不放大）

```
①本卷量的是【這塊地自己養不養得活】(raw regen)，★不涵蓋 granary 存量／貿易／掠奪
  ⇒ ★★它【不是】說「大隊會餓死」，是說「大隊【不能靠地】活」。
②與 GATE-A 離家 positional 餓 56-61% ★不是同一件事但同方向：
  本卷【更上游】—— ★★★即使不離家,規模 > 10 就不夠。
```
