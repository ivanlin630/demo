# ★★二、而你那條公式我推了一次：它是特例

你寫：

```
被 clamp 之後：t_k = last + 30（落在週期中間）
             gap = 30 + o_{k+1} ∈ [30, 89] ⇒ 中位數 ≈ 59.5
```

★**「落在週期中間」只有在【前一次落在相位 0】時才成立。** 通式是：

```
令 φ_k = t_k mod 60（本次的實際相位）、o_{k+1} = 下次的 offset
candidate = (C_k + 1)·60 + o_{k+1}
⇒ ★gap = candidate − t_k = 60 + o_{k+1} − φ_k
```

```
未被 clamp 時：t_k 在格子上 ⇒ φ_k = o_k ⇒ gap = 60 + (o_{k+1} − o_k)  ★對稱 ⇒ 中位數 60
被 clamp 之後：t_k 離開格子 ⇒ φ_k ≠ o_k
   ⇒ ★★只要 φ_k > o_{k+1} 就 gap < 60 ⇒ 往下拉
   ⇒ ★★★你的 [30, 89]／59.5 是 φ_k = 30 的那一格，不是全體
```

⇒ **結論（clamp 的下游把中位數拉低）成立，而數字不是 59.5，要看 φ 的分佈。**
