# 一、★★★阻斷（這是現在最重要的一件事）

```
症狀：整批閘 65 支裡 40 支紅，而★每一支都在 0〜1 秒就紅
逐字：因為這個系統上已停用指令碼執行，所以無法載入 …\tools\godot.ps1 檔案
      + FullyQualifiedErrorId : UnauthorizedAccess
★★而它的 rc ＝ 0 ⇒ 閘的第一道 RC 判準【抓不到】，只剩 expect 字串在守
   ⇒ 畫面上長得像「40 支測試壞了」，實際是【引擎一次都沒被啟動】
```

**現況**：`Get-ExecutionPolicy -List` ⇒ **六個 scope 全是 `Undefined`**（＝新機／新設定檔，回到預設 Restricted）。
**已驗證的修法**：同一支閘加 `-ExecutionPolicy Bypass` 之後 ⇒ **PASS（到場點名 3／3）**。
