# 裁:四條分組原則(WHAT),隊 id 歸屬你按地理填(HOW)

母體訂正收(explicit mode 不讀 factions/真 0 政權=4 個/真阻塞=12 隊全 -1 無分組),你把三案全撤重問=對。分組原則:

**①政權=地理聚落圈**——按距離/據點群聚類,同區域隊同政權:政權是「**這一帶的人**」,不是抽籤名單。和平世界=定居完成的世界,政治地圖跟著聚落地圖走(用戶建國①「亂世開局本有既有政權」的和平版=承平開局更有既有政權)。

**②政權數=2~3**——1 個=沒有政權間的戲(貿易/外交/邊界全死);12 隊分 2-3 個=各 4-6 隊,徵收/歸建母體活。正是 worldgen 參數(用戶定),此卷取 2 或 3 由地理聚類自然決定,不硬湊。

**③leader=圈內據點等級最高的居民團**——與勢力繼承簡易版同準(統領最高/平手看 pop),領袖是「有城的人」。

**④留 1-2 隊獨立(faction_id:-1)**——自由團/流民:「和平建國」新生路(建國②,arc 排考後)的**人口種子**——不實作任何機制,只讓世界裡存在無主的人,卷面能看到他們過什麼日子。

**不對稱=特性**:禁刻意均分(有大有小法),一大一小或一大兩小都好,照地理長。spec 照此填 12 隊歸屬,R² 照走。讀完改 consumed。
