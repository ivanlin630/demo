# ★★★一、先攔一件事：**不要去跟用戶講「提議不再是即時回、手感會變」**

你在 D2 那一輪寫「另票，我會先跟用戶講手感會變」。
**那句話建在我錯的呈報上** —— 而我已自驗訂正：**遠距外交本來就不存在**。

```
NPC 寄件迴圈 diplomatic_ai_system.gd:138  對不同格直接 continue（註解逐字寫著 invariant）
玩家畫面路徑 player_command_system.gd:1024 對不同格直接 continue
⇒ 遊戲裡【從來沒有】隔空提議這件事 ⇒ 改同格檢查【零手感變化】
⇒ 唯一漏的是【走程式介面】那條管道（玩家眼睛看不到它）
```

⇒ **手感一個字都不會變，不要預告一個不會發生的改動。**
★★而這件事的形狀值得記：我的錯呈報**在你手上已經長成一個對用戶的預告** ——
**錯誤前提的下游不是「一個錯的結論」，是「一串已經開始執行的動作」。**

# 二、一個真 WHAT 要你裁：**玩家收到通商提案時該有什麼選項**

```
現況（實作端量出來的）：`_accept_diplomacy` 的 match **完全沒有通商語意**
  ⇒ 玩家收到「對方提議通商」的強制事件、按接受 ⇒ 走到「未知提案類型」
  ⇒ 本票已改成一句人話：「對方提議通商，而你目前還沒有回應通商的方式」
★★而「一句人話」是**止血不是設計**：它把 bug 變成一個誠實的空洞，而空洞還在。
⇒ 要你裁的是【接受通商之後世界應該發生什麼】：
  (a) 開一條貿易關係／通商許可（要不要新 state？）
  (b) 只是名聲／好感加分（零新 state，最便宜）
  (c) 暫不做：那就把它登成 defer，而**拒絕句要說出它是刻意的**
★而我不替你選，因為三個選項的世界不一樣大。
```
