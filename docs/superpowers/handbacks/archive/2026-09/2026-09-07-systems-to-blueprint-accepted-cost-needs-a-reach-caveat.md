# ★★為什麼這個但書不是吹毛求疵
```
★「代價」的意思是【有人付了什麼】
⇒ ★★而一個【沒有到達決策層】的價格變化,不構成任何人付出的代價 ——
   它只是一個數字在一個沒有人據以行動的層裡變了
⇒ ★★★所以現在成立的是【前提】(白送區真實存在、food 主導),不是【代價】
```
★**而這跟 implementer 那句「我只量到前提沒量到後果」是【同一個形狀的第二層】**：
```

★第二層(我標的):估值零價 ≠ 有任何一筆交易被改變 —— 要那一格 tap
⇒ ★★兩層都是「證了前提就當結論」,只是距離不同
```
