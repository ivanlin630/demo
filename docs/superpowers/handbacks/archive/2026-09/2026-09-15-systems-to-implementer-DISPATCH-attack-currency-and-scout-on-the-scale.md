# ① 一刀三件（★順序不可拆）

1. **單位**：`faction_ai_system.gd:380` ⇒ `Σ (各項估值 × BASE_PRICE[該項])`，**拿掉手填的 100**。
2. **型別可行性**：`:382`（只有 `resource_scale`）與 `:384`（皆無資料）⇒ **該目標不被產生成攻擊 candidate**。
   ★★**必須是結構排除**：`score` 是加總 ⇒ 「少一項」與「那一項＝0」**逐位元相同**。
3. **偵查 option**：對這些目標生「去偵查」候選，**進同一個 argmax**。
   ★**禁走廊**：不得在排除之後直接 `try_set(TASK_SCOUT)`／直接派遣。

★**②③不可分兩票**：只做①會讓兩條路的量級從同級變成幾百倍 ⇒ **靜默判死**（spec 有算術）。

# ② 全盲那一格：**誠實具名的先驗 ＋ 三道守衛**

```
①**具名**（例 `SCOUT_VALUE_BLIND_PRIOR`），不得埋在式子裡
②**標 TEST VALUE ＋ 明寫「世界答不出，所以這是設計選擇」**
③★★★**它是【先驗】不是【替代值】** —— **真情報到手後必須被取代、不得繼續參與**
```
★**正當性判準（可以套用在下一個同類問題上）**：
**問「世界答得出來嗎」—— 答得出而你手填 ＝ 掩蓋（禁）；答不出而你手填並誠實標示 ＝ 設計選擇（合法）。**
★★「對一個**毫無情報**的目標預設它值多少」⇒ **沒有情報就是前提** ⇒ **定義上不可導出** ⇒ 合法。

# ③ ★★★驗收五格（★三組成對，缺一組就不可判）

```
① **不出現**：同 weakness／同 border，一個有分項情報、一個只有等級 ⇒ 後者**不在候選清單裡**
② **補齊後出現**（★與①成對 —— 否則「永遠不出現」與「沒接上」不可分辨）
③ **偵查會輸**：要有它輸掉的樣本
   ★母體＝**每一次 argmax、且候選集裡確實含偵查 option 的那些次**
   ★★**用結構事實篩，不用隊的情報標籤篩** —— 標籤是分類，候選集才是決策當下真的比較過的東西
   ★★★否則「生成失敗」會混進「生成後輸掉」，把勝率稀釋或扭曲
④ **早期窗偵查真的出現過並贏過**（★與③成對：一個防「恆贏」、一個防「恆不出現」）
   ⇒ ★★否則「偵查時代」只是一個說法，而世界實際上是【什麼都沒做】
⑤ **先驗被取代的【逐筆】證據**：同一個目標，情報到手前後各一筆
   ⇒ ★**逐筆，不是聚合** —— 聚合答不出「這一筆用的是哪一個」
```

# ④ ★量測紀律（藍圖立，連動既有讀數）

**戰爭類讀數的窗必須【蓋過偵查時代】，否則會量出【假和平】。**
★**這與「每個數字帶窗」不同軸**：那條是**窗有多長**，這條是**窗在哪裡** ——
★★**一個夠長、但整段落在世界剛生完那段的窗，會誠實地量出一個假結論。**
⇒ **你的驗收床報數字時，除了天數／config／seed，要講【它從第幾天開始】。**
