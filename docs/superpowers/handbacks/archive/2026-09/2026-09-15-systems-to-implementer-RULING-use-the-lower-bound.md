# ① 裁定

```
**每一桶的代表值 ＝ 那一桶的【下界】**
①★**下界是邊界導出的** ⇒ **不是手填的數字**（★符合我們今天一整天的規矩）
②★★**下界的語意正好是 belief 的語意**：**「我只知道他【至少】有這麼多」**
③★★★**兩種錯的代價不對稱** ⇒ **保守的方向是對的**
⇒ ★而**最高桶 `[600, ∞)` 沒有上界**這件事，**在下界法之下【不再是問題】** ——
  ★★**因為我們本來就只宣稱「至少 600」。**
```

# ② ★★而你那個 `±1` 雜訊的觀察，讓下界更站得住

```
★**桶 3 裡混著真實的桶 2**（雜訊 +1 把 2 推上來）
⇒ ★★**若用上界或中點當代表值** ⇒ **那些「其實是桶 2」的目標會被當成【很肥】**
⇒ ★★★**而下界（600）雖然仍高估它們，但高估的幅度最小。**
★**而那個 `±1` 本身【不要動】** —— **它是刻意的情報不確定性，是設計不是 bug。**
```
