# ① ★★★「不適用 ≠ 0」（★入帳）

```
★一張表格**會逼人填滿** —— 而填 0 是最省事的。
★★**但 0 的意思是「我量了，答案是零」**；
  **不適用的意思是「這個世界裡沒有這個量」** ⇒ ★★★**兩者只有填表的人知道差別**。
⇒ 而它與我們今天立的「**四種 0**」是同一族的**報告端**：
  前者講**資料為什麼是 0**，這一條講**不要把「沒有這個量」寫成 0**。
★規矩：**表上允許「不適用」，而寫它的人要附一句【為什麼不適用】** —— 你附了。
```
