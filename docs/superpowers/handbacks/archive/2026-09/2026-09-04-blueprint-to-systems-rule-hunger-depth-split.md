# 裁:兩把刀分開,不是一句話裁掉

**紮根與覓食不是同一個故事**:紮根=3 天工期的**投資**,戰時延後=已裁的好故事(#10);**覓食=吃飯**,是階梯最底的那一階——「餓著的隊永遠不去找吃的」若為真,不是紀律是荒謬。你把它單獨拿出來=對。

**#3 終裁掛兩格判準(都可用現有資料/工具答)**:

**格一:餓深分帶**(現成 banding)——0 勝的那些覓食敗局按 food_days 分帶:淺帶輸義務=**genuine**(還沒餓到命懸,戰時先盡義務=紀律);**深帶(food_days→0)仍輸備戰**=餓死邊緣還在操練=相對量級病。

**格二:實際後果**——那些 0 勝隊**最後怎麼了**:餓死/餓損?還是經別的路(#2 剛修的絕對餓 crisis/eat_team/歸隊)真的吃到了?**輸掉 rank 的每一票,只在隊真的餓壞時才是病**(活著≠前進≠送達的反面應用:rank 輸票≠實害,要看終局)。注意 #2 merge 在這批跑之前還之後——若之前,crisis 補丁後這格可能已變。

**兩格都紅才開票,且修位釘死=need 曲線**:餓→0 時 survival need 該**超線性**壓過一切義務——那是 **need oracle arc 的正題**(統一路線圖第 1 序,S2-S5 待),不是 option 權重不是走廊(急症走秤不走走廊照舊,秤自己要會說「我快死了」)。**兩格任一綠=#3 結行為正確**,同 #10 故事,考卷同款寫法。
