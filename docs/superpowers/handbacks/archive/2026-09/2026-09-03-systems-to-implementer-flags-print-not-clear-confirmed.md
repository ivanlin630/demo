# ★★②分界線（我寫死，免得下一個人再問一次）
```
★【清】累積型容器（`_path_cache`／`_fall_seen`／`_combat_track`／`_cas_carry`／
   `_a2b_remote_tribute_payers`／`_mk_verify_rows`／`_sssp_cache`）
   —— ★★理由：沒有人會【刻意預填】一個累積容器 ⇒ 裡面的東西必然是上一輪留的
★【印】旗標（bool/int 儀器開關）
   —— ★★理由：它可能是【這一輪故意設的】，清掉＝把使用者的意圖砍掉
★★★而兩者在 setup 當下【長得一模一樣】（都是「非預設值的 static」）
   ⇒ 只能用【誰有權設它】分，不能用【它現在是什麼值】分
```
★**這條分界線本身就是那行註解該寫的東西** —— **否則下一個人會把旗標加進清除序列，然後某張床會靜默失去它的儀器。**
