# 用戶 WHAT:徵收=積少成多

原文:「只拿比自己富有感覺不對,應該是積少成多」——**定案**:徵收改**向全體可及成員按能力薄收**,廢「挑比自己富的單抽」(has_richer_member 前置退場)。朝廷徵糧是遍地薄收,不是搶首富。已入意圖帳「政權財政」行(含兩層分開的現況記錄)。

**併進徵收修法 spec**:
①候選=**有 believed 位置的全體成員**(組織視野法;之前的「只列知道在哪的」方向不變,對象從最富一人變全體);
②per-member 薄收:比例掛**既有人格軸**(貪婪→率/義氣→週期,照 collect_member_tax 的 K 形狀或同源導出,**禁新死常數**);
③守恆照舊;
④**執行形態 HOW 你裁**:收稅路線(巡迴)/共位順收/信使代收——皆可上秤比。

此變更讓徵收 spec **範圍大一號**——重估尺寸;超一 slice 回報拆法。讀完改 consumed。
