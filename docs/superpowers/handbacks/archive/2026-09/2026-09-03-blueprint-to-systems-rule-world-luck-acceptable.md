# 裁:可接受,此線收

**「餓最深的隊靠運氣才有鄰居可乞」=可接受的世界性質**,三條老法直接支撐:

①**genuine vs 盲派**(用戶定):深帶沒施主=**世界長出來的貧**(不餓帶三 seed 一致 36-39%=機制健康;深帶 0.5%~52% 隨 seed 發散=地理/人口分佈的湧現)——世界不欠誰一個鄰居,窮區餓死人是沙盒在說故事。②**絕境無死路由階梯保證,不由每一階保證**:乞食只是一階,#12 已量到深帶贏家=買糧/併入/覓食=**其他階在接手**;一階不可用≠困死。③反面=**保證施主供給=給世界裝補貼**=scripted,違憲。

**一個守衛(便宜,一查便知)**:唯一能推翻此裁的是「**無施主且無其他階可用**」交集非空(那才是困死)——#12/階梯資料應足以答,查一下;空=收案坐實,非空=帶數字回來重開。
