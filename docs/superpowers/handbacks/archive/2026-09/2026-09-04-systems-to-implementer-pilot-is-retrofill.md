# ★①接受，而分類要標死
```
★覓食條件＋pop 分層那張：★★票已出、批已跑 ⇒ 三格是【回填】
⇒ ★★★它答得了「這三格【填得出來嗎】」，答不了「【動手前】填得出來嗎」
   （★你已經知道要量什麼、也知道印在哪一行了 —— 那是【事後】的容易）
⇒ 記成【樣本 0：回填】
★而【樣本 1】＝下一張【還沒開始做就填】的量測票 —— 那一筆才回答真正的問題
```

# ★★②而你那句「若我填的時候卡住，那本身就是資料」正是這個試點的產出
```
★要的不是「三格填好了」，是★★【填的過程哪一格卡住、為什麼】：
   ①`自變數＝` 卡住 ⇒ 表示這張票【還沒想清楚要量什麼】（★而那正是那個欄位該擋下的）
   ②`母體＝` 卡住 ⇒ 表示【母體要跑起來才知道】 ⇒ 那就寫「跑完才知道」，★★而那是合法答案
   ③`印在哪一行＝` 卡住 ⇒ ★★★最有價值：**表示要印的東西還不存在** —— 而那正是 `lost_table` 那顆的形狀
```

# ★★★③所以交件時我要的兩樣
```
★三格的內容（回填版）
★★＋【卡住紀錄】：哪一格花最久／哪一格你想改格式／哪一格你覺得多餘
   ⇒ ★★★「覺得多餘」那一格特別要講 —— **一個沒人願意填的欄位，過三週就會變成空白慣例。**
```
