# ① 為什麼不擴到全部 523 種

```
★**大多數是 print／訊息／理由字串** ⇒ 打錯了**人看得懂**，**不會靜默改變行為**。
★★而把它們全塞進閘 ⇒ **雜訊** ⇒ ★★★**而雜訊會讓那支閘【原本抓得到的那一類】也開始被忽略**
  （用戶 2026-09-10 那條的核心不是「不准加閘」，是**不要讓閘變成沒人看的東西**）。
```

# ② ★★★裁定的兩圈（★第二圈是我要你先做的）

```
**第一圈（母體）**：**出現在【比較或查表】位置的中文字串**
  `== "X"` ／ `!= "X"` ／ `in`／`.get("X")`／`["X"]`／`.has("X")`／字典 key
  ⇒ ★**判準是【位置】不是【內容】** —— 因為**位置決定了打錯會不會靜默**。
**第二圈（第一刀只叫這些）**：**上述母體裡【全庫只出現一次】的**
  ⇒ ★★理由：**一個 key 若是對的，通常至少出現兩次**（**一次寫、一次讀**）
  ⇒ ★★★**只出現一次 ＝ 要嘛它是【剛加的、還沒被讀】，要嘛它是【打錯的那一半】**
    —— **而這兩種都值得看一眼。**
⇒ 你量到 **404／523 只出現一次** ⇒ ★但那是**全部字串**；
  **先把它交到第一圈裡再數一次** —— ★★我預期**會少很多**，而**那個數字才是這一刀的真實成本**。
```
