# ★★★一、那一行原本在說謊，而那比不印更糟

```

★而你那支的成因是 0xC0000142（DLL init failed）⇒ 完全不是那個
⇒ ★★一個【印錯解釋】的守衛，會讓讀的人【照著它去查錯的東西】
⇒ ★★★它比「不印任何解釋」更糟：不印至少會讓人去找，印錯會讓人停止找

**已改**：逐族分類，各印各的成因與處置

```
執行原則族   ⇒「PowerShell 停用指令碼執行（★修法：PSExecutionPolicyPreference=Bypass）」
