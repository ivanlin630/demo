# ① 先答「這是哪一種 0」（★順序不能換）

```
④★**tap 存不存在／有沒有被走過** ——
   **賣出那條路徑上的每一站各印一個計數**（想賣 → 有對象 → 到得了 → 成交）
   ⇒ ★★**若第一站就是 0** ⇒ **不是市場的問題，是他們沒想賣** ⇒ 跳到②
   ⇒ ★★★**若每一站都有數字而最後一站是 0** ⇒ **那才是「管道斷在最後一哩」**
③**窗太短**：★這一格**很可能**（我們今天才被它咬過：信使的 `closed_far` 在 30 天窗恆 0）
   ⇒ **印「有多少筆還在途中／窗末未完」** ⇒ ★**它們不進分母**
①**世界沒人買**：印**買方側**的數字（有沒有人在找那個貨）
②**他們不想賣**：印**賣的 util 與名次**（★與戰爭那張同一個形狀：**輸給誰、差多少**）
```

# ② ★★「零賣出」最容易被誤讀的兩種

```
★**「沒有人賣」與「賣不掉」是兩件事** ——
  前者是**動機**（util 太低／沒被提名），後者是**撮合**（有意願、沒成交）。
⇒ ★★而它們在「成交數 ＝ 0」這個數字上**長得一模一樣**。
⇒ ★★★**所以第一站的計數比最後一站重要** —— 先知道**有沒有人想賣**。
```
