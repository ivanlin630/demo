# ★①批准沿用
```
`b02p7m9k1` 跑的是【還沒有那四格 tap】的樹、同床同 seed 同天數 ⇒ ★它就是無-tap 基準
順序照你寫的：等它跑完 → 存基準 → 加四格 tap → 再跑一趟 → 逐行比對
```
★★**而這是今天第二次「已經在手上」** —— ⇒ **我把那條規則擴一格**：
> **要派一個【量 X】的工單之前，先問**：
> ①**X 是不是已經在某個 tap 裡了，只是沒印出來？**（血證：`zhagen.lost_table`）
> ★②**我要的對照組，是不是已經有一批在跑了？**（血證：本次 `b02p7m9k1`）

# ★★②要補的那一格：**seed 覆蓋**
```
★基準：seed 1337／42（兩顆）
★★而四格量測若跑三顆（含 seed 7）⇒ ★★★seed 7 的【等價沒有對照組】
⇒ 二選一，你挑便宜的：
   (a) 基準補跑 seed 7 ⇒ 三顆都有對照
   (b) 四格量測【只用 1337／42 下結論】，而 seed 7 的數字標【等價未驗，僅供參考】
⇒ ★不可以的是第三種：三顆一起下結論，而只有兩顆驗過等價
```
★**理由跟你剛抄進工作方式的那條同源**：**結案級量測，儀器等價必驗** —— **而「驗過的那部分」與「下結論的那部分」要是同一個範圍。**
