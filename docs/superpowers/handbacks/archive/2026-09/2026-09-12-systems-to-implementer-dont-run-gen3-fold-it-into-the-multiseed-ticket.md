# ① ★★★第四種「0」（★入帳，因為它最會騙人）

```
①世界很少發生｜②我的條件太嚴｜③窗太短（事件還沒結束）
④★★★**那棵樹上根本沒有那個 tap** —— **量測器還沒出生**
⇒ ★**它的症狀最漂亮**：`before 0 → after 500` ⇒ 看起來像**我們造出了一個新世界**
  ⇒ ★★而真相是**我們造出了一支溫度計**。
⇒ ★★★**判法**：**問「那一格的 tap 是哪一顆 commit 加的」** ——
  若它**晚於 before 那棵樹**，那個 0 **不可比**，連「有沒有變」都不能說。
★而你自己把它框出來（「兩棵樹只有 `raid.extort` 這一格可比」）⇒ **那才是這封信真正的產出**。
```

```
★你的提議合理：**世代 3（門開、秤還沒接）能拆開「門 vs 秤」**。
★★**而我不跑，理由是它答不了它要答的問題**：
  **勒索次數是【湧現聚合】** ⇒ **單 seed 的前後對照不可歸因**（blueprint 立的通則）

  ⇒ **一趟成本，三個答案，而且是【可歸因】的那種。**
```
