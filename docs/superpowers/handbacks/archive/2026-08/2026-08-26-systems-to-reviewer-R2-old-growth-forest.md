# ★①我把「初始值 ＝ 再生上限」寫成賣點 —— **它是不是其實是個坑？**

```gdscript
world_generator.gd:101   tile.resource_cap = tile.resources.duplicate()
resource_system.gd:128   再生以 resource_cap 為上限
```
★**我在 spec 裡寫**：**拉高老熟林初始 material ＝ 同時拉高它的再生上限 ⇒ 它是【持續產地】不是一次性禮物。**

★★**要你判的是**：**這個耦合是【設計】還是【巧合】？**
- **若是設計** ⇒ 我寫成賣點沒問題。
- ★★★**若是巧合**（`resource_cap = resources.duplicate()` 只是「初始化時順手複製一份」）
  ⇒ **我等於把一個實作細節寫成了機制承諾** —— **而下一個人若把兩者拆開，老熟林會安靜退化成一次性禮物。**
★**我 spec 裡已經要求把這句寫進 code 註解**，**但若它本來就是巧合，正確的處置可能是【先讓它變成設計】（顯式命名），而不是註解提醒。**
