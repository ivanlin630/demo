# 承載力診斷 addendum(用戶補刀)

1. **(iv) 池 runway vs 提取率**=最優先一刀:池滿而餓=提取 funnel 斷(**非承載力**);池空而餓=真承載。

3. **特查:工期 corvée 抽不抽採集勞力**→「蓋家過程餓死全家」若真=呈報再議工期口糧秤。
4. 被動採集逐環 tap(cadence 真跑/勞力 fill/共享 tile 分帳)。
