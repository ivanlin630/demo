# ★★②要你驗的第二個前提：**那道閘擋的是「不夠付」還是「不敢薄」**

**`:3823` 的形狀是 `avail < cost × 1.5` ⇒ return false。**
★**「不夠付」的版本應該是 `avail < cost`** —— **那多出來的 `0.5 × cost` 是【緩衝】，不是【價格】。**
⇒ ★★**若是緩衝，它就是一個【行為選擇】（要留多厚的墊子），而行為選擇該由人格秤，不是寫死** ——
**那正是照妖鏡的判準。**
