# ★★★真根因定案（四輪翻案後）：**村不是「地養不起」，是「沒把嘴接到池子上」**

## ① 我的 `cap` 決定論**死透**（我認）
萎縮隊 **`terrain = {plains: 9, forest: 2}`** ⇒ **82% 在 plains** ⇒ **`cap` 大照樣萎縮。**
**用戶一句「池不是蠻多的嗎」直接戳破** —— 我當初只從 3 隊推論，**相關當因果**。

## ② ★★★決定性證據
**8／11 萎縮隊【站在滿／近滿食物池上】（runway 61–364 天），卻 `effective_food` 只有 2.3–9.2。**
⇒ **「池滿人餓」成立 ＝ 提取 funnel 斷，不是承載力。**

## ③ ★★物理機制坐實
**無 outpost ＋ `camp_level = 0` 的團隊 ⇒ 該 cadence 物理上零被動食物**
（`collect.no_outpost_no_camp_zero_food` **累計 984 次**）。
**正面對照組**：`camp_level = 1` 的 **team10／11** ⇒ `effective_food` **暴漲 388／457**。

## ④ corvée 假說**不成立**
code 讀**未發現** `labor_pop`／`pool_of` 依 construction 狀態扣減的路徑
（measurer **自標信心中等、未做即時快照** —— 照抄，不當更強的結論）。

## ⇒ 這條與既有 arc 對得上
memory `project_size_matter_arc`：**「三接入動詞各斷：紮營分數輸／settle 從未 dispatch／建設 argmax 贏但 `try_set` noop」**
⇒ **本輪是那條 arc 的【獨立再確認】，而且證據強得多**
（**984 次零採集 cadence** ＋ **8/11 村站在滿池上餓死**）。

## ★兩個排程後果要你裁
**(a) `FARM_UNIT_YIELD` 的 tuning 議程【降級】** ——
**先修接入，再談產量**；否則是**對著沒接管的水龍頭調水壓**。
（我先前查的「L1 只養 2.5 人」紅旗**仍然記著**，但**它不是現在的瓶頸**。）

**(b)「三接入動詞」arc 是否升為主線？**
它現在有**具體、可重跑的證據**，而且**它擋著的是「村莊這個概念能不能存在」**——
`recovery-path`／`size-matter` 兩個既有 arc 的地基都在它上面。
