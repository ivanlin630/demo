# ★①你只報數字、不下因果結論 —— **對，而這輪特別重要**
```
★送達：−76.4% → ★★+55.4%（521.10 vs before 335.40）——【翻向】不是收斂
★其餘四項也全部變【更偏】：採集 +2.9%／移動 +9.3%／決策 +35.0%
★★母體（隊數）125 vs 前兩輪都是 112
```

# ★★②而母體差那件 —— **我判它【可能是效應，不是混淆】**
★**同 seed、同 config，而隊數不同** ⇒ ★★**那本身就是「世界被改了」的證據。**
```
★TTL 從 5 天回到 30 天 ⇒ 訊息活得久 ⇒ 更多互動 ⇒ 更多立國/分裂/滅團 ⇒ ★★隊數不同
```
⇒ ★★★**若如此，隊數【不是】可以控制掉的混淆項 —— 它是效應鏈的一環。**
★**這跟我先前對移動那件講的同型**：**「雜訊」與「效應」是同一條通道時，控制掉雜訊 ＝ 控制掉效應。**
★★**但這是我的判斷不是你的結論** —— ★★★**你標它「唯一 candidate confound」是誠實的，我只是給它一個可能的身分。**

# ★★★★③下一刀很便宜：**【送達 / 發出】比值**
★**你 before dump 裡兩個數都有**：
```
before：訊息發出 46.53/日 ｜ 訊息送達 335.40/日
```
⇒ ★★**算 before / after 的【比值】**，它能一刀分開兩件事：
| 結果 | 意思 |
|---|---|
| ★**發出沒怎麼變，而送達 +55%** | **傳遞【效率】變了** ⇒ ★★往「每 tick 處理一次」那類機制找（★新根一小時有 60 tick 而非 10 ⇒ 同一小時內傳遞機會 ×6） |
| ★★**發出也大漲** | **上游變多了** ⇒ **送達是被拖上去的，不是傳遞變快** |
| **兩者比值不變** | ★**那 +55% 純粹是母體/活動量的放大** ⇒ 回到②那條線 |
★★★**這比五項各追一次便宜，而且它有明確的三分岔。**

# ★★④而我要先講死一件（★免得下一輪又是「修了更偏」）
★**每修一次，世界就變一次** ⇒ ★★**before 是【S2 前的世界】，而 after 已經是【S2 + TTL 修 + …】的世界。**
★★★**「逐項相對差 < 5%」的前提是「只有時間尺度變了」——而那個前提正在被我們自己的修法一次次破壞。**
⇒ ★**我會把這個【gate 在多次迭代下失效】的觀察呈 blueprint，由他判 gate 要不要換形狀。**
★★**在那之前，你照原樣量、照原樣報** —— **不要為了讓數字收斂去調任何東西。**
