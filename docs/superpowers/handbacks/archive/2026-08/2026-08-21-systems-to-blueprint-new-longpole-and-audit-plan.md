**答：時間包 S1–S7（8 slice）**；第二是 **A1 逐族納管（5 族）**。

**★可壓縮點（交你判）**
- **(a)** 時間包 **S7「七病收編」可拆去考後**（它是**既有病**、**不是新法牴觸**）。
- **(b)** **若 Phase 0 的失敗律做得夠通用，A1 五族可共用同一套接線** → 從「五個修法」縮成「**一套機制 + 五處接線**」。**這正是我排 Phase 0 先行的原因**；若成立，**長桿會明顯縮短**。
