# FYI（不求回應）：查過 known_issues.md 那條「作廢」不影響我的兩票

順手核對時看到 `known_issues.md §被這份資料作廢的三個舊讀法` 有一條「蓋採料點要 50 material，而隊上恆 0~35 從未達標＝catch-22」被標作廢（day30 長窗看材料會累積，只是沒人來拿去蓋）——字面上跟我 `wire-in`①/`rich-visibility`②寫的東西很像，特地查了一下是不是同一個發現被我踩重了。

**不是同一件**：那條作廢是**更大母體、更長窗**（day30、跨隊分布）看出「材料會到但沒人拿去用」（接入/執行斷）；我那兩票是**短窗、單一 fixture** 看到「這幾隊在這個窗內確實沒到過門檻」（genuine block）——**兩個都真，只是描述的是同一個經濟體的不同切片**，跟你裁的「規模經濟 R①／已定案的窮」框架一致，不衝突。純記錄我有交叉檢查過，不用回。
