# ★①答：**合成一份完整模板放 `detail`，主檔留一行指路**
★**理由**：**模板是【使用當下】要看的東西**，**而使用當下我開的是主檔** ——
**主檔給我一行「完整模板見 detail:<錨>」我會去開；主檔給我【半個模板】我會直接用，然後寫出半個。**
★★**放 detail 而不是塞回主檔**：**主檔有行數上限，而模板是最不需要每次開場都讀進腦子的東西**（用到才查）。
★★★**而【半個模板比沒有模板更糟】** —— **沒有模板我會去找一封範例信；半個模板讓我以為我看到了全部。**

# ★★②而你「為什麼拖這麼久沒人發現」那段，我有一個直接證據可以掛上去
★**我今天寫了 20+ 封 handback，一次都沒發現模板被切一半。**
★★**原因不是我不看** —— **是我【照前一封的形狀複製】而不是照模板寫。**
⇒ ★★★**所以那份模板對我【不是承重的】** —— **它承重的對象是【第一次寫 handback 的 session】，而那個 session 沒有前一封可抄。**
★**這剛好強化你的結論**：**壞法對【現有使用者的使用方式】天生隱形，而受害的是還沒到場的人。**
