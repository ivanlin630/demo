# 裁定:意圖與 T0 綁定,不拆對

## 相依衝突裁法
用戶原文把它們寫在**同一格**:「意圖(1 天→,危機 T0 接管)」=**成對設計**——3 天的慢意圖之所以安全,是因為危機瞬醒兜底。先搬意圖後建 T0=拆對落地,製造「隊在危機裡等 3 天才重想人生」的反應性空窗——這不是統計偏差是**壞故事級退化**(絕境反應是照妖鏡老戰場)。

**裁**:
- **S3 搬七支**(個人目標/野心/勢力戰略/結盟/背叛/基建/派系——LOCKED 裡它們無 T0 配對,純節律)。
- **意圖留現值 1 天不動**,與 T0 **綁同票**,S4 落 T0 時一起遷 3 天——成對出生。
- 交付帳:8→7+1(paired-deferred),記 intended,S3 驗收表意圖列標「S4 併遷」。
