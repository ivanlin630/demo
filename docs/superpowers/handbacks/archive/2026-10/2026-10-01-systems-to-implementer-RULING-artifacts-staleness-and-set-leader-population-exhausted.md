# 一、artifacts 那件：你的判準我收，而裁定不是「進閘比對」

★你放上檯面的那句我抄進判準庫：
> **一份產出如果沒有任何斷言在讀它，它的過期是靜默的** —— 而它比沒有那份產出更糟
> （沒有的話人會去跑，有的話人會去讀）。

★★而它為什麼會發生也講得清楚：那一格的 expect **只比橫幅那一行**，而 artifacts 是它的**產出**
⇒ 沒有人在讀 ⇒ repo 裡躺著一份**說謊的卷面**（打開看到 72 筆 (d)，而世界早就 0 筆）。

**★★★裁：不要把 artifacts 的【內容】進閘**（你自己已經指出那個坑：
把「症狀 N 筆｜步數 N」釘進 expect ⇒ 那一格會變成「**世界不許改**」的閘）。
**要做的是讓【過期】不靜默**：

```
①artifacts 第一行必須帶【產生它的樹】：`跑的是哪一棵樹：<sha>`（你這一輪已經加了 ⇒ 保留）
②★那支床自己多印一行：**那個 sha 落後現在的 HEAD 幾顆 commit**
   （`git rev-list --count <sha>..HEAD`），並且斷言**那個 sha 是 HEAD 的祖先**
   —— ★★祖先那一條是真的會紅的（artifacts 來自一棵不在歷史上的樹 ＝ 有人手改過它）
③★★★而【落後幾顆】**不設門檻、只印出來**：門檻會漂（今天 5 顆合理、下週 50 顆也合理），
   而一個**印在卷面上的距離**讓「114 列來自 20 顆 commit 前」這件事不再是靜默的。
⇒ ★這不是新開一支閘（用戶立法「不要一直加閘」）：它是**產出 artifacts 的那支床自己**
  多報一個關於它自己產出的數 —— 而它最該報那個數。
```
