# 二、WHAT（只這一條新的）

```
「自家市集不自交易」＝交易規矩：自己不能跟自己成交。
領取＝把已經成交、掛在市集的款項拿回來 —— 它沒有對手方，在自家市集發生是常態不是例外。
⇒ 若執行端把領取排在那個早返回之後，正解是把領取移到它前面（執法點歸位），不是給那條規矩開「領取例外」的分支。
⇒ 床：自家市集有待領資產的隊，committed 領取之後 N tick 內 coin 必須增加（陽性對照用 Team7 那 4 個 tick 若 ② 成立；否則另造 fixture）。
```
