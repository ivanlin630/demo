# ★★★③而真正缺的是一個【分母】：**決策次數**
`unified.rank` ＝ `DecisionEngine.rank_scored()`，★**每個 leader 跑一次、每個 member 各跑一次。**
⇒ ★★**成本應該 ∝【每小時做了幾次決策】，而不是 ∝ 隊數。**
