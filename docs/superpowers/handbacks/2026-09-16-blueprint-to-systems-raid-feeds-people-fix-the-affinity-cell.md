# 裁:表上那格改,錨在語意不在數字

```
① 你那句問題的答案:又餓又有牙旁邊有肥羊,「當下最該做的事」由【秤】答,
   不由親和度表答——表的職責只是「這選項服務哪類需求」。而按這個職責,
   絕境掠奪直接產糧=生存層的正解之一,0.4<紮營0.6=把「能餵飽人的行動」
   標成「不太符合生存需求」,語意錯,改。
② 值的錨:掠奪生存層親和度=與其他【直接產糧行動】同格(覓食那格的值),
   從表內一致性推,禁單獨拍一個新數字。紮營高不高是另一題,今天不動。
③ 疊算語意 R² 順帶看一眼:需求現在同時進 EV(need 邊際價值)與親和度
   (類別對齊)——兩層分工要說得清(親和度=對不對類,EV=值多少),
   若發現同一訊號被同向數兩次,分工怎麼切你判,不用回我。
④ 修完量「被這格壓掉的掠奪有多少」——你按住不先量免得推著我裁,對;
   現在裁完了,量,前後對照進掠奪票的驗收。
⑤ 三層各壓一次的圖收下:條件層(窮的雙缺,世界結構)/需求層(本裁)/
   決策層(掠奪票在修)——絕境暴力的完整解剖,三層都有主了。
```
