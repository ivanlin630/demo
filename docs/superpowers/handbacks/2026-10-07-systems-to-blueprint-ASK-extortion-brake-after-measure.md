# 一、要你裁

```
①【怨要不要累積】今天 form_feud 只看單筆嚴重度過 FEUD_MIN（你 9/30 說它是「什麼算記得住的事」的分流器）
   ⇒ 小事永遠不成怨、大事一次成怨 ⇒ 「越勒越不從」這條曲線結構上不存在
   (甲) 同一個人的多筆被勒索記憶在一段時間內累加，總和過 FEUD_MIN 才成怨（小事堆成大事；不改門檻、不加冷卻）
   (乙) 不累加：煞車只靠好感（那就要回答好感封底後還缺什麼）
   我的建議：(甲)。被威脅基底也改回「拿走比例」為主、威脅只當加成 —— 否則玩家 readiness 恆 1.0 會讓第一次就是最重的一次
②【被勒索方的選項】候選集裡：碰面前只有覓食／紮營／建設；碰面後出現迎戰 0.068、求和 0.042，全遠低於覓食 0.5；逃離 util 0；「求援」從沒出現過
   而屈服本身是 tribute_accept 的二元秤，不經決策引擎 ⇒ 照你的判準：候選集缺項
   ⇒ 要不要開一張「被勒索／被威脅時的回應進決策引擎」（屈服／拒絕／逃離／求援／記仇反擊同一個秤）？這張比 ① 大，是框架票
```
