# ①第四種解釋——兩個seed方向一致，質性結論站得住，量級不宜過度解讀

親自核了普查原始輸出：
```
seed1337: 選中strong_neighbor=22｜X(live有據點)=3｜Y(看過)=0
seed42:   選中strong_neighbor=22｜X(live有據點)=5｜Y(看過)=1
```
兩個獨立seed都顯示同一個形狀：**22→X這段掉得比X→Y這段更多**(seed1337: 19 vs 3；
seed42: 17 vs 4)。這代表「選中的host站在據點上」這件事本身的稀缺，比「有沒有被親眼看過」
這個本票真正動的那個開關，對最終「有值的隊有多少」這個數字的影響更大——兩個seed獨立
指向同一個方向，這不是單一樣本的巧合，質性結論（母體本身罕見是主因，不是本票把它擋掉）
站得住。

但要誠實加一句：X=3、X=5是很小的絕對值，**「站得住」是指方向(哪個因素影響更大)，
不是指可以拿這兩個數字去算精確比例**——如果你或任何人之後想引用「約13-23%的強鄰站在
據點上」這種具體百分比，那才是樣本太小撐不住的地方，要另外量更長的窗口或更多seed才能
談數字精度。方向性結論可以用，精確量級不行，這條界線要劃清楚。

# ②佔領那條的「不可判」——判得對，不是過度保守

核了兩個seed：`選中occupy_target的隊=0`——兩邊都是，這不是「碰巧樣本少」，是**這個決策分支
本身在12天窗口裡一次都沒被觸發**。母體是0,不是接近0，[不可判]是正確判法，跟今天別的
案例(escrow-audit的checked>0、equivalence-pruning剛剛才討論過的母體恆空)是同一個處置，
一致。

「有沒有哪一格已經被床蓋到而他過度保守」——**沒有，這是兩個不同的問題，不能互相借**。
我自己重跑了床，確認1-d那三格（occupy_target_flow的機制）全部[OK]——**這證明的是
『如果occupy_target真的被選中，估值邏輯是對的』**，是一個邏輯正確性的斷言，跟世界實際上
會不會選中它是兩件事。床證了前者，世界普查在問後者，而後者這一輪的答案就是「沒有樣本」——
拿床的PASS去填補世界普查的[不可判]，會把「邏輯對」偷換成「這件事在世界裡常發生」，是這
整條線今天已經打過好幾次的假窮盡形態。這裡沒有犯，保持[不可判]是對的，不是保守，是誠實。

# ③跨樹改同世界內X-Y——判準軸本身正確

你的軸「要驗的變因在不在同一棵樹裡」用對了方向：這一票要驗的是**一個邏輯子集關係**
（belief-gated的候選集是不是live-gated候選集的子集，而且子集邊界劃在哪）——這個問題
的答案完全可以在**同一次世界跑**裡回答(對每個candidate同時檢查live條件跟belief條件)，
不需要真的分別在兩棵不同的樹上各跑一次。跨樹比較(前3後0那種)混進的是**兩次不同RNG序列
導致的世界分岔**（104隊vs98隊那個差異），那個分岔本身跟這一票的修法邏輯無關,拿它來說
「3變成0是因為belief閘」是把世界噪音當成信號——你判斷"換掉跨樹比"是對的,不是找藉口
避開一個難做的驗收,是換成真正能回答這個問題的工具。
