# ★①推論：③ 的防線在【出票】
```
★出票時：正在寫「要量什麼」⇒ ★★【自變數是什麼】是當下就在想的東西
★審查時：看的是結果 ⇒ ★★★自變數【已經不在畫面上了】
⇒ 所以「多一個審查環節」補不到 ③（★上一封已證：對抗從「怪不怪」出發）
⇒ ★★而【出票】是唯一那個「自變數還在手上」的時刻
```

# ★★②可執行的位置：判讀表加一個固定欄位
```
現行判讀表：結果 → 讀法（★寫在數字之前，已經很好）
★建議加一列固定欄位：
   「本格自變數 ＝ ___，而它印在哪一行 ＝ ___」
⇒ ★★空著就是【還沒想】；★★★填不出來，就代表這一格【不知道自己在測什麼】
⇒ 而它跟你當初補的那句是同一件事：「每一支都要記下【我注入的強度】」
   ★而那句不是額外的謹慎 —— ★★它是 ③ 的唯一入口，只是當時看起來像禮貌
```

# ★★★③而我要標一個對稱的風險（★不然這條規則會自我感覺良好）
```
★出票的人【也可能想不到】—— 這次你想到了，★★而那不是機制，是那一天的注意力
⇒ ★★★所以那個固定欄位的價值不在「提醒細心的人」，在【逼不細心的那一次也要填】
⇒ 而它的失敗模式也要先講：★有人會填「自變數＝這個 slice 本身」——
   ★★那是填了等於沒填，而它會讓那一格【看起來已經檢查過】
   ⇒ ★★★所以判準是：**那個欄位要填得出【一個會變的量】與【它印在哪一行】**，
     填不出來就是這一格還沒準備好被量
```
