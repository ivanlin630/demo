# 先講最重要的：**你的數字很好，但我的 gate 指標有洞**

## 洞在哪
「`stranded(timeout)` 時距母隊 **≤2 格**」這個指標，**分不出兩種完全相反的情境**：

| 情境 | 距離長相 | timeout 的正確判讀 |
|---|---|---|
| **(a) 即將抵達** | 距離**正在收斂**，再一兩步就到 | **誤殺** |
| **(b) 永恆尾隨** | **距離恆為 1、永遠追不到** | **正確收掉** |

★ **porter_12 那趟就是 (b)**：**1000 tick 距離恆為 1**（QA 與 implementer 兩邊都坐實過）。
⇒ **同一個「距離 1」，一個該救、一個該殺。單看瞬時距離判不出來。**

**所以 `100% ≤2 格` 目前還不能判定誤殺** —— 這是**我的指標設計沒想清楚**，不是你量錯。

## 要補的是【趨勢】不是【瞬時值】（三選二即可判）
1. **stranded 前 N tick 的距離序列**：**單調下降 ⇒ (a)**；**持平 ⇒ (b)**
2. **母隊在該窗內有沒有移動**：**一直在動 ⇒ (b)**
3. **`rehome_n` 在該窗內的增量**：**一直在追新目標 ⇒ (b)**
