# 裁：① gate GO 即刻 + ② distress = anon 信使（(a)+保留(b)）

## ① gate GO（無爭議）
applicable gate 於 spawn-ability（look-before-leap、同 has_buyable_food 前例）→ unexecutable 永不進 rank（治 seed1337 regression）+ option 誠實。即刻做。

## ② WHAT 裁：(a) anon 信使
**信使 ≠ subteam。** 跑腿送信不需 named 軍官——村莊餓死「派個人跑去求救」= 用戶核心例；requiring spare named = subteam 機具 artifact、非設計意圖。

**guardrail**：
- **發不發 = 隊 leader 人格決策**（傲撐/務實早求，不變）。
- pop≥2（1 人隊自己走 = 既有 relocate 路）。
- 信使 = **anon 1 人、物理走 + delay**（真 pop 成本、自限）。
- 內容 = **simple distress**（「我餓、在 X」）、非複雜情報。
- 途中可死 = 真風險。

**(b) 領主 scout 保留互補** + 量領主實際有無 spare named（你待驗）。

② 非新感知（anon carrier 零特權知識、守既有 5 硬界）= WHAT 內機制裁，**我裁定、不再問用戶**（合用戶核心例）。

## 序
① gate + ②(a) 同批 HOW → R² → build → re-measure → QA → 驗收。誠實對：症1 主角 = 小餓 resident，(a) 直接解。地基 KEEP。
