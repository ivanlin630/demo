# 一、兩問的裁

```
①進不進 belief：進，且必進。
   理由：#41 附身=繼承記憶（他知道的你全知道 ⇒ 你問到的他也得知道）；資訊網「一個資訊模型零特例」
   ⇒ 打聽到的東西＝一筆 claim，source=被問隊 id、tick=now、走 BeliefSystem 既有寫入（跟 relay 到達同一條）。
   ★禁：只印給玩家看不寫 belief（那是今天的現況，也是 P13b 量出 fp 不變的原因）。
②代價：v1＝對方【同不同意】，由被問隊領袖秤，不是常數價。
   秤的輸入：關係/恩怨帳（#56 人級 typed 邊）、是否敵對勢力、領袖人格（開放/多疑）、你們是否同 faction。
   輸出：拒答（回結果句「他不願多說」）／答（給 claims）。
   ★答的內容＝他 belief 裡【該主題】的 claim（市場/威脅/據點/人）——他不知道的給不了 ⇒ 零 god-view，不用另造內容。
   ★收費（用幣或物換情報、商人賣情報）＝待辦，等 #51 賣家兩型與市場厚度到位再接，不在 v1 偷渡常數價。
③時間成本：v1 不另收（跟其他互動一樣在消費 tick 內完成）；「問話占一個時辰」若要做是 TimeScale 的事，另票。
```

# 二、P13b 那格的去向

```
P13b「confirm_gather_intel 連呼 5 次 fp 不變」現在要【翻紅】：問成功一次 ⇒ 玩家隊 belief 多 ≥1 claim ⇒ fp 變。
拒答那次 fp 仍不變（除了可能的恩怨帳寫入，HOW 定要不要記「被拒」）。
陽性對照：把 belief 寫入拿掉 ⇒ 這格回到「不變」必紅。
```

# 三、驗收句

```
同格、關係中性、對方 belief 有市場 claim ⇒ 問「市場」⇒ 結果句列出他給的 claim 摘要，玩家記憶頁多那幾筆，來源標「來自 TeamX」。
對方敵對 ⇒ 拒答，記憶頁不變。
對方 belief 裡沒有該主題 ⇒ 結果句「他也不知道」，記憶頁不變（不是拒答，是不知道；兩句要分）。
```
