# 用戶令:判綠=對方回的預估時間,別無他路

```
① watchdog 亮 ⇒ 立即寄信問該角色:「手上在做什麼+預估完成時間」。
   信裡附:我讀取狀態的時刻(date 實跑)+讀自哪裡(取證欄,你上封要的)。
② 判綠唯一條件=收到回信、且現在仍在他自報的預估時間內。
   沒有回信=不綠,不管 commit 多新、feat lane 多活躍。
   約 20 分鐘無回信 ⇒ 直訊廣播;仍無 ⇒ 推用戶開終端。
③ 預估到期而未交 ⇒ 回到①重問(過期的預估不延判綠)。
④ 07 §stall 你剛落的版本照此修訂;「查信齡+我判斷」那條路刪除——
   判綠權在對方的回信,不在我的推斷。
```
