# ★arc reframe：material 取得脊椎 = 決策層無「material-need → found-forest」pathway

## 真 root（race 前提崩 + 補充坐實）
race 框架前提 measure 崩（0 清伐事件、forest pool 不動）→ 補充 code-scout 坐實真 root：**決策層根本沒有「material-need → found forest outpost」pathway**。
- `settle_fit`（`terms.gd:184-190`）= **flat by option-type**（駐守 .9 / 生產建設 .4 / else 0），**讀零 terrain/material/forest**。
- 建設 option terms = `[settle_fit, ambition_drive]` → **founding = ambition + 知足行為，非 resource-acquisition**。
- ∴ 缺料隊**零決策 pull 去 forest**——harvest near-zero 的決策層因（不只 gate 矛盾②，是 **motivationally absent**、連想都沒想去 forest）。

## ★這是本場病的最深版 + means-end 真 binding 處
- **flat 決策常數病最深版**：該 need/utility 驅動的「要不要 expand / 去哪」，被拍死成 flat by option-type 常數（同 extraction 0.4 / cost / reserve_factor 族）。
- **means-end 核心缺口**：決策模型不會「我需要 X → X 在某地 → 去拿」。
- **★訂正我先前**：我說 means-end 在 afford 層 latent-not-binding——對，但**在取得層是真 binding**。**這裡才是 means-end 真正咬住的地方**（不是 afford，是 acquisition）。

## ★keystone 修方向（WHAT）
把 **material-need 接進 expand/settle 動機**：缺料隊 (a) 被 pull 去 expand（取得 material）、(b) 往 material-rich 地形（forest）。
- = **need WEIGHT**（utility-driven，人格 modulate：野心隊 expand 更多），**非 hard gate**。
- 合 **憲法「utility 餵 utility」+ 剛定的「人格 WEIGH 不 GATE」+ material-territory 願景**（隊追 forest 因為需要 material）。

## ★序 reframe
1. **KEYSTONE = settle-motive material-blind → need-aware**（root；everything 下游沒它 moot）。
2. **gate 矛盾②** = fix contradiction（attempt-gate 8 vs effective 13、浪費 100%）= **hygiene**。但★這是 **repopulate 自己空 outpost 非 forest-grab 閥**，且**下游於 motive**（gate 通了隊也不想去 forest）→ **次要**；方向傾向 **enable**（擴張是 material-territory 引擎）但 measure 母隊 viability。
3. **tile-selection forest-bias** = 補 measure gap（settle_fit 評 option 非 tile；chosen tile 偏不偏 forest 未查 → 決定 (b) 要不要另修）。

## ★PARK（下游，隊上 forest 採之後才有意義）

- BUY 閥③（沒隊產 material = 無賣家，supply 存在才修）。
