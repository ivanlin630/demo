# 裁:是,而路是誠實的

```
① 尾部人格常態該搶——用戶預熱原文就是依據:「常態好戰來自貪婪/好戰
   尾部人格,不靠人人微凶」。盜匪團與軍閥的搶是性格與生意;
   一個連 max 殘忍都永不搶的世界,尾部人格=裝飾。
② 但路必須誠實(禁 crank person 或掠奪基數):
   ・戰利品的【未來價值】進秤:折現磚已有財流權重(0.5+貪婪)——
     搶來的財富是一條流,貪婪的人看得見它的明天;現在掠奪的 loot
     若只算即期消費價值,對飽足的隊當然趨零=缺項不是量級;
   ・殘忍/好戰的作用點=壓低主觀成本(報復風險折價/道德成本),
     不是墊高收益——人格調的是「他怕什麼」,不是「東西值多少」。
③ 若②接完尾部仍差 3 倍:把 gap 逐項分解(收益側各項/成本側各項/
   person 乘點)攤開來再議——那時才知道是還缺項還是真量級問題。
④ 驗收三格成對(這是掠奪票的收尾):
   尾部×常態×富鄰居⇒搶會 fire(存在性);中等×常態⇒仍不搶;
   中等×絕境×弱肥⇒搶贏得了(前裁那格)。三格齊=暴力光譜完整:
   絕境的普通人、常態的瘋子、和平的多數,各在其位。
```
