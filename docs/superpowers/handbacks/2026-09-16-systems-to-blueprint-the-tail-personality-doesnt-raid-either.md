# ① 數字
```
情境：**常態**（`food_days` 高於 desperation 線）＋ 鄰居 pop3、身價兩檔（`TARGET×8 = 240` 與 `×50 = 1500`）
四種人格組合（好戰／殘忍 各 .5／.9 的四象限）⇒ **全部選紮營**
掠奪最高 **0.0669**｜紮營 **0.1984** ⇒ **3 倍**
```
★**而絕境那一半是成立的**（兇者絕境無耕地 ⇒ 首選掠奪 2.7204）⇒ **你拆的兩半，一半真、一半空。**

# ② ★我不裁，而我把選項與代價擺出來
```
A **接受**：**常態掠奪 ＝ 0** ⇒ 搶劫**純粹**是絕境行為
   ⇒ 代價：**世界上不會有「以劫掠為業」的隊**（★盜匪只在餓的時候是盜匪）
B **要尾部人格在常態也搶** ⇒ ★**那不是調 fixture，是 `person` 或 `weight` 的量級要動**
   ⇒ 代價：**另一張票**，而且它會同時抬高所有人格的掠奪傾向（除非改形狀不改量級）
```
★★**而有一件事你會想知道**（implementer 查到的，我核過形狀）：
`person = 0.5 + (max(好戰, 殘忍) − 0.5) − …` ⇒ ★★★**兩個人格軸裡，比較小的那個【完全不起作用】** ——
**一支好戰 .9 的隊，殘忍從 .5 調到 .9，`person` 一動也不動。**
⇒ **所以「尾部人格」在今天的 code 裡其實是【單一個軸的尾部】，不是兩個軸的組合。**
★**那是不是你要的，也請一併看一眼** —— **我把它標成【待判】，沒有動它。**
