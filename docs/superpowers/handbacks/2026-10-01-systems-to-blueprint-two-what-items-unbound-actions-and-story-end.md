# 一、★互動那一屏的數字鍵不夠用了 —— 結構我裁了，**剩兩個 taste 給你**

```
現況（實作端撞到、我開檔核過）：
  ·自家隊動作從「只列可做的」改成**常駐全列 11 列**（＝你裁的「不可做也要列出＋原因」）
  ·而目標清單的鍵是**偏移算出來的**：`text_ui_main.gd:1814`
    `pending_idx = num − self_acts.size()` ⇒ self 變成常駐 11
    ⇒ `num − 11` 對 num=0..8 **全是負數** ⇒ ★**目標選擇用數字鍵按不到了**
★★而這不是新壞掉：同一個算式本來就違反不變量 #10（鍵的意義由一個會變的計數決定），
  本票把 self 釘成常數之後，那個違反**消失了**，病換成「鍵不夠用」。
```

**★我已經裁掉的（HOW，依據是既有條文與既有語彙，不是新發明）**：

```
①刪掉偏移（不是調偏移）②兩張清單各自獨佔 1..9**且各自獨佔頁計數**
③切換兩者的**必須是玩家按的鍵**（不變量 #10 的推論逐字授權）
④鍵不夠用就**翻頁**（`,` `.` 已是交易／倉庫／互動三處的既有語彙，畫面已經在印「第 N/M 頁」）
  ★**不得用字母**（字母被強制回應獨佔）
⇒ ★★所以「11 選 9、其餘印（未綁鍵）」**不必做**：11 列 ＝ 2 頁，**零未綁鍵**。
⇒ ★★★順帶解掉一件我原本要單獨呈你的事：`ignore`／`beg`／`offer_surrender`
  三個動作今天**看得見而按不到**（`text_ui_view.gd:88-94` 具名寫著）
  —— 翻頁之後它們拿得到鍵，**這一件不用你裁了**。
```

**★要你裁的只剩兩個純 taste（成本我標了）**：

```
(丙-1) **並列兩屏**：自家隊動作屏 ⇄ 目標清單屏，一鍵切
  ⇒ 最小、可逆；兩屏各自獨享 1..9 與 `,` `.`，零新語彙。
(丙-2) **先選目標再列動作**（自家隊 ＝ 其中一個「目標」）
  ⇒ 概念更統一（一個清單模型零特例），★但它**重排玩家流程** ⇒ 比較貴，且要你想清楚
    「對自己隊做事」要不要先按一次「選自己」。
＋ 切換鍵用哪個、兩屏的標題文字怎麼寫。
★我的 HOW 意見：先 (丙-1)（最小可逆），(丙-2) 以後再說。
★★而**無論你裁哪個，實作端現在做的都留得住**（靜態鍵表、獨立頁計數、無偏移兩邊都要）
  ⇒ ★★★所以你**不用急**：他不是在等這一封才能動。
```

# 二、★★玩家那條線結束時，活介面一個字都不說

```
現況（我開檔＋grep 核過）：
  ·引擎**真的有**結束狀態：`state.game_over` ＋ `game_over_reason`
    寫者兩處：`event_system.gd:80-82`（「玩家絕後（Team%d 無繼承人）」，並 print `[GameOver]`）
              `player_command_system.gd:1188-1189`（「玩家絕後（隊已滅,無繼承人）」）
  ·`sim_runner.gd:114-116`：`game_over` ⇒ **凍結世界、不推進 tick**，回 `"game_over"`
  ·★★`grep -rn "game_over" scripts/ui/*.gd` ＝ **0 命中**
⇒ ★★★所以玩家看到的是：**世界停住了，而畫面什麼都沒說**。
  （那句 `[GameOver]` 只印在 stdout —— 玩家看不到 stdout。）
```

**要你裁的三個**：

```
(甲) 一屏結束畫面：死因 ＋ 那條線的幾個數（活了多久／隊伍最大規模／最後一件大事）＋ 任意鍵離開
  ⇒ 最貴，但它是「自己說故事」那把尺上**唯一真的收尾**。
(乙) 最小：狀態列印一行「故事已結束：<原因>」＋ 停止推進
  ⇒ 最便宜；★它只解決「畫面不說話」，不給收尾。
(丙) ★結束後**切觀察者**：玩家死了，世界**繼續跑**，視角變旁觀
  ⇒ ★★機制**已經存在**：`player_id == -1` 時「觀察者世界永不凍結」是明文寫死的
    （`event_system.gd:75`／`player_command_system.gd:1190`）
  ⇒ ★★★所以 (丙) 的 HOW 成本**可能比 (甲) 低**，而它是三個裡最有玩味的那個
    —— 但「玩家死後還能看世界」是一個 WHAT 選擇，不是我能裁的。
```

★**我的 HOW 意見**：(乙) 可以**先做**而不擋後面任何一個（它只是讓畫面開口）；
(丙) 的地基已經在了。(甲)(丙) 不互斥。
★★而這一件我認為**比第一件重要**：它不是「有個按鍵按不到」，
是**一條線走完了而遊戲沒有告訴玩家**。
