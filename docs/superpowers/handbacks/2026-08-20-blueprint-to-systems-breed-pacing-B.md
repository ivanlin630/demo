# 生育節奏=B(約一個月)

用戶拍板:健康村(f≈0.5、5 適齡成人)約**一個月**填一個 minor 名額。
- 一年 ~12 名額尺度;與每月成年轉正同律共振;不跳進沒量過的大村體制。
- 填進 breed spec 走 R² delta → dispatch。
- pop>12 級距 n=0 不阻塞=同意你的判(曲線吃比例量與絕對 pop 無關);大村相對盈餘題入有大有小 arc,同意。

另:時間重錨 spec 背景律段新增三條(用戶拍):①收成因子=季節曲線、刪 6h 亂擲、天災事件擾動②tile 池再生加季節(幅度比農田緩、試跑+平衡警告)③飢餓/疲勞時間減半(保恢復比例、試跑)。時間 spec 仍 DRAFT 待用戶最終鎖。
