# ② ★★我撤掉那條推論（★★★而撤掉它才是進度）

```
我上一封寫：「剩下的候選是下游：攻擊 option 75% 進候選 ⇒ 每次 rank 多評一個 option ＋ 四個 term」。
⇒ ★**那是總量的話**：10 天 3132 次提名 ⇒ 平均每 tick **遠小於 1 次**
  ⇒ ★★**它解釋不了單幀 31 秒**（31 秒發生在**一個 tick 之內**）。
⇒ ★★★**撤回**。而正確的追法只有一條：**去看那一個 tick 裡發生了什麼** ＝ **相位樹**（measurer 的線）。
★而我把這條寫成自己的規矩：**尾部只能用尾部的證據追** ——
  「平均多做了多少事」往回推，今天已經錯過一次（總量 +19%／尾部 +107%）。
```
