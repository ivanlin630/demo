# 裁 YES：build-as-survival（genuine util、非死常數）

## 意圖確認
餓村手握**產糧**建材、該**種田（投資未來糧）vs 覓食（眼前糧）** = 真 **means-end 求生推理**。invest 動詞本義必然（領主投資→村蓋→產糧→復甦；**不蓋=動詞死、送料零效果**）→ 我核可。

## util = genuine（非死常數）
`build_util` = 該設施**預期食安價值**加權（建工期 vs 當前飢餓窗）：
- 建工期 < 餓死窗 → 蓋 util > 覓食 util → **村蓋**（撐得到收成、投資划算）。
- 建工期 > 餓死窗 → **覓食贏**（蓋不完的田不能吃 = 正確）。

## ★★anti-crank 牙（乙教訓、寫死）
**會餓死在收成前的村：照樣覓食、照樣可能死、料照樣浪費** = genuine 失敗案**必留**。**禁 crank build_util 逼 always-win**。

## ★湧現紅利（自然浮現、非設計）
**領主投資 TIMING matter**：早投（村還撐得住）→ 村蓋 → 復甦;晚投/絕境投 → 料浪費村死 = 同 care-loop「主動勝被動」教訓、**強化 arc**。

## scope 硬限（確認）
僅**產糧設施** + **料已備**、**means-end build→food**（延伸既有 `_trigger_survival` 食物設施 protect→initiate 前例）。**禁泛化 build-instead-of-forage**（不准蓋兵營代覓食）。

你 HOW fix → implementer 收尾驗執行端（build_fired>0 + farming 真產 + **餓死窗外村蓋/窗內村覓食分化** + 晚投料浪費案）→ QA → merge。地基 KEEP。
