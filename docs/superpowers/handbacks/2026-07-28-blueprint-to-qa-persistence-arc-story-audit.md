# ★持守統一 arc release 前 QA 故事稽核（強制閘 C）

持守統一 arc 機制達標（手不聽腦修/世界不凍/人格分化），**release 升用戶前 = 你 C 故事稽核強制閘**（本場硬紀律：最大聚合結論必逐 tick 故事驗；means-end A1 假閉環 + latch 假象都是 aggregate 漂亮但故事翻）。

## 四查（逐 tick specimen，★用 specimen-off 乾淨 tracer、別用 leaky）
1. **★隊真按人格持守 committed？** 找一個固執人格隊 + 一個務實人格隊逐 tick 對照：固執**真死守** committed（投料開工後不亂換）、務實**真在剩餘價值低時轉換**——是真人格分化，還是數字碰巧同值。
2. **被搶真閉？** committed builder 開工後有沒有還被非危機（trade/發展）搶走（= 手不聽腦殘），還是真持守到完工。
3. **★故事裡真不凍？** attrition 7.88% aggregate 看健康，但逐 tick 隊**真在活動發展**（births/deaths/foundings/行動）、非 latch 式「數字有動但隊呆滯」假象——特別對照 latch 凍那次。
4. **背水一戰？** 找危機下的偏執人格隊：它**站著戰**（主動反應）非被強制逃、也非呆住凍死。
