# 修正：統領願景 + 升 believability 北極星不變量

覆蓋 `2026-06-28-...unify-commander-decision` 的「單一姿態/壓掉第二令」那段——**那是錯方向**。用戶走查校正：氣點不是「發兩個命令」，是**命令無法解釋從哪來、為什麼**。

## A. 統領願景修正（推理多重性，非收斂單一）
夢想 = **類深度 AI**：統領決策有**戰略意圖與推理**。

**多重命令 OK、甚至嚮往**——只要可解釋：主戰統領發「戰爭+外交」是對的，**戰為主、外交是掩人耳目**（欺敵/拖住敵盟/爭取時間）。

修正 WHAT：
1. **意圖驅動**：統領先 utility 選一個**戰略意圖**（征服敵X / 防衛 / 致富 / 擴張…）。
2. **意圖生成協同子命令**：征服X → 攻擊X（手段）+ 對X盟友外交（欺敵拖住）+ 徵收（籌軍費）= **多令服務同一意圖**。
3. **每令帶「為什麼」**（連回父意圖）：外交不是獨立閾值跳出，是**因為**服務戰爭，且是**不真心的戰術外交**。
4. **連貫來自共享意圖，非單一**。多重性是 feature。
5. （前版仍成立的：姿態/意圖要 commitment-hysteresis、吃人格、吃 belief 非真相；成熟並行軌=擴充。）

→ 廢掉前版「外交是不打時才做、單姿態」。改「意圖→協同子命令、欺敵可並發」。

## B. ★ 升不變量：凡 named 意圖必有可解釋驅動（請納 invariants.md）

**陳述**：每個 named 意圖（派系令 / 隊 task / 人物 action / 野心階）**必有可解釋驅動**，追得回根（need/value/belief/父意圖）。**追不出驅動 = bug**（閾值/tag/latch 憑空跳=該病）。

**這是兩條 arc 的合一**：
- 因果脊椎（運動 vs 因果）+ 統一決策（一連貫決策）→ **本條把它升成強制不變量**。驅動鏈 = 因果脊椎顯化+強制。

**為何是對的北極星（非鍍金）**：直接定義玩家錨 C 玩法。世界 driver-complete → 玩家情報遊戲 = **從看得到的 action 反推看不到的 driver**（外交=真結盟還是欺敵？囤糧=遠征還是投機？）。欺敵完美嵌入：driver 真實（服務征服X）、action 不真心 → 玩家賭錯被咬。亦是 believability 審計鏡（走任一意圖問 driver，答不出=洞）。

**範圍紀律（重要，別又亂修/鑽牛角尖）**：
- 北極星 + 不變量，**不是現在停下給所有 action 塞 driver 欄重寫**。
- **統領層現在落實**（commander-unify 第一處）。
- 其餘 = **審計鏡頭**，按 player-visibility 排序逐步補；新工作須滿足、舊工作照洞補。
