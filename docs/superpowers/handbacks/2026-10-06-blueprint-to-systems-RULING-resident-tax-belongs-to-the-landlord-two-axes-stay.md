# 一、裁定（WHAT）

```
土地軸：一格一地主。居民（TAG_PRODUCE 住在他人格）向【該格地主】繳居民稅（tax_rate＝地主人格＋處境，窗 v1 ①）。
勢力軸：一隊一盟主。成員向【自己勢力】繳貢（tribute 分支）。
兩軸獨立並存：一隊可同時是房客與成員 ⇒ 兩種稅都可能落在它身上，但每一種只有一個收款人。
★非地主對居民取財＝勒索／掠奪，不是稅：要走那兩條路的全部規矩（對方的決策、關係帳、濫按煞車、可拒絕、可反抗）。
「一隊一領主」不立為規則——它把兩個軸硬併成一個，會逼出「加入勢力就不能住別人的地」這種不自然的限制。
地主換人 ⇒ 居民身分與稅權跟著地走（屬家與歸屬 ⑤ 的待裁，先登 defer，不在票 R）。
```

# 二、票 R「居民稅收權屬地主」

```
現況：interaction_system.gd:663-720 的 PRODUCE 居民分支：收稅者找到一個居民即抽，註解「跳過勢力守衛」，沒有「收稅者＝居民所在格的 outpost_owner」檢查。
修：居民稅路加地主檢查（收稅者＝居民所在 tile 的 owner，或 HOW 定義的地主代理）；非地主進這條路 ⇒ 不是稅，改走勒索（既有路、既有後果）。勢力守衛照舊跳過（地主收房客的稅不看勢力，窗 v1 ①）。
床：佈置「非地主 vs 居民同格 ⇒ 下一 tick 居民稅條目＝0、若取財則 reason＝勒索」「地主 vs 居民 ⇒ 居民稅條目有、rate＝地主 tax_rate」；陽性對照用 Team7 在 (3,7)（owner 26）被 Team5 抽的那幾刀。

序：T 之後、票 A 普查床之前或並行由你排（它改經濟流向，觀察輪重跑要在它之後）。
```
