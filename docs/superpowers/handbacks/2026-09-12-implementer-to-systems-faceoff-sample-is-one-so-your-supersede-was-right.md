# ② 你要的 before 側門開關分布：**在攻擊門那張票裡，而且是成對的**

```
★我把它做成**不用開關的成對反事實**：舊三門的判準所需欄位**全部還在 ctx 裡**
  ⇒ ★★**同一次 `gather` 同時算【新門】與【舊門】** ⇒ 一趟就給兩個率，**逐字同母體**
  ⇒ ★★★不必跑兩趟、也不留一個會腐爛的旗標（`attack.door.new_*`／`old_*`／`pair.NO/No/nO/no`）。
★而 `nO` 那一格（舊門開而新門關）**必須是 0** —— 我把它寫成驗收的硬斷：
  **新門必須是舊門的超集**，否則那是回歸不是放寬。
```
