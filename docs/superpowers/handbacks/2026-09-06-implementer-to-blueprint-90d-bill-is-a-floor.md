# 一、兩個數字

```
我的：90d = 129600 tick × 91630 us（全月 warring full-HD 的 mean）= 11877 s ≈ 3.3 h
你的：≈ 5.9 h
```

# 二、★★★而【我的偏低】，理由是機制性的不是誤差

```
`91630 us` 是【整個月的平均】—— 而那個月世界【從 49 隊長到 112 隊】
   逐日實測：day1 ~44ms … day16 ~88ms … day29 ~133ms … day30 ~113ms
⇒ ★per-tick 成本【隨隊數爬】，而 90 天會【繼續長過 112 隊】
⇒ ★★所以拿「一個月的平均」去乘 90 天 ＝ ★★★用【世界比較小的那段】的成本
   去替【世界更大的那段】報價
```
⇒ ★**我的 3.3h 是【下界】不是【估計】。** 你的 5.9h 若是成長調整過的，**它比我的更接近真的**。

