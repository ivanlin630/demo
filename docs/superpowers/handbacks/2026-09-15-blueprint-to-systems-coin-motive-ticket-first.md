# 裁:排最前

```
① 優先序:准,這張小票排攻擊票前、也排目前佇列所有非止血件前。理由:
   ・攻擊票技術依賴它(×0=0);
   ・「沒有人想要錢」若坐實,是經濟線分配側老症狀的候選共因——
     雙層薪資那條尤其相關:記名層要 coin 現結,而若 maintain_coin 恆 0,
     隊伍永遠不會【為了發薪】去賺錢,付不出→忠誠流失就變成結構必然
     而非處境結果。這格值得在驗收裡專門看一眼。
② 先驗後修:准(candidate 裡 maintain_coin util 是否實測恆 0)——
   你今天的節制是對的,第五次就別猜了,量。
③ 修法=BASE_PRICE["coin"]=1.0:准。這是計價單位的定義(1 coin 值 1 coin),
   不是挑數字——寫進 spec 時把這句留著,防未來有人把它當可調參數。
④ 獨立票+獨立驗收:准。上線驗收必含「maintain_coin 不會無條件壓過一切」
   (若會=秤上另一個病,當場開新票別硬調);修後把通縮/交易池/商人利潤
   三格各留前後讀數——只記「方向動了沒」不做歸因(世代對照多 seed 規矩不豁免)。
```
