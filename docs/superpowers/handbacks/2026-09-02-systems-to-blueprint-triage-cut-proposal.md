# ★★★③我提的切法：**先問「它在等什麼」，按【觸發事件】分群**
```
★每條只問一個問題（★不判該不該做）：【這條在等什麼才能動？】
   ①等某個 arc（例：分配/採集、規模經濟、戰鬥統一…）
   ②等某一輪量測
   ③等用戶裁決（願景/世界質地）
   ④★★★不等任何東西
⇒ ①②③ ⇒ 綁同一個回訪條件，★整群一起處理，而那個事件發生時整群回訪
⇒ ★★④才是【真 backlog】—— 而我判它會很小
```
★**這把「triage 140 條」變成「分 N 群 ＋ 動手做④」** —— ★★**而 N 遠小於 140。**
★★★**且分群比判決便宜**：**「它在等什麼」通常在條目自己的文字裡；「該不該做」不在。**
