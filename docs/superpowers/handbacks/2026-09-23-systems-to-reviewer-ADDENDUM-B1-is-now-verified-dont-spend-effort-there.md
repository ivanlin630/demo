# 一、B1 結案：分母確實共用，逐位元對得上

我在送 R² 的信裡把 §1 那個減法標成「待驗斷言」。**現在不用了** ——
我去讀了原始 log（不是卷面摘要），兩個百分比印在同一段、用同一個絕對微秒總量：

```
seed1337（log:8604-8606）
  near.faction_ai = 143,167,037 us   ★印出來的單格佔比 50.8%
  S_fixed(7格+fai) = 198,169,389 us   ★印出來的 70.3%
  ⇒ 反推分母 = 198,169,389 / 0.703 = 281,891,023 us
  ⇒ 用這個分母回算 faction_ai = 50.79%   ← ★與卷面印的 50.8% 對得上
  ⇒ 7 格本身 = 198,169,389 − 143,167,037 = 55,002,352 us ＝ 19.51%

seed42（log:8139-8141）
  near.faction_ai = 67,775,383 us     ★印出來的 45.6%
  S_fixed          = 107,810,256 us    ★印出來的 72.5%
  ⇒ 反推分母 = 148,703,801 us ⇒ 回算 faction_ai = 45.58%   ← ★對得上
  ⇒ 7 格本身 = 40,034,873 us ＝ 26.92%
```

★**為什麼這算證明而不是算術巧合**：若兩個百分比用的是**不同**分母，
拿其中一個反推出來的分母去回算另一個，**不會**落在印出來那個數字的四捨五入誤差內。
兩顆種子各對一次，都落在 0.02 個百分點以內。

★★另一條獨立佐證：`55,002,352 us ÷ 110 個 pass = 500,021 us` ——
卷面「7 格每 pass 平均 = 500.0ms」那一行**是同一個數**。
⇒ 分子分母同一個母體（110 個 >2s 的 pass tick），沒有換母體。

★★★所以 spec §1 的結論成立、而且現在有主詞：

```
S_fixed(前置票之後) = 19.51%（seed1337）／26.92%（seed42）
⇒ 兩顆都在 40% 門檻【之內】——(A) 的天花板夠了
```

我會把這段補進 spec §1，把「這是推導不是量測」那句改成「這是從卷面 log 反推核對過的推導」。
