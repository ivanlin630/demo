# 裁：material 供給方向 = A（純取得閥，不加設施）— 用戶 2026-07-24 定案

## 方向定案：A（地理張力 = feature）
用戶裁 material 供給方向 = **A**：地理 food≠material 錯位是 **intended feature，非 bug、不 flatten**。

## ★關鍵邏輯（用戶）：material = 物流/地理，非耕作
- **food = 耕作**：作物**季節級**快再生 → farming 原地改良永續產量（`×(1+farming_level×0.5)`）coherent。
- **material = 物流/地理**：樹**年代級**慢生 → **無法原地快速增產** → 放大設施（育林/砍樹**皆**）在**時間尺度上不 coherent**。
- **∴ food 有 farming、material 無設施的不對稱 = 刻意、對的。** 材料取得只能**控產地（擴張搶 forest tile）+ 貿易 + 遷徙** = 取得閥，非原地增產。

## ★裁決
- **不加供給側設施**（伐木/育林/sawmill 皆否——時間尺度不 coherent）。
- **不 regen rebalance**（選項 b 否——flatten 地理張力）。
- **material 脊椎解 = 純取得閥**（GATE-B 貿易 + 擴張控地 + 遷徙）。

## ★用戶明選的後果（設計立場，非疏漏）
**材料稀缺是真的、發展是「競爭性」非「普世」**：能控 forest 地/買得到的隊才發展得起來，控不到 = 發展不起。**這是地理遊戲的核心張力非 bug**——長出搶 forest tile 衝突 + 材料貿易路線 + forest 材料國 ↔ plains 農業國互賴。**不是每個隊都該爬到頂，那正是戲。**

## ★measure 問（先量再定閥 spec，照本場紀律）
**aggregate 材料（全世界 forest regen 總量）夠不夠讓「修好閥」就解鎖發展，還是稀缺緊到本質競爭（只少數控地隊發展）？**
- 這決定：(1) 閥要修多強 (2) 要不要接受競爭性發展當設計（非全隊都該發展）。
- **別假設 aggregate 夠或不夠，measure。** systems 上封說 binding = 「aggregate SUPPLY + mismatch」——(ii) 賭 binding 主要在 mismatch（閥），若 measure 證 aggregate 也真不足，回報，那時再議（但仍不走加設施/regen，可能是接受競爭性 = 稀缺就是稀缺）。

## 序
- **取得閥 = GATE-B（貿易，已 queue）+ 擴張控地（bootstrap/expand，原 survival-blood thread）+ 遷徙。**
- **先 measure 現在缺料 plains 隊：三閥（買/擴張/遷徙）哪個對它最可達** → 定先修哪閥，別三個都猜（同本場「別預修、先量哪個近」紀律）。
- **ore→material 製造（c）用戶未選 = 暫緩**（未來 mountain-archetype 深度可回訪，但別拿來繞地理張力）。
- game-design:291 後已 folds 此 world-model 裁決。
- 三腿 material-hold 照 guard merit 已 merge（獨立正確性）。
