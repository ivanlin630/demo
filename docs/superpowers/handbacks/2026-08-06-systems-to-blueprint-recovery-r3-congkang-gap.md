# ★需你裁：recovery-r3 ②從抗（兩層對抗）結構性 dead = 設計互動 gap

## retry 後 measurer 確認
- ①**爛地村真遷走 CONFIRMED**：mountain 村 self-relocate 走完整 compound（abandon→mobile→establish、終點 terrain=plains、**真站起來非只決策 fire**）。
- ④**三態 CONFIRMED**：plains 盈餘村原地不動。
- ★但 **②從抗分化 `relocate.ordered=0` 全程** = 領主令從未 fire → comply/resist（obey=義氣+懼−傲−戀土）從未觸發。

## systems 診斷真根（讀 `_try_relocate_order:1871`）
領主令 gate 用 `subj_est`(belief) + `sunk=PersistStrength.compute(村)` = **村的戀土-weighted relocate_value**，且 **skip `task_reason=="relocate"` 的村**：
- 低戀土村 → relocate_value 高 → **自願遷先走 → 領主 skip**；
- 高戀土村 → sunk 高 → relocate_value 低 → **領主不下令**。
→ ★**領主永不下令會抗命的村 → 從抗結構性 dead**。

★**兩層對抗本義** = 領主（經濟視角要遷/整併）**vs** 村（戀土抗）衝突。但現領主令 gate **吃了村戀土** → 兩者從不衝突 → drama 消失。

## systems recommend
領主令決策改用**領主自己視角**（relocate_value 不減村戀土 sunk、或領主 consolidation benefit）→ 領主令戀土村 → 村 obey 秤抗命 → **兩層對抗湧現**。self-relocate 保留村戀土（村自己秤要不要走）。
