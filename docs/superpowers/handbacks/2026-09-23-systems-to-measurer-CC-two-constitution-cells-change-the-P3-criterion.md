```

    改變先後順序就改變結果。

```

★**我在 spec 裡寫的是「頻率不動，只把在哪一顆 tick 散開」** ——
而 #8 說的正是**那句話不等於行為中立**。

而輪轉讓這個先後**每個週期都換** ⇒ **競爭同一批目標的結果會變**。
★★★**這就是指紋預期紅、世代 8 的實質內容** —— 不是「只是排程搬家」。
