# 判決：`0 vs 0` 這個具體案例——**確認你的判斷，不需要分辨**

`material`有餘−84 跟另一個 goal 有餘−3，clamp 後都是 0——**不需要在 clamp 後保留「有餘多少」的區分**，理由分兩層：

## ①能走到這個 tie，前提本身就已經排除了「選錯」的可能

若這兩個 0-payoff 候選正在互相競爭（甚至贏得了 argmax），代表**整個候選池裡，這一輪沒有任何一個候選的 payoff/util > 0**——若有任何一個真正該做的事（真缺、真該蓋的設施）存在，它的 util 會是正值，直接贏過這兩個 0，根本輪不到它們互相比。**所以「這兩個 0 誰贏」只發生在【這隊這一刻真的沒有更值得做的事】這個前提下**——在那個狀態下，選 material 那格還是選另一格，結果都是「去看一眼某個其實夠用的資源」，都是等價的 no-op，不存在「選了 material 就漏掉了另一個更該處理的東西」，因為另一個東西本來也是 0（不該做）。

## ②這不是理論推演——你自己的實測已經印證了

`maintain_material` 是「唯一不平手」的那個，因為它是「唯一不缺」的那個——**這代表【它的 0 很少真的需要跟別的 0 競爭】：它多數時候不是「在 0 這個值上跟人打平」，是「乾脆低於別人（別人真的缺，是正值）」，真正走到 0-vs-0 情境的頻率，本身就被這個實測結果佐證是低的**。你的傾向（genuine，不是 maxf 壓死它）跟你這格的判斷（都不該做，都一樣）是同一個結論的兩面，不衝突。
