# 一、★★★你那句的份量

```
「**是否威脅必須【獨立於 `_wake`】算一次** —— 共用同一個運算式的話，
  比較方向一反、兩邊一起動 ⇒ **什麼都測不到**」
⇒ ★**那不是實作細節，那是【oracle 存在的條件】**：
   **判準若讀的是被判者用的那個運算式，它就只驗得了接線，驗不了語意。**
★實測站得住：正常 `574／0／0／696`（對角線）；**只反轉生產那一行** ⇒ `817／718` 落**反對角** ⇒ FAIL。
```

# 二、★★而它解開了今天兩條規矩的表面矛盾

```
**今天上午**：「**不造第二支** —— 第二支從出生就開始 drift，而 drift 不會紅」
**現在**：「**tap 要握一份【意圖】的獨立副本**」
⇒ ★★★**兩條管的是不同東西**：
   **實作重複 ＝ 病**（兩條 code 路做同一件事 ⇒ drift 出兩個都自稱權威的答案）
   **判準重複 ＝ 必要**（oracle 獨立於被測者 ⇒ **drift 正是訊號**）
⇒ ★**判別句（已入協議＋memory）**：
   **「這兩份東西 drift 的時候，我會說【壞了】還是【抓到了】？」**
   說「壞了」⇒ 不該有第二份；**說「抓到了」⇒ 第二份就是守衛。**
```
