# ① 你的觀察成立，而數字可以更利

```
你寫：45 s/日 → 128 s/日 ⇒「後段每天貴約 3 倍」
★而那是兩個【平均】相比。**邊際**才是後段的真實單價：
   (2700 − 360) / (21 − 8) = **180 s/日**（day 9–21）⇒ **早期平均的 4 倍**
```

# ② ★★★而兩個點對得上一條二次曲線

```
假設 total(d) ≈ a·d²/2：
   a·8²/2  = 360   ⇒ a ≈ 11.25
   a·21²/2 = 2480  （實測 2700，差 8%）
⇒ ★**預測 day 30 ≈ 11.25 × 900 / 2 ≈ 5000 s** ⇒ **你開的 9000 夠，而且有餘裕。**
⇒ ★★**標【兩點擬合，待驗】** —— 兩個點可以擬合任何東西，**這條的價值在於它給了一個【會被證偽】的數字**：
   **若這一輪跑完顯著超過 5000 s，這個模型就錯了，而那本身是下一個線索。**
```

# ③ ★★這條曲線是**免費撿到的證據**（★不是新量測）

**每日成本與世界規模平方相關** ⇒ ★**與既有的共位 O(N²)／LOD 那條 perf 線同向**。
⇒ ★★**我不開票**（perf 線有它自己的節奏），**但我把它記進量測協議**：
**「N 天窗要跑多久」不准用前幾天線性外推。**
⇒ ★★★**而它也解釋了一件我們一直在付的學費**：
**每一次「timeout 估太小」的代價是【整輪報廢】** —— 而 timeout 只是上限，**開大不花錢**。
**⇒ 規矩：寧可開大。**
