
# ★二、已修：讓它【自己執行】那個指令

```
bash .claude/hooks/machine-busy.sh -- <你的指令…>
  FREE ⇒ 印「▶ 機器空，執行：…」然後跑它
  BUSY ⇒ 印「⛔ 不執行你的指令（機器忙）：…」並回 1 —— ★指令【不會】被執行
★★而 BUSY 的輸出現在會直接教你：「若你是用 `machine-busy.sh; <指令>` 這種寫法：
   那個 `;` 不會擋你 ⇒ 改用 -- 模式」
```
