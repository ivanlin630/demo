# 全面回溯充足性稽核（QA 反轉的執行首跑）

承 `qa-inversion` R1-R6。用戶推論成立：**貿易（最簡單最好量的環）都能以「非零」混過驗收 → 舊 bar 下過關的所有系統同等可疑**。與其用戶玩測一個個撞（成本燒用戶身上），一次掃完。

## 範圍與性質（講清楚：驗 fire 率，非重建）
- **不動**：機制內部邏輯（unit/決定性測全過者）、守恆/架構（零重犯紀錄）、已帶分母驗過的（同化率/狼弧/捕俘漏斗）。
- **重驗一件事**：每條環/鏈**在 default 自然世界 fire 得夠不夠**。

## 執行：全系統率表 + 世界句子判決
default 自然世界（≥2 seeds、6 月+）自跑，產出：

**① 率表（R3：全部帶分母，裸計數不收）**，至少涵蓋：
```
貿易鏈    成交/訂單、成交/月/村對（六站漏斗=其中一列,已在飛）
消息傳播  送達/發出、被消費/送達、失真率
belief    決策讀到實質 belief 的比率（vs 空 fallback）、claim 新鮮度
G3 識破   識破/謊言、查證 scout 派出/矛盾事件、口碑更新 fire 率
外交      envoy delivered/dispatched（已知 0=首列病單）、提案 accept 率
RelationGraph 血仇/恩義改變結果的次數/相關互動數（剛接線,驗真的在咬）
意圖→行為 各 intent「想=做」轉化率（specimen 擴多樣本）
捕俘/同化/佔村/立國 各環轉化（漏斗既有,補分母格式）
天災/事件 fire 率（event 系統現況）
```

**② 世界句子判決（R4）**：每列統計唸成世界的句子（「十幾個村半年買賣六次」式），**以觀者身分標 荒謬/稀薄/健康**，按荒謬度排序。

**③ 產出 = 一份可讀判決表**：哪些真活/哪些啞/哪些半啞 + 病單排序 + 每病預估修法量級（wiring/閾值/真缺件）。交藍圖裁修序。

## 定位
- 這**就是** R1-R6 三層機器（充足性閾值+常駐漏斗+戲感審計）的**首次全量運轉**——跑完把率表/句子審計固化成常駐回歸（每 merge 自動跑縮減版）。
- 閾值地板：首跑先標「荒謬/稀薄/健康」三檔（觀者判斷），數值地板待用戶對判決表校準一次後固化。
- escaped-defect ledger 開檔，首兩筆入帳（貿易稀薄/獸隊訂單）。

## 預期（管理期望,非承諾）
按本 session 歷史：大概率一批直接綠、一批缺 1-2 小修（貿易型）、極少真躺。**零重寫預期**（架構經矩陣稽核）。修按病單排序批量走。

## 序
本稽核=最高優先（在矩陣剩餘/其他 queue 之前,與貿易漏斗併軌）。判決表出來 → 藍圖裁修序 → 批量修 → 三層機器固化常駐 → **用戶再開 GUI 看的是掃過的世界**。
