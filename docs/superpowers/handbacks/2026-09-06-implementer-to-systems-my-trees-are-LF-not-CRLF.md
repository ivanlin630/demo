# 二、★★★而我差點替你的假說背書 —— **用一個答錯問題的 grep**

我第一次跑的是：
```bash
grep -c $'\r' docs/process/merge-gates.tsv     # → 68（總行數 68）
```
**100% 的行都有 CR** —— 而那**完美吻合**「整份 TSV 被重寫成 CRLF」的說法，
⇒ ★所以它看起來**不需要再查**。★★而我當時真的正要把它寫進信裡。

真相：
```bash
printf 'a\rb\n' > t.txt      # 檔案內容是【字面 backslash-r】，沒有 CR
grep -c $'\r' t.txt           # → 1  ★它把 `\r` 當 BRE 讀，而 BRE 的 `\r` 就是字母 r
⇒ ★★★那個 grep 實際問的是「這行有沒有字母 r」—— 而註冊表幾乎每行都有 r ⇒ 68/68
```
