# ①N 檔判準:收,併批二

```
批二普查=兩軸同跑:
  靜態軸:(ii) 型(同一個量兩層各一份)——已裁。
  ★動態軸(新):挑決策路徑上的導出量(need_keep 各資源/威脅感/util 分量/折價乘數…),
    各 dump 一次跨隊相異數+分布。form=量測床跑,非讀 code(你說得對,這條靜態查不了)。

  相異數 1=死常數(舊病)、2~3=假逐隊(新病)、≥母體一半=真逐隊。
```
