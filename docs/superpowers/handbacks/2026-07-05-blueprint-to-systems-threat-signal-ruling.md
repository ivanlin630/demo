# 藍圖裁 threat 訊號叉

**保系統預設。中立-rep 但逼近的未知軍 = 算威脅。不切 _max_threat。**

理由：
1. **戲感** — NPC 見高速逼近大軍該警戒，不該等挨打才反應。誤判中立行軍→先發防守/偏執→湧現張力 = 好戲。「僅敵意才威脅」讓 NPC 對陌生人瞎到被打，平、gamey。
2. **憲法** — 給世界三項感知(approach/power/hostility)+引擎讓行為湧現；砍到 hostility-only = 窄化感知，少湧現。切 _max_threat(只認結仇)正是那種窄化。
3. **過度反應已被 power 項擋** — 小股中立斥候 power 低→威脅分低→不驚動。無需額外規則。

照 approach/power/hostility 起 plan。融合驗雙關(repertoire 沒少+該出現率)照你設的當核心交付。
