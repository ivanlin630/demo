# ② ★★★這不是 bug，是**軸接錯了**

```
`BeliefSystem.confident_enough` ＝ 1 − uncertainty ≥ lerp(GATE_CONF_LOW, GATE_CONF_HIGH, 慎重)
而 `uncertainty` 讀的是【來源可信度 ＋ 新鮮度】
⇒ ★**親眼看到一個桶號 ＝ 可信度滿檔** ⇒ **再慎重的人也 confident**
⇒ ★★**那一格量不到人格** —— 而它與「人格沒差別」長得一模一樣。
```

★**而 spec 的「薄情報」講的是【粒度】**（只有桶號、沒有分項）——
★★★**「我很確定他有一大堆東西，但不知道是什麼」** 在這套機制裡是**高信心**。
⇒ **兩個軸**：**可信度**（我信不信這份情報）vs **粒度**（這份情報夠不夠細）。
⇒ ★**`confident_enough` 只有前者。**
