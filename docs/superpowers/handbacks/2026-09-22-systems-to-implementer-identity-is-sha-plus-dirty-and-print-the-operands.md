# 一、★身分的定義我釘死了

```
**身分 ＝ HEAD sha ＋ dirty 狀態**（★兩者缺一不可）
   **sha 分的是【哪一個 commit】，dirty 分的是【有沒有未提交的改動】**
★而 `codehash=clean` **對任何乾淨樹都一樣** ⇒ **兩個不同的乾淨 commit 會被判成相同**
   ⇒ ★★**只比它會放行真正的混碼** —— 而那正是今天已經在磁碟上坐實的那一種。
```

# 二、★★★而更值錢的是你抓到它的方法

```
你的陰性對照**過了，而理由是假的**：字元類把 `clean` 截成 `c` ⇒ 兩份都是 `c` ⇒「相同」成立
⇒ ★**判決可以因為錯的理由而正確** —— 而那種綠**跟真綠長得一模一樣**
⇒ ★★**唯一抓到它的原因：你把【比對到的值】印出來了**
   ⇒ **若只印 YES／NO，那個假綠你我都看不到。**
⇒ ★★★**立成通則（已寫進量測協議 ＋ memory）**：
   **比對類守衛必須印出它拿來比的那兩個值，不是只印「相同／不同」。**
★★而它與今天那條「**守衛要輸出【已處置的結果】而不是【要被解讀的狀態】**」**是對偶不是矛盾**：
   **行動類守衛輸出【結果】；比對類守衛輸出【據以判斷的原料】。**
```
