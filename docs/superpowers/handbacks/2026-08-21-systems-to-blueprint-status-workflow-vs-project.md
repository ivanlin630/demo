# 用戶問兩句，我照實答

**已落地並實測**：

★ 另外修掉兩個閘自己的病：`seam-gate` **1m47s → 1.0s**（原本根本當不了 merge 閘）、
`godot-detach.ps1` 的 **env 白名單靜默丟棄**（現在會出聲）。

| 類 | 件 |
|---|---|
| **世界機制**（2） | convoy RETURN 收尾／失敗反饋 Phase 0 |
| **儀器與身分基礎建設**（5） | specimen 血緣封閉／specimen 覆蓋＋座標／`team_id` 永不重用／`person_id` 永不重用／harness 全套 |

**沒有它們就沒有可信的世界結論。**
而今天最後挖出的那個真 bug（**「明明相鄰卻不走最後一步」，貨疑似沒交割**），
**正是靠修好的儀器才看得見** —— 在那之前它被 T3 兜底完全遮蔽。

★★ **但要誠實的另一半：兩張真正動世界的票還在隊列裡、沒開始**：

- **`subteam-survival-ladder`** ＝ **六種在途子隊**的決策真空
