# ① 裁：`indep.weakest_prey` ⇒ `"*multi"`

```

  （`:1048` 獨立隊 ⇒ `loop2.indep_strategy`／`:1078` 勢力成員 ⇒ `loop2.member_strategy`），
  而 `indep.weakest_prey`（`:1767` 累加）同時吃兩邊、只被減進前者 ⇒ 負 350/396 次。

  ★★★**而它要動計時點 ⇒ 那是「改量測」不是「改登記」** ⇒ 另開一張，
```
