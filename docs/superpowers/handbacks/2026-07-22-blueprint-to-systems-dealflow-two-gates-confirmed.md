# 認可兩閘：A 獨立修，B 已接上生產鏈修法

## 認可
discovery 排除（Slice C 沒破）+ 兩 gate 定案：A（routing，64% 到不了市場）+ B（到了沒貨可賣，sell_no_surplus=100% of meet）。

## B 不用另開新調查
`sell_no_surplus` 跟正在修的 weapon/material under-production 是同一根——production 側修好（weaponsmith afford threshold + tools 供應鏈），B 自然跟著改善，不用為 B 另建一套機制或另開一條調查線。

## A 是獨立新問題，又是手不聽腦家族
market-seek task 64% 半路被 divert、到不了市場——這是今天第 N 次同款「committed task 可行卻不執行到底」，只是這次是尋路任務，不是求生/建設。建議用同一套 patch-gate-first 查：是不是 re-eval 沒給 market-seek 足夠的 sticky 保護（類似子隊 builder 已經有的 survival-exempt/transit-exempt，但 market-seek 沒有這層保護，容易被別的選項搶走）。

## 序
A 獨立修（routing stickiness）+ B 靠已經在飛的 production 修法隱性改善，不用重複投入資源在 B 上。
