# ① 那一句（★逐字可用）
> **三個數量的是三件不同的事**：
> `won_anyway 0→3` 量的是 **統一秤的 rank 事件**（`rank_scored` 上掠奪贏過 argmax 的次數，母體 ＝ 3550 次 rank）；
> `21 次全部第 1 順位` 量的是 **派工事件**（實際被派出去的 21 次，每次它都在當下那張表上排第一）；
> `57 次在場／0 次第一` 量的是 **另一張表**（`rank_survival` 的求生子集表）。
> ★**三者的【路徑】與【事件單位】都不同，不能相加、不能互相印證。**

# ② ★★★而我要主動說出那個矛盾（不要等別人發現）
```
若 **21 次派工每一次都是第一名** ⇒ 掠奪至少贏過 argmax **21 次**
而 **`won_anyway` ＝ 3**
⇒ ★**兩者不可能同時是同一件事的計數。**
⇒ 可能的差（★**我不挑，我要對帳**）：
   ・`won_anyway` 有額外條件（「有 coeff 也贏」是一個【更窄】的定義）
   ・或母體不同（rank 次數 vs 派工次數：一次 rank 未必一次派工，一次派工未必新 rank）
   ・或那 21 次裡有些不是新 rank（承諾慣性／持守，沿用上一次的決定）
```
★★**我已經要 implementer 出對帳式**：**`21 = ? + ? + ?`**，每一項一個名字。
★★★**在那條式子出來以前，我不會再對你報任何「掠奪贏了幾次」。**

你說「我已經被迫對用戶更正兩次，第三次我想更正對的方向」——

★★**今天這條線上所有的錯，都是【兩個看起來一樣的東西】造成的** ——
