# ★一個 pacing 問題要你（或用戶）一句話定——spec 其餘全部已定案、不卡

## 形狀已定（錨在真數字）
`f(r) = r/(r+K)`、**`K = 0.15`** ＝ peaceful d45 的 **p90（0.148）** → 語意：**「本世界前 10% 健康的村」落在 f ≈ 0.5**。
分布背景：**p75 三份全 ≈ 0**（約 **3/4** 的隊相對盈餘 ≤0 ＝ 世界真的窮）；正尾**細而長**（max **12.7**）→ 飽和必須，K 型曲線**自動壓住尾端**（r=12.7 → f≈0.99）。

## ★填 `BASE_RATE` 時算出一件改變前提的事
舊規則期望值 ＝ `chance 0.15/次 × near pass 24 次/日` ≈ **3.6 次/人/日** → **一旦通過，數小時內就把 `minor < cap` 填滿**（`cap = max(1, int(pop×0.25))`，pop 6 → **1**）。
∴ **舊系統的真實語意是「通過＝瞬間填滿 minor 上限」，真正 binding 的是 cap、不是機率**。
→ 「**錨定舊量級**」**不能**解釋成「對齊舊期望 births」（那會直接爆炸）；正確解釋是對齊**已實現結果**（健康村最終把 minor 池填到 cap），而**新設計真正要決定的是「花多久」**。

## 「花多久」＝ pacing 決策，不是我可獨斷的技術參數
（且與 HOLD 中的時間重錨包相鄰。）三個候選量級與世界後果：
- **(A) 慢**：健康村（f≈0.5、5 名適齡成人）約 **一季**填一個 minor 名額 → 人口成長是**世代尺度**、村莊變大是長期成就；12mo 大考大概只看到個位數成長。**風險：仍舊像停滯，觀察者感受不到。**
- **(B) 中**：約 **一個月** → 一年約 12 個名額尺度，村莊在一年內**明顯長大但不失控**。**（我的 lean。）**
- **(C) 快**：約 **一週** → 村莊數月內撞 `pop_cap`、擴點門檻 pop≥12 很快被摸到、經濟科目迅速轉向「大村時代」。**風險：把世界推進一個我們還沒量過的體制**（規模經濟 absent 那批問題會立刻放大）。

★**我不預設**：你要的是「**世界會長大**」還是「**世界會慢慢長大**」——這題的答案**直接決定下一輪大考看到什麼**。回一個字母即可，我填進 spec 走 R²delta → dispatch。

## 另：pop>12 級距空缺（measurer 三份 snapshot 全 n=0、誠實回報，day360 補測撞時限被 kill）
**我判不阻塞本 spec**：`rate` 只吃 `rel_surplus`（比例量）、**不含絕對 pop** → 曲線形狀與大村資料**構造性無關**。大村資料真正能答的是「**大村的相對盈餘是否系統性不同**」＝**有大有小 arc** 的素材，已改記那邊、不為它擋這輪。
