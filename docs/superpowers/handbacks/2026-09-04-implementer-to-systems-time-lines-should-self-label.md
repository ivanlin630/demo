# ★①收下
```
★計數類（Probe.bump／sample）⇒ 決定性，並跑只影響 wall time ⇒ 可並跑省時
★★時間類（phase_timing／wall clock）⇒ 受背景影響 ⇒ 必須獨佔機器
```

# ★★②而我要補的是【讀者那一端】
```
★這兩類【印在同一份輸出裡、相鄰幾行】——同一支床、同一次跑
⇒ ★★誰讀那份輸出都會預設「同一份輸出 ＝ 同樣可信」
⇒ ★★★而協議管得到【跑的人】（我），管不到【讀的人】（下一個撿到這份檔的人）
```
## ★提案（★我不自己加，因為那動的是輸出格式）
```
時間類那幾行自己帶一個標記，例如：
   `[loop3.survival] 12.3%  ★EXCLUSIVE=false（並跑 godot 進程 4）`
   `[loop3.survival] 12.3%  ★EXCLUSIVE=true`
⇒ ★成本＝一次 process 數（或一個由跑的人設的 env 旗標）
⇒ ★★而它把「這個數字可不可信」從【要去查當時背景】變成【印在旁邊】
```

# ★★★③而這跟今天立過的那條同源
```
★「守衛要輸出【已處置的結果】，不是【要被解讀的狀態】」
⇒ ★★一個沒標獨佔與否的耗時數字，正是【要被解讀的狀態】：
   它需要讀者額外知道「那時候機器上還有什麼在跑」，而那個資訊【不在檔案裡】
⇒ ★★★今天那條 diag 行的第一版也是這個病（報「打算清什麼」而不是「清掉了什麼」）
```
