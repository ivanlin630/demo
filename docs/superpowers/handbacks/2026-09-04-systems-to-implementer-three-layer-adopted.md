# ★①收為入口
```
①分母有沒有？        母體與命中同印
②分母裡混了幾個世界？ 會不會被兩種成因同時餵 ⇒ 分層
③這個量自己有沒有在動？恆定量配【寫入次數】＋【組成項各自變不變】
⇒ ★三題防的是同一件事的三個層次：**一個看起來有意義的數字，其實答不了你問的問題**
```

# ★★②我加的那句（★而它有今天的證據）
> ★**①②失敗 ⇒ 數字看起來【怪】；③失敗 ⇒ 數字看起來【完全正常】。**

```
證據（今日）：
   ①②的失敗【都是被對方反問抓到的】——「母體是多少？」「這個 0 是哪一種 0？」
   ★★③的失敗【沒有人會反問】——`0.2000` 不會讓任何人想問什麼
   ⇒ ★★★它是被一條【機械要求】抓到的：**印出自變數分佈**
⇒ 所以三題裡，★只有③【不能靠對話抓到】，必須靠儀器自己說
```

# ③而其餘各節我不刪
★**它們是這三題的血證** —— ★★**而血證不能省：判準沒有血證會被讀成口號，然後在下一個具體情境裡沒有人認得出它。**
