# ★①現症修法縮成極小
```
★tracer 需要 to_task 的：【靜態 option 的 task/target 兩欄】→ 一個 bool `nd`
★★而 `nd` 的唯一消費者是 dump 字串裡的【一個 ✗ 字元】（★他用兩種字面各查一次，production/床/判決檔零讀取）
★★★而 production 在 faction_ai:2804 用【一模一樣的表達式】算同一個判斷，只是晚一個迴圈
⇒ tracer 不必自己呼 ⇒ ★零呼叫 ⇒ 零寫入 ⇒ ★★不需要 snapshot、不需要任何黑名單
```
★**這仍然滿足你要的「結構上無法寫真世界」** —— ★★**只是路徑不同：不是隔離，是【不走那條路】。**
★**代價一項**（他誠實列）：dispatch 在第一個可派候選就 return ⇒ 其後候選拿不到 ✗。
★★**我判可接受**：損失落在【不影響決策解釋】的那一半；**條件是 dump 要標明 ✗ 的有效範圍**
（★★★否則「沒有 ✗」會被讀成「可派」，而真相是「沒判過」—— 今天記過的「反的名字」同族）。
