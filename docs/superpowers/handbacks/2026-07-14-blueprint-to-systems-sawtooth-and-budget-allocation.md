## 第4層：買糧鋸齒——觸發線=收手線，結構上累積不到安全存量
查證（`options.gd:136` + `interaction_system.gd:766-808`，已坐實）：
- 買糧觸發資格 `food_days < DESPERATION_DAYS(3)`，收手資格 `>= 3`——**兩條線重疊在同一個「3天」上**。
- 買到 food_days=4 → 當場失去買糧資格 → 下週期不會再跑市集補到位，得等跌回 <3 再救一次。
- 單次買糧也**沒有「買到目標安全存量才停」的上限**，是「有錢有位就買到 coin/carry/賣方餘糧見底」。
- ∴ **窮隊每次只買得起到 ≈4 天 → 永遠在 3 天線上下鋸齒，累積不到安全存量 → 一遇風吹草動就餓死**。

**這是讓「人格化安全存量水位」真正能運作的關鍵齒輪**：不修這個，安全存量水位訂再高也沒用（一脫離絕境就收手了）。修向＝**觸發線 ≠ 收手線**：觸發線低（開始買），收手/續買目標線高（= 人格化安全存量）。沒買到位、只要還有償付能力，下輪繼續補，直到達標才收手。**仍不是新 option**，是給既有買糧一個「目標水位 + 跨週期續補」的收手條件。

## 第5層：★預算戰略分配——別為買糧把錢全砸下去
用戶原則：「不能把錢都花在同個地方，要戰略分配」。
- 前幾層若只做「續買到安全存量」，可能矯枉過正 → 隊伍把 coin 全砸買糧、囤糧囤到沒錢發展/軍備，變另一種極端（謹慎隊全變糧倉、廢了發展）。
- 真正要的：**可支配資源在「備糧 / 軍備 / 發展(升階/囤貨/生產)」之間按個性+處境權衡分配，任一項都不該吃光預算**。
  - 謹慎領袖：較高比例留給備糧安全存量，其餘才發展。
  - 野心/賭徒領袖：容忍薄糧，較高比例投軍備/擴張。
  - 處境調節：真逼近餓死時備糧權重才壓過一切（但這是短暫救急，非常態全砸）。
- 效果：資源分配本身浮現個性與戰略，不是「非全砸買糧、即全砸軍備」的二元擺盪。

## 修向定調（給你判斷如何落 HOW）
這兩層把本輪從「修幾個門檻」升級成「**求生/資源決策是一個受個性調節的預算分配問題**」——但**仍恪守用戶原則：不加新 option/行為**，是讓既有 buy/囤/升階這些 option 的 weight 曲線共同吃一個「人格化預算權衡」，而非各自獨立死門檻。你判斷這是否需要一個 allocation/budget 的內部機制（非玩家可見新行為，是決策層內部的權重協調），還是能用既有 coeff/urgency 架構表達。若牽動架構較大，回報範圍讓我知情。
