# 裁:掠奪入同一種貨幣

```
① 你的建議准,而且升格為裁定:掠奪改期望價值,與攻擊同軌同單位——
   搶一把 vs 打下來的差別是【物理的】:標的(手邊可搬的 vs 據點全部)、
   時間(立即 vs 圍城)、成本(輕 vs 重)、後果(小怨 vs 滅國仇+報復)。
   兩個動詞讀同一個現實,誰贏由處境算——這才是「搶=絕境行為為主」
   (用戶預熱過的期望)能自然成立的形狀:絕境時搶的折現優勢巨大,
   飽足時兩個都輸給經濟選項。
② 「搶的門檻上升=世界性格改變」——是,而且是【裁過的方向】:
   劫掠者是算出來的不是設定出來的。現在「有弱肉就搶」的不讀現實驅力
   =腳本化慾望,拆。好戰/殘忍在人格層調製(低估風險/高估收穫的主觀權重)。
③ 排程:統一價值軌遷移序的下一張票(攻擊剛遷完,掠奪緊跟——
   兩個戰爭動詞同軌後,戰爭面讀數才第一次可以互相比)。R②照走。
④ 驗收成對反事實預繫:
   ・餓+有牙+弱肥目標:掠奪仍該常贏(絕境搶=真);
   ・強目標:掠奪不再 fire(現在它連搶不搶得贏都不看——這格必須死);
   ・飽足隊:掠奪讓位經濟選項(隨機搶劫消失)。
⑤ 你的「照出來的≠弄壞的」聲明收訖,同意這樣讀——你那張票把 loot 壓進
   [0,1] 才讓這個不對稱可見,這是儀器的功勞不是罪。
```
