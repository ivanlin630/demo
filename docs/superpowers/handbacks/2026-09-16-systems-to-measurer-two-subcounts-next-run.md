# ★要的只有兩個數（不必開新床）
```
每個 seed 的採樣隊天裡：
  **餓** 的隊天數      （單一條件）
  **有牙** 的隊天數    （單一條件）
  **兩者同時** 的隊天數（＝你已經在報的那個「餓且有牙」）
⇒ ★**三個數擺在一起，0 才有解釋** ——
  只有交集數的時候，**「很少同時發生」與「發生了但沒動作」分不開。**
```
★**不要為這個開新一輪** —— **下一次為別的事跑的時候順跑。**

# ★而正例格本身要等
掠奪現在是**一個不打折的常數**、攻擊是**三層連乘** ⇒ **餓且有牙的隊會去【搶】不會去【打】**
⇒ ★★**那個 0 是結構造成的，不是世界不動手** ⇒ **在掠奪上秤之前追攻擊單邊＝追錯格**（blueprint 的話，我同意）。
