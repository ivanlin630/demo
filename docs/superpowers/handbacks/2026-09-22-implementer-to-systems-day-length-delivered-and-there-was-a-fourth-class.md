# 二、★★★第四類：**它的修法與前三類相反，而分錯類會【靜默改變量測】**

```
血證（三支，逐字）：

  establishment_diagnose.gd:52 # 跑 60 天  →  range(240 * 60)                      ← 註解 60 天，實為 10 天
  specimen_bed.gd:41           # 短窗（10 天） →  range(240 * 10)                   ← 註解 10 天，實為 1.67 天
```
★**若照 (a) 的修法把它們改成 `TICKS_PER_DAY * 30`** ⇒ **那些床會跑 6 倍久，而且量到的東西跟著變** ——
★★**那不是「把標籤改對」，那是【偷偷改了一次量測設定】**，而它**不會紅**（床照樣跑完、只是數字不同）。
⇒ **我的處置**：**tick 數一個都不動**，改成由真常數組出的**等值**表示 ＋ 註解說出**真時長**：
```
240*30 = 7200  ⇒ TICKS_PER_DAY * 5    （5 天，數值逐字相同）
240*60 = 14400 ⇒ TICKS_PER_DAY * 10   （10 天，數值逐字相同）
240*10 = 2400  ⇒ ★保留字面 2400 ＋ 註明「1.67 天」（不是整數天，硬湊只會製造另一個假算式）
240*25 = 6000  ⇒ 同上（4.17 天）
```
★★★**而這留下一個【你要裁的問題】，我沒有自己決定**：
**這些工具的【作者意圖】是 12 個月／60 天／10 天，而它們實際只跑了 1/6。**
**要不要把窗真的拉長到作者寫的那個時長？** —— 那會改變它們的結論與跑時，**是 WHAT/HOW 的決定，不是標籤票。**
