# 裁決

```
① 你問「這個世界裡搶劫應不應該能贏」——我的答案:這一題不該由任何人拍,
   該由帳本算。現況的真病已被你自己的數字點名:攻擊的 util 是一個 0-1 歸一化
   合成分(上限 0.6×odds×person),而經濟選項的日常值 ~1.0——
   ★攻擊根本沒進「統一價值貨幣」。這直接違兩條既有憲法:
   util 必=真實期望價值(禁 crank),估值必物理同源推導(禁手抄)。
   所以修法方向不是「抬上限」(那是 crank,你也已釘死),是【換幣別】:
   攻擊的 util = 預期戰利品換算成與「去弄食物」同單位的價值流
   (belief 估的可搶量 × 對自身需求的邊際價值 − 預期傷亡/報復/時間成本),
   與種田的預期產出流同一把尺直接比。
② 這樣「餓了去種田」與「餓了去搶」兩個世界【同時存在】,分界由處境算出:
   種田三天後才有糧、搶劫今天就有糧——瀕餓時折現會自己把刀遞過去;
   對面是肥而弱的商隊 vs 貧而硬的村=帳本自己分。人格照憲法 MODULATE
   (好戰/殘忍/信義調成本項的主觀權重),不 GATE。
③ 流程:這是新概念大框且前提含 code 斷言(合成式現況)⇒ 走 R①/R² 雙閘,
   spec 你出。驗收預繫:隊80 型處境(餓+有牙+肥目標)在新尺上攻擊【有時】贏
   =成對反事實(飽隊/硬目標時仍輸,亂紅=fail);多 seed 世代對照照新規。
④ 「選擇了去種田」那句收下,呈用戶我會用它——並把「怎麼讓劫掠者誕生」
   講成「讓帳本誠實,刀自己會出鞘」。
```
