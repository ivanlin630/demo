# 統一統領決策 — 補完統一框架 arc 的另一半

回你 p4-war-priority。藍圖與用戶走查戳出真根，方向變了：**不認可 war-priority 補丁，直接統一統領層**。

## 真根：統領沒在思考，是並行閾值
你報的「好戰霸主同時下打仗+外交」= 症狀。根 = **`_update_goals` 仍是舊多閾值並行**：每種大事各算分、過閾值的全發 → 同時下矛盾令。

這是我們整條 arc 在殺的**同一隻病**（決策不統一、latch 互搏、無單一連貫決策）——我們在**隊層**修好了（統一引擎），但**統領層沒遷**。所以「他域鏈到頂」只對一半：**隊層統一了，統領決策還沒。真根在統領層還活著。**

war-priority（戰>和、成員側 1.5>1.0）= **OK繃**：成員端被掰回看似正常，統領仍下矛盾雙令。**不要這補丁當設計**。

## 裁定：直接統一統領決策（下一塊框架，玩家面之前）
統領也跑統一引擎原則：**一個連貫戰略姿態**，非並行閾值。

### WHAT 規格（believability 願景，HOW 你定）
1. **單一主姿態**：統領每 cadence 秤 攻擊/徵收/外交/結盟/守成… 當競爭 option（utility argmax），挑**一個主姿態**。外交是「不打時才做的事」，不是跟打仗並列同發。守成 = default。
2. **姿態要 commitment（hysteresis）**：統領別每 tick 翻 攻擊↔外交（同 churn 決策抖動病，統領層更傷——戰略反覆 = 最蠢）。一旦committed開戰，材料情勢沒實質變就別翻。**統領層是戰略承諾最該硬的地方。**
3. **姿態本身吃人格**：好戰霸主傾攻擊姿態、商業 leader 傾外交/守成。姿態選擇即染人格（不只執行染）。
4. **姿態吃 belief 非真相**（接 G3 / 玩家錨 C）：按統領**以為**的敵強度選攻擊。已部分在（吃 belief gate），保留。
5. **成熟派系並行軌 = 未來擴充**：大型立國派系**能**一面打一面談（不同戰線）——但這是**制度化擴充**（接 P3 擴充軸 #3 協同隨制度化），**非現在**。現在 = 單一連貫姿態。當前 = 小派系下矛盾令的蠢，先治。

→ 統領下**一個連貫令** → 成員照混合協調 A 響應 → **不會有打+談矛盾、不需 war-priority**。

## war-priority 補丁 = 可丟 interim
- 若 dev 過程 world_sim 需暫穩，war-priority 可留當**拋棄式 interim**，明標。
- **統領統一落地時移除**（統一統領令後它 moot）。不留死 OK繃。

## 大方向（連帶）
這塊 = 統一 arc 真正收尾，排**玩家面之前**（連貫派系是玩家在霧裡讀的對象，下矛盾令的派系 player-visible 蠢）。統領統一 done 後再轉玩家面/G3。其餘 polish 債照舊擱。

## 結論
不認可 war-priority 當設計。下一塊 = 統一統領決策（上 5 規格）。spawn 子 session 前先 brainstorm/spec。卡點：先確認 `_update_goals` 現況範圍（grep 驗多閾值），measure-first 量「統領同發幾個矛盾令」當基準。
