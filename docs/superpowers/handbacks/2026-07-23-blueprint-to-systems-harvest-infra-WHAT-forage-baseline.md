# 裁 WHAT = (a)，no-outpost 隊可 forage 到 subsistence 率

## 認可 HOLD GATE-A
新證據出來前別浪費 cycle 在少數案例，正確。

## 裁 (a)：允許 no-outpost 隊 forage tile 食物到 subsistence 率
不到 full-farm 效率，但足夠活下去。

**理由**：
1. 遊戲既有的「覓食」本來就是既有求生選項之一（今天 SURVIVAL_OPTION_SET 反覆出現）。這次的洞是 `tile_food_pool`（平原/富饒格）這個特定資源池需要設施才能好好採，野生植物糧的基礎採集不該被鎖死在同一道閘後——站在滿糧格上活活餓死違反沙盒憲法「世界代價非行為腳本」的精神，是純技術缺口，非設計意圖。
2. **不弱化建設意義**：farming/outpost 仍該給遠高於 subsistence 的產出/效率，只是「沒設施＝0」該改成「沒設施＝低效存活」，settlement 的價值在「從 subsistence 升到 surplus/specialization」，不是「活下去的門票」。
3. **nomad 自足不 settle 是合理 archetype，非 bug**——DF/Kenshi 這類靈感遊戲本就允許純採獵求生的活法，不用每隊都被逼著蓋 outpost 才能活，連上「多元文明類型的戲」（工匠追建設是一條路，非唯一路）。

## 認可 measure-first
先量 no-outpost-starving 佔絕境比例確認主體規模，再定 subsistence rate 要多少、跟既有設施化 foraging 差多少——你 HOW 定 spec 細節。

## ★附帶觀察，值得你評估
「facility 極少建 → 多數隊 no-outpost」這個發現，直接呼應昨天 weaponsmith 鏈挖到的 workshop-build 終閘——同一個病：**facility construction 本身系統性稀少**，可能是比 food/goods/weapons 都更上游的 keystone。值得你評估要不要拉出來當獨立的「為何設施普遍蓋不出來」調查，橫跨所有資源鏈，不只 food 這條。
