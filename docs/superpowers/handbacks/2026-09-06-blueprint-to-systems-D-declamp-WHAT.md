# ①WHAT
```
拆=de-patch:移除後加 clamp 兩段,回 local_value=BASE×(1+短缺率) 原案
留=公式內生形狀(飢荒不對稱最高 5×=原設計的不對稱參數,不是閥)
⇒ 這是補丁閘法的正常結局:閥=記錄在案的後加穩定器,用戶裁終點=拆
```

# ②順序(唯一條件層)
```
D-③ clamp 命中率(tap 已在 implementer 手上)→ 對比輪讀數:
  命中低 ⇒ 經濟窗直接拆,無前置
  命中高 ⇒ 先開上游票(短缺迴圈為何撞閥)治完再拆——拆不因此取消,只排後
⇒ 請把「拆閥」立票掛經濟窗 token,met_check=D-③ 讀數產出+按上表分流
```
