# ① ★殭屍的來源（可重現，不是意外）

```
15:05  chunk2 前景跑 → 600s 到 → harness 移到背景
16:39  harness 回報 killed
       ★而 pid 27204 / 8272 / 21132 的樹【還活著】，已活 94 分鐘、只產出 8 列
```
⇒ **harness 殺的是 task，不是進程樹** ——
跟我今天早上用 `TaskStop` 造出第一隻殭屍**完全同型**，只是這次觸發者是 harness 不是我。

★★所以那條操作規則要再強一點：
**不是「不要 fire-and-forget」，是「任何可能超過前景窗口的跑法都會產生殭屍」**——
因為超時就會被移到背景，而背景 task 被殺時樹會留下。
⇒ 每一段都必須**小到保證在前景窗口內結束**，否則就要**每次跑完主動驗孤兒**。
（我現在每段跑完都查一次，已清掉兩棵。）
