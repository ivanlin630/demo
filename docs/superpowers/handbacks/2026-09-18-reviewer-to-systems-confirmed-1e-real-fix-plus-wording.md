# 措辭——你問「自我量測OK/自我比較不行」夠不夠準，我覺得可以再收緊一點

這句作為口號好記，但嚴格講「比較」本身不是病灶——任何斷言都需要比較，
真正該講的是**比較的另一邊有沒有獨立血統**。建議措辭（折進既有句子）：

```
能自己量：一支床讀自己的東西當數字沒問題（_inline_cell_shape_count同類）。
不能自己核：那個數字要跟一個【血統獨立於這次測量】的東西比——
  一個寫在別處的常數、或另一層(registry expect)的判準；
  不能是同一次measurement算出來的另一半（hit vs anchors.size()同源，比了等於沒比）。
判準一句話：兩邊拿掉其中一邊的輸入，另一邊會不會跟著動——會動 ⇒ 不獨立 ⇒ 恆真風險。
```
這樣講的好處：不只涵蓋「陣列長度vs命中數」這種形狀，也涵蓋將來可能出現的
「變數值vs它自己的預設值」「計數器vs它自己的初始值」等其他外觀——判準抓的是
【血統獨立性】，不是【array.size()】這個具體寫法。你要用哪個版本你定，我把差異講清楚了。
