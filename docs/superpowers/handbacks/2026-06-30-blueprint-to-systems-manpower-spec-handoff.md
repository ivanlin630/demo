# 受控人力統一系統 spec 移交

藍圖 brainstorm 完成（用戶逐情境走查）。spec：`docs/superpowers/specs/2026-06-30-controlled-manpower-unified-design.md`。接 HOW + 分階 plan。

## 緣起（接你 climb-stall measure）
你量出攀爬主卡點 = pop 崩（征服只 loot 不長 pop）。真因 = **戰爭非累積**（贏了不吸收敗方人）。turtle-world = 對「征服不 pay」的理性反應（commander 沒錯，世界缺吸收經濟）。
→ 用戶要**統一架構系統**含俘虜/招募/待遇/拷問等，非窄吸收 patch。**(a) 的吸收 = 本系統一條 entry 通道**，不另做。

## 核心（spec 詳）
- 統一管線 ENTRY→待遇→OUTCOME；5 類 entry 介面（強迫/自願/交易/關係/策反）。
- **受控狀態欄**（free/captive/slave/conscript/merc）掛 subteam/cohort；**子團=持有、主團成員=同化**，待遇推軌跡。
- 待遇 = **means-end 決策**（零新政策系統，跟攻擊/貿易同框 option）。
- **跨域 affordance 槽**（拷問→G3/奴役→經濟/人質→外交/策反→entry），各 **gated by 目標域**（孤兒不掛，affordance 真實性 invariant）。
- named/anon 兩帶（決策者=named leader；(a) 被處置=anon pop）。

## ★ (a) 怎麼解（本系統首要交付）
征服 → 吸收敗方 **anon pop**（captive 子團）→ **同化才算數**（厚待→併主團 free pop→算攀爬 pop→兵力長→爬）。**征服只有消化才 pay**。
→ means-end 選征服 → pop 累積通。

## build 分階
```
Phase 1（先，解 (a)）：anon 吸收 + 受控狀態欄 + 批次待遇 + 同化/暴動/逃（純 anon、零跨域）
Phase 2：named 俘虜戲 + 其他通道 fold + stakes(guard-cap/救援) + 待遇 richness
Phase 3：跨域 affordance（拷問等，gated by 目標域）
```
