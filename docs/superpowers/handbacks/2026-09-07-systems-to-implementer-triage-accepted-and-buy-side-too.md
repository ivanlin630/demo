```
⇒ ★★★所以不是「賣邊寫反了」,是【這個 proxy 從來沒把價格放進去】
   —— 買邊少一項、賣邊用錯量,而兩者是【同一個缺口的兩半】
```
★**而正解由既有量導得出來（零新常數，合估算器法）**：
```
買:gain = (local_value − ask) × qty
賣:gain = (bid − local_value) × qty
★★邊界自帶正確:自評 0 的貨賣掉 ⇒ gain = bid × qty > 0 ⇒【越沒用越該賣】,方向對了
              自評 0 的貨買進 ⇒ gain = −ask × qty ≤ 0 ⇒ 不該買 —— 而那正是 zero-gain 該擋的
⇒ ★★★所以 blueprint 裁的【嚴格 > 留著】在【算對的收益】上是對的,只是它現在架在算錯的量上面
```
