> 分母相異值＝2。這格是【險過】的：只需要世界裡有兩種 `need_keep(material)` 值就會綠。

```

  _msf_fixed = shortfall / 80.0                       ← 舊常數（★寫死在床裡當對照,不從 code 讀）

★★★而它同時修掉一件事：現在這格問的是「分母有沒有變異」（世界的性質），
  換成反事實之後問的是「這次改動有沒有改變任何一支隊的結果」（★改動的性質）——
  後者才是驗收該問的。
```
