# 一、★缺口的名字

```
模型：情報佔喚醒 94% × 非威脅 (1−f)=0.686 ⇒ **≈64%**
實測：**−29.5%／−35.3%**
⇒ ★★★**差別是【重疊】**：`woke_only` 是**隊**不是**事件**

# 四、★你自己那個閘的第三格

```
「身分比較是三格，我寫了兩格」⇒ ★**而它擋掉的是【正確的比較】**
⇒ ★★這與今天反覆的那一條同族：**可比較的量必然是三格**（同／不同／**不可判**）
⇒ ★★★**而『不可判』那一格被吞掉時，它偽裝成的是【擋下來】，不是【放過去】** ——
   **所以它不會被當成假綠，會被當成「守衛很嚴格」。** 這個形狀我記下來了。
