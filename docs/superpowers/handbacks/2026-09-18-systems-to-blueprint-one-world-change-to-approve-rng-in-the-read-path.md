# 一、發生什麼

實作端照我裁的形狀做完第一步（把兩個欄位收成單一計算點、值逐欄相同），**世界仍然變了**。
量出來的原因**與它算出什麼無關**：

```
蒐集脈絡 → 威脅評估 → 接近程度 → 觀測對方速度 → 抽一個亂數
★而那個亂數抽出來的【值】在這條路上被丟掉（威脅評估只讀「看不看得見」與「往哪個方向」）
⇒ ★★少呼一次蒐集 ＝ 少抽一個亂數 ＝ 之後所有隨機事件整條錯位
```

★**這是今天第二次同型**：上一次是「排程欄位」，這一次是「亂數抽取」——
**兩次都是「這個函式看起來只是在讀，其實它在動世界」。**

# 二、要你核准的那一格

**修法（我裁的最小形狀）**：**讓不需要那個速度值的人不要抽亂數**，把抽取搬到**真正用它的那個地方**
（有一個消費者真的在用：追擊時預測攔截點）。

```
代價（一次性，誠實講）：
  ★世界的隨機序列會錯位一次 ⇒ 所有既有的指紋基線作廢一次，要重新錨
  ★★而【之後】它就不會再因為「誰多呼叫了一次觀測」而漂移
收益：
  ★觀測不再改變被觀測物（這條是既有的硬規，今天是它第 5 次被繞過）
  ★★而效能票的驗收（語意零改變）在修這條之前，【在構造上】做不到
```

# 三、我**否決**了什麼（免得你之後看到覺得漏了）

另一個方案是把亂數換成「由 tick／觀察者／目標算出來的決定性雜訊」——
★它**同時**解掉另一件現在就存在的怪事：**同一個 tick 內問兩次，會得到兩個不同的觀測速度**。
⇒ ★★**但它會改掉所有觀測雜訊的值**，而**這是一張效能票** ⇒ **我不准在效能票裡偷渡觀測模型的修改**。
⇒ 已登成獨立票（連同另一格：**「距離越遠估越粗」這個設計意圖對【方向】從來沒有生效** ——
★★★而那**不是**感知鐵律違規：親眼看見時讀真值是合法的，它只是**設計意圖沒接上**）。

# 四、你要回的只有一句

**「這一次的世界改變，准或不准」**。★准 ⇒ 我讓實作端做最小那個形狀，並在信裡明寫基線作廢一次；
★★不准 ⇒ 效能票收在「陽性對照床 ＋ 四條通道的量測」結案，修法整個移到前置票之後。
