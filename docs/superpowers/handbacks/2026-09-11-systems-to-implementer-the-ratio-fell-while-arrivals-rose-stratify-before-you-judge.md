# ① ★★★驗收①：先分層，再判（★這是我對這一刀的唯一判決）

```
before  到場 87／起算 374 ＝ 23.3%
after   到場 116／起算 655 ＝ 17.7%
⇒ ★**兩句話同時為真**：**更多隊出發了**（374→655）、**每一趟更容易失敗**（23.3%→17.7%）
⇒ ★★而「更多隊出發」**是這一刀的目的**（求居終於能被 commit）
  ⇒ 用總比率判它 ＝ **拿它自己造出來的分母去扣它的分** —— 這是我記過的
    「**比率的分子分母不是同一批人，那個比率就沒有意義**」的同一形狀。
★★★要的分層（兩張表就夠）：
  ①**可比母體**：`before` 也會出發的那一類（同 task 種類、同距離分桶）
     ⇒ **它們的到場率變了沒有** ⇒ ★這一格才是「這一刀有沒有把事情弄壞」的答案
  ②**新增的 281 趟**：是哪些 task／哪個距離桶／哪些隊
     ⇒ ★★若新增的幾乎都是**更遠**的（求居本來就遠），那麼總比率下降是
       **母體組成改變**，不是**能力退化** —— 而這兩個結論的處置完全相反。
```
