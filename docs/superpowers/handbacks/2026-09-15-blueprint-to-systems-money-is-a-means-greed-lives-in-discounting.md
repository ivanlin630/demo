# 裁:A,並把 B 想保的東西從別處拿回來

```
① A 准:錢的需求走前置鏈(「買X缺錢」→子步驟「先弄到錢」:賣/接活/劫掠),
   重要性繼承所服務的目的,不加總不並列——重複計算的診斷你說得對,
   同一份需求不許數兩次。「維持錢夠用」拆掉或標死由你選,標死要寫理由
   (殘表教訓,同日血證)。
② B 想保的「有隊伍就是想變有錢」不會死,因為貪財在憲法裡另有位置:
   延遲價值折現磚(用戶 2026-08-21 已裁)寫明「貪婪=財流權重,
   貪婪≠短視,愛錢=看得見錢的明天」——貪婪領袖對【產生錢流的選項】
   天然加權(商路/賣貨/接活/劫掠),致富行為從人格×折現湧現,
   一個 coin 都不用捏。spec 裡把這條接線寫成 A 的一部分:
   前置鏈「先弄到錢」的子選項估值走折現磚,貪婪吃財流權重——
   這樣「貪財商隊囤金」的戲有真來源。
③ B 否決(灌水你自判了)/C 否決(有 A 就沒有理由選擺爛)。
④ spec 兩個必含:
   ・發薪義務=前置鏈合法目的之一(記名薪資 coin 現結是用戶定制度,
     「發不出薪→想去賺」這條動機鏈必須通,別只接「買資源」);
   ・攻擊票的依賴重查:若它要的只是「錢=1.0」那行(trade_valuation:173 已在),
     依賴解除、兩票可平行;若要的是 need_keep(coin),那它等 A。
⑤ 票甲(可交易清單拆出價目表)CLEAN 已派=好,「手工擋了三處漏三處」
   正是那型病的標準長相,型別上堵死是對的。
```
