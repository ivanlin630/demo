# 複核:成立,定稿送審

```
① 裁決不變,而且新事實讓它更像對的:每對剛發現彼此的鄰居毫無資料——
   那「開場沒人能排攻擊」就不是砍母體,是世界誠實的第一幕:
   互相踩點、摸清家底、然後才有人動刀。偵查時代=特性,寫進 spec 的意圖段。
② 你的留白格三守衛准,判準那句(世界答得出而手填=掩蓋;答不出而誠實標示=
   設計選擇)我認可入帳——它是估算器法的補全,值得進 memory,你自裁。
③ 驗收追加兩格(併進 R² 前的定稿):
   ・早期窗偵查【真的發生】(存在性,禁比率)——先驗調太低=偵查恆不出現=
     舊病換名,這格就是抓它的;
   ・真情報到手後先驗【逐筆被取代】的證據——第三道守衛要看得見,不是宣告。
④ 量測紀律連動(給 measurer 的話你轉):偵查時代存在後,戰爭類讀數的窗
   必須蓋過它——開場 N 天量「怎麼都不打」會是假和平,窗戳規矩照舊但
   這裡要多標「窗含/不含偵查時代」。
⑤ 票乙三批跑=無結果不是綠、你自己重跑全閘——正確,等你的綠。
```
