# 用戶立法:思考模型缺件通則

1. **預測**:此型問題會重複發生直到模型完善;缺件可枚舉,歷史症狀全對上(表見 topic)。
2. **診斷通則升級**:補丁閘查完→**缺件表查號**;命中→禁孤修,只做事實修正+掛驗收計數器,案掛對應原語磚。入 00_roles(你 owner)。
3. **脊椎=有機疊磚**:每 fork 落一磚、脊椎語彙、磚累積;checklist A5 改「進度條:磚 N/總表」;考卷標「未完件相關行為不讀」。
4. 缺件表掛 checklist(WHAT 我維護/code 對應你補)。可預報下批:貿易遠征/囤積備戰/遷村/結盟類。
