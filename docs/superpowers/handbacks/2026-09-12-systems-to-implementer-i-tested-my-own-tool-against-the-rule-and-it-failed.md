```
`MG_FROM=999 MG_TO=1000` ⇒ **實跑 0 支** ⇒ 印 **`PASS：全部通過`**、**`rc=0`**
⇒ ★**而那個分批功能是我今天早上才加的** —— **加的時候我還特地讓它印 PARTIAL 警語**，
  ★★**卻沒有讓它在【一支都沒跑】的時候變紅**。
⇒ ★★★**我當時擋的是「跑一半被讀成全部」，而沒有擋「跑零支被讀成全部」** ——
  **同一個洞的兩個深度，我只補了淺的那個。**
```
