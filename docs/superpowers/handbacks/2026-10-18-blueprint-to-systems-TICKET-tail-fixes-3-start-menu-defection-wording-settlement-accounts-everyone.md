# 排位
一、8 批尾：… → 跳窗報價 → **★批尾小修三** → 全員在場 → 玩家從子隊繼位。不插隊、不動小修二（實作二已開工）。

# WHAT
1. **開局可選**（★N1）：開場一個選單，三種開局＝獨立遊團／自己當勢力領袖（有據點與成員）／加入既有勢力。選單先、不做角色自訂。`new_faction` 在預設設定下悄悄退回獨立開局＝列的條件≠做的條件，一起修；選了哪種就必須是哪種，不成要說為什麼。
2. **改投視窗句子**（★N6）：別勢力的**成員隊**想投過來，視窗與回句要寫它真做的事：「Team13 想脫離勢力 3、加入你的勢力 0」，接受前就寫明。行為本身照挖角裁定（意圖帳「挖角」行）不改；領袖隊那條「兩勢力結盟還沒做」照第三張卡不動。原領主收到消息才跑關係＝社交層深層批，這裡不做。
3. **結算交代全部人**（★N4，升 WHAT）：一場仗前後的人口差，結算單必須逐項對上＝死／傷／被俘／逃散／被對方處置，各寫人數（記名寫名字），總和等於差額。一個人都不能憑空消失。這條也是「玩家戰場傷亡入帳」對稱裁定的直接推論。
4. **「收到了情報」洗版**（第一局 21、本局再證）：它把勝仗結算擠出事件區，玩家一次都沒看到。權重升：結算與找上門不得被情報句擠掉（怎麼做你定：情報句合併、或結算釘住到玩家看過）。
