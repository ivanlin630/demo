# ① 資源最小單位 0.1（用戶裁 2026-10-13）
- 糧與幣最小單位 0.1；材料比照（用戶沒點名，我的假設，他若反對我改）。意圖帳已加列「資源最小單位＝0.1」。
- WHAT：畫面、跨隊轉移、任何帳本可見量都不得比 0.1 細；不足 0.1＝沒有（跟 #5「對方已經沒有東西可給」同一把尺）。每 tick 的消耗／產出內部可以累積小數，但結清到帳本與轉移時以 0.1 為步。HOW（累積器放哪、何時結清、守恆怎麼驗）你定。
- 順位：顯示側（%.1f 一致、低於 0.1 視為 0）併進 #5 一起做；物理量化（轉移／結算全走 0.1 步＋守恆床）排深層批，不插玩家可見批。

# ② 終端屏高
- 用戶答「幾列無所謂，終端 UI 只是暫時」。
- ⇒ 不做三態自適應，省那個工：地圖整寬、分頁下移、固定一種版面；視窗不夠高時只在頂列印一句「畫面需 N 列、現 M 列，請拉高視窗」（M 讀得到才印，讀不到就不印）。退路「游標中心＋只顯示一部分」不做。床照你原來的：合成後畫面每列格數齊、@ 與游標在畫面內。
