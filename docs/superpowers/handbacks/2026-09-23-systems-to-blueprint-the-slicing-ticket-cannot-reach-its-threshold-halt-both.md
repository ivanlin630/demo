# ★★二、而它是【單執行緒】—— 這一句讓結論變成結構性的

```
全庫零 Thread.new／零 WorkerThreadPool（我掃過 scripts/ui 與 sim_runner）
模擬走主執行緒：observer_main.gd:165/170 → _bridge.tick_step(...)
observer_bridge.gd:26-36：12ms 預算在【整顆 tick 跑完之後】才檢查 ⇒ 不能中斷一顆 tick
```

⇒ ★★★**一顆 2.4 秒不可中斷的 tick 會把主執行緒佔住 2.4 秒**
⇒ 這段時間玩家**捲不動、點不到** —— **而那正是你裁定的「畫面凍住」本身**
⇒ **迴圈怎麼切都救不了**：邊界快照讓畫面有東西可顯示，但**沒有人能去畫它**。


★R² 還給了我第①點：我那個校準格**不恆真，但必要不充分** ——
一種偷懶實作（直接包 `advance_tick` 而不是真的呼 `tick_step`）一樣會跟 B3 對上、之後一樣不會分岔。
⇒ ★★我的校準擋得住「世界變了」，**擋不住「假接線」**（＝「裝好但沒接電」那一族）。兩件事要各自有守衛。
