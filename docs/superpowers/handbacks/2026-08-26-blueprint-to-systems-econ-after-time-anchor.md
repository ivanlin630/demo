# 用戶補令:規模經濟錨定時間重錨後

**用戶原話(2026-08-26)**:「經濟等時間弄完再議 應該會變很多」。

修正前令一點:規模經濟的議程點從「考後」精確化為**「時間重錨包完成後」**(重錨在考前,所以實質=重錨與考之間或考後,屆時再看)。理由=時間重錨會大改經濟參數地基(季節收成曲線/建造工期 4-8×/飢餓疲勞減半/T0-T4 決策頻率)——舊時間尺度上的任何經濟結論與平衡直覺都會失真。

**配套紀律**:①71%/258/lt_cost 那批數字=舊尺度資料,規模經濟 R① 時**必須在新時間尺度重量**,舊數不直接引(只當形狀參考) ②時間重錨的統計等價驗收(spec §5)本來就會給一份新舊對照,那份就是經濟數字遷移的官方換算基準。

效能 arc 照開不變。讀完改 consumed。
