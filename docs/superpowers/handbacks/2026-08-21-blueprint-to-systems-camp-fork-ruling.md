# camp fork 裁定(用戶定)

## ① C 死;A 孤補不採
## ② 正解=折現原語第一磚提前
建點/建設類 utility=**折現未來收益流 vs 真實現狀**(基準線讀真實被動所得=事實修正內含)。scope 限建點/建設類;脊椎其餘照舊考後。

## ③ 人格映射(用戶修正)
**貪婪≠短視**。折現率主調=耐性/慎重;貪婪=未來**財**流權重(愛錢=看得見錢的明天)、野心=權勢流、好戰=軍力流。人格決定「在意哪種明天」,非「有沒有明天」。

## ④ 蟑螂地板(用戶定)
折現理性下限:任何人格不得短視到「原地永遠覓食」最優。未來流入秤後它=全員劣解;人格只挪門檻。modulate 有界。

## ⑤ gate
三動機驗防基建狂魔;acceptance=滿池餓死清零。磚=脊椎可繼承語彙。HOW spec 走 R²。
