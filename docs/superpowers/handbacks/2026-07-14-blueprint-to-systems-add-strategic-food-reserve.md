# 併入：食物戰略備糧對稱化（比Fix3門檻更根本的根）

補`2026-07-14-blueprint-to-systems-attrition-rootcause-personalize-threshold.md`（Fix2漸進+Fix3人格化）。追一條**更深的根**，跟門檻人格化是同一塊，一起做。

## 查到的不對稱（用戶質疑，已坐實 file:line）
`options.gd` 觸發門檻對照：

| 採購 | 門檻 | 性質 |
|---|---|---|
| 買糧 | `food_days < DESPERATION_DAYS(3.0)` | 純絕境救急 |
| 紮營/乞食/併入 | `< 3.0` | 全絕境反應 |
| 囤貨 | `intent=致富 && food_days >= SURPLUS_FOOD_DAYS(7.0)` | 戰略主動 |
| 貿易 | 無 food gate | 主動致富 |

**食物只有「絕境買糧」，沒有對稱的「充足時戰略備糧」。** `terms.gd:203` 明確把餘糧(≥7)的機會權重只給貿易/囤貨，把買糧排除在戰略層外。

## 這才是 Team14 餓死的更深機制
- 糧食一到 ≥3 天 → 買糧 option **直接失去 applicable 資格**（模型眼中「買糧」選項消失）
- 檯面只剩囤貨/買武器等戰略 option → 自然跑去買武器
- 糧食慢慢跌回 <3 → 買糧才又冒出，常已來不及
- ∴ **不是模型「選擇」不備糧，是系統根本沒給它「戰略備糧」這個選項**——像一個人只准快餓死時才能去買菜，平常不准囤糧，必然週期性挨餓。

物資有戰略採購、食物沒有＝設計缺口，比 Fix3 門檻常數更根本。

## 修向（併入前信，同一 spec）
買糧對稱化——除絕境下限觸發外，加一條「有餘裕(有錢/糧價便宜/有 arb)時主動補到**安全存量**」的戰略觸發：
1. `options.gd` 買糧 applicable：新增中間帶觸發（`food_days` 在絕境3.0 ～ 安全存量水位 之間 + 有市集 + 有錢 + 糧價便宜/arb 也 offer 買糧），或新增獨立「備糧」option 複用 TASK_TRADE（如囤貨複用模式）。
2. `terms.gd` 新增「安全存量水位」常數——**★這個水位就是前信要人格化的門檻本身**（謹慎領袖備糧水位高、賭徒低），兩件事合併：`ESTEEM_FOOD_REF_DAYS`(該不該鬆懈去發展) 跟 安全存量(該備糧到幾天) 是同一個「安全感門檻」的兩面，都接領袖謹慎/野心 trait。
3. `terms.gd` buyfood_drive 權重：加「糧食充足但低於安全線、且糧價低」時仍有適度驅力的曲線，否則 applicable 放行但 rank 永遠輸給其他 option＝白做。
