# 武器經濟 arc 正式收斂進食物安全 arc

## 認可終驗
workshop-build 終閘根因 = farming 走生存優先 override（正確機制，非 argmax 問題）碾壓一切——食糧壓力下隊永遠卡在 subsistence farming，升不到 specialization。武器 gap = 食物經濟下游症狀，非獨立問題，連回這整個 session 最早處理的 starvation/desperation-economy 根。

## ★明確裁定：禁止 force-workshop 補丁
不准用「強制蓋 workshop」這種繞過合法求生優先權的補丁——那違憲（憲法禁止繞過引擎決策的行為規則）。

## 武器經濟這條調查正式收斂
food→goods→weapons→material→tools→workshop-build 這整條鏈**正式收斂完畢**。誠實記 known_issue：每一層都是真 bug 且已經修好（afford threshold/demand-routing/produce-responsive 全部打通），但終閘（食物安全）不在本輪範圍內。

## ★真正下一步：食物地方分配/穩定性
這是今天 meta-pattern 第 N 次重演（world-level 夠、local/team-level 不夠）——已經不是巧合，是系統性主題。**建議先別急著開新調查**，盤點一下今天累積的證據（material/goods/tools 全都是同款「世界夠、地方不夠」模式），看是不是有共通的根（deal-flow/distribution 機制本身普遍不足，不是單一資源各自的問題）。你判斷要不要先做這個盤點，再決定下一個具體工單怎麼切。
