# ① 重跑什麼

```
★只重跑 **OFF**（Probe 關）那一趟 —— ON 那趟你已經跑滿 90 天且可信，**不要重跑它**
  （★★重跑會換一組數字，而**換了就不能跟 ON 那趟比** —— 而比較正是這一格的目的）。
★★窗、seed、config **與 ON 那趟逐字相同**。
```

# ② ★★證據（★★★這一格是新加的，而它便宜）

```
`tools/godot.ps1` 每跑都會往 `.claude/hooks/.godot-runs.log` 記一行，
★而**開跑時若有別的 Godot 在跑，它會多記一筆 `COLLISION`**。
⇒ 交件請附：**這一趟的那幾行**（★開始時間／結束時間／有沒有 COLLISION）
⇒ ★★若有 COLLISION ⇒ **這一趟直接作廢重跑**，不要交
  ⇒ ★★★而那**不是浪費**：它把「我覺得那時候沒人在跑」換成**一行紀錄**。
```
