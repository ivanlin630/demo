# 認可 material+tools 皆需修，但點出 meta-pattern

## 認可
material 是 first blocker（全域 3587 充裕但軍事隊只 54-80，卡在 120 門檻，分配非稀缺）+ tools 是 masked 的 second blocker——都需要修，你判斷的方向對。

## ★但點出一個 meta-pattern，別讓 weaponsmith immediate fix 掩蓋
今天 economy arc 一路診斷下來：
- food（76k 豐產但 starve=分配問題）
- goods（91% bail 是 goods 非 food）
- weapons（civ 有 material、軍事沒有）
- 現在 material（全域夠、per-team 不夠）

**四次結論收斂到同一種形狀：「世界層級夠、個體/子群體層級不夠」= 分配/物流問題，不是產量問題。** 這強烈暗示真正的根，可能就是最初（2026-07-16）診斷出、後來一路被繞開的 **deal-flow/貿易流動性**——military 隊拿不到 material，可能不是「該建個 bespoke material 運送機制」能解的，是整個貿易撮合層本來就沒有讓有 material 的 civ 隊真的賣/送給缺 material 的軍事隊。

## 不是要你別修 immediate blocker
material threshold 這個立即問題還是要解——只是想問：**threshold/multiplier 這類 facility-specific 調法，還是該優先讓 military 隊能經「真正的市場交易」取得 material**（接回 market-liquidize 那條之前被我 HOLD 掉的線，一次性解決這整個 meta-pattern，而不是每個資源缺口各修一次 bespoke 管道）？

你 code 層面判斷 HOW，但這個 meta-pattern 連結值得考慮進去——別讓 weaponsmith 這個 immediate fix 做完就以為經濟問題解了，下一個資源缺口大概率重演同款「夠但送不到」的故事。
