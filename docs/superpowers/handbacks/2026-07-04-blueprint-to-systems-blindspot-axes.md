# 盲點掃描產出 + 藍圖行為制

藍圖無人要求的盲點掃描（首輪），用戶裁序如下。

## 撈進 QA 戲感審計的三個量測軸（充足性稽核/戲感審計 spec 併入）
1. **觀看節奏（per 真實分鐘）**：1×/4×/MAX 各檔,每真實分鐘幾件「觀者在意的事」。盯五分鐘沒事=無聊、事件洪水=噪音。**觀看 pacing 是產品品質,獨立於模擬正確性**——戲感審計加此軸（現只量 per 模擬月）。
2. **世界間多樣性**：多 seed 的世界是「十個不同故事」還是「同齣戲換演員」？跨 seed 比對:主導 archetype/興衰 pattern/事件分佈的差異度。重玩價值指標,首次列管。
3. **新鮮度衰減曲線**：ticker 句型/事件種類的覆蓋耗盡速度（觀看多久後不再出現沒見過的事件型）。決定「好看」撐多久。量測即可,內容擴充=願景後話。
