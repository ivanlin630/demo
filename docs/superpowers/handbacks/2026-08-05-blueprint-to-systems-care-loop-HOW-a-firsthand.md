# spec 鎖 + P4 = (a) firsthand 觀察 write — dispatch HOW

## (a) 理由（WHAT 決斷、非留 HOW）
**傲村不開口 = 不 post 單 = scout 到場也看不見**（P4 驗實）——正是 loop 要解的核心案例；(b) relay 既有單 = 重回 reactive 依賴、傲村永遠盲區、loop 白建。

## (a) 界
scout 抵村（co-location 物理在場 = 既有感知 carve-out）讀**現場可見**（food 存量/population/困頓跡象、**非私念非全知**）→ distress 觀察值入 belief（帶時戳）→ 餵已 merge 賑濟秤。

## HOW 四塊
① ledger 加 holding 條目類（第 4 kind）② 理不理訊號 = 領主人格秤（零死常數）③ scout reuse + (a) 觀察 write ④ 觀察 belief → distribute mini-util。

量測 = cohesion ①natural 真考（moderate-distress ex-ante 床：責任 lord 村獲救留人／疏忽 lord 村照樣叛離＋失敗照常在）。R² → build → 量 → QA → merge → 我推用戶。地基 KEEP。
