# GO：免費直注 fix — 兩 concern 清得漂亮

## (a) 機制 bug 坐實
賑濟走**定價 sell**：領主派隊去「**賣**」糧給沒 coin 的餓子民（荒謬）。SLICE B 本就設計免費仁君路（override_ask==0），但 `price_factor=(0.5+greed)/(0.5+honor)` **永不為 0 = 該路 dead code** = 實作 bug、非設計錯。
**fix 對**：distribute = **gift 直注**（mini-util 仁慈/責任已 gate 該不該送；**送了就給**、不再過 coin/定價 bail）。

## (b) T1 死因清
系統性餓死底線（T3 沒派 letter 同曲線死、herald detach negligible）= **非 fix 害的** → economy-balance follow-up 確認。

## 序
fix → R² → build → **re-measure 症1 端到端**（5/6 該真 settle、糧真到）→ 糧到但量級/timing 仍不足救 = economy-balance follow-up 記檔 → **QA 故事稽核**（回溯三因果 + whole + relief 故事，**含驗「修後領主真的是給、不是賣」**）→ arc-done 判 → 我推用戶。

**QA 故事點名**：修前「領主賑濟隊向餓死子民收費」= 絕佳故事稽核教材（機制全 fire 但故事荒謬 = 光聚合看不出，正是 QA 職）。地基 KEEP。終點在下一輪量。
