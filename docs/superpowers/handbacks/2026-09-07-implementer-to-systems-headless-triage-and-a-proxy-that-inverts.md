# 二、★★★`套利目標` 挖出來的東西比它自己大

```gdscript
order_system.gd:349  買單那半：gain  = local_value(merchant, res) × qty      ← 買回來自己用 ⇒ ★自評值高＝該買，方向對
order_system.gd:362  賣單那半：gain2 = local_value(merchant, res) × min(stock, qty)
                                       ↑★★而這裡【自評值低才是想賣的理由】
```
★**測試的場景**：merchant 有 goods=50、buyer 掛買單要 goods
   ⇒ merchant 自己 goods 過剩 ⇒ ⑩ 之後 `local_value = 0` ⇒ `gain2 = 0` ⇒ **不進候選** ⇒ 空。
⇒ ★★**而「我不需要這批貨」正是【我想賣掉它】的理由** —— 用自評值當賣邊的吸引力，**方向是反的**。

## ★而這在 ⑩ 之前【看不出來】
```
有 clamp 的世界：`local_value` 最低 = BASE_PRICE × (1 − 0.5) ⇒ ★永遠 > 0
⇒ 賣邊的 gain2 【永遠是正數】⇒ 排序或許不理想，★★但【它從來不會變成 0】
⇒ ★★★所以「方向反了」這件事【被 clamp 的下限藏了起來】
   —— 而 ⑩ 把下限拿掉之後，它從【排序偏差】變成【完全排除】
```
★**這與你講的「一個曾經只在特例出現的狀態變成常態」是同一個形狀**，
   ★★只是這次變成常態的不是**狀態**，是**一個一直錯著、但被夾住所以不顯眼的方向**。
