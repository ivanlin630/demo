# 框架驗證套件（WHAT）

統一框架最大風險 = 行為被洗平（破我「連貫≠同質」bar）。下面是**框架必須通過的行為測試**（Part 1）+ **驗 6 條魂的觸發場景**（Part 2）。框架一落地立刻跑這套，不用等發現問題才回頭。每案我給「驅力 → 應有行為 + 為何」；HOW（怎麼擺 config、怎麼斷言）你定。

## Part 1 — 行為測試案例（框架必過）

每案核心驗證:**讀得出「因為 [驅力綜合] → 此刻做 [動作]」,且不震盪。**

**TC1 精神分裂案（THE bug）**：商隊 tag + 定居人格（義氣.7/貪婪.4）+ 有 outpost + 糧 OK。
→ 應:**COMMIT 一個選擇不震盪**;框架把 tag(角色) 與人格(傾向) 併成連貫選(如:定居性格的商隊頭把商隊當「謹慎本地小貿」經營),持久矛盾走 `tag_shift` 漂移收斂。**FAIL = 每 2 天 trade↔生產 震盪**(現狀)。

**TC2 survival override**：任意隊,糧近 0。
→ 應:拋一切求生;**殘忍→搶劫、義氣→覓食/乞**。驗 survival = 高權重**輸入**(非獨立 latch),且人格仍 flavor 手段。

**TC3 feud 脫軌 + 分歧**：爬「擴張」中 + 強仇(高 intensity) + 衝動(好戰.8/慎重.2) → **脫軌打仇人**(哪怕戰略蠢)。**同一仇 + 慎重.8 → 隱忍待機,有利才動**。驗私人驅力為輸入 + 人格分歧。

**TC4 ambition 無壓力驅動**：安全(糧 OK/無威脅) + 野心.9 → **主動爬階**(擴張/立國)。**野心.3,同安全 → 知足平台期**。驗野心驅動**不需飢餓**(用戶早先戳的點)。

**TC5 經濟 + 情報**：商業隊糧滿(倉滿) + 情報說 X 缺糧 → 去賣;**情報假/過期 → 撲空吃虧**。驗經濟狀態 + 殘缺情報為輸入。

**TC6 多驅力權衡**：糧中等 + 野心中 + 小仇 + 派系要徵收 → weigh 成**一個**合理選,**讀得出為何**(如:糧還行+仇不深+派系命令 → 此刻徵收最合理)。驗多輸入連貫收斂。

**TC7 分歧壓測（硬 bar）**：**同一情境**放 3 種 leader——霸主(野心.95/好戰.9)、商人(貪婪.9)、隱士(義氣.9/慎重.8/野心.2)。→ **3 個不同動作**。**框架嚴禁把這洗成同一個樣**。這條過不了 = 框架失敗。

## Part 2 — 6 條魂觸發場景（驗 dormant 魂 fire）

每場景:**最小 config 設置 → 成功判準(probe + 可信行為)**。

**S1 立國**：野心 tail leader + 資源 + 空間 + 可吞的弱鄰。
→ 成功:`faction_found>0`,且弧**漸進**(生存→積累→擴張→立國,非瞬跳)。

**S2 血仇 feud+vendetta**：預置一樁殺戮/暴行(殘忍 raider 屠某隊但留餘部 / 或預置 feud 邊)。
→ 成功:`feud_formed>0` + `vendetta_trigger>0`;高義氣/好戰受害方記恨追殺,寬厚方放下(分歧)。

**S3 scout 查證**：對目標有**矛盾/不確定**情報 + 慎重 leader。
→ 成功:`scout_dispatch>0`,**查證後才行動**(不確定→scout→Tier0→動)。

**S4 誘殺 ambush + 分歧**：偽裝弱餌(假低報 armed 的 intel) + 莽攻擊者(好戰.8/慎重.2)。
→ 成功:`ambush>0`,莽者**被誘殺**;同場放慎重者 → **scout 識破避開**(分歧)。

**S5 鑄幣 mint**：faction 控金礦 tile + 鑄幣廠設施 + 經濟脈絡。
→ 成功:`mint>0`(ore_gold→coin 等值守恆),**W8 解**。

**S6 經濟閉環（= 框架首驗案例）**：商業隊 + 市集/depot + 缺糧買家。
→ 成功:`[Market]成交`常態 >0、`履約率`脫 0、囤糧峰值受糧倉 cap 封頂、分工鏈跨隊流動。

## 用法
- **框架落地 → 先跑 Part 1**(尤其 TC1 震盪消失、TC7 分歧)。過不了代表框架洗平或仍不連貫。
- **Part 2** = world_sim 場景台(已建)加對應 config,驗 6 魂從 0→非零 + 行為可信。
- 數值全 TEST VALUE。場景 config 的 HOW(座標/隊配置)你定;成功判準(WHAT)如上,有疑義回呈。
