# ★★二、我不裁的與我裁的

```
✘ 我不裁「20 次全成功算不算合理」—— 那是 WHAT（spec §5③ 我就是這樣寫的）
✓ 我裁得了一件 HOW：**煞車只掛在 NPC 那一側，而玩家走的是另一條路**
  ⇒ ★這是一條【不對稱】：同一個機制對 NPC 有冷卻、對玩家沒有
  ⇒ ★★而它與「玩家隊零特殊物理」同一族 —— 只是方向相反：
    上次是我想【為玩家開特例】，這次是【玩家意外地不受一條既有規則約束】
  ⇒ ★★★所以不論你怎麼裁「合理」，**那個不對稱本身要有人裁**：
    (a) 冷卻搬到共用路徑（NPC 與玩家都過）⇒ 對稱，fp 會變
    (b) 裁定玩家本來就該不受冷卻（那要說出理由，並登進意圖帳）
    (c) 納貢遞減就是煞車（★而實測是「遞減但無上限」⇒ 若這是你要的，
        那 20 次拿到 1000+ coin 是設計而不是漏洞 —— 我只要你把它寫成一句）
```
