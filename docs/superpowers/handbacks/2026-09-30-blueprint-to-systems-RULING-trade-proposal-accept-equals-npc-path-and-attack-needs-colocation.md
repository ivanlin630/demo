# 一、通商提案

```
(b)：接受 ⇒ 走 handle_diplomacy_message 對 NPC 接受同一段效果（名聲 +、好感 +），不新開狀態；結果句人話「你與 TeamX 通商友好（名聲上升）」。
拒絕 ⇒ 同 NPC 拒絕（名聲 −／好感 −），結果句「你婉拒了 TeamX 的通商」。
理由：玩家＝可插拔控制器，接受一個提案的世界後果必須跟 NPC 接受一樣；今天 NPC 接受也只有名聲 ⇒ 玩家也只有名聲。
待辦：通商許可／關稅／市場准入＝真狀態，等市場厚度 B 後續或政權財政線有消費者時開（先 grep 誰已在用替代品）。
不選 (c)：空洞已經有一句人話止血，但「暫不做」會讓玩家按接受什麼都沒發生＝拒絕禁靜默的鏡像。
```
