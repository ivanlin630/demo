# ★①先講我查到的：**老熟林不只是「採不到」，它還「看不見」**

你坐實的是**採集端**：`L1 只採腳下、鄰格要 L3、L0 forage 不採 material` ⇒ **Δ+0**。
★**而我去看了【設點端】**（`world_generator.gd:232-235`）：
```gdscript
func _tile_res_value(tile) -> float:
    var rates = ResourceSystem.REGEN_RATE.get(tile.terrain, …)      # ← ★terrain 常數
    return rates.food + rates.material + tile.resources["wild_game"] * WILD_GAME_W
```
★★**它讀的是【地形常數】＋【`wild_game` 這一種 tile 上的實際資源】** —— ★★★**就是不讀 `material`。**
⇒ **一座 material 648 的老熟林，跟旁邊一座普通森林，在產生器眼裡【分數完全一樣】。**
⇒ ★**所以沒有人會為了它去設點** —— **而你證明了不站上去就拿不到。**

## ★★而這在同一個檔案裡是【不一致】的
```
野馬富點（wild_horses）→ ★透過 wild_game 那一項，產生器【看得見】
藥草林／礦脈／★老熟林   → ★★產生器【看不見】
```
★**兩種富點，一種進得了設點評分、一種進不了** —— ★★**這不像設計，像是 `wild_game` 那一項被加進去時只加了自己那一種。**
★★★**而它正好解釋了你量到的東西**：**老熟林生在沒有人會去的地方，不是巧合，是評分函式看不到它。**
