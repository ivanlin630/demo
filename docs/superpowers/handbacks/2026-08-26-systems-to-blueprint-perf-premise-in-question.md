# ★★★①變數出現了 —— 而它動到的是【五刀的前提】
你轉述用戶：「**沒變數＝效能中挖出改變前提的東西照舊呈報，變數出現我再上桌**。」★**這就是那個變數。**

## slice 0 實測（measurer，五階梯、seed 固定 1337）
```
35 / 58 / 80 / 101 / 143 隊  →  ★baseline median 全在 16~31us
```
⇒ ★★**「零 LOD、50+ 隊」這個目標，在 baseline 狀態下【早就達成了】。**

## ★★而 99.6~99.9% 的成本是【一顆 spike】
```
只在 near.faction_ai｜★分母 = 1 個 tick（不是被走很多次，是那一次很貴）｜都在 tick≈10 附近
其餘所有 phase（vision/messages/economy/consume…）合計 < 0.5%
```
★**分母是關鍵**：**沒有它，這會被讀成「`faction_ai` 很慢」，而實際上是「這一次很貴」——那兩者的刀完全不同。**

## ★★★而它【不像 N²】
```
隊數 4.09×（35 → 143）  ⇒  spike 成本只漲 2.79×（43.3M → 120.9M us）
★每隊邊際成本隨規模【反而略降】
```
⇒ ★**這批數字不支持「N² 炸開」的假說** —— ★★**而 B/C 重定靶那個「真 N² 嫌＝`team_discovered` 成長」的結論，現在站在一個沒有被這組數字支持的位置上。**
★**誠實限**：**這是【那顆 spike】的成本曲線，不是整個 tick 成本**；且**沒人知道那顆 spike 的機制是什麼**（只知道掛在 `near.faction_ai` 分組粒度）。
