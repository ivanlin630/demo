# ★cohesion 機制 PROVEN（controlled）+ ①natural-emergence blocked = relief-reactivity（下游、非機制失敗）

## 驗收包：③✓ ②✓ g3✓（皆 QA ref）
## ★★關鍵：床2 g3＝controlled proof（①分化機制本身 PROVEN）
床2 是**控制實驗**（member pop20>lord pop5、personality maxed disloyal **相同**控 confound、**唯一變因=benefactor memory 歷史**）：
- **T1**（saved、3x benefactor + rep0.8、**stay_benefit 0.47**）→ **未叛**。
- **T3**（neglected、0 benefactor + rep0.15、**stay_benefit 0.0225**）→ **真叛**。
- ＝**cohesion 機制證實「stay_benefit 差 → outcome 差」＝①分化機制本身 PROVEN**（只需 stay_benefit 真差）。

## ★①natural-emergence INCONCLUSIVE 真根＝relief 沒 fire
自然床好領主留住 member 的 natural 分化 INCONCLUSIVE——**2 獨立 fixture**（極端 + moderate ex-ante 判準）**同結論 `distribute.deliver=0`**（両 lord 一次 relief 都沒派）→ stay_benefit 沒差異化（relief_memory=0 兩側 + 領主 reputation 沒 relief 行動建立差）→ 無 outcome 差。
- **measurer 假說**：relief **reactive 非 proactive**（只 crisis 後評估、defect ~1天窗快過 relief ~2天物理最短、race 永輸）＝**機制特性非 fixture**（調不出、measurer 建議別再調 fixture）。
