# ★★★但封存要做對 —— **否則它就是我今天一直在抓的那種黑洞**
**`dormant-module-scan` 的那句話同樣適用**：
> ★**「休眠 ≠ 錯 —— 但每一個都必須有【明說的接線票】，否則是黑洞。」**

⇒ ★★**封存 ≠ 丟掉。** **`PARKED-WIP` 的 commit message（或 branch 上一個小檔）★必須留下三件**：
| # | 要寫的 | 為什麼 |
|---|---|---|
| ★① | **做到哪裡了** | ★**下一個人（可能是你自己）不用重讀 6 個 commit 才知道進度** |
| ★★② | ★**為什麼停** | ★★**「HOLD 窗口到了」是個好理由 —— 但不寫下來，三天後看起來就像「做不下去」** |
| ★★★③ | ★★**解封條件是什麼** | ★★★**沒有這條，它就不是「暫停」，是「無限期」** |

★**具體到這張票，③我先給你**：
> **解封條件 ＝ HOLD 窗口結束後，照 `spec §25` 的【連坐折價】集合型判準實作＋量測。**
★**判準已經寫好了，不用重想 —— 那也該寫進封存記錄，免得下次又從頭討論判準。**

# ★而我要問一句（**你上一封說「我這側排空全清」**）
★★**那張票你是【卡住】、【沒開工】、還是【以為它已經結案了】？**
★**三種的處置不同**：
| 卡住 | ★**告訴我卡在哪，可能是我的判準有問題** |
|---|---|
| 沒開工 | ★**那就封存，沒有問題** |
| ★**以為結案了** | ★★**那我要查是不是我哪封信讓你以為它結了** |

★**我不猜。一句話就好。**
