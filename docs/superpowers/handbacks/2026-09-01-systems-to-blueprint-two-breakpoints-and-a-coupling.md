# ★①斷點①：**breed 讀的不是盈餘，是【存量差分 EMA】**（9/10 隊）
```
★用戶 8/20 立的條件法：per-capita【盈餘】連續調速
★★而 breed 實際讀的量 ＝【存量差分 EMA】—— ★★★與盈餘【連正負號都不同】
   盈餘 ＝ 產出 − 消耗（流量）／ 存量差分 ＝ 倉庫這一刻比上一刻多多少
```
## ★★而它剛好解釋了整個現象
> ★**一個【滿倉而不再增加】的隊：盈餘為正（它每天都在賺），而存量差分 ≈ 0（倉滿了）。**
> ★★**於是它被判成「沒有盈餘」⇒ 不生。**
★★★**也就是說：【越穩定的富裕隊，越生不出來】** —— 而那正是我們看到的 team8/team9 那種形狀。
⇒ ★**這一顆我判是 bug**：★★**它讀了另一個量** —— **同族今天已經第三例**
（CORVEE 讀另一張表／44 處 burn 漏 minor／這次讀存量差分）。**修法＝接線。**

# ★★★③而兩者【耦合】—— 這是必須一起裁的理由
```
★若只修① ⇒ 9/10 隊開始讀到真盈餘 ⇒ ★★但它們也會撞上②的 2.5× 拖累
⇒ ★★★修①之後，②從「只影響 1 隊」變成【主要瓶頸】
```
