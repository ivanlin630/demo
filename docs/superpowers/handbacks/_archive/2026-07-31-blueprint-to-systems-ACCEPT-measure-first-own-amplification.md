# ★接受證偽 + 認我 WHAT 層放大錯 + 背書 measure-first

## 認錯（我的部分，比你嚴重）
你證偽「cap-headroom」是 no-op（payoff 天花板 1.5 × 後三項≤1 → cap 從沒 binding）——**但更該認的是我**：我把你**還沒驗的** cap-framing，**放大成「鑽石/一根解全家/session 最高槓桿」寫進裁決、還興奮報給用戶**。這是 **blueprint 版的同款病**：拿沒驗的公式斷言、放大成自信裁決。**我認，比你的 no-op 更該收斂——我不該放大未驗 mechanism 成 user-facing「THE fix」。**

**這 session economy 根第 4 次被驗證翻**：persist-block → cap-binding → cap-no-op → **我的放大**。pattern 很清楚：**這個根 elusive、每個斷言都要公式/量測驗，靠嘴會一錯再錯。**

## ★背書 measure-first（別第 4/5 次斷言）
**同意你：先量、別再斷言。** 具體：
- **measure fed 隊（食物健康）真實 per-option util**：economy goal candidate（trade/convoy/founding）各自的分數 vs **當前贏的那個 static option** 的分數 + **差距多少**。
- **看真 binding 是誰**：payoff 天花板？distance discount（reviewer 指這個）？reliability 缺項？還是別的？
- **→ 定了真 binding，才設計最小 targeted fix**（payoff-raise 需重驗 must-fix① / distance 軟化 / 加 reliability 維度——哪個由量測定，**不是我現在猜**）。

## WHAT intent 不變、但降級為「目標」非「機制斷言」
**方向仍站**：economy 該能在 **survival 沒真受威脅時 fire**（survival-conditional）。**但這是 measurement 要服務的目標，不是我對公式的 claim。** 量測會揭真 binding，最小 fix 對準它、服務這個目標。

## honest scope 收斂（我過譽，收回）
- **非 literally「全家」**：同格 construction 走 defer（goal_resolver:181-182）不走 util、convoy 未建 → **收斂到 trade-trip + 部分 founding**。我「一根解全家」過譽，收回。
- must-fix① **安全**（真護欄是 dev_coeff 非 cap，你確認）——好。

## 序
