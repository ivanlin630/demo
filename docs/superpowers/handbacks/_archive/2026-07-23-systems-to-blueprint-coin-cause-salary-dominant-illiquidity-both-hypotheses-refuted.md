# coin-cause 坐實 = salary 主因（illiquidity 非 shortage）；你兩假說皆 refuted/次要

## measure 坐實（R① 前置，你堅持對）
- **net coin flow 兩族群兩 seed 結構性負**（mil -0.03~-0.10/day、civ -0.08~-0.09/day）= 機制坐實 91% chronic coin_urg。
- **★salary = 兩族群共同最大 drain**（mil 50-67% / civ 51-55%，跨 seed 一致）= 判準③「salary-drain 通吃」。

## ★你兩 coin-cause 假說 measure 皆非主因
- **① mil-loot→anon_treasury 不流**：**假說原型不成立**——conquest-loot（loot_full/share/wipe/massacre）**兩 seed 零事件**（機制根本沒 fire）；**mil trade net 反而正**（+4~+31/3mo）= mil 不因低賣虧，反駁 mil-loot-drives-poverty 單因。
- **② civ-dealflow / GATE-B**：**真但次要**——civ trade net 兩 seed 小幅負（-4~-31/3mo），但**比 salary 小一個數量級**。→ **GATE-B 非 coin 引擎**（維持排後獨立 arc，不 pull 進 coin relief）。

## ★root = illiquidity 非 shortage（code 坐實，守恆）
coin **不是沒有，是拿不回 spendable**：
- salary → `AnonTreasuryBank.deposit`（付薪隊**自己的 anon_treasury**，illiquid pool，非流失）。
- extraction（anon_treasury→spendable team.coin）= `_consider_extraction`：`extract_score = greed - prudence×0.5`，**需 > 0.4 才 extract**（faction_ai:2365）。**中庸領袖**（greed 0.5、prudence 0.5 → 0.25 < 0.4）**永不 extract** → coin 鎖 anon_treasury。
- ∴ 多數隊 spendable team.coin 慢性低（付薪掏空 → 鎖 anon_treasury → 取不回）→ 湊不到 afford。

## ∴ fix 偏 salary 機制（非「加 coin」）

- **extract/recovery gate 太嚴**（`greed-prud×0.5>0.4` 讓中庸隊 coin 永鎖 anon_treasury，取不回投資本）？
- （既有 `_recover_member_tax` faction_ai:2369 也是 recovery 但月 cadence+人格 gated，可能跟不上。）
- **liquidity framing**：coin 守恆存在（anon_treasury），問題是**流動性**（拿不回）——fix 偏「讓隊取得自己的錢」非「印錢」。
