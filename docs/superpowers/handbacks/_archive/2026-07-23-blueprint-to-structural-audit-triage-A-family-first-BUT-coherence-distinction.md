# 裁：A 家族先 measure，但 ★critical coherence 分辨（別毀 archetype 願景）

## ① triage 認可：A 家族 + #3 第一批
- **A 家族先**（persona>~0.6 硬閘：#1 軍營、#2 戰爭基金、#5 掠奪、#7 礦）——認可 systems：**最高 yield + 最強 prior**（extraction 同型已證真）+ 批量 measure 省。
- **#3（misplaced TARGET_PER_POP，定價表當 need = smell ①、跟 117 同型）併第一批**——117 已證真 = 強 prior，check 是否 live reader 便宜。若是 live 誤用，就是坐實的 117-sibling。

## ★★② critical WHAT 分辨（measure-convict 必守，否則毀願景）
**A 家族「persona>0.6 硬閘排除中位領袖」本身 ≠ bug！** 這是這批最容易搞砸的地方：
- **extraction 0.4 是 bug**，因為「拿回自己的 coin」是**普世 need**（任何人格都該能取用自己的錢 → 排除中位 = incoherent）。
- **但「慎重領袖不掠奪」「和平領袖不建軍營」很可能是 archetype 願景正在 working**——**人格差異化 = 多元文明戲的本體**，persona-gate 正是綜合發展模型「人格走不同路」的機制。**亂修 = 把 archetype 多元化毀成同質 soup = 跟願景反著走。**

**∴ measure-convict 每筆必分兩類**：
- **(a) incoherent = bug**：被排除的中位領袖有**真 need / 情境該做那行為、卻被 flat 閘擋**（如：防禦是 need 非 martial 偏好；挖礦是發展 need 非 greed expression）→ de-patch。
- **(b) coherent = 非 bug**：純人格 appropriate 差異化（掠奪、戰爭基金這種 strategy-expression，慎重領袖不做很合理）→ **別碰**。

**逐筆判準**：被閘的行為是 **serves 普世 need** 還是 **express 特定人格**？need → 該對所有人格開（flat 閘是 bug）；expression → persona-gate 合理（非 bug）。

## ③ 我的初判（但別靠我猜，measure 定）
- **較可能 bug（incoherent）**：#7 礦（發展 need，中位領袖也該能發展礦業經濟）、#1 軍營（防禦是 need vs martial 偏好，borderline 須 measure——危險世界裡和平領袖也需要防禦）。
- **較可能 coherent（非 bug）**：#2 戰爭基金、#5 掠奪（strategy-expression，慎重/和平領袖不做合理）。
- **measure 定**：每筆量「中位領袖被排除時，有沒有真 need/情境觸發那行為」——有 = incoherent bug；沒有（純人格偏好）= coherent 別碰。這是 gating-coherence 的 measure，照新 R①。

## ④ 延後
- **B 家族（flat facility-desire #4/#8/#9）**：means-end 本場證 latent-not-binding（demand/argmax 健康）→ 低急，queued。
- **#6 CONSTRUCTION_CAP 100**：等 poverty-trap 解、reserve 升近 100 才回訪（那時才 bind）。

## 序
三腿修 + material-hold measure 後 → **A 家族 + #3 第一批 measure-convict（帶 coherence 分辨）**，平行不擋。**每筆 hypothesis 照新 R① measure 坐實才 spec**（靜態本場錯 3 次）。
