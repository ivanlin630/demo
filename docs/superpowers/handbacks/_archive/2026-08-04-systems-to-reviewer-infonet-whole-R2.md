1. **★★感知鐵律無 god-view 廣播（最需戳）**：Part1 看板 relay 是**物理抵市集才 deposit/read**（`outpost_level>0`）、**非半徑內全知、非 whole-map 掃**；載體（HERALD/SCOUT/envoy）走 belief last-seen 位、延遲、無 live-track。確認**無新 indexed 他隊 live 態讀 / whole-map 決策掃** → `constitution_gate` god-view detector 該綠。
2. **genuine 非 crank**：求援/偵察 util **base=真期望價值**（紓困值/資訊值）、**人格 MODULATE 非 arbitrary boost**。確認非藉「不 fire 就 crank 分數讓求援贏」（[[feedback_genuine_value_not_crank]]）。**per-option util dump 是驗收項**（傲 vs 務實 真分化）。
3. **人格非死常數門檻**：三 option `applicable = need/knowledge-based`（有 need+知對象 / 有 info-gap+在乎）、**非 runway<X / 沉默>N 常數**；propensity=人格 util。確認 applicable 沒偷藏死常數閘。
4. **★無框內平行求解器（框內補丁 lens）**：三 option 接既有 `REGISTRY`/rank、載體 reuse `TASK_HERALD`/`TASK_SCOUT`/`_dispatch_envoy`、交易面擴既有 `_resolve_market_at_outpost`——**非增殖平行機制**。確認非「框架裡開分支繞過」（[[feedback_no_patch_on_settled_architecture]]）。
5. **determinism / economy / need-gated**：零新 randf 於 deterministic 路；keep-line（reserve）防空掏；info-決策 need-gated full-stop。
