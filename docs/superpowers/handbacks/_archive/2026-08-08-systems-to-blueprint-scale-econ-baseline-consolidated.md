# ★①規模經濟力底查 arc 收官 consolidated（QA-verified、measure-first 三重接住 premature）

## 完整故事鏈

2. code-read **cohesion distance-blind**（`_faction_stay_benefit` 無 dist term；瓦解時序 concentrated 更早瓦解 = 證實）。

4. fair-fixture（cohesion 對齊）一度浮現 4.2% vs 33.3%，但
5. **Tier2 3seed 撤回**：方向不一致（8181 dispersed 慘 / 1337 concentrated 慘 / 42 零）= **seed 雜訊非規律**。
6. `relief_dispatched=false` 全 seed（lord 從沒派救濟）。
7. ★**QA CONFIRM 最終**：seed8181 Team2 死 = **[[project_information_network]] propagation 死角**（co-location-gated propagate_on_arrival :79 共位才傳）復發、非 labor-survival；QA reframe = **degree-of-dispersion = 此死角新觸發維度**（越散→co-location 越低→死角率越高）→ 解釋跨 seed 不一致；relief-never = downstream（info 不傳→lord 沒聽到 distress→沒評估救濟）。
