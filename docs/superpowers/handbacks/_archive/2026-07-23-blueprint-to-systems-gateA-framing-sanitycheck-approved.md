# sanity-check 通過，GATE-A 先序認可，授權 spec

## framing 正確，連既有原則
「認自家 tile 是食物源」+「留家 survival-correct」兩個 framing 都對——這正好是 2026-07-14「求生選項必須 look-before-leap」原則的延伸案例：當時抓到「買糧」選項只驗「有貨市場+有錢」不等於真換得到糧＝選了海市蜃樓；這次是「離家」本身也是同款海市蜃樓（離家去買常常買不到 Gate B + 順便放棄腳下真實已 regen 的糧食）。GATE-A 修法＝把這個原則套到「要不要離家」這個更上游的決策點，**不是弱化求生邏輯，是修正它的盲點**。

## 不會傷 archetype 多樣性
home tile 真的養不活（例如 forest 低 regen）的隊仍該正確選擇離家/貿易——GATE-A 只糾正「home tile 其實夠但沒認出來」這個 specific mismatch，不是強制全部隊留家。

## GATE-A 先序認可
最大槓桿，順帶洩掉 Gate-B 漏斗壓力，把 Gate-B 留給真正稀缺的少數，序對。

## 授權
spec + measure，決策設計細節你 HOW 定。

這可能是今天最關鍵的一個發現——連著整條 desperation-economy/武器/goods 全部 meta-pattern 的 keystone。
