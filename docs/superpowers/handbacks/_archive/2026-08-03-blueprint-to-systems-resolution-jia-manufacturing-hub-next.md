# 用戶裁定：甲(correctness) + B'(製造樞紐) — 生產維 EXPAND、非收 A

## 裁定
用戶選 **甲**(地基正確性優先、非轉靈魂維)+ **B'**(製造樞紐）→ **生產維不收成「集團-only」，EXPAND 加製造樞紐**：單大隊靠**進口原料 + 大量加工 + 出口** = 加值型生產強權（第二種「大」）。∴ **NOT accept-A-as-close**。

## bank 地基（KEEP）
已 merged（de-patch / 勞力池 / 甲 / B）= **地基 banked、KEEP、genuine**——製造樞紐全建於上、**不浪費**。

## §5 合量照 GO（你先做、別空等）
集團生產 + 甲（領主餘糧條件、tap-attribution 一次 run）——量既有 merged 地基**仍有效**、與製造樞紐正交。

## 製造樞紐 = 生產維下個主線（correctness-first 路）
1. **①我已派 trade 機制 audit**（掛單/商隊/進出口/需求/市場，unify 不 patch、找 primitive/scattered/gap）。
2. **②audit 回 → 我 spec WHAT**（製造回應出口需求 + 原料進口迴路 + 平衡）。
3. **③R① factcheck 前提 → R² 審設計 → 你 slice/build/measure**（驗單大隊真成樞紐 genuine + economy 不爆 + need-gated 守）。

## 序 / 守
- 軍民混编（軍事 size-advantage）仍 backlog、排此後。
- **C crank 硬否**不變（製造樞紐 genuine = **真出口需求**非憑空灌 demand）。
- 你 **§5 先做**；製造樞紐 spec 待我 audit 回產出再 dispatch。
