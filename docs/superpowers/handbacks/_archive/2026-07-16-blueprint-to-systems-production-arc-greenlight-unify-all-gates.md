# 生產 arc greenlight（甲）：拆光補丁閘融入框架（用戶定，同商業那套）

用戶 greenlight 甲，且**方法同商業統一**：不是 de-patch 單一 `恆-hungry` 閘，是**拆光生產/設施子系統所有補丁閘、全融進框架（引擎 + 人格秤），無殘補釘再量。**

## 為何甲（乙不成立）
供給根＝製造設施幾乎不建（`has_facility` 恆 1）。**隊想製造（TASK_MANUFACTURE 1→11）、有材料（surplus 破千）,純被 gate 擋**（頭號＝恆-hungry 永建農）。**這是 bug 閘非天生稀缺 → 補丁閘優先查通則＝de-patch,不能把 bug 當設計接受（乙）。** ∴ 甲。

## 願景意圖（WHAT）＝綜合發展模型落地
- **食安地基後多維發展**：食物是門檻,吃飽之後該按人格發展（製造/軍事/建設）。**de-patch `恆-hungry`：糧倉有糧的定居隊不算餓,不該被逼永遠建農田。**
- **設施建造人格化**：建什麼設施走 DecisionEngine + 人格秤——工匠/發展型建工坊/冶煉、農夫型續農、好戰型建軍事。**同 [[綜合發展模型]] 人格化多路、同商業「全程人格化」。**
- **節奏**：食安 → 製造 → 餘貨 → 貿易,人格+情境定速,非瞬發。
- **這是「吃得飽的窮部落爬薄階梯」的突破口**——拆這批閘,部落才從求生升到發展。

## 方法（同商業，用戶定）
- **拆光所有補丁閘,非單一**：別只 de-patch 恆-hungry 就量→又抓下個閘（打地鼠）。**列全 → 全融框架 → 無殘補釘 → 再量乾淨。**
- **我已派靜態稽核**列全生產/設施子系統補丁閘 + 引擎外硬碼 + 死常數（file:line）→ 完成餵你,對照你 patch-gate-first dynamic 定哪閘主導。
- **全程人格化 + 新決策/no-op 路徑接 tap**（守全量暫態可觀測；「想製造但 has_facility=0 空轉」要可觀測）。

## HOW 全交你
- 哪些閘拆、怎麼進引擎、facility 決策怎麼走 utility+人格、切幾 slice ＝你 HOW。
- 我只要結果：**製造設施蓋得起來（has_facility 成長）+ goods 產出 + surplus 進市場 + 貿易活 + 無殘補丁 confound + 行為隨人格分化（工匠隊 vs 農夫隊 vs 軍閥隊建不同）**。
- 大小你判：目標「拆光補丁閘的完整生產框架」再量,非拆一道就量。
