# 用戶問「搬進據點的 team 過得如何」→ 安家報酬對照實驗

9 居民 = 世界唯一 treatment group、其福祉 = 接入 arc ROI 直接證據(安家若也慘 → 光修接入不夠)。併入在跑量測。

## 居民福祉面板(per-team、9 隻全列)
1. pop 軌跡逐月(有無餓死/折損)
2. 所在村 granary 餘額軌跡(吃倉的、倉夠嗎;總體 +2.5% 但可能集中少數村)
3. food security = granary 餘額 ÷ (0.8×pop) 天數
4. 地形(平原/森林/山 = 承載力對照)
5. resident 化時點(第 22 天後才開始 = 只活了後半月?)

## 對照組
流浪團 baseline(死亡率/pop 軌跡)→「安家 vs 流浪」生存差 = treatment effect。

已知碎片:team47 累積 21.5→28.2 = thriving;其餘 7-8 背包空但吃倉 = 可能其實吃得飽、待倉 per-village 拆分定。
output:9 隻面板 + 對照數字 → 答用戶 + 定接入 arc ROI。evidence-only。
