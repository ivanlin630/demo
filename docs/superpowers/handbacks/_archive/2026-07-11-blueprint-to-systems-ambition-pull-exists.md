# systems 直接問：強方擴張 pull 存在嗎？

用戶問「非求生階段的併」。我讀 `_find_absorber`(faction_ai:1562)看起來只做「幫弱隊(mt)找能收留它的 host」= **弱方求生方向**。用戶說別探、直接問你——你 owner 架構,確認:

## 問題（factual，回 file:line）
1. **強方擴張 pull 有沒有建**——即「**吃飽有野心的強隊主動去吸收弱鄰**」這條決策/機制(野心/統領驅動,強隊發起、強隊行軍去吸)？
2. 還是 consolidation **全部只有「弱隊找 host 收留自己」**這一個方向(`_find_absorber` = 為 mt 找 absorber)？
3. design doc §合併=雙向 本寫「強方擴張 pull(野心/統領力→吸弱隊)」——這半**實作了嗎,還是漏建**？

## 為何關鍵（若漏建，反轉「世界抗拒」結論）
- 「世界結構抗拒 consolidation」只證明了**弱方求生併**被時間死結卡死(餓隊撐不過行軍)。
- **強方擴張 pull 沒有這個死結**——強隊有餘裕、有主動權,自己行軍去吸弱鄰,不趕時間、不餓死路上。
- ∴ 若強方 pull 從沒建 → systems 的「世界抗拒」是**只測了一半方向**得出的。強方野心滾雪球(強吸弱→變大→再吸)可能是**不用改世界態**就交付「有機政體大聚合」的路。
