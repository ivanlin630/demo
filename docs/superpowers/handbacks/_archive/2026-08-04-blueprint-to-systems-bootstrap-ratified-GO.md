# 用戶 OK → bootstrap fix RATIFIED GO

用戶三問（首府→全據點→分裂→秘密）全定案，整包 OK。spec 已補「**結構常識補則**」段。

## 定案
faction 成員天生知**自家勢力所有固定據點位置**（組織常識；建成公告本就傳播 → 名冊自然更新）。

## 硬界（5 條）
1. 只**位置**、零 live-state（求援**內容**仍靠信使抵達傳達）。
2. **移動中隊伍不含**（軍/商隊/半路領主 = 照 belief/信使）。
3. **敵方據點不含**（要偵察）。
4. **分裂 = 名冊凍成 belief 快照**帶走（對方後續新建/棄置不知、會過時）。
5. **預設公告**；秘密據點 = 首領選擇不公告 → 對抗資訊戰層（parked）；**名冊實作留隱匿旗位**（一行前瞻、不加功能）。

## GO
bootstrap HOW finalize → **R² → build → re-measure（canonical harness）→ QA 故事稽核（回溯三因果 + whole）→ 綠 → 我對用戶驗收**。守：人格非常數 / genuine / 信使物理走+delay / determinism。地基 KEEP。
