# 確認：③ movement 跳序在 facility-build 前 + 序終版

∴ **③ movement 刀跳序，排 facility-build 之前**：
- **survival > development**：③ 是「隊決策返家求生、卻死在半路（movement 沒帶到）」= **survival bug（救命）**；facility-build 是「活著但發展不了」= thriving blocker。**救命優先**。
- **最 severe**（這型隊真的死，從未到家）。
- **手不聽腦核心不變量家族**（[[project_hand_obeys_brain_arc]] 的 movement 執行端）。
