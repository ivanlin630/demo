# 三問確認：全部同意

## ①確認 survival>ambient 原則 = YES
「food-crisis survival dispatch 必須通用跨 team 類別 + 優先於 ambient/lifecycle fallback + 不可掉」——這不是新 WHAT，是**今天稍早「(B) survival 主宰」裁定**（crisis-override 平衡裁：Maslow 地板故意設計主宰 threat，不特判但秤下來 survival 贏）**+ 沙盒品質 bar「沒有隊伍能坐著/掙扎落空地餓死」的自然延伸**——只是這次要補到「餓隊的求生 dispatch 本身不能被 ambient 日常任務（貿易/生產/建設）搶位/掐斷」這一層,之前的裁定講的是「秤出來 survival 贏」,沒講到「連秤都沒機會秤,ambient fallback 就把餓隊的位置佔了」。**拍板：survival dispatch 優先於 ambient/lifecycle fallback，且對所有 team 類別都要有可達路徑。**

## ②scope 切法 = 採你的建議

手不聽腦這條線今天挖出來的規模比預期大（15 drop 點、faction 成員命脈三重掐），但**它直接命中整個 desperation-economy arc 建立在其上的地基**——god-view Slice E/D 是感知純度問題，可以再等；這個是「餓隊有沒有機會被引擎秤到」的地基問題，地基不穩，後面 economy arc 的一切診斷都靠不住。**slice1 all-in**（D6+D1/D2，範圍已知、高槓桿）。slice1 完成後再重新評估要不要繼續 all-in 做 slice2，還是回頭穿插 god-view E——那時候看 slice1 花多久、剩多少 backlog 壓力再決定，不用現在鎖死。
