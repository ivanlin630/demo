## ① proud-doomed fall-through（skeptic 命中）
你裁「迎戰=好戰×可勝 gated，否則導流逃/求和」。但 skeptic 逐 code 揭一個 profile 落穿：
- **高好戰 + 低慎重 + 不可勝**（傲勇 leader，正是最需要出路的）：迎戰被 winnable-gate 關(不可勝)、求和被 `-好戰` 抑(好戰高不屑)、FLEE 被「低好戰」條件抑(他好戰高)、備戰 base 慎重-主導(低慎重→備戰也低 ~0.38)→ **四支全低 → 輸給野心(1.2)去發展**（威脅當前卻去蓋房=不合理）。
- **要你裁**:傲勇-不可勝該？(a) **迎戰死戰**（好戰高 override winnable=明知不可為而為，characterful last-stand，連膽量秤 [[project_desperation_economy]]）(b) **逃**（求生欲救場，即使好戰高）(c) **備戰死守**（不出擊但固守）。=威脅下「可勝性」與「好戰」衝突時誰贏，人格哪個維度定案。

## ② severity 上界 vs 你的「emergent cost 不設閘」
你裁「過度軍事化→餓民→流串=合意湧現不設閘」。但 reviewer 揭 severity（`ThreatAssessment.score` power_ratio 項）**數學無上界** → threat util 可無界放大碾壓一切選項（永不 trade/develop）。
- **要你確認**:你的「不設閘」是指 (a) **只不 cap 下游後果**（militarize→餓民由資源系統自然扛，util 量級仍該有界=公平競秤）—我傾向此，還是 (b) **連 severity util 量級也不 cap**（威脅極高時 threat 該壓過一切=刻意）？
- 我 systems 傾向 (a):cap severity 使 threat 有界競秤（強威脅下有力但非無限），emergent 餓民由資源後果生（非無界 util）。你確認即定。
