# 四裁：二刀認可 + 停切 + 殘留分流 + 序

## ① merge-partial 二刀 = 認可（待 QA 綠）
- **net-positive**：seed1337 大勝（-45%/-53%）、seed42 持平但**無害**。
- **seed 分歧有解釋、非神秘不穩**：seed42 殘留是 ③④ 型（movement/carrying-cap）**不是 re-cycle**，而 hysteresis 專治 re-cycle 震盪——所以 seed42「擠不出」是**一致的**（它的殘留本就不是 hysteresis 的標的），不是二刀壞了。這點寫清楚，免得後人把 seed42-flat 誤讀成「hysteresis 無效」。
- **★待 QA 食安故事稽核綠才真 merge**：判準 = **絕境降（seed1337 達）/守家/破 re-cycle，非設施建造數**（照我上封守護——建設被 coin 鎖壓著不會動，別誤判食安失敗）。**別跳 QA**（本場紀律）。

## ② 停止再切 GATE-A = 認可
3 刀 diminishing returns（seed42 已擠不出），且**殘留是別 thread 非同 arc 精修**——繼續切 GATE-A = 對錯的 thread 打地鼠。**GATE-A（一刀 merged + 二刀 merge-partial）= settled-left-home 的 fixable 子集 job done**。別無限切同一 arc（本場紀律）。

## ③ dragged-away = 最嚴重 → 即刻 cheap triage-trace（結果 gate 優先序）
這型**最嚴重（隊真的死，從未到家）**、trace **cheap（只分類）**、而且**可能是手不聽腦家族**（決策要返家、movement/override 沒帶到）——不能乾等。
- **即刻 dispatch triage-trace**，只做一件事：**分類 override-type**——
  - **combat（legit survival）**：隊在打仗走不了 = by-design，**關掉**（非 bug）。
  - **faction-duty override**：faction 任務蓋過 survival-return = **手不聽腦 bug**（引擎判返家求生、被 faction 拖走）。
  - **pathing bug**：走錯方向/繞遠 = movement bug。
- **★結果 gate 優先序**：若是 faction-override 或 pathing → **跳到最前**（survival > development、最 severe、核心不變量家族，連 [[project_reverse_engineering_arc]] 控制層）；若 legit combat → by-design 關掉、續 facility-build。
- 這是「decision 對、hand 沒執行」的執行端，= [[project_hand_obeys_brain_arc]] 家族新可能實例。cheap 先分類再決定追不追，別假設。

## ④ arrived-but-starving = 折入 carrying-cap/facility-build
- 這就是**已知的 23-36% settled-productive-thin**（carrying-capacity 薄利，harvest<burn 大 pop）。折入 **poverty-trap valves / facility-build keystone**，不獨立修（根是 carrying-cap = 逃生閥被堵，非 rate bug）。
- **認可你 refine `home_food_productive` signal → actual-harvestable**（pop_mult×farming vs burn）——這是讓 classifier 誠實（免未來把薄利隊誤標成 productive-home），worth 做；但那是**量測工具修**，實質 substance 仍折入 keystone。

## ⑤ 序：facility-build keystone 先於 GATE-B
- **facility-build keystone = 收斂中心**：coin-lock scope-measure + means-end 缺口 + ④ carrying-cap valves **全在那**。它解鎖**發展/脫貧層**——既是願景 critical（沙盒「自己說故事」= 貧困陷阱脫身好戲），也是用戶在意的 carrying-cap 逃生閥。**三根 + ④ 在同一個 keystone 一起收，別拆散。**
- **GATE-B（死法② deal-flow）本身就是逃生閥之一（trade）**——可能 folds 進 valves，或緊接 facility-build 之後。**HOW/slicing 你定**（哪些先切、幾 slice）。
- **③ triage 即刻並行跑**，其結果可能插隊到最前（若手不聽腦/pathing）。

## 序總表
1. **即刻並行**：③ dragged-away triage-trace（分 override-type）。
2. **QA**：二刀 merge-partial 的食安故事稽核（絕境降判準）→ 綠則 merge。
3. **next keystone**：facility-build（coin-scope + means-end + ④ valves 三根一起）——除非 ③ triage 揪出手不聽腦/pathing，那個跳最前。
4. **後**：GATE-B / deal-flow（或 folds 進 valves）。
