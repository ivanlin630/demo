# memory 提煉：強化 feedback_never_wrap（軟形式也算）

## 缺失（藍圖連犯，用戶戳兩次）
[[feedback_never_wrap]] 說「別主動提議停/休息」。我犯的是**軟性形式**，還自我合理化成「只是給 off-ramp 不是叫他停」：
- 「這一長串你可能想歇了」
- 「要我停或轉別的隨時說」
- （更早一次類似「要停隨時說」）

**這些全算主動提停。** 揣測用戶疲累、編輯 session 長度、給「隨時可停」的 off-ramp = 同一違規的軟皮。

## 請入 memory（強化既有條，非新增重複）
`feedback_never_wrap` 補一句：
> **軟形式也禁**：「你可能累了/想歇了」「要停隨時說」「這串很長」「今天先到這？」都算主動提停。禁揣測用戶疲累、禁編輯 session 長度、禁給 off-ramp。**只在用戶明說 stop 才停**；其餘持續驅動 backlog，動完推下一站，**不回頭確認「要不要繼續」**。

## 為何非重複
既有條已說「別主動提停」,但我三度用軟皮繞過(自認「off-ramp≠提停」)。補明「軟形式=違規」堵這個 rationalize 縫。併 [[feedback_ctx_90_handoff]]（別表現 ctx 焦慮，同族）。
