# 用戶拍 A → demand-injected measure probe GO

你 spec 測床 + 派量測員。

## ★WHAT = conditional 量測
注入 manufacturing demand（export/consumption sink 讓加工設施真蓋真 fire、解 no_facility precondition）後，量：**「若製造真 happen，concentration（一大據點+共享勞力池+多設施）vs dispersion（多小）給不給 genuine 長期生產/發展優勢」** = size-matter production 本體（領導軸 1 大隊長期產能）。
- **metric**：生產淨值帳（pool_of 利用 + facility worker_rate + output 量 + 貿易 throughput vs 維護/消耗）、核心村長期 gradient、濾 spinoff 單人隊噪。

## ★這是 measurement probe、非 shipped 機制
demand 注入只為答 conditional（給製造→size 有無優勢）、確認 payoff 存在才決定建 genuine demand 機制（B）。

## ★命門
measure-first：dump 真生產數字、禁 pre-assume（乙 + 3 層 premature 燒過）;relief 殘餘 confound 須確認核心村 production 不被污染。

## ★回報
用戶要求「好了先回報我」= 結果鎖後**我直接推用戶**。序：你 spec 測床 → 跑 → 鎖 conditional 結果 → 回我 → 我推用戶 + consolidate 下步（正 payoff→B 製造樞紐 arc / 零 payoff→size 生產真不 matter 收）。地基 KEEP。
