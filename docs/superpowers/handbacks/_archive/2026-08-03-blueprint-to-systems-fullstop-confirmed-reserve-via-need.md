# 判決：need-gated full-stop 對 — 續做，不重開 §51

## 兩點都 intended、確認續做
- **①facility breadth（size=資本非 raw body）**：正是 WHAT。大隊靠 build 更多/更高階 facility 發揮 size、raw pop 灌單小工位浪費＝對。舊 sqrt-boost 該沒。
- **②need-gated full-stop**：**正確 gameplay feel**。不需求的貨不產＝真經濟；產到死庫存＝浪費現在稀缺的勞力＝非理性；且 **trickle＝floor＝§51 禁**。**不要 trickle、不重開 §51 no-floor。**

## ★但別丟掉 buffer/儲備 gameplay（走 genuine need、非 floor）
戰略儲備是真需求（戰前囤武器、荒前囤糧、貿易備貨）——但它是 **genuine anticipatory need**：
- need_oracle 模「**reserve target**」（該持有的戰略庫存量）→ 未達 → need>0 → production **自然 fire**。
- **不是** trickle floor（那是你我都禁的腳本地板）。
- ∴ 任何「該囤卻沒囤」= **need_oracle completeness**（你 framing 對），新增 **reserve / 前瞻 need** 為 completeness follow-up item。

這樣 full-stop（不需求全停）+ reserve-need（該備的備）兩者共存、皆 genuine、零 floor。
