# 量測回報：經濟長程供給診斷（食物流月曲線，3seed×12月）

工單：`2026-07-12-blueprint-to-measurer-economy-longrun-diagnosis.md`。控制config（warring_states）、3 seed（1337/42/7）、12月，新增 `food_econ` 月快照（複用既有 `TeamData.food_flow_avg`，L3純觀測擴充，`scripts/debug/warring_harness.gd`）。

## 三seed一致的三階段模式（非猜，逐月數字）
| 階段 | 月份 | 負flow隊比例 | pop 變化 | 判讀 |
|---|---|---|---|---|
| **①急性危機** | 1-3 | **~86-96%**（幾乎全隊） | 436→221(-49%) / 424→238(-44%) / 362→202(-44%) | **~45%總人口在頭3個月就沒了**——這是總attrition的大宗 |
| **②相對穩定** | 3-9 | **~40-55%**（降但仍近半） | 緩降（每月個位數%流失） | flow 圍繞0震盪（正負交替），非全面轉負，衰退趨緩但未停 |
| **③二次惡化** | 10-12 | **~76-96%**（回衝到接近①） | 再度加速下滑 | 3 seed 都在此區間出現負flow比例回衝 |

具體月10-12負flow比例：seed1337(27/28→24/25→20/25)、seed42(23/25→21/22→17/20)、seed7(26/29→24/26→14/21)——**三個 seed 都在月10附近出現二次惡化**，非個別 seed 偶然。

## 判讀（我只給趨勢形狀，不猜code層根因）
1. **非「慢慢入不敷出」的單一漸洩模式，也非單點 cliff**——是**週期性**：急性→穩定→再急性。
2. **急性危機從月1就在**，非「隨時間累積才崩」——起始狀態就有 86-96% 隊伍是負食物流，供給/需求失衡從一開始就存在，不是逐漸惡化出來的。
3. **月3-9的「穩定期」仍有 40-50% 隊伍持續負flow**——這不是健康期，是「淘汰掉最脆弱的之後，剩下的隊伍裡仍有一半在慢性透支」，只是死亡率暫時降低（可能因為最脆弱的已經死光，剩下的稍微耐打一點）。
4. **月10附近二次惡化**——三個 seed 高度一致的時間點，暗示可能有隨時間累積的結構性因素在此時點集中爆發（例如：資源磁區耗竭週期、pop 成長觸頂遇到供給天花板、某種週期性 event/季節機制），但**我不代猜是哪個機制**，這需要 code 層對照月10附近觸發了什麼。

## 待你/systems（我不裁）
- 「月1急性危機」+「月10二次惡化」這兩個時間點，是否對應到 code 裡任何已知週期性機制（季節/資源再生週期/pop成長觸頂/某 cadence 常數），值得對照查。
- 「40-50%隊伍長期負flow卻不死」——這批隊伍撐著沒死但持續透支，可能是靠 stock（存糧倉緩衝）撐住，值得查其 `total_food_stock` 是否也同步下滑（本次 snapshot 有記錄，可再細看）。
