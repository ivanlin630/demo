# 改序：框架 god-view 殲滅先於 economy（藍圖認先前漂移）

## 觸發
用戶戳：「框架還沒統一就在看合理性?」＝點出我把 **economy arc（行為/balance）排在框架零殘留綠之前**＝違「框架先，行為後」（`game-design:321`）。**我認漂移。**

## 改序裁定（藍圖 WHAT/序權）
1. **god-view 後門＝殘留非框架閘的一種**（讀真值繞過 belief＝違感知鐵律＝汙染源，同 `_threat_recent`/恆-hungry hidden-gate 家族）。清單：`has_food_market` 掃全圖（`known_issues:35`）、**創世全知 `game_setup:569-578`**、near/far LOD 非中性。→ 屬「零殘留閘」殲滅範圍＝**框架工作**。
2. **awareness/掃近隊 arc 的 belief-gate 部分＝框架，非行為** → **排 economy 前**。
3. **改序**：**framework god-view 殲滅（slice2 感知 + awareness belief-gate，含 has_food_market/創世全知）→ 零殘留閘綠（constitution_gate 強化抓全閘型跑綠）→ 才 economy balance。**
4. **硬理由（非只原則）**：`has_food_market` god-view **直接汙染 economy 決策**（隊全知所有市場位置）→ **28% doom / 貿易不流 在 god-view 髒基底上診斷不可信** → god-view 殲滅必須先於 economy 診斷。
5. **economy arc 第一動作＝補丁閘優先查**（28% doom＝殘留閘 or 真稀缺？）非先調 balance。

## ★請你做（audit owner 域）
**盤點 framework 零殘留閘的真實 scope** → 決定 economy 前到底還差多少框架工作。具體：
- `constitution_gate.gd` 現抓一閘型 → **強化抓全閘型**（硬門檻/override/continue/絕對閾/RNG 決策閘 + god-view 讀真值繞 belief）的進度/計畫。
- **exhaustive 殘留閘清單**（section A 已列 `_threat_recent`/tribute override/紮營獵食硬門檻/applicable DESPERATION 天閾/diplomatic RNG… + god-view 後門三項）→ 哪些還在、哪些已殲。
- **切幾 slice**：slice2 感知(3 違憲) 是第一塊；其餘 god-view + hidden-gate 殲滅怎麼切。
- ★注意「稽核系統性 over-count」前科（R① 三次打臉）→ 盤點時**每項先 verify 真是殘留閘再列**，別假設。

## 序現況
- slice2 感知(3 違憲) = framework god-view 殲滅第一塊，**照舊先 dispatch R²**（此改序不動它，只把它歸類為框架-first 的開頭）。
- awareness arc 其餘（掃近隊 perf-bounding vs god-view belief-gate）：**belief-gate 部分提前（框架）；純 perf-bounding 部分可仍後**（HOW 切分你定）。
- economy arc：等 god-view 殲滅乾淨 + 零殘留閘綠，且第一動作走 patch-gate-first。
