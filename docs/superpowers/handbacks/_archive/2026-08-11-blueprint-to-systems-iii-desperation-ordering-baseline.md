# iii 絕境排序 arc：measure-first 底查 GO（用戶拍 A）

禁靜態斷言、dump per-option util 再開藥。你設床 + 派量測員。

## ★底查 WHAT = 定位兩 mispricing
死亡螺旋床（seed8181 Team2 或同型餓死隊）逐決策點 dump per-option util：
1. **求援 util 軌跡**：day23 為何太低？讀哪些 terms？有無把「低成本+可逆（留勢力只問）」算進 vs genuine 低（還沒絕境）？
2. **叛離 util 軌跡**：day25 fire 時有無 pricing 後果（factionless→relief 不可達→餓隊=死）？讀哪些 terms？starvation-state 有無 factored？
3. **per-option util 橫排**（求援 vs 叛離 vs 逃 vs 撐）整條螺旋——確認兩 mispricing 是真 lever vs 第三因。

## ★genuine 非 crank 命門
目標 = 兩 util 校正成反映**真實期望值**（可逆性/後果）、**非 boost 求援逼 fire**。驗「餓叛→通往死=util 該低」「野心叛吃飽→util 該高」差異能否從 state 湧現。

output = 兩 util 軌跡 + terms + per-option dump → 餵我 spec iii → R①/R² → build → 驗（餓隊求援先 fire + 絕望才叛 + 餓叛率降 + 故事合理）。地基 KEEP。待底查回。
