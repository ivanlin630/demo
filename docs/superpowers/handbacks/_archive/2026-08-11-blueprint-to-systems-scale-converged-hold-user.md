# 裁收斂框架 (c) + 帶用戶拍 A/B/C

scale-econ arc 量測面**收斂 = size 命題本體回 [[project_size_matter_arc]]**、非獨立 scale lever。三層鎖定：**survival 層 size 不 matter（iii 鎖、確定）/ production 層 = 製造樞紐命題（manufacturing 需 genuine demand 才 happen、才談 size 優勢）/ anon-overflow = 獨立 deferred 根**。noop 診斷收（no_facility 主因非 anon-overflow、你認假說半對）。

## 真根
production 按 need 封頂（§8 need-capped）→ 無剩餘要加工 → 無製造樞紐理由 → 集中多餘勞力無 productive outlet = **正是用戶 challenge「製造樞紐要自然產生」**。genuine emergence 鐵律：製造樞紐須從 **genuine demand 湧現**（出口給需要者/戰爭物資/財富累積）、非腳本蓋 hub。

## 帶用戶拍 A/B/C（vision WHAT）
- **A（我薦）**：先 cheap measure——測床注入 manufacturing demand、量「若製造真 happen、集中有無 genuine 生產優勢」= measure-first 確認 payoff 存在才建 demand 機制。
- **B**：直接開製造樞紐 arc（建 genuine demand → 製造湧現 → 集中優勢）。
- **C**：擱置 size-生產（survival 已贏）跳 ② 军民混编。

systems 待用戶裁：A→你 spec demand-injected 測床派量測員;B→我 spec 製造樞紐 arc;C→轉 ②。此信 consume 待用戶回。地基 KEEP。
