# ★後勤統一 WHAT 定案 → 交你做 HOW

## Spec
`docs/superpowers/specs/2026-07-31-logistics-supply-movement-design.md`（用戶核可）。

## 一句話
補經濟缺的循環系統——供給能跨距離移動到需要的地方。三層各有用、誰不取代誰。

## 骨架
- **① 後勤（transport）**：運自己的供給跨距離。**誰搬=腳夫子隊（複用子隊 dispatch + 載重模型，不發明新實體）**；**誰派=供需雙方、動機不對稱**（需方拉最穩/供方推看理由，**領主推=分配政策**）、誰派誰出成本；**劫掠延後**。糧橋=現成零件。
- **② 分配政策**：領主拿到供給後怎麼給居民——**人格 WEIGH（施捨↔剝削），非自動福利**；餵現有 unrest/defection。「補給到什麼程度」由此決定。
- **③ 貿易**：換外面的（自己沒有的）+ **逃離內部剝削**（外部價<內部→外買=對剝削的制衡）。修 GATE-B trade-trip under-fire。

## HOW/R② 給你
- **★大 arc、真新元件（非接線）**——§6 誠實標，記取 means-end 樂觀低估教訓（R① 兩次接住）。transport 系統/分配政策/GATE-B 修皆真工。**大框你要升異質 R① 框外審自便。**
- **premises 全 file:line 驗**（§8：公庫 auto-tax/tile-local、_deduct_cost、levy=coin、detach、trade-trip funnel）→ R① 覆核非重 factcheck。
- **★第一驗收（這 session 的鬼）**：決策生成 ≠ 真執行。**「派 convoy」決策只要輸 argmax 就是死的**——硬驗 convoy 真派、真到、供給真到手（同 trade-trip under-fire/founding-preempt 家族）。
- **徵收（levy, coin）別碰**（另議、別跟材料流混——用戶定）。**公庫/生產不動**（好的）。
- 憲法：後勤派/分配給多貴/貿易去換皆 util 秤、人格 weigh 非 gate、全接 tap。

## 序（slice）
1. **SLICE A — 後勤 transport 地基**（最缺、統一散件）：convoy 物件 + 供需雙方「派」決策（**真 fire**）+ 供給真到手。折入糧橋/auto-withdraw/provision-carry/harvest-carry 散件為零件。**先驗 convoy 真派真到。**
2. **SLICE B — 分配政策**（領主人格→施捨/剝削 + unrest 耦合 + 內部定價）。
3. **SLICE C — 貿易**（修 GATE-B trade-trip under-fire + 逃剝削動機）。**GATE-B 從「補丁 trade-trip」升級併入此 arc 當 SLICE C。**

## 不變
runway A/B1 banked、持守 RELEASED 不動、material 舊 PARK 溶入此 arc（founding-viability 那條其實是「供給移動」的一環）。
