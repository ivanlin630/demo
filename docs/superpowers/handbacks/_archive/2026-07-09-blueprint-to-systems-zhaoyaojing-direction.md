# 照妖鏡方向：死常數人格化（並行 workstream）

絕境經濟設計 session 結論：**死常數消失＝矩陣完成的另一半**（統一暴露常數、照妖鏡溶常數）。照妖鏡躺 backlog（game-design line 204），這輪證它**產湧現**（匪/絕境戲/勇怯差異）。**開成並行 workstream，配 A2c-2 統一 arc 兩腿走。**

## 願景（藍圖 owner）
- **decision-side 死常數 → 溶進人格/記憶/現況**（三個家第一家）。**不是刪數字，是換家**：平頭常數 → per-agent 人格驅動。
- **憲法一致**：同一門檻由人格調製（勇者晚逃/怯者早逃＝同 margin 由膽量調），非全域壓平。
- **每刀＝一個可證的湧現**：溶一個常數 → 該行為出現人格差異（照妖鏡照出個體）。

## 首刀＝你選（seam/選常數自決），建議準則
1. **孤立**：不跟未解 arc 糾纏（例：掠奪門檻 `LOOT_SCORE_THRESHOLD` 雖誘人但**卡在 weakness=0-if-armed + 三閘軍事化死鎖**，單溶它不出匪 → 非好首刀，等三閘）。
2. **清人格湧現**：溶完立刻看得到個體差異。
3. **可量**：有探針或易加，full_probe 對照證「人格差異出現」。

**候選（game-design line 204 backlog）**：
- **combat 潰退門檻 `0.2` → 士氣/膽量**（勇者血戰、怯者先逃）——孤立✓、湧現清✓（同戰局不同結局）、可量（潰退率 by 膽量）。**我傾這把當首刀**：最乾淨、不卡 arc、戲感直觀。
- `PREEMPT_MARGIN=2.0` → 謹慎度（膽小早搶先手）
- VENDETTA 常數 → 記仇性（睚眥必報 vs 寬宏）
- （掠奪門檻 → 貪婪：**留三閘軍事化解鎖後**，那時一溶就出職業匪）

## 交付/驗收（新模型）

- **無斷點自動鏈**：spec 完直接推下游，別 park。
