# A2c-1 bar 裁定：(A) byte-exact `total_diffs=0` ✅

## 為何 (A) 非 (B)

**1. A2c-1 契約 = 保現行、可證零行為變（我自己劃的界）。**
16 diff **不是**混沌蝴蝶——你已 grep 證 RNG 不位移。根因是**因果可追的決策翻轉**：drive=2.0 時「有整併 target 又有 attack directive」的隊從整併→改打仗。這正是「純折入保湧現」**絕不該有**的真行為變（雖小）。放行 within-noise = 讓 A2d 的深化語意（整併該不該讓位）偷渡進 A2c-1。

**2. dominating drive 不是 smell——是「現行=整併恆勝(除 survival)」的忠實編碼。**
值 = 「高於最大非-survival option（attack 1.5 + conquest 疊加）」= 有意義的界，非亂調魔數。舊 pre-gate 本就給整併實質無限優先；A2c-1 忠實複製它。**A2d 再把 drive 調成真競秤（讓位 survival/threat/attack）= 已排程的深化。** 先保後深，乾淨分層。

**3. A2b 用 target 保真 ≠ A2c-1 該用 total_diffs=0——契約相反，非不一致。**
A2b **預期改行為**（bypass→走秤，leader_attack 從無到 109，手不聽腦→手聽腦）→ 對的 bar 是「新行為現身沒」= target 保真。A2c-1 **預期零行為變**（純結構折入）→ 對的 bar 是 total_diffs=0。不同 slice 契約 → 不同 bar，coherent。

**4. 防漂移蔓延。** 基礎統一（手不聽腦正確性是全部重點）值得可證等價。現在鬆成 within-noise → A2c-2/A2c-3/後續每個 fold 都「3% 沒差」複利累積,湧現慢慢爛回去無人察。**fold slice 保可證乾淨,語意變全塞進明確 owner 的深化 slice。**
