# R①覆核 + 升異質框外驗規模：糧流感知

糧流感知 WHAT 定案+用戶核可（`docs/superpowers/specs/2026-07-29-runway-aware-persistence-survival-design.md`）。premises §8 全 file:line 驗過（blueprint）→ **覆核非重 factcheck**；但大框升異質框外驗規模（★means-end R① 我 orientation「非新引擎」樂觀低估被異質駁血證——這次「多為接線」同款要驗）。

## 設計大框
- **一個糧流感官**（每隊 `net=inflow−burn`、`runway`、每日算快取、★inflow 內生-only 外生不預測）。
- **三消費者共用**：①存活持守（safe_ratio×人格餘裕=team14 nuance 根治）②派遣配糧（糧橋+載重=解 A1 子隊餓死 viability，立國極端）③在家前瞻（餵 maintain_food goal）。
- blueprint 稱「多為現有零件接線」（burn/載重/persist_strength/maintain_food 現成）。

## ★reviewer focus（覆核 + 升異質規模，明確 refute）
1. **premises §8 覆核**（抽驗 file:line）：persist_strength:44-47 只讀 sunk+人格不讀糧？task_arbiter:64-70 hold 純優先權閘？resource_system:57-61 無據點只打獵？movement:137-140 載重現成？goal_registry:16-40 maintain_food 現成？subteam:36-42 母隊補給只出發一次性？——驗過的抽幾條確認沒 stale。
2. **★★規模斷言「多為現有零件接線」真否**（means-end 血證：別樂觀低估）：一個糧流感官 + 三消費者 + 糧橋 + go/no-go + safe_ratio×人格餘裕——**真是接線現成零件、還是又一個新子系統偽裝成接線**？哪些是真接線（讀現成值）、哪些其實要新建（新機制/新狀態/新迴圈）？糧橋（配糧+半路重算+撤退）像接線還是新 build？
3. **內生-only inflow 定義**：inflow 只算內生（自產/打獵/地形回補）、外生排除——這定義乾淨否？「內生 vs 外生」邊界有沒有 case 模糊（貿易買糧算哪個）？
4. **三消費者真共用一個感官否**：safe_ratio（存活）/糧橋（派遣）/前瞻（在家）真讀同一 net/runway、還是各自要不同計算？

## 判準
- premise_contradiction（premises stale 或規模斷言「接線」不成立=其實新子系統）→ halt 回 blueprint 調 WHAT。
- CLEAN（premises 確認 + 規模誠實=真接線）→ 我進 HOW 架構 spec。
- ★用異質模型 + 明確 refute（means-end 樂觀低估血證，這次規模當真驗）。
