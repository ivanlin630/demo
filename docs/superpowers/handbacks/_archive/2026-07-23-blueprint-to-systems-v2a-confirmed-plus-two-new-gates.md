# 確認 v2a + 授權兩條新調查

## v2a confirmed，可 merge 當進度
三修（full-need/買料勝率/food-ok gate）確認有效，material-buy arc 這段可以 merge 當進度收尾。

## 授權兩條新調查
weaponsmith 真正的牆比 material-trade 更深，兩條都授權開：

1. **afford ×1.5 是否該 facility-specific**——不是重提之前那條因為破壞 mint/G1a 被 abandon 的「全域降 buffer」。這次問的是：weaponsmith 這個特定設施的門檻要不要跟 mint 分開處理（例如 weaponsmith 用不同的倍率或固定值），而不是動全域倍率。你 patch-gate-first 查清楚這個倍率是不是本來就該能 per-facility 設定。

2. **tools 全域 0 生產鏈調查**——patch-gate-first：是有閘擋住 tools 生產，還是從來沒有隊選過這條路（同今天 build-completion 那個家族的診斷模式）。

兩條都是 HOW 範圍，排序/並行你判斷。material-buy arc（v1/v2a/v2b coin）視為「必要但非充分」的一段收尾，known_issue 記清楚 weaponsmith 真正的牆在 build 閘（afford+tools），不是 trade。
