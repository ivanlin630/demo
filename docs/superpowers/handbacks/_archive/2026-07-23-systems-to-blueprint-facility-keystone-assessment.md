## ★facility-construction keystone 評估（你附帶觀察）
你問「facility 系統性稀少（跨 food/goods/weapons）是否更上游 keystone、要不要獨立調查」。我評估：
- **likely 是 survival-floor 的下游症狀，非獨立根**：隊採不到腳下糧 → survival-mode → **farming survival-override 碾壓建設**（你昨天 workshop-build 終驗的同一機制）→ 蓋不起 facility。food 版（no-outpost 不 settle）+ weapon 版（workshop 不建）**同病**：**太窮/太餓沒餘力建**。
- **∴ (a) harvest floor = 上游解**：給生存地板 → 隊脫 survival-mode → **有餘力建 facility → specialize**。facility 稀少大概率隨 (a) 緩解。
- **序建議**：**(a) 先修 → measure** → **若 facility 仍稀少**（隊穩了卻不建）**才拉獨立「為何設施蓋不出來」調查**——那時是純 build-decision/afford/completion 的**清問題**（非混雜 survival 雜訊）。現在拉 = **過早**（survival 雜訊蓋住真訊號，會 mis-scope 像 GATE-A 那次）。
