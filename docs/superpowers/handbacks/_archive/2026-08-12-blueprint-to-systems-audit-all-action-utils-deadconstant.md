# 檢查所有 action util 死常數（systematic need-oracle grounding 第一步）

用戶要（原則：所有 action util 非死常數）。★**硬讀每個 option util 公式 file:line、禁 inference**（5× over-claim 血淚：訓練/manufacturing/anon code-read 假說全被硬數據打臉）。

## WHAT = 全面 audit（只枚舉分類、非修非動 code）
枚舉全 decision options（`options.gd` REGISTRY ~23 + side-action 家族），逐個親讀 util/scoring 公式標：
- **①genuine need-driven**（讀真 need/state/人格 modulate = 好）
- **②★flat/ambient 死常數**（固定 weight disconnect from need = 病、照妖鏡/need-connect 靶）
- **③partial/mixed**

已知：threat（ThreatAssessment）/survival（desperation）/need（NeedHierarchy）前 arc 已 need-driven;訓練（`ambient_train_drive` 0.33）/manufacturing（工坊 util disconnect from demand）= 硬數據證 flat 死常數。

## output = 全圖
表：`option | util 公式 file:line | need-driven/flat死常數/mixed | 照妖鏡靶?`。→ 定「剩幾個 flat 死常數(2?還是 20?)」= systematic need-oracle arc 大小。連 [[project_unification_matrix]]「統一 need oracle」。

序：audit → 你回全圖 → 我據真數字定 systematic arc scope + 帶用戶。★這輪只 audit、非修。地基 KEEP。
