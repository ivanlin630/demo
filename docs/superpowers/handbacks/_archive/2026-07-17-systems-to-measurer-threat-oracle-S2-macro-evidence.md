# evidence 產：threat-oracle S2 macro 批的 3 證據（blueprint HOLD）

blueprint 不批也不退（要證據判 feel），我給的證據不足。你產這 3 個，我轉 blueprint：

## ① 絕對迎戰率 %（非倍數）
- **現 main（`3a429632`，S1/S1.5 但無 S2）vs S2-calibrate（`e3d34ffc`）**，同 seed（1337/42/4201）×2mo。
- 出 **decision 中迎戰(engage) 佔比 %**（迎戰 dispatch / 總 threat-eligible decision 或 / 總 dispatch，你定分母說清楚）——改前 X% → 改後 Y%。31x 倍數判不了 feel，要絕對 baseline+delta。
- 順帶備戰/求和/FLEE 絕對率（threat repertoire 全貌，看分流不只迎戰）。

## ② 2-3 specimen trace 證人格分流落地（★補裁①核心）
- **聚合迎戰↑ ≠ 分流對**——要證「對的人格迎戰、對的人格避」。挑 2-3 具名 leader specimen（SpecimenTracer/決策 trace），跨象限：
  - **proud-doomed**（好戰高·慎重低·不可勝 winnable 低）→ trace 證選**迎戰**（死戰 last-stand，modulate_win override）。
  - **cautious-hawk**（好戰高·慎重高·不可勝）→ trace 證選**備戰/求和**（避不可勝，respect winnable）。
  - （可加 coward→逃 / pragmatic→求和 補全四象限）。
- trace 要顯 leader 人格值 + winnable + severity + 各 threat option util + 最終選中——證分流機制在真 organic 決策生效，非只 char bed 窄構造。

## ③ economy delta vs 現 main（基準修正）
- **別比「calibrate 前 seed1337 全滅」（那是壞版低 bar）——比現 main（`3a429632`）**。
- S2-calibrate vs 現 main 同 seed：**trade 量 / build_outpost / farm_pos / merge / rung 爬升掉多少 %**。blueprint 要知「相對正常世界，threat-oracle 讓經濟縮多少」判可接受否。

## 流向
3 證據 → 我轉 blueprint 判 macro feel → 批則 merge S2 / 要調則再 calibrate。**非改 tune**（blueprint 明講要證據非 tune 變更）。同 seed 同你既有 organic 床，加 specimen trace + 絕對率 + 對現 main 基準。
