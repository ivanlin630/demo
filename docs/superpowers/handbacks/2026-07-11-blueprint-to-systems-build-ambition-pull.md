# 藍圖批准：建強方擴張 pull

認可你的自糾（「世界抗拒」premature，只測雙向的弱方那半）。批准建強方 pull——**這是補完 design §合併=雙向 早就定的另一向,非新 scope,非新願景 fork**。出 spec。

## WHAT 守則
1. **擴張-class 非 survival**：強方 pull @PRIO_DISPATCH（同 攻擊/佔村），野心×統領餘裕×有可吸弱鄰驅動。**別 collapse 進 survival**——這正是它避開絕境時間死結的關鍵(強隊有餘裕自己行軍去吸)。
2. **複用統一併入分流 + 忠誠 init**：強隊吸弱鄰的結果照樣走 dissolve/子隊(依人數/好感/凝聚)+ set 新人起始忠誠。**強吸弱常=低好感 → 弱鄰變子隊帶怨 → S-B 叛離燃料**(天然接上)。
3. **公平競秤,不硬保**：強方 pull 跟 攻擊/佔村/貿易 同層競——軍閥可能寧可**征服**而非吸納,那也合理。別給它 rank 硬優勢湊 volume(重蹈 flat 病)。measure 哪個湧現。
4. **防 mega-blob**：野心軍閥滾雪球別滾成吞掉全世界一坨。隊數/多樣性守(同既有守則)。
5. **S-A/S-B 切分**：強方**主動吸納 + 弱方自願/默許接受** = S-A(補雙向)。**顯性脅迫**(最後通牒、拒則攻)= S-B。S-A 只做「強隊發起、弱鄰接受」的併,coercive teeth 留 S-B。

## measure-first（守你自己的紀律，別重蹈斷言）
- 建強方 pull → measurer 量它的 **dispatch + completion**(強隊真去 rank 它嗎?vs 攻擊/佔村?吸成了嗎?)。
- **強方 pull 有量** → consolidation 活、有機政體交付 → 我 signoff。
- **強方 pull 也 marginal** → **那才是真結構結論**(雙向都試過)→ 屆時才升 user a/b/c。
