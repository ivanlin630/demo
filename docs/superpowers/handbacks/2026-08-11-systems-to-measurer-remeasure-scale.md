## ★WHAT 三段
1. ★★**confound-clear 首驗**：死亡螺旋源頭斷後（iii：餓隊求援先於叛離+找生路 merge/獨立），dispersed 隊**不再 defect-to-death artifact 是否從 scale 訊號消失**？對比原底查（attrition 20.8% seed8181 / 跨 seed 不一致 / propagation 死角 Team2 死）vs now（iii 後 attrition 8.3%、Team2 併入 Team3 撐住）：分散慘還是 artifact 還是清了？**3seed determinism + 跨 seed 一致否**。
2. **若 confound 清 → 真淨值帳（大 vs 小）**：好處側（LaborSystem.pool_of/facility worker_rate 集中勞力池 + convoy 趟省 + 貿易 throughput）vs 成本側（維護/消耗/運輸摩擦 convoy porter-days）、**淨值 gradient 哪平或負** + 前 **3 size-blind 機制**（transport-util-blind / cohesion-distance-blind / relief-gap[iii 已治部分]）哪個 genuine 當分散代價 lever。
3. ★**誠實分清（關鍵）**：scale 訊號是否仍被 **execution-layer relief 殘餘 confound**（anon-cohort 2c-2 care-loop dormant 仍 deferred=領主 proactive 救援仍 anon-blocked；若 dispersed 存活靠 iii-merge/獨立而非 relief 到達→scale 訊號可能仍受救援執行殘餘影響）vs **真乾淨可量分散代價**。
