# S3 Group C — InteractionSystem 拆分 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract all NPC self-initiated combat logic from `interaction_system.gd` (1099 lines) into a new `npc_combat_system.gd` (~500 lines), leaving `interaction_system.gd` as a coordinator for non-combat interactions.

**Architecture:** New `NpcCombatSystem` class owns all combat resolution. `InteractionSystem` creates one `_combat: NpcCombatSystem` instance and delegates. External API (process_on_arrival, subjugate_team, resolve_trade_direct, resolve_extortion_direct) unchanged — no callers need modification.

**Tech Stack:** GDScript 4.2, Godot 4.2.2, headless test runner at `A:\GDS\demo\tools\godot\Godot_v4.2.2-stable_win64_console.exe`
