# 裁定：脊椎量測 3 問（回應 spine-measurement + 2yr-measurement）

量測漂亮，measure-first 生效。核心判讀：**世界沒壓力 → 沒戲 → 魂不長**。先講這條，它串起三問。

## #1 G1 訂單閉環 + 囤積壓力 → 兩個都 YES，且這是 root

**(a) 履約該真發生。** G1 spec §4 的「撲空」是**例外**（趕到太遲被搶單），**不是常態**。常態 = 買單吸引賣方/商隊 → 送達 → **成交扣量**。0% 履約 = G1d 履約 task 沒接（trade 不認 order）→ 接上閉環。

**(b) 囤積要有壓力 = YES（腐壞/儲限）。** 食物無限囤 = 不擬真 + **沒稀缺 → 沒人急買賣 → 訂單沒人接**。加食物腐壞或儲存上限 → 稀缺 → 經濟有動力。守恆安全（食物本就是消耗品、非 coin，不破 coin_eq）。

**關鍵：這是「世界沒壓力」的 root。** 無限食物 + 經濟空轉 = 世界 placid = 沒戲 = 魂不長（#3 的 6 條全 0）。**#1 升為最高優先**——不只修 order loop，是給世界裝上稀缺壓力。修完很可能連帶讓世界自己開始有衝突/野心/血仇。

## #2 識破：多數被騙＝對，但「0 裁決 ever」過頭 → 修技能 spread，不修門檻

- **信假主導 = 正確**（亂世多數人就是會被騙）。**別動 DETECT 門檻**——降了變人人識破，破「多數被騙」。
- 但 **0 裁決 EVER = 過頭**：代表沒一個 NPC 夠精明 → 識破機制是死的、也不擬真（總有老謀深算的人）。
- **修法 = 世界生成要有「高感知尾巴」**：種一些高偵查/計謀 NPC（謀士、精幹斥候）。目標 feel：**裁決罕見但非零**——精明的少數抓到多數人吞下的謊。
- payoff moment：精明謀士識破全隊都信的假軍情。

## #3 觸發場景：YES，但先修 #1 再量

- **YES 建驗證場景**（de-risk 6 條魂的碼真會 fire）——必要 QA，world_sim 台已現成。
- **但別把場景當目的。** 目的 = 預設世界**自己**長出血仇/立國/scout。2 年全 0 的 root 很可能就是 #1（無壓力 placid 世界）。
- **序：先修 #1 壓力 → 重量預設世界 → 魂若自己冒出來，場景只需驗 edge；若仍 0，才是門檻太嚴，調。**
- 各場景成功判準（WHAT，待真要做時細化）：
  - **偽裝誘殺**：偽裝弱目標（假情報）誘莽攻擊者入陷 → 驗 不確定攻擊 + 誘殺 fire。
  - **預置血仇**：種一樁殺戮 → 驗 feud 邊成形 + vendetta 追殺 fire。
  - **立國競逐**：資源 + 野心 leader + 空間 → 驗 階梯爬到立國。
  - **鑄幣經濟**：faction + 金礦 + 鑄幣廠 → 驗 採礦 + 鑄幣 fire（W8）。

## 修訂（2026-06-20，用戶質疑「沒壓力野心也該驅動擴張」→ 追 world-gen 找到更根本真因）

用戶戳破：野心階梯靠野心爬不靠飢餓，立國 0 光「沒壓力」解釋不了。追 `person_generator.gd`：

**真因 = 世界沒有極端值（人人平庸）。**
- `p.values[v] = randf_range(0.2, 0.8)` → **無一人** 野心>0.8 / 殘忍>0.8 / 計謀>0.8。
- `skills base = randf_range(0.0, 0.3)` → 人人起始無能。
- 預設量測走 `PersonGenerator.generate`（程序化）→ 整個世界都是平庸人。

→ **沒 outlier = 沒戲**：
- 沒 0.9 野心霸主 → 沒人爬到立國（**立國 0 真因，非食物**）。
- 沒 0.9 殘忍屠夫 → 沒暴行 → 沒血仇（feud 0）。
- 沒 0.9 計謀謀士 + skills 鎖 0.3 → 沒人識破（**裁決 0 = #2 真因**）。
- 中庸壓縮 + 複合門檻（好戰>0.7 AND 野心>0.6，且兩值 ≤0.8）→ 戲劇行為極難跨閾。

### 重排優先（**新 #0 取代原 #2 窄修**）

**新 #0（最高）：world-gen 要有戲劇性尾巴。**
- values 不該 uniform [0.2,0.8]；要**極端尾巴**——多數平庸，但**少數極端**（0.9+ 霸主/屠夫/天才、0.1 懦夫）= 驅動戲劇的記憶點。
- skills：leader + 一條尾巴要**高起點**（宿將/老謀斥候），非全鎖 0.3。
- feel：**世界 = 多數凡人 + 關鍵少數狂人，狂人驅動立國/血仇/陰謀。**
- generalize 原 #2 → 不只感知，是 野心/殘忍/好戰/計謀/慎重 全要尾巴。
- 分佈形狀（80% 窄 + 20% 全幅？顯式極端 roll？）= 你 HOW。

**#1 經濟（履約+腐壞）** 仍有效，屬「經濟空轉」軸，**非戲劇魂的根**。與 #0 並行。

**次要：地圖尺寸。** radius 4=61 格容不下帝國弧；即使有狂人，61 格塞 8 隊難鋪大局。考慮放大（你評估），但**分佈 > 地圖**。

### 修訂後總序
**#0 分佈尾巴（戲劇魂的根）> #1 經濟閉環+壓力（空轉根，並行）> 地圖尺寸（scale）。** 改完 #0 重量，很可能立國/血仇/識破一起冒——比食物壓力更直接解 #3。修完 #1 重量預設世界，數據會說 #3 還要不要場景。
