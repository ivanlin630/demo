# (a) fix 裁定 — gen 劇本 vs ongoing 誠實，兩分

回你 a-rootcause。真因（leader 太弱、measure 出非猜）採信。但**修正我會錯意的方向**——用戶走查切出關鍵兩分。

## 修正：不是「faction leader 一律偏強生成」
我先前傾 #1（領袖偏強生成）= 盲目。那會連 **ongoing 湧現的領袖也 buff → 作弊選擇**。正解切兩種情況：

### ① 起始（劇本擺放）— authored，特殊池 OK
依劇本放幾個實力派系，從**領袖池/特殊池**拿強人 = 沒問題。這是 authored premise（佈局戲種子，倖存者偏差寫進劇本前提）。戰國 seed bed 變體即此。

### ② ongoing（世界自己跑）— 誠實階級池，**不 buff**
人才**從哪階級出來就從哪階級池拿**，帶其**真實 rolled traits**。農民崛起立國 = 農民池那個人、靠他真有的野心+統領爬上來（**真選擇**），**不是因為當了領袖就給強數值**（生成 fiat 作弊）。
- 立國 gate 本就 attribute-based（統領/野心），其他 component（readiness/member）已過 → **誰夠格誰爬上去 = 已是誠實選擇**。ongoing 不需改機制、不需 buff。

## ★★ 攀爬動力才是核心（修正：稀有度旋鈕在攀爬壞時無用）
**池裡有能人但爬不上去 = 一樣龜縮。** 攀爬動力（能人從底層升到立國/征服的鏈）若壞，調屬性分佈也沒東西可調。所以 (a) 主體 = **攀爬動力**，非 gen/分佈。

攀爬鏈每段要通（**假說，待 measure 證**）：
- **累積 > 損耗**：招人/攢資源/威望快過停滯+死亡。feud churn（teams 101→31）可能把爬到一半的人先殺了。
- **每階有可走轉換**：生存→積累→擴張→立國→稱霸，某階轉換缺/太硬 → climb 卡那。
- **跑途中能新立派系**：強隊長能不能自己 founder 新派系？若派系只 gen 固定 → ongoing 無頂階可爬。
- **活得夠久爬完**：太暴力世界爬者死路上。

**measure-first 找卡點（別猜）**：instrument 一個高野心/統領個體的一生，看**爬到哪階卡住**（累積太慢/rung 轉換缺/途中被殺/founder 不了）。卡點量出來才知修哪。

## 稀有度 = 屬性分佈旋鈕（攀爬通了之後才有意義）
征服者多寡 = 調 dramatic-distribution 尾巴。但**這是攀爬動力修通後**的頻率微調，seed 量「CONQUER 0→小正、不 over-war」。攀爬沒通前，這旋鈕無效。

## ★ 升原則（請納 invariants/game-design family）
**凡位置必有可解釋的上位路徑**——位置持有者（faction leader / established ruler / named commander）的 traits 必須**靠真選擇掙來、可解釋**，非生成 fiat 欽定。= 選擇域的「無憑空」，與「凡意圖必有驅動 / 凡 belief 必有 provenance」同 family。
- 例外：**起始劇本擺放**是 authored premise，明示豁免（不是憑空，是設計者佈局）。

## (a) fix = 三件（按重排序）
1. **★ 攀爬動力（核心）**：measure-first instrument 能人一生 → 找攀爬卡點 → 修那段。讓能人從底層真能升上去（誠實階級池、不 buff）。**這是 (a) 主體、沙盒 bar 真戲源。**
2. **gen-time**：起始劇本/seed 從領袖池擺強派系（priming，次要）。
3. **稀有度**：調屬性分佈尾巴，seed 驗 CONQUER 0→小正、不 over-war（**攀爬通後才微調**）。

## 待系統
**先 measure 攀爬卡點**（能人一生 instrument，找哪階卡：累積/rung 轉換/途中死/founder 不了）→ 回報 → 據卡點開 (a) fix spec。**別跳過 measure 直接修**（leader 弱那次 measure-first 就對了，這次同樣別猜）。
- ① gen 劇本特殊池 OK（priming，可先做）。
- ② ongoing 誠實階級池**不 buff**——攀爬動力修的是「能人爬得上去」，非「給領袖塞強數值」。
- 升原則：凡位置必有可解釋上位路徑（起始劇本豁免）。
