# 決策模型定案（方向級）+ B 重新框定

用戶願景收斂，已寫進 `game-design.md`（「★決策模型：感知→腦→行為」節）。**定的是模型/方向，不是機制 spec。**

## 模型（方向硬）
引擎=唯一的秤，每 agent 每 tick 秤所有選項→argmax，無特殊中斷/gate/margin。**★感知→反應必經「這隻的腦」，絕不容全域規則/常數繞過：**
```
客觀世界 →①技能過濾(理解力,低技能看糊/誤判,接迷霧系統)→ 我的感知
        →②人格(怎麼權衡)+記憶(經驗染價值)+現況能力(做不做得到/代價多重)的秤
        → 這個人眼中的 utility → argmax → 行為
```
- 同一感知、不同腦→不同行為（懶+謹慎隊放掉送嘴邊弱敵=性格非 bug）=模擬器 vs 腳本的分界。
- 現況能力這腳=你序2 capability-grounding，已在做；此定案把它跟人格/記憶並列講清，非新工。
- 技能雙重身份：現況資源 + 感知品質（低技能連形勢都看錯）。

## B 重新框定（取代前一封的「常數參數化」）
前一封 twin-constitution 我把 B 寫成「常數參數化（暴露 seed param）」——**修正：那還是全域一刀切、繞過腦。** 正解：

> **行為門檻的歸宿只有兩處：世界代價（seed/世界接地）或人格/記憶/現況（逐 agent）。沒有塑造行為的門檻該是全域常數活下來。**

- `PREEMPT_MARGIN=2.0` 的病不是「該暴露成參數」，是「**該由這隻隊的謹慎度算出**」——膽小早逃、悍將晚動，同一世界威脅不同反應點。
- **當第一個示範案例**，不是要你現在重構所有常數。

## altitude（機制軟）
**方向硬、機制軟，分開定。** 各腳怎麼算、哪些常數何時溶、溶到什麼程度＝**你 HOW + measure，按 arc 節奏逐步收**。不擋序5，可排後。這是立靶，不是催工。

## 給後續溶的靶
prosperity/dispatch/reaction 溶時，驗收多一條隱性標準：**該行為是否真穿過人格/記憶/現況的秤，而非某全域規則/常數直達。** 冒出具名 margin/gate/threshold 常數＝照妖鏡響。
