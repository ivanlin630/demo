# TC7 裁定（覆蓋前版）— 不加角色硬 gate

回你 tc7-role-correctness。**裁定改了**：藍圖不要硬 gate。下面是新裁定 + 1 個要你確認的點。

## 核心裁定：角色 = 權重輸入，不是硬 gate
角色**不該 pre-filter option 集**。商隊 leader 桌上**仍有**建設/治理，只是分數低——沒材料、離領土遠、leader 商人人格 → 軟壓低。**能蓋但很少蓋**，軟壓力非硬牆。

理由：硬 gate 是 pre-filter，違背統一框架 arc 精神（萬物 fold 成決策輸入、讓它湧現）。角色該是 DecisionEngine 的一個 weigh-down 輸入，不是引擎前的閘。

## 連帶解掉的（這刀順手的）
1. **TC7 原樣復活**：商隊 3 leader（霸主→建設 / 隱士→駐守 / 商人→貿易）又能分歧，因建設回桌。**不改隊型、不要 TC7b（撤回我上版的 TC7b）**。
2. **野心階梯問題湧現解**：霸主商隊夠富夠野心 → 建設分數爬過 → 蓋城 → 自己變定居勢力。角色轉換**湧現**，不用機制（前版標記的問題自然消解）。
3. specialization 改靠人格+情境軟分歧，非 label 硬鎖。

## 要你確認的 1 點（HOW，可能呈報）
角色正確化（含 gate）是你做**商隊餓死修**時 bundle 的。請判：
- **gate 是餓死修 load-bearing，還是順手的獨立 correctness？**
  - 獨立 → 拔掉乾淨，餓死修照走、商隊 option 集恢復全集（含定居 option，靠權重壓低）。
  - load-bearing（如：不 gate 商隊永遠選不到貿易/餓死修失效）→ **呈報成本與機制細節，喬**。

## believability 守則（拔 gate 後系統量測看這條）
specialization 不可崩成 mush（每隊啥都做一點 = 沒特色）。標準：
- 商隊**多數時候**仍貿易（人格+情境壓低其他），只是**不被硬禁**。
- 即：軟分歧要夠強到「看起來像商隊」，但弱到「富裕霸主商隊終會破框蓋城」。
- TC7 即守這條（同隊 3 人格 → 3 option，證軟權重有效分歧）。

## 結論
撤回上版（TC7b/定居隊換型/gate 確認）。新向 = 不加硬 gate、角色當權重輸入、TC7 原樣。先確認 gate 是否 load-bearing，再併 plan。卡此一確認。
