# 他域協調裁定（解鎖一大串）

回你 otherdomain-coordination + arc-progress。藍圖拍板，3 點。

## 1. 協調模型 = 混合
和戰大事頂層強制、日常個體傾向。**分界原則**：

- **頂層協同**（faction_duty term 權重高、壓人格）= **影響派系整體存續/版圖的大決定**：
  - 主動開戰/攻擊、立國、結盟與外交締約、大規模徵收/動員。
  - faction goal 對成員強制性高 → 協同行動（派系像有組織勢力）。
- **個體傾向**（faction goal = 弱 term，leader 人格 weigh）= **隊自身日常運作**：
  - 巡市集/貿易、scout、日常小掠奪、就地求生、小徵收。
  - 各隊照 leader 人格走，不需派系命令。

口訣：**stakes-to-faction → 頂層；team 日常 op → 個體。**

## 2. believability 守則（混合內，別讓頂層強制洗平人格）
- **頂層決 WHETHER，人格染 HOW**：即使大事頂層強制，leader 人格仍上色執行——好戰 leader 的派系打**激進**仗、慎重 leader 的派系打**保守**仗。協同 ≠ 同質。
- **脫軌逃閥保留**（連 G2 私驅動脫軌縫）：faction_duty 權重高**但非無限**。極低忠誠 + 高野心成員，大事上仍能**破framework脫離/叛變**（= 分裂/叛變戲劇）。頂層強制不是 100% 服從。這是 believability，別焊死。

## 3. 主動開戰 feel = 稀有 + 蓄意 + 吃 belief
- 主動擴張開戰**稀有**：保留 readiness/強度門檻。驅動 = 野心 × 機會 × 低風險。
- 決策在**派系頂層 leader**（霸主），**蓄意**——非每隊噪音。一旦決定，faction_duty 拉成員協同（接 #1 頂層）。
- **吃 belief 非真相**（連 G3 情報 + 玩家錨 C）：leader 按他**以為**的敵方強度開戰 → 誤判打了更強的 = believable 戲劇。
- feel 目標：多數派系多數時候**不**主動攻擊（守成/成長/貿易）；稱霸野心 + 強派系 + 弱鄰 = **征服者故事**。戲劇尾巴，非 noise。

## 4. mint：現在排 G1a（覆蓋我前判的「緩做」）
藍圖決定**現在排 G1a**（金礦 tile 生成 + AI 建鑄幣廠決策路徑），讓 S5 mint 魂在 default 世界真活，非永休眠。理由：specie/貨幣脈絡對玩家經濟魂有價值，值得讓它自然 fire。
- 建廠決策走統一引擎（option，非硬腳本）。
- 優先序：可排在他域連鎖內/平行，你判 HOW 序。
