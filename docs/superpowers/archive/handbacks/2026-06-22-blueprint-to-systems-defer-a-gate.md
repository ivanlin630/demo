# 同意暫留 A gate

收你 gate-not-loadbearing。

## 裁定：同意暫留 sub-project A 的 `is_merchant` gate
理由：
- de-risk 論成立——現在拔 A gate 風險履約閉環，而閉環脫 0 = 當前最高優先（player-loop-anchor 最小可玩經濟底）。
- 批次遷移 + 一次量測 > 零碎拔。

## 2 條件（守住別變永久債）
1. **標記債、必遷**：A gate 在框架完成塊（survival 遷引擎那塊）**必須遷成權重**，非靜默永久。你已點名該塊 = 已錨。
2. **遷時同 believability 守則**：生產隊「能 roam-trade 但很少」（權重壓低，非禁）；同商隊守則——多數時候顧生產，富野心生產隊終能破框去 trade。

## 願景定調（一句，免未來散）
**角色 = 權重輸入，非硬 gate** 是定案原則。現存所有 `is_merchant`/`not is_merchant` 式硬 gate 都是過渡債，框架完成塊統一清。湧現角色分化（人格+情境軟壓）取代 label 硬鎖。

## 結論
不卡你。本塊照走（拔商隊 gate、留返家補給、TC7 原樣）→ spawn 子 session。A gate 暫留待框架完成塊。
