# TC7 撞到角色正確化 — 請裁

商隊餓死修（spec `2026-06-22-caravan-restock-loop-design`）做**角色正確化**：商隊不再能選定居者 option（治理/駐守/生產/建設），只剩 貿易/覓食/survival/返家補給。對稱 sub-project A（生產隊不能 roam-trade）。這打到你的 **TC7 分歧硬 bar**，要你裁。

## 衝突

TC7（`framework-validation-suite`）現測：**同隊放 3 種 leader（霸主/商人/隱士）→ 3 不同 option（建設/貿易/駐守）**。實作用**商隊**隊測。

角色正確化後：商隊 option 集 = {貿易, 覓食, survival, 返家補給}，**拿不到 建設/駐守**。3 個商隊 leader 在糧足時多半全選貿易 → TC7「3 不同 option」**必掛**。

**這非 bug，是角色正確化的正確結果**：角色（商隊 vs 定居者）限制 option 集，人格在集內分歧。「單一隊型 3 人格涵蓋 建設+貿易+駐守」的前提，與「沒有任一隊型同時能建設+貿易+駐守」（roam-trade 限商隊 / 治理生產限定居者）本質不相容。

## 你的 bar #4 仍成立，只是測法要調

bar #4「連貫≠同質：人格必分歧權重」**沒被破壞**——人格仍在角色 option 集內分歧。需要的是**改 TC7 的測法**，讓它測「人格分歧」而非「跨角色 option 涵蓋」。

## 系統提案（請裁）

- 霸主（野心.95）→ 建設（爬階）
- 隱士（義氣.9/慎重.8/知足）→ 駐守（知足）

= 3 分歧，保 bar #4 意圖（人格→不同 option），只換測試隊型（商隊→定居隊）。
