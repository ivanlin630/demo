# 北極星：遭遇 = 統一反應（arc 收斂點）

用戶×藍圖願景討論定案，已寫進 `game-design.md`（「★遭遇=統一反應」節，憲法旗艦案例）。這**不改 arc 計畫，是講清它的終點**——你一序序溶 threat/solo/vendetta… 看似溶五個子系統，**其實是把五個結局收斂進「一次遭遇的統一反應」**。

## 給你的架構意圖（HOW 你 own，我只給收斂方向）

**遭遇 = 感知 → 引擎秤 → 挑一個結局。** threat/trade/diplomacy/vendetta/loot **不是平行系統，是同一遭遇評估的不同 option 輸出**。剩下的溶請朝「它們都落進同一個 encounter 評估」架，別各溶各成孤島。「友軍不理／敵軍戰逃／陌生去接觸」= 同一秤餵不同關係+軍力的自然輸出，非寫死岔路。

## 兩條鐵律（納入設計，影響你現在寫的序3.5 + 後續）

1. **★感知鐵律**：威脅/身分感知**只吃可見表象（數量/逼近/可見武裝）+ 已知關係（盟友/宿敵）**；**不吃對方 tag（商隊/軍隊/山賊）或真實意圖**——遠看分不出。分不出照最壞繃緊（但「繃緊」可是「派斥候」非「恐慌」）。
   - 落在序3.5：preempt 門檻讀感知表象，**別**讓目標偷讀逼近者的 tag/意圖來打折（「喔是商隊，放鬆」= 把可信度弄回 bug）。
   - 生湧現戲：虛驚（繃緊結果是路過商隊）、誤判釀仇（先發制人結下本無的仇）。
   - **新 option 要加**：「陌生+不緊迫 → 派斥候/使者探底」（探而後戰，非一律繃緊）。這也是虛驚的良性版（探明是商隊→改貿易）。

2. **★深度靠感知非規則（防坑）**：加深度=**讓世界更多狀態可被感知**，同一引擎自算反應；**不是為每種社交組合寫新規則**（組合爆炸=墳場）。
   - N 方（A 看 B、C 交戰）**不建三方處理器**。做法=把「交戰中/被打殘/威脅落盟友」變**可感知世界事實**，背刺殘敵/馳援盟友自己長出。
   - **順序**：先做完**兩方遭遇**統一反應；N 方是湧現延伸，靠加可感知事實非加規則，觀察後按需一次一個、過四關。
   - 成本標注：背刺殘敵≈免費（只要讀對方當下戰力，capability-grounding 已備）；馳援盟友=要新感知（威脅落盟友，現在只算對我）=有成本，**不反射建，等觀察缺戲再說**。

## 不擋你什麼
序4 vendetta / 序3.5 preempt 照跑。這是收斂方向+兩鐵律，讓你溶時往一個 encounter 評估靠，不是要你現在重架。感知鐵律的落地點在序3.5（門檻語意）+ 未來 trade/diplomacy 溶。「派斥候探底」option 何時排你定，我標它是 repertoire 該有的一格。
