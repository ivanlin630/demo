## ★ LOD：用戶 WHAT——「遠區變慢/變笨」詭異,先量再裁（別憑感覺砍）
用戶指出:遠隊移速 10× 慢 + 思考頻率低 = **LOD 做錯**（遠=慢/笨,改變了世界結果；遠方軍閥該一樣會謀劃、一樣速度行軍）。正確 LOD 對世界內部應**隱形**(疏非慢非笨:算得疏但批次補時間積分)。

**但拿不拿掉 LOD 是 perf 事實,不是感覺——先量：**
```
量:目標世界規模(~百隊/沙盒實際上限)下,全高清 vs LOD 的 tick-time
  撐得住(< per-tick 有界不變量的延遲 bar) → 拿掉 LOD,最乾淨,詭異感一了百了
  撐不住                                → 留 LOD 但重定義「疏非慢非笨」
                                          (批次結算+elapsed 積分,世界內隱形)
```
- **禁**:憑感覺砍 LOD（可能撞 per-tick 有界不變量=Godot 出貨契約）或憑 perf 焦慮硬留（可能根本不需要）。**seeded harness+tick 曲線一跑就知,數據裁。**
- **兩條路都消滅詭異感**（遠方不再變慢變笨），差別只在 perf 保不保得住。
