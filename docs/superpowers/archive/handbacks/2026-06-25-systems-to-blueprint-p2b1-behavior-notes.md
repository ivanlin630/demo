# 知會：P2b-1（survival 動作選擇統一）believability 行為變

純 HOW 重構（消 survival 動作選擇雙 owner——non-unified 隊與 unified 隊現用同一套 engine term 選絕境動作）。機制細節略。回報 3 個你可能在意的**行為微變** + 1 個 measure 揭露。非求裁，覺得哪點不對喊一聲（皆 TEST VALUE 可調/可回退）。

## 統一後 3 個行為變（我判可接受/改善，呈你確認願景）

1. **遠家殘忍隊不再「就近打劫」**：舊邏輯「離家很遠(>5天) + 殘忍/好戰 leader 餓了 → 就近搶弱者而非長途返家」的**距離感知**沒了 → 現一律返家補給。loot 很稀有（2yr 才 11 次），影響小。要保「遠家狠人就地搶」的戲劇感 = 我可後補（restock 驅力隨距離衰減）。**你要不要保這味？**

2. **絕境定居/生產隊會返家**：統一後「任何有家隊餓到絕境 → 返家吃」涵蓋生產隊（先前只商隊會 proactive 返家）。= 餓了回家天經地義，我判 believability 改善。

3. **大軍餓了不能靠覓食苟活**：覓食現限 pop≤15（小隊才划算，舊 homeless 規則，統一後也套大軍）→ 大軍絕境得靠返家/投靠/掠奪而非覓食撐。= 防「大軍蟑螂靠採野果無限苟活」，我判合理。

## measure 揭一個 pre-existing 問題（記 backlog，非本塊引入）

量測本想驗「1037 次 survival 多是回家吃」，結果發現 **1037 大多是攻擊隊輕飢的 churn**：攻擊隊有點餓→進 survival 評估→沒有可派的絕境動作→放掉→變 idle→又去攻擊…來回 927 次/2yr。這 churn 是**既有的**（本塊前後幾乎沒變），非我引入。記了 backlog（攻擊隊輕飢來回擺）。**對你的意義**：世界裡攻擊隊「想打又有點餓」時行為有點抖；不影響存活/守恆，但 believability 上是個既有小瑕。要不要排修由你（玩法優先序）。
