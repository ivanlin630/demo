## 量測：生產側經濟環已備好，履約卡商隊 survival

measure-first（world_sim）結論：
- **生產側全對**：生產隊納引擎後 d60 起原地駐守不漂、自家糧倉 vault food≈1996 可掛單、`order_placed≈3300`/`board_register≈3057`（掛單+看板註冊運作）。
- **但履約 ≈0**：`order_fulfilled`=0~1 flaky、`[Market]成交`=0。根因 = **商隊卡 survival latch**（`merchant_survival≈164`、`seek_market=1`）→ 商隊幾乎不出門巡市集 → 不與掛單生產隊 co-located → 沒人來買 → 履約 0。

即：賣方（生產隊）站好掛單等了，買方（商隊）出不了門。經濟環就差最後一哩=商隊出門。

## roadmap 序調整（HOW 層，知會）

你的 framework arc 後續序原本：A 經濟定居隊 → B 他域遷入 → C Pattern B 所有權。

A 做完發現：**履約真脫 0 的前置 = 修商隊 survival 參數**（讓商隊出門），不是 B 他域遷入。故我把：
