# UI 設計 Spec

## 目標

為現有 headless GDScript 世界模擬器加入 Godot 2D 玩家介面，讓玩家能在大地圖操控自己的 team，並在遭遇戰中操控自己的角色。

---

## 架構原則

- **Sim 層完全不動**：所有現有 headless 系統（sim_runner、interaction_system 等）保持不變。
- **SimBridge**：唯一橋接點，封裝 sim 呼叫，回傳 player-relevant events。
- **每 tick 重繪**：推進時地圖即時更新（快轉感），不是跑完才刷新。

---

## 場景結構

```
Main.tscn
├── SimBridge.gd              ← 唯一 sim 接口
├── WorldMapView.tscn         ← 大地圖渲染（flat-top hex TileMap）
├── RightSidebar.tscn         ← 右側欄（情境感知）
├── BottomBar.tscn            ← 底部：圖塊資訊 + 訊息欄
├── TurnControls.tscn         ← 結束回合 / 自訂跳過
├── EncounterView.tscn        ← 遭遇戰覆蓋層（encounter_active 時顯示）
└── PopupLayer.tscn           ← 彈出視窗容器（成員/物品/歷史）
```

## SimBridge

```gdscript
# scripts/ui/sim_bridge.gd
class_name SimBridge

const TICKS_PER_TURN: int = 24  # 1 遊戲日

# 推進最多 n ticks；每 tick 後掃 player-relevant events
# 遇到 player event 則提前停止
# 回傳本次推進產生的 player events array
func advance_ticks(n: int) -> Array:
    ...

# Player-relevant event types:
# "encounter_triggered"   — encounter_active 變 true
# "diplomacy_received"    — 有 team 對玩家 team 發起外交
# "new_team_spotted"      — 新 team 進入玩家視野
# "encounter_enemy_action"  — 遭遇戰中敵人行動（遭遇戰用）
# "encounter_enemy_spotted" — 遭遇戰中新敵進場
```

---

## 時間推進

| 按鈕 | 行為 |
|---|---|
| 結束回合 | advance_ticks(24)；遇 player event 提前停止 |
| 下拉選單 | advance_ticks(N)，N = 10 / 50 / 100 |
| 等待到事件 | advance_ticks(MAX_INT)；遇 player event 停止 |

推進期間：每 tick 呼叫一次 `advance_tick()` → 重繪地圖 → 掃 events。速度由常數 `TICKS_PER_SECOND` 控制（TEST VALUE）。

**取消等待**：推進期間任意時刻按 **Escape**（或再次點擊結束回合按鈕）立即停止推進，回到等待玩家輸入狀態。UI 顯示「取消」提示（按鈕變色 or 文字改為「停止」）。

---

## 六邊形規格

- **方向**：Flat-top（平面朝上，頂邊水平）
- **頂點**（circumradius = 30）：`points="15,0 45,0 60,26 45,52 15,52 0,26"`
- **Grid spacing**：欄間距 45px（60 × 0.75）；奇數欄下移 26px

## 大地圖

### 版面

```
┌─────────────────────────────────────┬──────────────┐
│  Top bar（Tick / Day / 時段 / 結束回合 / 跳過選單）     │              │
├─────────────────────────────────────┤  Right       │
│                                     │  Sidebar     │
│         Flat-top Hex Map            │  (210px)     │
│         （最大化，佔剩餘空間）         │              │
│                                     │              │
├────────────────────┬────────────────┴──────────────┤
│  圖塊資訊（200px）   │  訊息欄（其餘）                  │
└────────────────────┴────────────────────────────────┘
   Bottom bar（85px）
```

### 地圖渲染

| 元素 | 顯示 |
|---|---|
| 地形 | 顏色區分（plains=綠、forest=深綠、mountain=灰） |
| 迷霧 | 未發現格 → 暗色遮罩（#0a0a0a） |
| 玩家 team | 藍框 + 🧑 emoji |
| 其他 team | 顏色依陣營（友=綠框、敵=紅框、未知=無框） |
| 據點 | ⚑ icon + 顏色依歸屬 |
| 移動目標 | 虛線箭頭 |

### 互動

- **QWEASD**：捲動地圖視角
- **滑鼠左鍵點格**：選取格子 → 右側欄更新選取格資訊；若格子有 team → 顯示 team 資訊
- **點自己 team 格 + 📍移動按鈕**：設定 move_target（自動尋路）
- **滑鼠滾輪**：縮放

### 右側欄結構

```
① Team 名稱 + 陣營 + 位置
② 資源（動態顯示現有資源，無 task 顯示）
③ 6 個按鈕：
   [📍移動]  [⚙命令]  [🤝互動]
   [👥成員↗] [🎒物品↗] [📜歷史↗]
```

### 彈出視窗

**👥 成員**

| 欄位 | 說明 |
|---|---|
| 名稱 + 角色 | 隊長/顧問/成員 |
| 裝備定義 | 指定兵種（刀手/弓手/槍手…） |
| 裝備欄 | 目前裝備的武器 |
| 健康狀態 | 正常/輕傷/重傷（簡化顯示） |
| 匿名人口 | 數量 + armed ratio |

**🎒 物品欄**

- 玩家背包：物品 + 使用/存入 Team 按鈕
- 「從 Team 取出」區塊：顯示 team 各資源數量，輸入數量 → 取出至背包
- 存入：背包物品 → 存回 team 資源庫

**📜 歷史訊息**

- 可捲動，顯示本 team 相關歷史事件（player_system 或 message_system 提供）

### 底部列

```
┌──────────────────────┬──────────────────────────────┐
│ 圖塊資訊              │ 訊息欄                         │
│ ▶ 游標指向格(x,y)     │ [T142] Team3 移動...           │
│ 地形 / 資源 / 據點    │ [T135] ⚠ 玩家相關事件（黃色）   │
│ 佔領 team（若有）     │ （可捲動）                      │
└──────────────────────┴──────────────────────────────┘
```

## 遭遇戰

### 版面

```
┌────────────────────────────────┬──────────────────────┐
│                                │ ① 主角狀態            │
│     Flat-top Hex               │   各部位健康           │
│     戰場地圖                   │   速度 / 疲勞          │
│     （單位不重疊）              │ ② 裝備                │
│                                │ ③ 行動指令            │
│                                │   [移動] [攻擊] [物品] │
│                                │   [命令]              │
│                                │ ④ 游標指向詳情        │
├────────────────────────────────┴──────────────────────┤
│ 底部資訊列：游標指向格的地形 + 單位部位狀態（即時更新）    │
└─────────────────────────────────────────────────────────┘
```

### 遭遇戰規則

- 每格最多 1 個單位
- 友軍、敵軍皆為移動障礙（無法穿越）
- **速度決定行動順序**：每 round 開始，所有單位依 `get_effective_speed()` 降序排列；速度高的先行動
- 輪到玩家角色時：暫停，顯示「你的回合」，等待玩家輸入
- 其他單位（友軍/敵軍/匿名）由 `_decide_action` AI 自動解算
- 注意：需修改現有 `advance_round`（目前為全單位同步輪詢）→ 改為速度排序佇列

### 右側欄詳細

**① 主角狀態**
- 各部位健康（頭/軀幹/右臂/左臂/右腿/左腿）
- 顯示等級：醫療技能低 → 文字描述（正常/輕傷/重傷）；醫療技能高 → 數值（0.82/1.0）
- 速度：`get_effective_speed()` 結果
- 疲勞值

**② 裝備**
- 右手武器欄
- 其他裝備格（未來擴充）

**③ 行動指令**
- 移動：QWEASD 提示
- 攻擊（R）：按後選目標（QWEASD 游標 or 滑鼠點擊），Enter 確認
- 物品（F）
- 命令（Z）：彈出子選單（等待/齊射/撤退等）

**④ 游標指向詳情**
- 敵方單位：部位狀態（偵查不足顯示 "?"）
- 空格：地形效果說明

### 底部列

游標即時資訊：
- 左區：格子識別（地形、是否有單位）
- 中區：單位部位狀態（如有單位）
- 右區：地形詳情（掩護加成、移動消耗、視野影響）

## 操作總表

### 大地圖

| 輸入 | 功能 |
|---|---|
| QWEASD | 捲動地圖視角 |
| 左鍵點格 | 選取格子；設移動目標（搭配移動按鈕） |
| 右鍵 | 取消選取 |
| 滾輪 | 縮放 |
| Enter | 確認（彈出視窗內） |
| **Escape** | **等待期間：取消等待，立即停止時間推進** |

### 遭遇戰

| 輸入 | 功能 |
|---|---|
| Q ↖ W ↑ E ↗ | 移動角色 |
| A ↙ S ↓ D ↘ | 移動角色 |
| R | 攻擊（進入選目標模式） |
| F | 物品 |
| Z | 命令選單 |
| X / C / V | 預留 |
| Space | 待機（跳過本回合） |
| Enter | 確認行動 |
| 左鍵 | 選取目標格（攻擊/移動確認） |
| 右鍵 | 取消 |
| 滾輪 | 縮放 |

移動選目標：QWEASD 移動游標 **或** 滑鼠點擊，兩者皆可。

## Team 標色規則（大地圖）

| 顏色 | 條件 |
|---|---|
| 🟢 綠框 | `team.faction_id == player_faction_id`（同陣營） |
| 🟡 黃框 | `team.faction_id != -1 && != player_faction_id`（他勢力） |
| ⬜ 灰框 | `team.faction_id == -1`（獨立） |
| 🔴 紅框 | `team.team_id in state.player_hostile_teams`（曾攻擊玩家，優先於以上） |

**`player_hostile_teams`**：`WorldState` 新增 `var player_hostile_teams: Array = []`。
寫入點：`InteractionSystem._try_interact` 觸發玩家遭遇戰時，將攻擊方 team_id 加入清單。
