owner: blueprint（WHAT）
★DRAFT 待用戶過目;與 2026-08-21 長考閘職能重疊待釐清。
溯源：③ 長期故事驗證 audit 暴露流程級缺口——有 code invariants、無「健康世界」量化參照系，每輪 audit 在 genuine-vs-bug 打轉無尺可量。用戶要求根本層視角後補。

## §0 命門
- vitals = **參照系非硬閘**：偏離 = 值得診斷的信號、非自動 FAIL（沙盒憲法：世界湧現、不腳本化目標值）。
- 所有數字第一版 = **TEST VALUE 待校準**（跑健康世界後回填）；方向與階序先定死。

## §1 守恆層（最根本、違反=世界設計錯非機制錯）
| 體徵 | 健康帶（初版） | 量法 |
|---|---|---|
| 糧帳比 P/C（總生產/總消耗、日） | 和平期 **≥1.0**（微盈餘）；戰亂容忍短期 <1 | daily_curve total_food 斜率 + 生產/消耗 tap |
| 世界糧跑道（存量÷淨燒率） | **≥90 天**（永不進入全域倒數） | 同上 |
| 時鐘比（餓死時鐘÷行動完成時鐘） | **≥3×**（空間策略來得及完成） | 私糧日數 vs travel-time 分布 |

## §2 人口/結構層
| 體徵 | 健康帶（初版） | 量法 |
|---|---|---|
| 人口月變化（和平） | **±5%/月內**；戰亂 <-15%/月需可歸因（戰死非全餓死） | pop curve |
| 死因構成（戰國配置） | 戰死 **>0**；餓死非唯一死因 | death.combat_pop vs starve_anon |
| 團規模分布 | **有大有小**（非均一碎小：max/median ≥3、非全員 pop<5） | teams census |
| 分裂/合併比 | 長期 **≈平衡**（單向棘輪=病） | split events vs merge complete |

## §3 故事層（沙盒品質尺：無玩家也要好戲）
| 體徵 | 健康帶（初版） | 量法 |
|---|---|---|
| 勢力興衰事件 | 觀察窗內 **≥1**（擴張/兼併/衰亡/立國任一） | faction census + established |
| 衝突→結局鏈 | 征服意圖 → 實戰 → 勝負後果，鏈至少偶爾走通 | intent→combat→death/absorb funnel |
| 復甦弧存在 | 崩過的實體有人回升（非全單調向死） | per-team pop/food 弧 |

## §4 用法
- ③ 型長局 audit 開頭先量 §1 → §1 不健康時 **§2/§3 的異常全降級為下游**（先修基底再判機制）。
- measurer 標準床輸出附 vitals 快照；QA 判「沒道理」以此為參照非直覺。
- 校準協議：基底修完後跑 3 seed 長局回填健康帶、TEST VALUE 轉正。
