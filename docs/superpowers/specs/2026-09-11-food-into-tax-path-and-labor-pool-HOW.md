## ⓪ ★★★這張票的形狀：**換路，不是換率**

```
★房客採到的糧**現在直接進地主公庫**（`resource_system.gd:413-421`）——
  **沒有經過私產、也沒有經過稅軌**。
★★而 `NORMAL_TAX_RES` **本來就含 food** —— 它只是**在這條路上永遠拿不到 food**。
⇒ ★★★所以卡① 不是「把 food 併進稅軌（調稅率）」，是
   **把 food 從【直入庫】那條路，改走【私產 → 一般稅】那條路**。
⇒ ★而 (b)「讓房客吃得到自己留下的那份」**不必另外設計**：
  ★★消費端本來就吃私產 ⇒ **food 一旦走私產路，房客自動吃得到** —— 它是 (a) 的自動結果。
```

## ① 卡①：兩半（★兩半要一起做，否則其中一半看起來沒效果）

```
(a)**換路**：採集所得的 food ⇒ 走 `_apply_normal_tax`（私產 → 按 `tax_rate` 撥給 tile owner 公庫）
   ⇒ ★**採集者就是 owner 時，結果與現況等價**（自己付稅給自己 ＝ 帳面轉移）
   ⇒ ★★而**房客**的情形才會變：從「100% 沒收」變成「按稅率分成」。
(b)★★★**`tax_rate` 接線**（現況**零寫入點 ＝ 死常數 0.3**，我裸掃過）
   ⇒ 由**領主人格 ＋ 處境**導出，★而**只准用既有的八軸**（人格鍵正典：單一消費者禁開新軸）
   ⇒ 建議形狀（★由 R² 打）：**貪婪↑ ⇒ 稅↑**／**慎重↑ ⇒ 稅↓**（怕不滿）
     ＋ 處境（例如**在建工程的缺料急迫度**）作為調變
   ⇒ ★★而**不得**變成一個新的死常數：**它要是一支函式，讀 leader values ＋ 當下狀態**。
```

## ② 卡③：勞力池只收【主隊 ＋ 登記居民】

```
現況（`labor_system.gd:72-78`）：**零 owner 檢查、零 faction 檢查** ——
  站在那格的**每一支 PRODUCE 隊**都被算進勞力池。
⇒ ★改成：**owner 隊本人 ＋ `is_registered_resident` 為真且登記在這格的隊**。
⇒ ★★而這是**行為改變**（白捐關閉）—— 卡③明文授權。
```

## ③ ★★★驗收：**而它現在【判不動】—— 這一節是本票最重要的部分**

```
★母體現況（登記錨那張量的）：**三個 config 在 t=0 的房客都是 0**
⇒ ★★所以「房客吃得到分成」「白捐歸零」這兩格**在自然世界裡不可判** ——
  ★★★而**不可判不是綠**：沒有房客時，「白捐 ＝ 0」**自動成立**。
⇒ 處置（兩層，缺一不可）：
  ①★**fixture 床**：**刻意造一支房客**（一支 PRODUCE 隊站在別人的據點上、登記在那裡）
    ⇒ 在那個床上，三格都**可判**：分成／吃得到／不再白捐
  ②★★**自然世界那一格明寫「不可判」**並附**母體數字**（房客 N ＝ 0）
    ⇒ ★★★而**不准**用「沒有不一致」冒充綠。
```

| # | 格 | 判準 |
|---|---|---|
| ① | **★★★fixture：房客分成** | 造一支房客 ⇒ 採 100 糧 ⇒ **它私產留 (1−tax_rate)×100、地主公庫收 tax_rate×100**（★兩個數字都印） |
| ② | **★fixture：房客吃得到** | 同一支房客 ⇒ 消費端**真的扣到它自己的私產**（★★而不是「有效糧看起來變多」——要看**扣**） |

## ⑤ 誠實限

```
★本票**不宣稱**世界會因此變公平：它只讓**房客留得下 (1−tax_rate)**，
  ★★而 `tax_rate` 由**領主**決定 ⇒ **重稅仍然合法**（那正是卡①要的張力）。
★★★而「重稅會怎樣」有既有機制接著（`_apply_chronic_tax_unrest` ⇒ 壓力／忠誠 ⇒ 起義）
  ⇒ **本票不動它**，但驗收⑤的分布會第一次讓那條路**有真的輸入**。
```

> ★★★**待母體複驗（2026-09-11 blueprint 裁）**：本票的驗收是在 **fixture** 上綠的，
> 而自然世界的母體是 **0**（登記居民 0／房客 0／被擋 0）⇒ ★**fixture 綠 ＝ 合法過渡，不是【世界變好了】**。
> ⇒ ★★待【登記動詞（招攬／上門請求）】落地、世界真的長出房客之後，**拿真人口回頭補一格自然驗**。
> ★★★而在那一格補上之前，**不得引用本票來說「房客現在吃得到了」** —— 只能說「機制已接、待母體複驗」。
