# §0 為什麼換軸（前一票量出來的，不是換個方向再試一次）

```
甲／乙／(丙-2) 三個形狀的共同動作都是「讓 gather 少被呼叫幾次」
⇒ ★而 gather 的純讀路徑【仍有合法的 RNG 抽取】（_find_strong_neighbor → estimate_catch_up
   → observed_speed，它真的在用那個速度值，拿不掉）：A1 之後仍有 31／40 的隊會抽
⇒ ★★少呼一次 ＝ 少抽一次 ＝ 之後所有隨機事件錯位 ⇒ 語意零改變在【構造上】到不了
```
⇒ ★★★**所以本票的動作換成：呼叫次數不動，【同一次呼叫裡少做事】。**
★而「觀測雜訊不再綁呼叫次數」那張票（決定性雜訊）**不是本票**，它的優先序在 WHAT 手上。

# §1 ★★★第一格是量，不是改 —— **先知道做了什麼事，才談少做什麼**

```
量：【同一次 gather 之內】每一段的耗時分解（per-field／per-scan），★兩個 seed
必報：①母體（gather 被呼叫幾次、每段被執行幾次 —— ★注意「算了但沒被讀」也算執行）
      ②占比（不是絕對秒數；★單輪排行不可依，這是 WHAT 已經立過的規矩）
      ③★★【算了沒人讀】的欄位要單獨列一欄 —— 它是最便宜的省法，而且它【不需要剪枝】
```
★**預先聲明判準（免得量完再挑一個好看的方向）**：

| 量到的形狀 | 本票要做的事 |
|---|---|
| 有欄位**算了但這次沒人讀** | ★**先做這個**：改成【誰讀誰算】（同 A1 的形狀）⇒ **不需要等價證明**，因為沒有人在看它 |
| 某個 O(隊數) 掃描占比高、且**有可證明的上界** | ★★做**等價剪枝**（見 §2） |
| 成本平均攤在很多小段上、沒有單一大頭 | ★★★**回報「這塊沒有便宜的省法」並結案** —— 不許為了交差去做一個省 3% 的剪枝 |

# §2 等價剪枝的形狀（★唯一允許的形狀）

```
只剪掉【可以證明不可能改變最終選擇】的候選：
  先用便宜的上界（距離／已知規模／既有 belief 欄位）算出「它最好能到多少」
  ⇒ 若那個上界 < 目前最佳值 ⇒ 不必算貴的那部分
★★禁止：改變評分、改變順序、改變 tie-break —— 那些都不是剪枝，是改行為
★★★禁止：用「近似」剪枝（剪掉「大概不會贏」的）—— 近似＝降真實，本票禁
```

# §3 驗收（★每格能紅）

| 格 | 內容 | 反向 |
|---|---|---|
| 2-a | ★§1 的分解數**兩個 seed 都報**，含母體與占比，★★含「算了沒人讀」那一欄 | 只報一輪／只報秒數 ⇒ 紅 |
| 2-b | ★★★**剪枝開關【關 vs 開】，兩邊的【選中結果】逐字相同**（不是只有 fp 相同）——★母體要印（比對了幾次選擇） | 有任何一次選擇不同 ⇒ **剪枝條件不等價** ⇒ 紅 |
| 2-c | ★fp ＋ 逐 tick 行為軌跡**逐字相同**（跨修法前後，★釘住修法前那棵樹的字串＋標 commit） | 不同 ⇒ 紅（判準軸：**變因就是樹本身 ⇒ 必須跨樹比**） |
| 2-d | ★★**陽性對照**：把剪枝條件**故意弄壞一格**（例如上界少算一項）⇒ **2-b 必須紅** | 弄壞了還綠 ⇒ 2-b 沒有鑑別力 |
| 2-e | ★效能**如實報**（含「沒省到」也要報），★★兩個 seed | 只報好消息 ⇒ 紅 |
| 2-f | 到場點名 ＋ expect 釘 `N／N`，★橫幅內容不得由共用計數決定 | 少一格 ⇒ 紅 |

★**2-b 是本票的命門**：fp 相同只證明「這一輪沒踩到」，
**而「選中結果逐字相同」是直接驗【剪枝等價性】本身** —— 兩者不可互相取代。
