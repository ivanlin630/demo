# §1 ★為什麼要它（★而它是被前一票的誠實限逼出來的）

```
前一票的結論：**凍結幀是「整個 tick 都大」，不是「某個相位爆了」**
★而它的誠實限第一條是：`[FaiPhase]` **只在 tick > 100ms 時才印**
   ⇒ **我所有的比較都發生在「昂貴 tick」之內** ⇒ **沒有比到普通 tick**
⇒ ★★★所以「整個 tick 都大」目前只是**相對於其他昂貴 tick**
⇒ **要回答「為什麼有些 tick 整體就是比較大」，需要一個【每個 tick 都有】的量。**
```

# §2 ★★量什麼（**每一 tick，不只昂貴 tick**）

```
每 tick 記一對：(**本 tick 的決策隊數**, **本 tick 的幀總時 dt_us**)
★★★**不要每 tick 印一行** —— 12 天 ＝ 17280 tick × 2 seed，
   ★而 **I/O 本身會變成被量的成本** ⇒ **累積在記憶體，結尾一次 dump**
⇒ 結尾輸出：
   ①**分桶表**：依決策隊數分桶（例如 0／1-2／3-5／6-10／11+），每桶印
      **n（母體）／dt 的 median／p90／p99／max**
   ②**凍結幀（dt>2s）在各桶的分佈** ＋ **各桶的凍結率**
   ③★**全體 dt 的 median／p90／p99／max**（★這是前一票缺的那個「普通 tick」基準）
```

# §3 ★★★預註冊的兩條岔路（**在看到數字之前寫死**）

```

    ⇒ ★★**成本在【單價】或別處** ⇒ 回到逐相位，而且**要先解釋為什麼同樣的隊數會差這麼多**
★★★**而「2 倍」這個數我現在就寫下來，理由是它是【可被證偽的】** ——
   ★不是因為我知道答案，而是因為**門檻必須先於數字存在**。
★★若落在 1.5~2.5 倍之間 ⇒ **判【不可判】**，不是硬塞進某一邊（★母體太小也判不可判）。

# §6 ★★★裁定：**(甲) 母體解釋得了** —— 而**我預註冊的那個統計量【算不出來】**

```
★**主判準失效**：我寫「凍結幀決策隊數 median ≥ 非凍結 2 倍」
   ⇒ 而**非凍結幀的 median ＝ 0**（**97% 的 tick 沒有任何一隊決策**）⇒ **40／0 未定義**
⇒ ★★**我在選統計量之前沒有先問分佈形狀** —— 中位數比值在「一邊恆為 0」時**沒有意義**
⇒ ★★★**而 implementer 沒有去挑一個算得出來的替代統計量** —— **那正是預註冊要防的事**，他守住了。

## §6.1 ★裁定依據：**分桶欄，而它【也是預註冊的】**

```
★`§5②` 我寫過：「**凍結幀在各桶的分佈 ＋ 各桶的凍結率**」⇒ **它不是事後挑的**
量到：
  **凍結幀 100% 落在【11+ 決策隊】那個桶**
  **0 桶與 1-2 桶的凍結率都是 0.00%**
⇒ ★★**這是【分離】不是【相關】** —— 不是「大 tick 傾向多隊」，是**少隊的桶【一次都沒有】凍結過**
⇒ ★★★所以 **(甲) 成立**：**母體解釋得了** ⇒ **修法方向是【母體控制】，不是逐相位優化**
```
★**而我要標清楚裁定的性質**：
```
①原本預註冊的**那個統計量**：**不可判**（未定義）
②裁定所依據的**分桶結果**：**也是預註冊要求的輸出**（§5②）⇒ **不是事後挑的**
③★★★**但「分桶」當初【沒有附門檻】** ⇒ 嚴格說，本裁定是
   **「用一個預先指定的觀測、下一個當初沒預先寫死門檻的判斷」**
   ⇒ ★**我把這件事寫出來，而不是假裝門檻本來就在那裡。**

```

## §7.1 ★這對「(甲) 母體解釋得了」這個裁定的影響（**逐句訂正，不整句撤回**）

```
★**仍然成立的**：因為 11+ 是**必要**的 ⇒ **消掉 11+ 就消掉 100% 的凍結**
   ⇒ **「母體控制」作為修法【會有效】** —— 這一句不變
★★**要訂正的**：我寫「**母體解釋得了**」⇒ **那句話太滿**
   ⇒ 正確說法是：**母體是【閘門】，不是【解釋】** ——
     它決定「有沒有可能凍結」，**不決定「會不會真的凍結」**
★★★**而這差別會改變修法的成本**：
   ・打 11+ ⇒ **有效，但過寬**：你會動到 **4~5 倍**於實際凍結的那些 tick
   ・找到第二因子 ⇒ **可能便宜得多**（只打真正會凍的那一小部分）
⇒ ★**所以「先找第二因子」現在是一個有明確報酬的選項，而不是完美主義。**
```
