# Spec — 征服×饑荒 咬合引擎（②③ 統一設計）

五代十國引擎的核心迴路。決策模型/世界模型雙側。定 2026-07-06（藍圖×用戶願景討論）。

## 一句
**餵飽的軍閥吞饑荒虛弱的地；over-militarize 自限。** 征服（③野心點火）+ 饑荒（②流串+hunger戰力）咬合成一個自我調節迴路，非兩塊。

## 咬合迴路（★兩互動分清，2026-07-06 用戶修正）
**霸主不殺饑民（饑民無地無糧無財=非征服目標）。兩條不同互動：**
- **霸主 × 饑民 = 吸收**（饑民絕境→**投靠**餵得起的強者=refugee 驅動的求生決策；霸主廉價得 manpower）。「投靠」option 已存。
- **霸主 × 據點 = 征服**（目標＝**土地/產能價值 × 弱守**，非難民；`find_prosperity_prey` 已吃 richness 項=偏好富而弱）。**hunger→戰力弱化的是「據點守軍」**→ 肥地+餓弱守=獵物；霸主拿**地**（不動、有產能），非難民。
```
饑荒 → 饑民流串 ──投靠──> 霸主(餵得起) → 軍隊長人(manpower)
                                           │需更多糧
霸主大軍 → 征服「肥地+餓弱守軍」據點 ─拿地─> 餵更大的軍
                                           │
過度長人/擴軍 → 自己也養不起 → 自饑荒 → 自軍戰力↓ → 自限(不雪球)
```
**深度軍事邏輯（強收/招募/編制/後勤細節）= deferred，後面加。** 本 spec 只鋪咬合骨架。

## ③ 野心點火（破死鎖）
死鎖：想征服←需看見弱獵物←需武裝←需選訓練←`ambient_train_drive`平頭0.5太弱。破法：
- **③a**：`ambient_train_drive` **隨野心/好戰人格化**（照妖鏡：平頭常數→人格）。霸主猛練兵，和平者不練。**狂者強到 train util 壓過民生**（產/建）=刪民生擴軍。
- **③b**：`_intent_scores` viability 層「無可見目標」時**別把霸主降級致富**；改「備戰+派斥候找目標」（真軍閥先建軍再找目標）。
- 守：capability/readiness 仍在秤裡（無牙/不備不亂攻）；三個家（fraction/門檻讀人格非全域常數）。

## ② 饑荒（適應消耗 + hunger戰力 + 流串）
- **②a 適應消耗取代 flat grace**：食物短→有效進食下修至 survival floor（勒緊）→存糧撐更久；hunger 依短缺漸升；**「撐多久」湧現=f(缺多少+存底+省多兇)**，非寫死 grace 天數。死走既有路（named hunger→血→死 / anon attrition）觸發於持續高 hunger。
  - 三個家：物理=吃 min(need,available)強制營養不良；判斷(可選)=慎重領袖**提前配給**撐供給、揮霍者先垮（人格戲）。
- **②b hunger→戰力**：餓→人均戰力↓ + 參戰意志↓（餵既有「戰鬥重量=Σ人均戰力×參戰意志」）。物理。→ **據點守軍餓→防守弱→肥地可取**（征服點火，目標=地非難民）；霸主過度擴軍→自軍餓→戰力↓→自限。（饑民本身=投靠被吸收，非此路成獵物。）
- **②c hunger→不滿→流串**：
  - **anon exodus**（平民整批逃/流竄，cohort 遷徙/投靠）
  - **named 分團**（餓部將 loyalty↓→異心→帶親信脫離；適應性=甩人母隊反而好活、splinter 遷徙劫掠找食）
  - 饑荒→loyalty↓ 已餵異心；需**強化 famine→split/flee 觸發**（現 unrest_turns 弱餵）。

## 護欄（調查坐實）
- **named 數安全**：split/defect **搬既有 named+搬 anon cohort，零 `generate_for_team`**；升 named 全結構 gated 非饑荒驅動。**無 anon→named runaway。**
- **真護欄=隊數**：split+exile 各生新隊→更多隊→LOD(O(N²)/50隊目標)。這是流串該有形狀，但需**流亡團 cluster/merge 偏好**（難民聚少數團非一人一團）界住。
- **不設 min-food 分團閘**（餓隊分裂是適應性，甩人求生，別擋）。

## 切片序列（單變量,各自可量,別一次全改）
1. **③a train-drive 人格化** — 破死鎖首片。測：seed 7 繁榮世界霸主(T23/T40)會不會選訓練→武裝↑→征服點火。用 `militarization_arc_bed`（活動組成 train%、self_armed 趨勢、漏斗 want→committed）。**不受饑荒干擾=乾淨測 ③。**
2. **③b intent 無目標→備戰+scout**（非降級致富）。
3. **②b hunger→戰力** — 閉環那塊；測餓隊 effective 戰力↓、成獵物。
4. **②a 適應消耗+湧現 grace** — 食物模型改；測 die-off 是否變漸進斜坡。
5. **②c hunger→流串+隊數護欄** — exodus+分團；測流串戲 + 隊數不爆。

每片：measure（arc bed/warring）+ 憲法閘 + 融合驗 + 非退化。三個家守則（新常數皆人格/世界參數化，不埋全域魔術數）。

## 待驗風險
- ③a 狂者刪民生→自饑荒：是設計的湧現（閉環），但要 measure 別失控成全員自殺式擴軍。
- ②c 隊數：measure 隊數增長帶不帶得動（50隊目標）；cluster/merge 界得住否。
