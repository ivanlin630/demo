### ②★★★事件側的可執行定義（★這是本票最難的一格，我先給判準再給桶）
> ★**判準**：**一個【狀態轉換】，若某隊在轉換當下【不重評】就會做出明顯錯誤的決策。**
★★**而它是語意判斷 ⇒ 必須配【機械 falsifier】**（同「手工分類表無法避免時」那條紀律）：
```
★機械 falsifier：對每一個候選,回答「若它【不】喚醒,最壞情況是什麼」
   ⇒ ★★答不出【具體壞結果】的 ⇒ 不是 T0（★★★而「答不出」要記進桶,不是靜默剔除）
```
