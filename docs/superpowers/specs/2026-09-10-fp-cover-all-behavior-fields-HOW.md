## ① ★★★核心難點：「會影響行為」是【語意】，不能直接導出 —— 用一個【保守的機械代理】

```
★代理判準（可導出）：**該欄位有沒有被【模擬層的 code】讀到**
   母體  ＝ 所有 typed data class（TeamData／PersonData／FactionData／HexTileData／
           WorldData／…★由 `_emit_*` 登記表導出，不手抄）的 `var` 欄位
   判準  ＝ `<變數>.<欄位名>` 是否出現在 `scripts/simulation/**` 與 `scripts/data/**`
           【非純輸出】的位置（★排除 `print(` / `Probe.` / `emit_message(` 的參數位置）
   ⇒ 讀得到 ⇒ **進尺**；只被觀測／記帳讀到 ⇒ 候選排除
```

★★**這個代理【故意偏保守】**：

```
「被模擬層讀到」⊋「真的影響行為」（★讀了之後丟掉也算讀到）
⇒ ★★所以它會【多納入】一些其實無害的欄位。
⇒ ★★★而這個方向是對的：**決定論尺寧可多守，不可少守** ——
   少守的代價是「fp 相同」變成一句空話（今天已經量到那個代價有多大）。
```

## ② 豁免必須【可被證明】，不是宣稱（★這是本票與前兩張的差別）

前兩張票把「排除清單」變成導出值；**本票要再進一步：讓【豁免的理由】也可驗。**

```
豁免只有三種，★每一種都要附一個【機械可驗的證據】：
 (a) ★**ephemeral 快取**：宣稱「它每 tick 由別的欄位重算」
     ⇒ 證據：**把它清空、推進一 tick ⇒ 它必須被算回同一個值**（★這一格是可跑的）
 (b) ★★**cadence 排程欄**（`*_eval_next_tick` 這類）：宣稱「它只決定何時算，不決定算什麼」
     ⇒ 證據：★★★**它進尺會讓兩顆語意相同的跑分岔**（把它加進尺 ⇒ 同 seed 兩跑仍相同才算數；
       ★若加進去就分岔，那不是「該排除」，那是**它其實影響行為**）
 (c) ★**觀測／記帳專用**：宣稱「只有 Probe／print／observer 讀它」
     ⇒ 證據：★★裸掃它的讀取點，全部落在輸出位置（★★★這正是 §① 判準的反面，同一支工具）
⇒ **沒有證據的豁免 ＝ 不豁免**（沿用「不呈＝不豁免」那條）。
```

## ③ 驗收

| # | 格 | 判準 |
|---|---|---|
| ① | **清單是生成的** | 進尺集合與豁免集合**都由 code 導出**；★在任一 data class 加一個假欄位並在 `scripts/simulation` 讀它 ⇒ **必須進尺**；只在 `print(` 裡讀它 ⇒ **必須落進 (c) 候選** |
| ② | **★豁免有證據** | (a) 類逐欄跑「清空 → 推進一 tick → 值回來」；(b) 類逐欄跑「加進尺 ⇒ 兩跑仍相同」；★★任一欄過不了 ⇒ **它就不是豁免，要進尺** |
| ③ | **★★決定論沒被打壞** | 擴張後：同 seed 兩顆無玩家跑 ⇒ fp **仍然完全相同**（★★★這一格是本票最重要的：**擴太多會讓 fp 變成噪音**，而噪音尺等於沒有尺） |
| ④ | **★★★哨兵還在** | `player_*` 那道哨兵（上一張票）**仍然有效**：注入偷寫 ⇒ 仍然當場紅 |
| ⑤ | **設施等級進尺** | `apothecary_level`／`mint_level` 這兩個【今天被點名的】欄位**必須在尺內**（★它們是本票的觸發樣本） |
| ⑥ | **數字對帳** | 每一類：進尺 ＋ 具名豁免 ＝ var 欄位總數，**差額必須為 0**（沿用子層級那張的第三種狀態歸零） |

★**誠實限**：③ 只證明【在那個窗、那個 seed】沒有噪音 ——
★★而噪音的來源通常是**時間相關的快取**，⇒ ★★★**窗要長到足以讓 cadence 轉過一輪**，
否則「沒分岔」可能只是「還沒輪到」。
