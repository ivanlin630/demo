## ⑧ ★★★blueprint 裁：**parent 軸不折進登記制，而落法是【一跳推導】不是【複製】**

```
★裁詞（逐字要留）：它們是**兩種關係** ——
   登記 ＝ **居住／雇傭契約**（隊 ↔ 據點）
   親緣／派遣 ＝ **組織隸屬**（隊 ↔ 隊）
  ⇒ ★★**子隊是母隊的延伸，回自家母村不該需要「登記」** —— 權利**沿母隊流下來**。
★★★而落法**不是**給子隊發第二份登記：
  **登記欄仍是唯一真值**，檢查處的通則寫成 **「本人登記 OR 母隊登記／擁有」**
  ⇒ parent 只是**查詢時多查一跳**。
  ⇒ ★若發第二份登記：子隊獨立／母隊搬家時**兩欄打架** ＝ **又一個兩真相源**。
```

**★而這件事要落成【具名謂詞】，否則它會長出第五種軸**：

```
`WorldState.registered_at(team, tile) -> bool`            ＝ 本人登記
`WorldState.registered_or_parent_at(team, tile) -> bool`  ＝ 本人 OR 母隊（★**一跳，不遞迴**）
⇒ ★★呼叫端**只准用這兩支**；★★★**手寫 `owner == team_id or owner == parent_team_id` 的組合 ⇒ 棘輪具名紅**
  —— 這正是「四種軸」當初長出來的方式（每處各自手寫一份）。
```

★**誠實限（★我加的，裁詞沒講而它是真的）**：

```
一跳推導 ⇒ **母隊的登記一變，子隊的權利【當場】跟著變** ——
★而子隊**不會知道**（它沒有被通知、也沒有自己的欄位變動）。
⇒ ★★語意上這是對的（權利本來就是借來的），★★★而它的觀測後果是：
  **一支子隊會突然「不能在這裡卸貨了」，而它自己的狀態一個位元都沒變。**
⇒ 處置：**接一顆 tap**（`registry.parent_hop.denied`）⇒ 讓這件事**可觀測**，
  否則它會變成一個查不出來的「為什麼它不做事了」。
```
