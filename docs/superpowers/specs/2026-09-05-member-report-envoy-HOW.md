## §3 ★必須先驗的一個前提（★我不假設）
```
★假設:envoy【抵達】時,既有的 arrival intel exchange 會把【母隊的位置】帶給領袖
⇒ ★★而我【沒有驗證】這一條 —— 它決定本 slice 是「只要派信使」還是「還要帶 payload」
⇒ ★★★驗法:控制床 —— 母隊在遠處觸發事件 → envoy 抵達 → 檢查領袖的
   `known_member_states[母隊]` 有沒有更新成【母隊當時的位置】
⇒ ★若沒有 ⇒ 才需要在回報訊息裡明確帶 pos（而那仍是既有 params 欄位，不是新管道）
```
