# 時間重錨+頻率層級制(WHAT / vision)

owner: blueprint(WHAT)
溯源:用戶 2026-08-20 時間軸系列討論(遭遇戰動作換算合理性→兩圖同速援軍帳→重錨方案用戶自提→全頻率盤點→層級制用戶提框)。素材=`2026-08-20-time-frequency-inventory.md`(全掃描)。

## §0 命門(用戶定)
- **綁死案復活、零繃帶**:世界格時間=遭遇動作×格數,公式無係數。
- **遭遇戰時間尺**(已入意圖帳):同一時鐘 1:1、動作粒度=速度差解析度地板、戰術速≈行軍速(援軍帳)。
- **世界以時間思考**:所有頻率/時長常數以遊戲時間宣告,tick=推導值。
- **頻率=決策層級**:想多勤由「你在想多大的事」決定,不是每系統自己發明一顆 cadence。

## §1 時間重錨
- 1 tick=**1 分鐘**(TICKS_PER_HOUR 10→60、TICKS_PER_DAY 240→1440;根源單點 world_state)。
- 遭遇動作=10 tick=**10 分鐘**(速度差檔位維持)。
- 世界格=動作×MAP_SCALE=240 tick=**4 小時**(平原);`WORLD_SPEED_MULT` **刪除**;A2 四件套出隊列。
- 行為≈不變(移動 4.8h→4h=唯一小 intended;糧耗/格 -17%);UI 播放 `TICKS_PER_SECOND` ×6 同步。

## §2 常數規約(裸 tick 禁絕)
- 全時間常數以 `TimeScale.days()/hours()` 宣告(如 `SALARY_DAYS=7`);**禁裸 tick 字面量**。
- 誠實命名:`PER_TICK` 只准真 per-tick;per-呼叫/per-窗改名。速度類附人話換算(格/天、動作/小時)。
- 審計工作清單=inventory 檔 B 派(~20 顆)+§9 魔法數;`debug/time_const_check.gd`=審計入口、擴充成規約守衛(新增裸 tick=FAIL)。

## §3 頻率層級制(T0-T4)
| 層 | 鐘 | 內容 |
|---|---|---|
| **T0 突發** | **事件驅動、無鐘** | **★所有突發事件全入(用戶定、原則性)**:被襲/跨餓線/勞力危機/關鍵情報/領袖死/目睹滅團/⋯——systems 全量盤點事件型別,**任何突發即喚醒相關決策層,不搞白名單挑食**;新增突發事件必掛 T0(與全量暫態可觀測性同族的不變量) |
| T1 操作 | 1 小時 | 物理心跳(採集/消耗/製造/移動/反應窗)——**不做選擇只執行**;不變 |
| T2 戰術 | 1 天(**試跑**) | task 重評/威脅/整併/子隊/徵收(人格調變保留)/俘虜/求援偵察/溢出 |
| T3 戰略 | 3 天(**試跑**) | 繁榮/goal 生成/居留/獨立戰略 ✓已是+**搬家八支**:個人目標(10h→)/野心階梯(10h→)/勢力戰略 AI(10h→)/結盟傾向(30h→)/背叛傾向(50h→)/基建方向(50h→)/派系更新(20h→)/意圖(1 天→,危機 T0 接管) |
| T4 世代 | 月/季 | 成年/野生再生/規劃視野/季節;現值 |
- 層級鐘=死常數**合憲**(=取樣格/基礎設施,同 TICKS_PER_DAY 類;憲法禁的是死常數替引擎做決策)。
- 人格調變=允許,三條件:劇情內理由+有界(floor/ceiling)+對稱(規則人人適用)。
- 公平三保證:同一取樣格/LOD 率等價不變/T0 人人瞬醒(鐘慢不害死人)。
- **試跑=T2/T3 值 provisional**:新基線考憑質地(故事反應性+效能)定案,考後可調。
