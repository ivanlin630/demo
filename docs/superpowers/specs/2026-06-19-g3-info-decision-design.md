# G3 情報→決策 — 設計 spec

> 藍圖(WHAT)spec。系統接此 → 設計 HOW(schema/公式/LOD)成 plan。
> 擬真審計第三脊椎 = **魂**(資訊不對稱 → 決策)。排序 ①G2 → ②G1 → **③G3** → ④Trait縫。
> game-design 第一賣點「資訊並不透明」「理解世界比戰鬥重要」的落地。

## 1. 問題

魂的底層斷鏈:message_system 會傳播+失真,但**只有交易讀情報內容**;威脅/外交/攻擊讀 `team_discovered`(可見性)不讀情報。①G2(目標讀 team_intel)、②G1(訂單走 message)已起頭。G3 = **把資訊不對稱做深、做成有後果、可被技能識破**。

## 2. 範圍

- **A(NPC 信以為真 + 被騙)+ B(認知/技能揭示),depth = (b)**。
- **OUT**(後續 spec):
  - **C 武器化/情報操控**(造謠/偽軍情/收買信使/封鎖,含玩家情報戰)→ 情報戰 spec。
  - **(c) 完整認知模擬**(每 NPC 世界觀模型 + 推理鏈)→ AI 完美化,measure-first 擋。
  - **信用幣**(money=信任)→ 自己的「貨幣信用」spec,但住 G3 之後同一資訊地基。

## 3. belief 模型(核心改動)

team_intel 從「單一 confidence-max 覆蓋值」→ **保留每目標的多條 sourced claim**(不覆蓋)。
- 每條 claim 帶:**值 / 來源 / 時效(tick) / 可信度 / 是否失真**。
- 不覆蓋 → 才有資料**比對、察矛盾**(現碼覆蓋會銷毀矛盾 = game-design「察覺矛盾」無資料可察)。
- **真值不隨行**:失真在傳播時改寫進 copy,原值不傳(否則人人存真相 = 資訊不對稱破功)。

## 4. 失真

既有(honest / unintentional / malicious / silent)+ 補 designed 模式(部分隱瞞 / 誇大 / 偏見)。
- **紀律**:只補「有決策或技能會讀」的模式,不憑空堆(免休眠)。

## 5. 來源可信度(雙層 × 衰減)

一條 claim 的可信度 = **類型基準 × 身份信任(動態) × 跳數 × 時效**。

- **第一層 類型基準**(game-design 表,直接用):親見 > 隊友 > 商旅(延遲) > 酒館謠言 > 官方(政治) > 書籍(過時) > 流民(情緒)。
- **第二層 身份信任**(track record，魂的核心):不是「商人」類別，是「**這個** X 以前準不準」。
  - 存:**複用 `known_reputations` + ①G2 RelationGraph**(信任=關係邊)。
  - **動態更新**:X 報的查證後對 → X 信用↑；錯/騙 → X 信用↓。
  - → 「可信線人值錢」落地：準線人愈被信、騙子看破後沒人聽。**誰情報網準誰賺/活。**
- **衰減**:跳數(每傳一手 degrade，既有 strength*=0.8)+ 時效(老情報掉分)。

## 6. 技能 = 理解力（b3）

對謊言：**信假 → 生疑 → 裁決**，按「我技能 vs 對方計謀」分級：
- 低技能 → **信以為真**（被騙、得出錯誤結論；低技能不是中立，是主動錯）。
- 中 → **生疑**（知有詐，未必知真）。
- 高 → **裁決**（評可信度 + 察源間矛盾 + 觸發查證 → 可靠源壓倒謊）。
- **非單則 un-distort**（真值不隨行）。高計謀大說謊家騙過多數，笨拙謊對多數透明。
- 相關技能：偵查 / 計謀（識破）、戰術（識破伏兵/佯動）、醫療（看懂病因）等 = 各專業的「理解力」。

## 7. 決策讀 belief（b：不確定性驅動行為）

多源 belief → **(最佳猜值 + 不確定性)**：
- 個性（慎重）要夠確定才敢冒險；**矛盾大/沒把握 → 先查證**。
- **查證迴路複用既有 scout/vision**（派偵查 → Tier0 親見 → 真相浮現 → 才動）。
- 莽者跳過查證 → **被假情報誘殺**。

```
情報打架 → 不確定 → 慎重者派偵查 → 親見壓謊 → 確定 → 動
                  → 莽者 跳過 → 被假情報誘殺
```

## 8. 決策接入面

把更多決策**從讀 team_discovered（可見性）改讀 belief 內容**：威脅評估 / 外交 / 攻擊目標 / 遷徙。
- ①G2 目標、②G1 訂單已起頭 → G3 加深它們讀的東西（含可信度/不確定性）。

## 9. 玩家認知

- 玩家**看 belief 非真相**（多源、帶可信度/疑點，非絕對數字）。
- 技能高 → 識破得多（世界真相隨成長展開）。
- **玩家還不能武器化**（造謠=C，後做），但**吃技能紅利**（被動認知 + 識破）。

## 10. 給系統 HOW（移交）

- **belief multi-claim schema** + **上限/剪枝/LOD/perf**（遠 NPC 別存爆：cap 每目標 claim 數、剪老的、遠區聚合）。
- 失真模式擴充（只補有消費者的）。
- **可信度計算**：類型基準表 + 身份信任（接 known_reputations/RelationGraph）+ 跳數 + 時效。
- **身份信任更新迴路**：查證對/錯 → 回饋調整對該來源的信任。
- 技能 vs 計謀 分級公式（信假/生疑/裁決閾值，TEST VALUE）。
- 查證 wiring（不確定 → dispatch scout，複用 vision Tier0）。
- 決策「估值+不確定性 → 風險調節」模型（個性風險容忍）。
- 各決策接入面改讀 belief（威脅/外交/攻擊/遷徙）。

## 11. 驗收

- **回歸閘**：headless 1000+ tick 無錯 + coin_eq delta=0。不用 multi drift。
- **行為可見**（量測/log）：
  - **被假情報誘殺**案例（莽者吃假情報吃虧）。
  - **慎重者查證**後才行動（不確定→scout→動）。
  - **高技能識破**他人沒識破的謊。
  - **矛盾觸發 scout**。
  - **線人信用漲跌**（準的被信、騙子被棄）。
- **守恆**：belief/認知改動不破壞 coin/pop 守恆。
