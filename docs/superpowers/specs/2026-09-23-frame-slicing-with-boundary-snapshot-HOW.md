## §4 不變量

```
・`advance_tick` 契約不動 ⇒ 模擬端看不出差別（★分片只作用在互動迴圈）
・全量暫態可觀測性：新的 driver 與快照路徑若產生新的 decision／state，必須接 tap
・感知鐵律：本票不碰決策讀值，★但 UI 快照【不得】變成一條繞過 belief 的新讀值路徑
・時間量跨機不可比 ⇒ B3 重跑要帶 [HW] 戳，且與 2026-09-23 這一輪同機才可比
```

## §5 誠實限

```
★樣本是 12 天 × 2 顆種子 ⇒ 它答【方向】不答【分布】。
★★兩顆都是【後半窗】才開始出現 >2s（day6+／day8+）—— 這個形狀本身要被解釋，
  而本 spec 【沒有】解釋它：若修完 p99 降了但那個「後半窗才開始」的形狀還在，
  ⇒ 那代表還有第二個成因，本票沒碰到它。
★★★本票不含【卡頓成因的診斷】—— 它是一個結構修法（把互動迴圈與 tick 解耦），
  而不是「找出那 107 筆是誰造成的」。★那是另一件事，不要在驗收時把兩者混為一談。
```
