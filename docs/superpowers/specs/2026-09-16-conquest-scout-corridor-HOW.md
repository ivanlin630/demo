# 修法：**降成可行性**，不是刪掉行為

```
`confident_enough` 為假 ⇒ **「攻擊這個目標」不可行**
   ⇒ ★**那個攻擊 candidate 不該被產生**（與本專案剛落地的 admission 分層同構）
   ⇒ ★★**而「所以去偵查」回到秤上** —— **偵查 option 已經存在，不必再造一條路**
⇒ **在 candidate 生成時擋，而不是在 dispatch 時改寫結果。**
```
