## ⑥ ★★★重裁後的定案（blueprint 2026-09-10，★本節取代 §② 的做法）

### (0) 先記兩個裁定，因為它們改變了這張票的形狀

```
①「接受世界改變」**不涵蓋**「全世界思考頻率砍半」——它指的是【同一小時內的次序重排】。
   ⇒ ★我沒讓 implementer 動手 ＝ 停得對。
②★★裁【選項 A】：per-team 到期檢查移出 60-tick 全域閘，**改成每 tick 檢查，只此一個 pass**。
③★★★【選項 B 正式處死】：N 桶 ＝ 思考頻率檔次化 ＝ **決策層 LOD** ⇒ **零 LOD 憲法禁**。
   ⇒ ★我原本只說「B 是偷工」，blueprint 把它升格成【憲法引用】——那比我的說法硬。
```

### (1) ★而 A 一旦成立，`CadenceStagger` 就【回到它原本正確的行為】

```
per-tick 檢查之下：某隊上次想 tick = 60+off_prev，下次 candidate = 120+off_new
⇒ 間隔 ＝ 60 + (off_new − off_prev)，★**長期均值恰好 ＝ 60**（偏移量會 telescoping 相消）
⇒ ★★而 `MIN_GAP = cadence/2 = 30` 夾住 wrap 那一次的下限
⇒ ★★★**所以「98.3% 砍半」不是工具壞，是【它被放在一個只看得到 60 倍數的取樣格】上**
   —— 檢查頻率一改成逐 tick，取樣格消失，工具就對了。
⇒ **因此本票仍然【沿用既有工具】，不造新機制**（★而這次是算過的，不是假設的）。
```

### (2) 視野時滯 ≤59 tick：★blueprint 的 WHAT 判詞 —— **【誠實時滯，非退化】**

```
一支在第 97 tick 才想的隊，用的是 tick 60 的視野 ⇒ 最多 59 tick（≒59 分鐘）的資訊延遲。
★blueprint 裁：**這個世界的資訊哲學本來就是 belief 有齡衰減**，
  ★★而「全隊都拿 tick-60 的零時差視野」正是【同步腦假象】的一部分。
  ★★★**拿 59 分鐘前的世界圖像做決策 ＝ 中世紀的正常，不是 bug。**
⇒ 所以它【不是本票要補償的東西】，而是要**寫進誠實限並印在交件裡**（讓下一個人知道它是刻意的）。
```

### (3) 修法（★取代 §② 的做法）

```
①`loop2.solo` 的 per-team 到期檢查【移出】`% NEAR_CADENCE` 那個閘 ⇒ **每 tick 檢查**。
  ★★而【只有這一個 pass】：視野／移動／forced_event 超時等其餘用途**維持每小時**。
②到期時間仍由 `CadenceStagger.next_tick(...)` 產生（cadence ＝ NEAR_CADENCE）。
③★★★新增一支 tap，掛在【到期檢查之後】（只在真的往下跑思考時 bump）——
  ★沿用 `%04d` per-team 格式；★★**既有的 `pass.byteam` 量的是「被排進 all_teams」，
  它錯開前後都會回報逐隊相同，量不到我們要守的東西**（R² 查實，我先前猜對）。
```
