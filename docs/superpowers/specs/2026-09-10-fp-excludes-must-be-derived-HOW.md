# HOW spec：`StateFingerprint` 的「本尺排除：…」必須由 code 導出，不能手抄

owner: systems ｜ 2026-09-10 ｜ 觸發：群乙交件時 implementer 發現
`player_pending_targets` 不在 fp 涵蓋內，而**排除清單沒有列到 `player_*` 那一整塊**。

---

## ① 現況與它的諷刺之處

```
state_fingerprint.gd:10-16
  ★那一段註解本身就是【一次血證的產物】（2026-09-01）：
    有人（systems）拿 fp 當「tracer 沒有污染世界」的證據，
    ★★而 fp 對那個 bug 類別是【結構性地瞎的】—— 不是量不到，是設計上就不看。
  ⇒ 當時立的規矩：凡輸出 fingerprint／比對結果的地方，同一段輸出要帶一行「本尺排除：…」。
  ⇒ :16 的 `const EXCLUDES: String = "…"` 就是那一行的單一來源。

★★★而它是【手抄的字串】：
  現值 ＝ "ephemeral 快取(food_runway/persist_strength/food_flow_avg/need_urgency)
          ＋ cadence 排程欄(*_eval_next_tick) ＋ observer/probe"
  ⇒ **沒有 `player_*`**（`state_fingerprint.gd` 全檔 `player_` 命中 ＝ 0）。
```

⇒ ★**「儀器對某類是瞎的」的修法，當初是【手抄一份排除清單】** ——
★★**而手抄的清單不會跟著世界長大。**
（同一條理由 implementer 已經用過一次：`snapshot_dict()` 用 `get_property_list` 抽而不手抄，
因為「漏掉新欄位的症狀正好是玩家看不到」。★★★這次它長在**儀器的自我描述**上。）

⇒ **這比沒有那一行更糟**：那一行讓讀的人（我，今天）**以為玩家狀態在尺裡**，
於是我寫了一個前提錯誤的驗收格。

---

## ② 修法：把 EXCLUDES 變成【導出值】

```
①在 fp 計算路徑上【記下它實際吃了哪些 state 欄位】（★不是另外維護一張表，
   是讓 hash 的那段程式碼自己回報它讀了什麼）。
②母體 ＝ `WorldState` 的全部 `var` 欄位（★用 get_property_list 抽，不手抄）。
③EXCLUDES ＝ 母體 − 實際吃到的 ⇒ ★**由 code 算出來，每次都對**。
④`blind_note()` 印那個算出來的集合（★可壓成分類摘要，但【必須由算出來的集合產生】）。
```

★**若①做不到（fp 的實作方式不允許自陳讀了什麼）**，退而求其次：

```
一支閘：把 WorldState 的 var 欄位清單 × EXCLUDES 字串比對，
★凡是【不在 EXCLUDES 字串裡、也沒出現在 state_fingerprint.gd 原始碼裡】的欄位 ⇒ 具名紅。
★★這比不上①（它仍靠字串比對），★★★但它至少會在【新增欄位而沒人處理】時變紅，
   而現在的形狀是【永遠不會紅】。
```

---

## ③ 驗收

| # | 格 | 判準 |
|---|---|---|
| ① | **`player_*` 現形** | 修法上線後，`blind_note()` 的輸出**必須包含** `player_pending_targets`（★這是本票的觸發樣本，它必須在第一版就被抓到） |
| ② | **★成對對照：新增欄位會紅** | 在 `WorldState` 加一個假欄位（不進 fp、不進 EXCLUDES）⇒ 閘／導出值**必須**具名它；★★移除後回綠 |
| ③ | **★★不得亂紅** | 一個**真的在 fp 裡**的欄位（例如 `teams`）**不得**出現在排除清單裡 |
| ④ | **fp 值本身不變** | 本票**只改自我描述，不改 hash 內容** ⇒ ★fp 必須**完全相同**（★★這一格與群甲那張相反，因為那張是改行為、這張是改文件） |
| ⑤ | **輸出處都跟著變** | 所有印 `blind_note()` 的地方（★grep 出來逐一列）輸出都更新了 —— **單一來源的意義就在這裡** |

---

## ④ 誠實限與不做

```
①★本票【不擴大 fp 的涵蓋範圍】—— 不把 player_* 加進 hash。
   ★★那是另一個決定（玩家狀態該不該進決定論指紋），要 blueprint 裁，不順手做。
②★★★本票只保證【那一行說的是真的】，不保證【排除的東西不重要】——
   後者要看每一個排除項各自有沒有別的儀器在管（`EphemeralStateHash` 管了其中一塊）。
③不改 EphemeralStateHash。
```

★★而那句謊今天**騙到的第一個人是寫驗收表的我**。
