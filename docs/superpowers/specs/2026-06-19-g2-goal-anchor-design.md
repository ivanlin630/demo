# G2 目標錨 — 設計 spec

> 藍圖(WHAT)spec。系統接此 → 設計 HOW(seam/schema/閾值)成 plan。
> 屬擬真審計「因果脊椎」第一脊椎(行為的因果脊椎)。排序 ①G2 → ②G1 供應鏈 → ③G3 情報→決策 → ④Trait縫。

## 1. 問題

世界「有運動、沒因果」:隊伍 tick-by-tick 飄,個性 roll 出短任務,沒有跨年的人生弧。問「這隊**為什麼**這樣做」答不出。G2 給**行為一條因果脊椎**:隊伍有 leader 驅動的長期野心弧,且**只依殘缺情報**行動。

## 2. 現狀(要收的債)

三套脫節的「目標」:
- **`person.goals`**(個人):birth goals(wealth/escape_war/domination/merit/peace,由 values 生)+ 記憶觸發(revenge/gratitude/protect,指向人)。
- **`get_goal_task_override`**:寫好了**無 caller** → 個人目標**從不驅動行動**,只 `check_goal_alignment` nudge loyalty。
- **`faction.goals`**(字串 tag:徵收/外交/攻擊/掠奪)+ **`strategic_goals`**(expand/defend/trade_net):驅動隊任務,但近乎靜態、與個人目標不通。

G2 統一成「**leader 目標 → 衍生隊/勢力行為**」單一鏈。

## 3. 設計決策

### 3.1 leader 即錨
隊伍無獨立目標。**leader 的人生 = 隊的人生。**
- `leader.values.野心` 定**終極野心高度**(封頂能爬到哪階)。
- 換 leader(死/被替/分裂)→ 隊方向**劇變**(emergent drama)。
- 三套 goal 統一:leader 目標為單一真值源,faction/strategic 行為由其衍生。

### 3.2 野心階梯（archetype 分岔）

骨架五階:`生存 → 積累 → 擴張 → 立國 → 稱霸`
- **當前實際追求** = 現有安全/實力下搆得到的**最高階**(≠ 終極野心)。
- 每階一個**最低安全門檻**(閾值=HOW)。

**「類型」= leader 的 value 側寫,非另開欄位。** 既有 values 已編碼 archetype 傾向(birth goals 即由此生):
- `野心`/`好戰` → **武力**；`貪婪` → **商業**；`義氣`/`慎重` → **定居/治理**。

**下層通用、上層方法分岔**(同一階不同走法):

| 階 | 武力 | 商業 | 定居/治理 |
|---|---|---|---|
| 生存 / 積累 | （通用：先活、再囤資源/人） | | |
| 擴張 | 征服地盤 / 吞併 | 拓商路 / 設據點 | 開墾繁衍 / 招民 |
| 立國 | 軍事政權 | 行會 / 商業城邦 | 領地 / 治理城邦 |
| 稱霸 | 武力霸權 | 經濟壟斷 | 區域繁榮中心 |

- **`野心` 封頂高度**(爬多高);**archetype 選方向**(怎麼爬)。低野心商人卡「積累/小商路」即知足;高野心軍閥一路到稱霸。
- **team tag 跟著漂**(reuse tag drift):換 leader → 換 archetype → 換路(商隊頭子死、野心繼任者上位 → 商隊變劫掠隊)。
- **餵 ②G1 不同需求**:武力路要武器、商業路要貨/商路 → 經濟因果更分明。
- **社會身份(農/商/貴/盜)的額外調制留 ④Trait 縫**,G2 只用 values,不把身份拉前。

### 3.3 升降:門檻為下限 + 個性決定冒進
- 不到門檻不升;安全崩(饑荒/戰敗/人口崩)→ 退階(可一路退回生存)。
- 門檻**之上**由個性決定步調:
  - 高野心 / 低慎重 → **躁進**,搆到門檻就過度擴張 → **可能自崩**。
  - 高慎重 → **鞏固**遠超門檻才動 → 長成穩定強權。
- 設計意圖:同一階梯養出**兩種勢力**(穩健帝國 vs 曇花暴發軍閥)。**過度擴張自崩 = 餵世界興衰**,非 bug。

### 3.4 私人驅動 × 階梯
關係型目標(復仇/守護/逃戰/報恩)疊在階梯上,影響度 = **烈度 × 個性**:
- **弱**恩怨 → **偏置**:不改階梯方向,只調對象(擴張時優先挑仇人那邊)。
- **強**恩怨(高 intensity)+ 衝動(好戰高/慎重低)→ **脫軌**:拉全隊去打仇人,哪怕戰略上蠢、哪怕還在低階。
- 冷靜頭子隱忍積累、莽頭子當場翻桌 → 每條弧不同。

## 4. Graph 縫(在此誕生)

復仇/守護指向**人** → 現有扁平 `p.relations`(`{person_id: float}`)不足以表達「X 殺了 Y 的兄弟」。升級成 **typed-edge 關係圖**。

**硬約束(不可談,否則破縫義):**
- 邊帶**型別** + metadata(intensity / tick)。
- 結構必須**可擴充**:未來加型別 = 加邊型別 + 加 reader,**不重寫圖核心**。
- 必須 admit 的未來型別(系統設 schema 時要塞得進):`kin` / `parent` / `child` / `spouse`(家族樹/繼承)、`master`/`師徒`、宗教/結拜等。

**紀律:形狀通用、內容按需。**
- G2 只**填/讀**它要的型別:`feud`(血仇)/ `killed` / `protect` / `gratitude`。
- 含**血仇傳播**:殺某人 → 其親族/同夥獲 `feud` 邊(恨你)。
- 完整家族樹/繼承 = 縫的**後續內容**(死亡繼承用),G2 不建,只留擴充骨架。
- 不預塞所有型別(否則又是休眠碼)。

## 5. 情報綁定(魂的底料)

目標決策**只讀 `team_intel` / `team_known`(殘缺),禁讀上帝視角(`team_discovered` 僅作可見性,不作真值)**。
- 挑擴張/復仇對象 = 看**傳聞**判斷誰弱、誰在哪。
- **可被假情報騙**:打「聽說很弱」結果硬骨頭 → 過度擴張自崩的另一條因。
- → ③G3(情報→決策)上線時 G2 **立即是其消費者**,不憑空 polish。

## 6. 成員摩擦(複用既有)

成員各有目標,與 leader 階梯不合 → 掉忠誠 / 離隊 / 分裂(reuse `check_goal_alignment` + 既有 defect/split 鏈)。
- 例:「逃戰」成員在「擴張」隊裡 → 不滿 → 走人。= **leader 野心的代價**。
- 不新做機制,只把既有 loyalty 摩擦接到階梯狀態。

## 7. 範圍邊界

- **NPC-only**。玩家無價值觀/目標限制(design 既定:主角無心理限制)。玩家**觀察/利用** NPC 目標。
- **OUT of G2**(明確不做):
  - 完整家族樹 / 繼承(死亡繼承)— Graph 縫的後續內容。
  - 情報操控玩法(造謠/偽軍情)— ③G3 / 情報戰。
  - 玩家主動操控 NPC 目標 — 同上。
  - faction 多隊深層協同編排 — 衍生即可,不深做。

## 8. 給系統的 HOW(spec 移交項)

WHAT 已定,以下為系統設計 plan 時的決策點:
- 三套 goal 統一的 **seam / 單一真值源**(leader 目標 → faction/strategic 衍生)。
- typed-edge 圖的 **schema / index / 查詢**(滿足 §4 可擴充硬約束)。
- 階梯各階**最低安全門檻閾值**(餘糧/基地/兵力;全 TEST VALUE,走後續正式平衡 pass)。
- 階梯 rung → 既有 `TASK_*` / `faction.goals` tag 的**行為映射**(含 §3.2 archetype 分岔:每階武力/商業/定居三走法各對應哪些 task/tag)。
- **archetype 從 leader values 的判定**(野心/好戰→武力、貪婪→商業、義氣/慎重→定居;混合側寫的決勝規則,TEST VALUE)。
- `get_goal_task_override`(dormant)接入點 vs 重寫。
- 升降 / 冒進 / 脫軌的**個性公式**(野心/慎重/好戰 權重,TEST VALUE)。

## 9. 驗收

- **回歸閘**:headless 1000+ tick 無錯 + coin_eq delta=0(4 config)。**不**用 multi drift(無 seed,不可重現)。
- **行為可見**(量測 / log):
  - 階梯**多階弧**出現(同一隊跨時間爬階),非全卡單階。
  - **兩型勢力**:觀測到過度擴張→自崩 與 穩健成長 並存。
  - **脫軌事件**:強恩怨+衝動頭子 derail 可觀測。
  - **情報誤判**:有隊依錯情報行動受挫的案例(為 ③G3 鋪路)。
- **守恆**:Graph / goal 改動不破壞既有 coin/pop 守恆。
