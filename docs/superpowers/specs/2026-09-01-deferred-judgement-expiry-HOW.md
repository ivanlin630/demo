# ★★②形狀裁定：**掃描一行，不做現況板**

# ★★★③判準：**不是「到期日到了 ⇒ 紅」，是「判決失去對象 ⇒ 紅」**
```
一條 b_defer 規則存在的理由 ＝ 「現在有東西命中它，而我們決定【延後】處理」
⇒ ★命中數 == 0 ⇒ 延後的【對象不存在了】⇒ 判決失去對象 ⇒ ★★紅
```
★**為什麼不用到期日**：★★**到期日需要有人【寫對】，而「對象還在不在」是機器本來就在算的東西。**
★★★**而它會在 S2 merge 的當天就紅** —— 這次的兩條，用這個判準會被當場抓到。
