# G1 供應鏈 — 設計 spec

> 藍圖(WHAT)spec。系統接此 → 設計 HOW(seam/schema/閾值)成 plan。
> 擬真審計第二脊椎(經濟的因果脊椎)。排序 ①G2 → **②G1** → ③G3 → ④Trait縫。
> 上游:①G2 archetype 生需求(武力→武器、商業→貨/商路),G1 接其需求信號。

## 1. 問題

世界「有成交、沒經濟」:有單隊供需定價、merchants 找估值差,但缺三塊——**貨幣生產**(W8 礦沒人挖、幣沒人鑄、coin 純零和)、**生產看需求**(有料就造不管市場)、**跨隊跨地分工鏈**(沒有礦村→冶煉→武器匠→軍隊的流動)。G1 給**經濟一條因果脊椎**:貨物沿分工鏈流動、需求驅動生產、錢被造出來——且市場知識走殘缺資訊。

## 2. 核心架構:湧現式區域市場

**(b) 分工鏈 + 訂單系統 + 既有消息系統 = 區域市場自己湧現。**
- **無中央撮合器、無全域價格表、無市場實體。**
- 價格 local(`local_value` 已是);**會傳播的是「哪缺貨/誰出價」的知識**,走消息系統 → 殘缺/延遲/失真。
- 市場 = 這張資訊網。

## 3. 訂單系統

- **雙向**:買單(要買 X)+ 賣盤(要賣 Y)都發。鏈要成立 → 礦村喊「礦出售」、軍隊喊「徵武器」。
- **走既有 message_system 傳播**:複用現有 propagate + distort,**不新做失真**。
- **coin 或 barter 計價**:訂單帶「要什麼 + 能付什麼(coin/貨/混合一籃)」,履約方用既有 `evaluate_offer` 估值判划不划算。

## 4. 履約風險(= a 吃癟有代價)

商隊聽「X 鎮高價收武器」→ 趕到撲空(過期)/假價(失真)→ 該鎮現不缺武器 → `local_value` 供過於求**壓價** → 賤賣或白扛 = **真虧**(白跑的糧/疲勞 + 賤賣)。
- **準情報值錢、套利有風險有回報、可信線人 > 酒館謠言。**
- **複用既有 local_value glut 定價,不新做。** 沒風險的市場是死的。

## 5. 物物交易

- **base layer。** coinless 隊**照樣交易**(貨換貨,等 `local_value` 互換)。沒人被踢出經濟。
- **雙重巧合摩擦**(只有「有 X 又要 Y」的人才接 barter 單)→ barter **黏本地、慢**;coin **全域流通**。
- **不另做 barter 系統**:= 付款非 coin 的 offer,同一套估值。
- 分兩級經濟:有 coin(交易快廣、能囤值) vs 物物為生(二等)= 擬真社會紋理。

## 6. 貨幣生產(W8)— 實物幣 specie

**coin = 金銀實物鑄造的實物幣(specie),非信用幣。**
- 機制:金銀礦從 tile 挖(harvest)→ 鑄幣配方(ore_gold/silver → coin)→ **任何有鑄幣設施的隊都能鑄**(specie 不需主權,金屬即價值)。
- **守恆安全**:鑄幣 = ore_gold(本就值 10)→ **等值** coin,**換形不生值** → `coin_eq` 守恆、閘不破。修掉 W8「錢生不出來」但不憑空造價值。
- **face value 1.0 維持有效**:coin 是熔的稀有金屬,供給被**礦量**天然卡死 → 無通膨、無需通膨模型(避無底洞)。
- **G2 咬合**:金銀礦是**領土** → 誰控金礦誰能鑄更多 → 經濟力綁地盤/政治(不靠人工「立國 gate」)。

## 7. 分工鏈湧現

鏈(礦村 → 冶煉鎮 → 武器匠 → 軍隊)**從每段供需 + 訂單自己長**,不建鏈結構。
- 礦村餘礦(local 低值)→ 賣盤;冶煉鎮缺礦(local 高值)→ 買單;**商隊(G2 商業 archetype)套利搬運**。
- 多段 = 多個單段供需差自然串成鏈。

## 8. 生產看需求

有設施**不再盲造** → 朝**已知訂單 / 在地短缺**生產(複用訂單當需求信號)。

## 9. 接 G2

- archetype 導需求:武力路要武器、商業路要貨/商路。
- **商業 archetype 跑商路 / 履約 / 套利**(誰當商人 = G2 決定)。
- 金礦控制 = 經濟力 → 餵 G2 領土野心。

## 10. 範圍邊界

- **world-sim-first**。玩家**聽到訂單(消息)→ 可履約 / 可發單** = 湧現商人玩法,**無 bespoke 玩家機制**。
- **OUT(明確不做)**:
  - **信用幣 / 主權發行 / 異地折價 / debasement 崩盤** → 移出。money=信任=資訊 是**魂**,歸 ③G3 之後「**貨幣信用**」spec(需信任建設 + 會破 face-value/守恆,不入基底)。
  - 情報操控 / 偽訂單散佈(主動造假)→ ③G3 情報戰。
  - 完整市場實體 / 中央撮合 / 全域價格發現。
  - 通膨 / 貨幣政策模型(specie 規避)。

## 11. 給系統的 HOW(spec 移交項)

- **訂單**訊息型別 + 生命週期(發布 / 過期 / 部分履約 / 完成 / 撤單)。
- 訂單**接 message_system 傳播**(沿用 distort/delay)。
- **生產決策讀訂單 / 在地短缺**的接點(demand-driven production wiring)。
- **鑄幣**:ore_gold/silver tile 挖採(harvest 接入)+ 鑄幣配方(ore→coin,守恆等值)+ 鑄幣廠設施(已存在,W8 記「從沒用」)。
- **商隊(商業 archetype)**履約 / 套利 / 跑商路的決策(接 G2 archetype + 殘缺情報)。
- 確認履約撲空走既有 `local_value` glut(無新機制)。
- 訂單計價估值複用 `evaluate_offer` / `TradeValuation`。
- 全閾值(鑄幣率 / 訂單壽命 / 採礦率)= TEST VALUE,走正式平衡 pass。

## 12. 驗收

- **回歸閘**:headless 1000+ tick 無錯 + **coin_eq delta=0**(鑄幣須守恆 = 等值換形,**這條是 specie 設計的硬驗證**)。不用 multi drift。
- **行為可見**(量測 / log):
  - **訂單發→傳→履約** 鏈出現。
  - **分工鏈湧現**:觀測到礦→冶煉→武器→軍隊的跨隊貨物流動。
  - **coin 被鑄**(W8 解:鑄造 Δ > 0、ore_gold 挖採 Δ > 0)。
  - **barter 在 coinless 區主導**、coin 區交易更廣。
  - **履約撲空虧損**案例(情報價值,為 ③G3 鋪路)。
- **守恆**:鑄幣 / 訂單成交不破 coin/pop 守恆。
