# 後勤統一（Logistics）— 供給跨距離移動 — WHAT 設計

**日期**：2026-07-31
**owner**：blueprint（WHAT）→ 交 systems 做 HOW
**規模**：★大 arc、真新元件（非「接線」）。三層、分 slice、後勤地基先。

---

## 0. 一句話

補上經濟缺的循環系統：**供給（食/料/工具/一切）能跨距離移動到需要的地方**。三層——**後勤**（把自己的供給運過去）、**分配政策**（領主拿到後怎麼給居民，人格驅動、施捨↔剝削、餵動亂）、**貿易**（跟外面換到自己沒有的 + 逃離內部剝削）。三層各有用、誰都不取代誰。

---

## 1. 病根（code 驗過）

整個 session 挖到底的根：**東西產得出來、決策做得出來，但供給不會移動到需要的地方。**

- **料生產→公庫是好的**：採集自動按稅率上繳**站立 tile 的公庫**（`resource_system:20-22,78`；food/material/goods）。礦/糧直接進公庫（:278）。
- **公庫是 tile-local**：建設先扣站立 tile 公庫（`_deduct_cost:780`）、吃糧從自家糧倉、auto-withdraw（mounts, `faction_ai:624`）——**都是「人在那格上」才用得到**。
- **★缺口：公庫的料要「出門」跨距離到別處，沒有任何自動路**。遠端殖民地餘料回不了母隊、founding 隊帶不夠糧餓死、圍城軍缺補給——全是同一件事：**沒有「把供給運過去」的系統**。
- 現有的搬運全是**散的 ad-hoc**：auto-withdraw(mounts)、provision-carry(food)、harvest-carry、remote-tribute、runway 糧橋——**各做各的、沒統一**。

**∴ 後勤 = 統一這些散件的「供給移動」維度**（矩陣漏掉的一維）。

## 2. 缺的兩個東西（承 §1）

1. **供給移動系統**（後勤）：把供給物理運到別處。
2. **內部分配是機械水管、沒政治**：領主對自己居民只有「自動福利 or 無」，沒有人格驅動的施捨/剝削光譜——經濟缺戲、缺政治。

---

## 3. 三層設計

### 3.1 後勤（transport）— 中性搬運層
把**自己的**供給跨距離運到自己的別處。一次運補 = {從哪 vault、到哪、載什麼 cargo、走多久、路線、**會被劫**}。
- 用途：供軍、殖民地餘料運回中央、糧橋補遠征、補給前線。
- **物理**：運輸隊真的走、要時間、**補給線可被切斷/劫掠**（= 真 gameplay，接時間尺度距離×時間）。**不是瞬移。**
- **不涉價、不換手**（同所有權內調度）。
- runway 糧橋（載重/糧/距離，已 banked）= **本層的現成零件**。

### 3.2 分配政策（distribution）— 領主人格驅動、餵動亂
領主拿到供給後，**怎麼分給治下居民團**——**人格 WEIGH，非腳本福利**：

| 領主人格 | 分配 | 後果 |
|---|---|---|
| 義氣/仁厚 | 缺就發、低價/免費 | 居民擁戴 |
| 貪婪/無良 | 囤 + **高價賣給自己的居民**（壟斷剝削） | 居民苦 → unrest |
| 忽視 | 不管 | 居民自生自滅 |

- **「補給到什麼程度」= 領主分配政策決定的，不是後勤自動福利**（否則稀缺消失、無戲）。
- **餵現有 unrest/defection 管線**：被剝削居民 → unrest 累積 → 脫離/投靠/造反。
- 憲法：領主貪婪/義氣是**連續權重**，決定分配光譜，非硬類別閘。

### 3.3 貿易（trade）— 外部交換 + 逃離剝削
居民/勢力跟**外面**換到**自己沒有的**（貨↔coin、跨所有權、在市場）。
- 用途 1：買自己產不出/整個勢力都沒有的（跨勢力專精交換）。
- **用途 2：逃離坑人的領主**——內部被剝削 → 寧可跟鄰國買 → **對內部剝削的制衡**。
- 修現有 GATE-B（trade-trip 決策 under-fire，隊掛單卻不去市場）。

---

## 4. 後勤 vs 貿易：各有用、誰都不取代誰

| | 後勤 | 貿易 |
|---|---|---|
| 搬誰的 | 自己的 | 別人的 |
| 跨所有權 | 否 | **是（換手）** |
| 價 | 無 | **有（貨↔coin）** |
| 目的 | 維持自己運作 | 取得自己沒有的 + 逃剝削 |

**互相搆不到對方**：後勤運不來「你整個勢力都沒有的」（只能貿易買）；貿易搬不動「你自己的餘料回家」（不會跟自己買 → 只能後勤）。
**可共用「東西怎麼在地圖上搬（載重/時間/被劫）」物理零件，但決策/用途各自獨立**——共用物理層 ≠ 誰吃誰。

---

## 5. 憲法對齊
- **utility weigh 非 scripted**：後勤「派 convoy」、分配「給多少多貴」、貿易「去換」皆決策層 util 秤，非寫死。
- **人格 WEIGH 不 GATE**：領主分配光譜（施捨↔剝削）= 貪婪/義氣連續權重，非硬類別。
- **全量暫態可觀測性**：convoy dispatch/arrive/cargo、分配 price/量、unrest 增量、trade fill 全接 tap。
- **★這 session 的鬼（第一驗收）**：決策生成 ≠ 真執行。**後勤只要「派 convoy」也輸 argmax 就是死的**——建時硬驗：convoy 真派、真到、供給真到手（同 trade-trip under-fire、founding-preempt 家族）。

## 6. 範圍：3 slice、後勤地基先（誠實規模——真新元件）

**★這是大 arc、多為真新建**（非接線）：transport 系統、分配政策層、trade-trip 修皆新工。誠實切：

- **SLICE A — 後勤 transport 地基**（最缺、統一散件）：convoy 物件（源 vault/目的/cargo/時間/路線）+ 「派 convoy」決策（要真 fire）+ 供給真到手。折入現成散件（auto-withdraw/provision-carry/糧橋）為零件。**先驗：convoy 真派真到。**
- **SLICE B — 分配政策**（領主人格 → 施捨/剝削 + 餵 unrest）：領主分配 util（貪婪/義氣秤）+ 內部定價 + unrest 耦合。
- **SLICE C — 貿易**（外部 + 逃剝削）：修 GATE-B trade-trip under-fire + 「逃離剝削」動機。

**徵收（levy）另議、別混**（收 coin、政治層，與材料流分開——用戶定）。**公庫、生產不動**（好的）。

## 7. 連結
- **runway 糧橋 banked** = SLICE A 的現成零件（provisioning=後勤特例）。
- **unrest/defection 管線現成** = SLICE B 接口。
- **公庫（tile-local vault）現成** = 後勤的源/目的節點。
- **徵收（levy, coin）** = 分開、本 arc 不碰。
- **時間尺度 wave（距離×時間、④後勤斷糧）** = 本 arc 正是那條「後勤」的正解。
