## §3 ★★★兩個部分，第二個我【不自己定死】
```

   ⇒ ★★而它是【分支】不是【大乘數】—— 乘數再大也只是把機率推高,不是「確定」
   ⇒ ★★★寫入內容:【真 pos ＋ 外觀層欄位】(親見的定義),★不寫內部狀態(那才是 god-view)

      ⇒ ★近場陡、無新常數;★★而它把【遠場也壓低】⇒ 違反目標③(遠處要保留現制)
   候選2 近場/遠場分段:dist <= 1 用陡曲線,其餘沿用現式
      ⇒ ★形狀對;★★而「1」是一個【手填的分界】—— 禁手抄物理那條會咬
   候選3 用既有量當尺度:近場範圍 = vrange 的函數(如 vrange/3),曲線用它縮放

      ⇒ ★★而 3 這個除數本身又是手填的 —— ★★★我沒有一個乾淨的候選,這正是要送審的原因
```

### ★★★★【定案】R² 第四案（2026-09-04）——**零新常數**
```
dist == 0  ⇒ ★分支:確定看見(不進機率閘)
dist <= 1  ⇒ ★★dist_f = 1.0   ←【沿用公式自己在 dist=0 已經定義好的天花板】,不發明新數
dist >= 2  ⇒ ★★★現有公式【完全不變】
```
★**而 R² 點破的區分是關鍵**：**`dist <= 1` 的「1」不是手填參數** ——
```
★離散 hex 距離的 1 是【格點結構事實】(相鄰),★★而 vrange/3 的 3 是【自由選的比例】
⇒ ★★★兩者性質不同:前者由座標系決定,後者由我決定 —— 而「禁手抄物理」禁的是後者
```
★**三段形狀因此成立**：**確定（0）→ 最佳機率（1）→ 現有曲線（≥2）**，
★★**而遠場【逐位元不動】** ⇒ 裁定的「遠處保留現制」拿到的是**最強的保證**，不是「大致相同」。
★★★**誠實限（我自己標）**：**dist=1 的數值變動很小**（現式在 dist=1 約 0.92 → 1.0）
⇒ **真正的變化是 dist=0 那個【分類上的】改變，不是數值上的** —— **這是好事：擾動最小化。**
