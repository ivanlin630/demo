## ★★★★而 S2 有一個【S1b 沒交給它、但它非處理不可】的東西
```
scripts/ui/sim_bridge.gd:7   const TICKS_PER_TURN: int = 24     ←★裸值，不跟隨根旋鈕

```
★**S1b 把它標成「(b) 延後、交 S2」，而它的【設計歸屬】其實是 S7**
（LOCKED §4 七病之一：**「turn 定義統一（60t vs 24t）」**）。
⇒ ★★**兩件事要分開**：
| | |
|---|---|
| ★**S2 必做** | **保住它【現在的真實時長】不被根旋鈕靜默改掉** —— **這是 S2 的直接後果，不做就是 S2 引入一個 bug** |
| ★★**S7 才做** | **「一個 turn 該多長」這個設計問題**（60t vs 24t 的統一） |

★★**這也順帶收掉 S1b 唯一那顆 (b)：`hours()` 只吃整數小時表達不了 2.4h，而 `minutes()` 可以。**
