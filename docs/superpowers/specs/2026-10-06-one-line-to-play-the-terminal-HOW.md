### ★①`Tick/Day`：玩家走法不印，★★而 debug 留著的那一份**要與頂列同源**

```
`text_ui_main.gd:1126`：`"Tick: %d  (Day %d)" % [tick, tick / TICKS_PER_DAY]`
⇒ ★**不一致的真因是【兩個時間表示法不同源】**：這裡 `tick/TPD` **從 0 起算**，
  而頂列走 `PlayerApiMapper.tick_clock()` ⇒ **「第 1 天」從 1 起算**。
⇒ ★★所以**只把它藏起來是不夠的**：debug 走法留著的那一份若還是這個算式，
  **它會繼續說謊，只是沒有人看** ⇒ **debug 那一份也要走 `tick_clock()` 同一支**
  （★「同一句話只有一個來源」—— 今天第 N 次）。
```

### ★★②`比例0%` **不是沒格式化，是標錯主詞**（我查到的，而它比他報的更嚴重）

```
