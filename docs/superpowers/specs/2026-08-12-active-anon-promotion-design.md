## §1 命門（genuine 非 crank、寫死）
- 提拔 = 領主的 **genuine 決策**、非機械、非免費。named-scarcity 是**真壓力**、提拔是**真出口**、出口有**真代價** → 湧現非 crank。
- **禁自動補滿**（「named 不夠就自動生一個」= crank/福利機、殺稀缺）。爛領主/多疑領主/窮領主照樣缺人手 = 分化。
- 與機械誤升（succession 誤觸孤匿名 bug、已除）**涇渭分明**：那是 bug（無故事）、這是領主刻意決策（有動機、有代價）。

## §2 決策（WHAT）
- **觸發/考量**：領主判斷需更多記名（想派任務沒 spare / 壯大村需副手 / 多線任務吃緊）+ **有夠格匿名候選**（資質/技能浮現、非每個平民都幹部料）。
- **util 秤 + 人格 modulate**：野心/擴張 → 樂提充實班底;多疑 → 吝嗇不輕信;絕境（現在就缺手）→ 被迫提。
- **挑誰**：較有能力/技能的匿名（genuine——資質浮現、非隨機）。

## §3 ★genuine 成本（核心、讓它不是 crank）
- 被提者從此是**有身分的個體**（自己的忠誠/慾望/目標）→ ①**脫離可替換勞力池**（少一個 fungible 勞力）②**★未來忠誠風險**（他日後可能不滿/要更多/甚至叛）= **提拔是投資也是賭注**。
- **不可逆**（一旦是誰就是誰、呼應匿名→記名有意義）。
- **optional texture（flag、非本批核心、待需要）**：養成時間 / 其他成員嫉妒反應。用戶未最終敲、build 可先不做、量測若顯不足再加。

## §4 anon→named 三路（本 arc 補第 3）
① 領隊戰死→跟班接班（湧現 succession）② 跟班不爽→脫隊/叛（湧現動機）③ **★領主主動提拔（本 arc、deliberate 決策）**。機械誤升（bug）除。

## §5 量測（湧現、硬數據、4× over-claim 教訓）
- **named-scarcity 紓解**：大床 T12 型 1-named 弱領主 → 有出口後能 genuine 提拔補班底（不再全程 0 派遣）+ 人格分化（野心多提/多疑少提/絕境被迫）。
- **★genuine 非 crank 驗**：提拔**非自動補滿**（有考量/代價、多疑領主照樣少提、窮領主照樣缺）;被提者真成個體（loyalty 可測、日後真可能叛=賭注真實非裝飾）。
- **前後對照**（同大床 4+16 隊：無出口 baseline vs 有出口）→ scarcity 壓力被 **genuine 紓解 vs 被玩壞（crank/補滿）**。
- 禁預設 payoff、RNG-confound 誠實標、UNTESTABLE 照實報。determinism / regression / constitution 綠（提拔=決策非硬閘、無新死常數）。
