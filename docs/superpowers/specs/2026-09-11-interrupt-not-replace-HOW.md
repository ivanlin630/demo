# HOW spec：**插斷非取代** —— ★用既有的「承諾」語彙，零特權走廊、零新機制

owner: systems ｜ 2026-09-11 ｜ **WHAT 授權**：blueprint 裁（插斷非取代 ＋ 目標校準 ＋ 成對驗收）

## ⓪ ★★★病的形狀：**插斷變成了取代**

```
量到的：`try_set` **noop 42／59，全部被「覓食」擋**；而抵達的 4 支**抵達當下已經不是求居者**
⇒ ★覓食走 survival ⇒ **PRIO_SURVIVAL(80)**；而仲裁對 ≥`PRIO_THREAT`(70) 的一側**不介入**
  ⇒ ★★**求居(50) 不是輸，是連比都不比**。
⇒ ★★★而 blueprint 的裁定**沒有改那一條**：**真餓先吃仍然對、當下照贏** ——
  要修的是**吃完之後**：**恢復被插斷的承諾，而不是把它丟掉**。
```

## ① ★★而這個語彙**已經存在**（★不是新機制）

```

  ＋ ★★★**掃描閘**：**新增承諾類欄位而沒分類 ⇒ 紅**（覆蓋是構造性的，不靠誰記得列全）
```

## ② 做什麼（★三件，全部落在既有語彙裡）

```
①**求居成為一個「承諾」**：加對應欄位並**在 `commitment_fields.gd` 分類**
  ⇒ ★★那支掃描閘會**強迫**這一步（沒分類就紅）—— ★★★**不要繞過它**。
②**插斷**：覓食（survival）照舊贏、照舊插斷 —— ★**這一條一個字都不改**。
③**恢復**：survival episode 結束走 `release()` → **re-rank**
  ⇒ ★而承諾**活過那次 release**（既有設計）⇒ 求居在 re-rank 時**重新是可選的**
  ⇒ ★★**不加特權、不加常數** —— ★★★而「承諾慣性」本來就是**決策層的加分項**

```

★**唯二出口要明確落地**（★★否則就是那條「禁死旗」）：

```
①**重派成任務**（吃完了、再上路）
②★**引擎解承諾**（重秤之後**真的放棄** —— 例如目標村沒了、或它決定去當遊商）
⇒ ★★★**既不重派也不解 ＝ 本票自己製造了一個新的手不聽腦** —— 驗收要擋住這一格。
```

## ⑦ ★★★R² 回件：**三格全有用，而 (3) 是一個我沒看到的覆蓋邊界**

### (2) 門檻：★90% 可信；★★**30% 改成【綁基準】**


### (3) ★★★掃描閘的**真實覆蓋邊界**：它只逼**分類**，不逼 `unfinished()` **真的長出分支**

