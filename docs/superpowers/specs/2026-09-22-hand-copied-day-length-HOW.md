# §0 事實（★我自己 grep 過，不是轉述）

```
真值：WorldState.TICKS_PER_DAY ＝ TICKS_PER_HOUR × 24 ＝ 1440（world_state.gd:16）
而手抄成 240 的至少四處：
  scripts/debug/world_sim.gd:36-42        `(tick+1) % (240*30)`（月）／`% 240`（日）
  scripts/debug/crisis_override_test.gd:9 `const TPD := 240   # WorldState.TICKS_PER_DAY`
      ⇒ ★★★它的註解【自己說它是 TICKS_PER_DAY】—— 手抄 ＋ 已經腐爛
  scripts/debug/game_sim_test.gd:158,165  `(tick+1) / 240`（日）
  scripts/debug/construction_funnel_bed.gd:162 `day=tick/240`
```
★**後果**：這些工具印出來的**天／月／年全部差 6 倍**（120 天被印成「2.0 年」）。
★★**而它不改變模擬** —— 世界照跑，錯的只有**標籤** ⇒ **次數／比例不受影響，敘述全錯**。

# §1 這是【已立法】那條的再犯

`memory: 估算器禁手抄物理`（用戶立法 2026-08-21）：**血統②手抄物理常數全禁**；
**修法形狀＝改接線，不是改數值**（把 240 改成 1440 三個月後會再爛一次）。
⇒ ★**所以修法是【讀 `WorldState.TICKS_PER_DAY`】，不是把 240 換成 1440。**
