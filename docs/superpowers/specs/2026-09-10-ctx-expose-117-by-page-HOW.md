## ② 每批的完成定義（★不是「我端了幾欄」）

```
①該頁所有欄位在 ctx-exposure.tsv 的 status ＝ exposed，且 who 欄寫【哪一支公開動詞】
  ——★不是「應該可以拿到」，是那支動詞的名字。
②★★覆蓋率閘 PASS（含它自己的四格陽性對照）。
③★★★該頁的欄位【真的能從 agent 層拿到】——
  用一段最小腳本呼叫那些動詞、印出該頁全部欄位，貼進交件。
  ⇒ 理由：C1 票① 已經有過一次血證——`map_global_messages` 早就存在，
    但只接了 GUI（`sim_bridge`）沒接 agent 層 ⇒ ★【函式存在】與【玩家拿得到】是兩件事。
```

★**不算完成的三種**：

```
①把欄位標成 exempt 來讓帳面好看 —— ★豁免要【呈用戶簽】，沉默不是豁免。
②端出一個【引擎沒有的值】（例如查詢時重新 gather）——
  ★★「觀測改變被觀測物」今天已有血證；沒有快照就照 inspect 票的形狀
     印 `{snapshot:false, note:"…"}`，★★★而那一格交付的是【玩家知道自己看不到，以及為什麼】。
③把 117 這個【名字比對的差集】當成進度數字 —— ★它改個名字就會降。
  ★★唯一算數的讀數是覆蓋率表。
```
