# Agent Workflow

```
┌─────────────────────────────────────────────────────────┐
│  1. 需求輸入                                              │
│     User / Tech Lead 描述任務或 bug                       │
└──────────────────────┬──────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────┐
│  2. 情境收集（Explore）                                   │
│     • 閱讀相關 .gd 檔案與 README                          │
│     • 確認影響範圍（哪些系統會受牽連）                      │
│     • 不足時向使用者提問（最多 3 個問題）                   │
└──────────────────────┬──────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────┐
│  3. 計劃（Plan）                                          │
│     • 列出 Todo，標示優先順序                              │
│     • 確認不超出 Agent 可動作範圍                          │
│     • 若需改動架構，提交 Architect Agent 審核              │
└──────────────────────┬──────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────┐
│  4. 實作（Implement）                                     │
│     • 每次只改動一個 Todo；改完立即標示 completed          │
│     • 遵守程式碼規範（coding-standards.md）               │
│     • 每 3–5 個步驟回報進度                               │
└──────────────────────┬──────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────┐
│  5. 驗收（Review & Accept）                               │
│     • Review Agent 或 Tech Lead 審查                      │
│     • 確認符合交付標準（delivery-standards.md）            │
│     • 通過後更新文件（由 Doc Agent 執行）                  │
└─────────────────────────────────────────────────────────┘
```
