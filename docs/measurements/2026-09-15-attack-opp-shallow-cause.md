## ① 重現那三個數（tier2 內、依 `loot` 分桶的平均 `opp`）

```

```

## ② 無牙比例（★預註冊的第二步）

```
   tier2 lootHi  n=73  ⇒ **odds == 0 的有 55（75%）**
   tier1 lootHi  n=120 ⇒ odds == 0 的有 19（16%）
   tier0 loot0   n=160 ⇒ odds == 0 的有 23（14%）
⇒ ★★**tier2 的頂端桶裡，四分之三是無牙的隊伍**。
```

## ③ ★★★排除無牙之後：**「淺」消失了**

```
   tier2  lootHi = **0.233**（n=18）  ← 排除前 0.057 ⇒ ★**4.1 倍**

⇒ ★**「淺」的名字就是【無牙混進了平均】** —— 而它是預註冊的三個候選之一，不是事後挑的。
⇒ ★★所以 `tier2` 的頂端**不是「知道得多卻不想打」**，
```
