## B. ★★★而最大的變化不在偵查，在**攻擊**

```

攻擊 贏 argmax：    before 3 次     →  after 3 次

```
★**贏的次數沒變、候選幾乎沒變，而【派出去】從 0 變成 6。**
★★**機制上說得通**：admission 把**沒把握的目標**擋在候選之外
⇒ 被選中的 prey **本來就是有把握的** ⇒ `_commit_conquest_attack` **不再中途 abort**
（實測 `conq.commit_abort.not_confident = 0`）。
⇒ ★★★**這一票真正改掉的是【意圖變成行動】那一段** —— **而那正是舊走廊吃掉的東西。**

★**誠實限**：**6 次很小**，單 seed ⇒ **存在性可引用（0 → 非 0），比率不可引用。**
