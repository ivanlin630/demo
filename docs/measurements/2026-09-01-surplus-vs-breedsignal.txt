# ★★★盈餘 → 生育 對帳：斷點【兩個，都量到了】
#
# ═══ 這條線的四段（母體先寫死）═══
#   A 名額閘   `minor_population >= maxi(1, pop*0.25)` ⇒ return
#   B 訊號閘   `f = breed_f(breed_rel_surplus(team))`，f<=0 ⇒ return
#   C 適齡閘   逐人 needs.safety>0.7 且 needs.food>0.7 且 _breed_balance>0；daily<=0 ⇒ return
#   D 累積     `progress += daily × elapsed_days`，跨 1.0 才生
#
# ═══ ★★★結論 ═══
# ①【B 段斷】9/10 隊：★inflow−burn 有 74–90 個盈餘天，而 breed 讀的 rel_surplus【>0 的天數只有 0–10%】
#    ⇒ ★★兩個量【連正負號都不同】：平均 rel_surplus 是 −0.08 ~ −0.36
#    ⇒ ★★★原因在【它們是不同的量】：
#         盈餘  ＝ FoodFlow._sustainable_inflow − burn        （產出 − 消耗）
#         breed ＝ team.food_flow_avg ＝ effective_food 的【存量差分】EMA（resource_system.gd:291-300）
#       ⇒ 存量會被【消耗以外的路】帶走（交易/給養/搬遷…），所以「產出>消耗」時存量仍可能在跌
# ②【D 段慢】唯一讀得到盈餘的 team9：rel_surplus>0 佔 69%、均值 +0.192（>K=0.15）、名額從未滿
#    ⇒ ★而它 90 天仍沒生：★★平均適齡人數 ＝ 2.00，而設計假設是【5 人】
#      （reaction_system.gd:7-11：1/30 = 0.0133 × f(0.5) × eligible(5)）
#    ⇒ ★★★速率 2.5× 慢 ⇒ 估算 90 天累積 ≈ 0.92 —— 【差一點點到 1.0】
#
# ═══ ★假說被推翻的紀錄（★留著，因為它是判準怎麼收斂的）═══
#   我的第一個假說：「存量到 cap ⇒ 差分歸零 ⇒ 訊號歸零」
#   ⇒ ★量到糧倉飽和度 0.000–0.026（離 cap 很遠）⇒ ★★假說錯
#   ⇒ ★★★而錯的方式有意義：不是「存量滿了不動」，是【存量在跌】—— 方向相反
#
