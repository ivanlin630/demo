  ⇒ ★★★單幀 >2 秒 ＝ 0 這條終線**不動**，而它從今起要在**活的世界**上達成

### ★★★什麼樣的 merge 才開新世代（判準，免得下一個人憑感覺）

```
★**開**：一個 merge 讓**某一類行為的發生率跨了一個量級**
  （例：2.5% → 75%｜静音 → 常態｜0 → 非 0）
  ⇒ 因為**舊數字的母體本身變了**，不是只有數值變了。
★★**不開**：純觀測（tap）／效能／修 bug／參數微調／只改工具與文件
  ⇒ ★★★**每次 merge 都開一代 ＝ 世代這個概念失效** —— 它的價值在於【少】。
★開了之後要做的只有一件：**在本檔加一段**（sha ＋ 理由 ＋ 受影響的分布）。
```
