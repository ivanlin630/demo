## ★七條缺陷（逐條指向下面原文裡的那一行）

```
①右框標題漏出一個 `[`：`┬─ [── 生存 (1/5) ──`
  （`tabs` ← `UiPages.header()` 之後 `.trim_prefix("[")` 只剝掉一個）        ⇒ 自驗 (a)
②`── 生存 (1/5) ──` 在【框標題】與【框內】各出現一次                        ⇒ 自驗 (b)
③`聚焦:   { "health": "", "stress": 0, "loyalty": 0 }`
  ＝ 原始 Dictionary 印給玩家 ＋ 英文識別字                                  ⇒ 自驗 (d)
④`── 未分類（票B 將搬走：2 行，皆為跨頁混合（拆行是另一張票）`
  ＝ 開發備註印在玩家畫面上，而且括號不平衡／被截斷                          ⇒ 自驗 (a)(e)
⑤★★★`── 真值·debug（非附身者所知） ──` ＋ `tile_id=9002`／格上真實資源／格上隊伍數
  ＝ **god-view 落在玩家面上，而那一區的標題逐字自稱「非附身者所知」**
  ⇒ 它自己說它不該被玩家看到，而玩家正在看它。★感知鐵律管【決策】不管【顯示】
    ⇒ 不是違憲；★★但這張票正在把這個畫面變成**唯一介面** ⇒ 交玩前要消失。
    ⇒ 「消失」有兩種（整區不印／移到明確的 debug 旗標下）⇒ **待 systems 裁**
⑥`─ 動作（0／0 可做，未綁鍵 0）` 與 `─ 事件（最近 8 條）` 都是**空區塊**      ⇒ 自驗 (e)
⑦事件區之後還有一條**空的分隔線**                                           ⇒ 自驗 (e)
```

★★而這七條**不是讀 code 讀出來的，是把畫面印出來才看到的** —— 與「宣告『沒有人在做 X』
之前先去讀真的在做 X 的那個東西的輸出」同一條。GUI 版把它們藏在 `visible = false` 的 Label
與一個沒人會截圖的視窗裡；終端版**一跑就全攤開**。
