# 估算器總帳（estimator ledger）

**立帳**：2026-08-21，**用戶令**：「**三個說謊的抓到了，別等第四個靠餓死一村曝光**」。
**審計尺**：意圖帳〈**估算器 ＝ 信念追物理真形狀**〉row。
**範圍**：引擎裡所有「**算給決策看的預估值**」。
**與缺件表互補**：**缺件表 ＝ 沒算的維度**；**本帳 ＝ 算了但算錯的**。

**分工**：**systems 列族譜＋假設欄（code-read）**／**measurer 抽驗物理欄（實測）**。
**分類**：`誠實` ／ `說謊` ／ `未驗`。**負斷言紀律：窮盡列舉、禁 `head` 截斷。**

## ★輸入血統（用戶立法 2026-08-21，`no-copy-law`）

| 血統 | 定義 | 合法性 |
|---|---|---|
| **①讀真實狀態** | 直接讀世界／自身當下值（食物存量、實際被動所得） | **誠實**，鼓勵 |
| **②手抄物理死常數** | 把物理常數**再抄一份**進估算器（`2.0` 格/日、`3.0` 天） | ★**禁止**——**物理存兩份必 drift** |
| **③純設計尺度** | 不對應物理量的設計旋鈕（耐性天、安全係數） | **合法**（多已人格化） |

**★【估算器禁手抄物理】**：估值必須
**(a) 從物理同源推導**（移動估 ＝ 移動系統同顆常數；工期估 ＝ 工期表 ÷ 自隊勞力 ÷ **施工推進 cadence**），或
**(b) 讀自身狀態／經驗**（覓食基準 ＝ **實際被動所得**）。

**∴ 修法形狀 ＝ 改接線，不是改數值。**（把 `2.0` 改成 `5.0` ⇒ **三個月後又爛一次**。）
**②類全數改推導／讀態。** 守衛見 §F。

## I. `CAMP_MARGINAL_CAP` 飽和實測 ＋ **我自己的過強說法訂正**

**measurer 2026-08-21**（母體 ＝ plain counter，**不受 first-N 影響**；200 筆 sample 只供分佈觀察）：

| 指標 | 值 |
|---|---|
| **飽和率** | **35.0%（122 / 349）** |
| clamp 前 `raw_ratio` **max** | **4.00**（＝ cap 的 **2.67 倍**） |
| clamp 前 `raw_ratio` **median** | **0.87**（**< cap，典型情況沒觸頂**） |

⇒ **35% 的評估在 clamp 前就 ≥ 1.5 被砍平** ⇒ **高產地與「剛好夠格」的地拿到完全相同分數**，
**真實品質差距（1.5 – 4.0 這一段）被 cap 完全抹平。**

### ⚠️ 訂正：我先前的說法**過強**
我寫過「**cap 吃掉折現磚的全部鑑別度、紮營變成常數滿分 ⇒ 人格失效（正好解釋「義氣隊未投靠」）**」。
**median 0.87 < cap ⇒ 65% 的情況鑑別度是好的，紮營不是常數。**
∴ ★**「cap 導致人格失效、解釋義氣隊未投靠」這個說法不成立，撤回。**
（那條紅的主因已另有解釋 ＝ **投靠的 host 未來流沒進秤**，有 file:line。）
**成立的部分是**：**頂端 35% 失去鑑別度** —— 真缺陷，但範圍比我說的小。

### ★這仍然是缺陷，理由不是「飽和率高」而是**量綱**
`marg / daily_need` **本身已經是正規化過的量**（單位 ＝ **日需的倍數**）。
在一個已經無量綱的比值上再 clamp 到 `1.5`，等於宣稱：
**「超過 1.5 天份的邊際產出，不再更有價值。」**
★**那是一個未宣告的價值判斷，不是量綱需要。**

### 修法形狀（**已開票，排 camp v2 之後**）
- ★**禁止只改數值**：把 `1.5` 改成 `4.0` **又是一顆手抄常數**，正面違反〈估算器禁手抄物理〉。
- **正確形狀二選一**：
  ① **移除** —— 四端同秤之後，跨選項可比性來自**共用的折現尺**，不再需要 per-term clamp（cap 是舊尺時代的補償夾具）
  ② **由真實量導出上界**（若確實需要上界，它必須來自某個世界量，不是一顆 TEST VALUE）
- ★**兩個消費端**：`terms.gd:212`（`camp_drive`）與 `terms.gd:233`（另一 term）**共用同一顆 cap**
  ⇒ 動它會同時影響兩處，**驗收要涵蓋兩邊**。
- **驗收**：de-patch 後重量 **§7 三條 ＋ 四端 `lost_to` 分佈 ＋ headless**；
  ★**若紮營因此壓過其他選項，那是真結論，照實報，不准回頭改 cap 藏起來。**
