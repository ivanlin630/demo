每項任務交付前須滿足以下所有條件：

| 項目 | 標準 |
|---|---|
| **可執行** | 按 F5 可正常啟動，無 GDScript 錯誤 |
| **功能完整** | 需求描述的行為可被重現 |
| **不破壞現有功能** | 原有按鍵與回合邏輯行為不變 |
| **數值可調** | 新增數值參數放入 `game_config.gd` |
| **文件同步** | 若新增/修改公開 API，需更新 `README.md` 對應段落 |
