# Project Goals

對應 [game-design.md](game-design.md) 四階段開發優先順序。

---

## 第一階段 ✅ — Vertical Slice（核心可行性驗證）

> 目標：讓人能玩到「資訊不對稱 + 世界自行演化」的核心體感。

- [x] 六角格大地圖，支援玩家移動
- [x] 統一時間系統：半即時回合制（可暫停、可切換）；1 Tick = 可設定秒數
- [x] 基礎資訊傳播：事件 → 透過人際/信使/商旅/流民延遲擴散 → 玩家只看主觀認知
- [x] 聚落聚合模擬（人口、糧食、武力）；不逐人計算，降低 CPU 消耗
- [x] 基礎遭遇戰（六角格、半即時），世界尺度與大地圖一致
- [x] 玩家死亡後可接手 NPC 繼續遊玩

## 第二階段 — Demo（可展示品質）

> 目標：讓玩家感受到「信任、欺騙、社會關係」帶來的決策張力。

**NPC 個體化**
- [ ] 與玩家深度互動後生成 NPC 個人檔案（性格、技能、目標、社會身份）
- [ ] NPC 目標驅動行為：求生、復仇、致富、晉升等長期目標影響合作與背叛

**記憶系統**
- [ ] 重大事件留下帶強度的記憶（輕微 / 深刻 / 刻骨）
- [ ] 記憶影響信任、好感、仇恨、忠誠；部分記憶隨時間淡化

**傳聞系統**
- [ ] 資訊多手傳遞後按來源可信度失真（如實/扭曲/不傳）
- [ ] 每條資訊帶來源、時間戳、信度標籤；UI 呈現主觀表述而非數字

**技能 = 理解能力**
- [ ] 技能不足時角色得出錯誤結論、被誤導、看不懂包圍或病因
- [ ] 技能達門檻後玩家可察覺矛盾、辨識謊言、讀懂隱藏資訊

**聚落需求循環**
- [ ] 聚落每 Tick 消耗糧食/安全/勞力；不足時觸發社會崩潰事件
- [ ] 崩潰後果：飢荒、治安惡化、人口流失、流民化、叛亂、土匪化
- [ ] 生產型 vs 武裝型群體行為差異（農業/貿易 vs 徵收/掠奪）

## 第三階段 — Full Game（完整商業原型）

> 目標：世界有自己的歷史，玩家只是其中一個人。

- [ ] 勢力完整演化（割據、戰亂、吞併、瓦解）與長期歷史痕跡
- [ ] 完整經濟循環（生產、貿易、徵稅、掠奪）
- [ ] 情報操控：玩家可散播謠言、偽造軍情、收買信使、封鎖消息
- [ ] 指揮鏈延遲：命令傳達受距離/地形/士氣/訓練影響
- [ ] 地圖資訊不完整：需探索/詢問/購買地圖才能掌握全局
- [ ] 社會文化差異：不同地區擁有不同法律、禁忌、習俗，影響 NPC 態度
- [ ] 玩家死亡繼承鏈（後代、聚落居民、勢力成員）

## 第四階段 — Far Future（遠期願景）

> 超出目前版本範圍，概念性保留。

- [ ] 語言差異與翻譯障礙
- [ ] 宗教系統與信仰影響
- [ ] 深層政治（朝廷、世家、派系）
- [ ] 繼承與家族多世代歷史
- [ ] 身體限制全系統：疲勞、飢餓、疾病、傷勢影響行動力

---

## 核心設計不變量（勿破壞）

- 世界時間統一：大地圖移動 1 格 = 遭遇戰穿越同等距離所需時間
- UI 顯示主角主觀認知，非客觀真相
- 玩家死亡世界不暫停，NPC 記得歷史
- 聚落以群體聚合計算，不逐人模擬
