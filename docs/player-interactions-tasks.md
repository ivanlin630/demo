# 玩家互動完整修復計畫

- 當前計畫：
  - 實作 team UI (feat/team-ui-implementation) → `docs/superpowers/plans/2026-06-02-team-ui.md`
  - 玩家互動修復清單 → `docs/player-interactions-tasks.md`（6 大任務優先順序）
  
## 優先順序

| 優先 | 行動 | 狀態 | 複雜度 | 理由 |
|------|------|------|--------|------|
| 1 | 攻擊 | ❌ 無戰鬥 UI、NPC 代打、無戰後掠奪 | ⭐⭐⭐ | 戰鬥 UI 是基礎；影響 NPC 互動全流程（勒索、要求納貢、同盟都涉及） |
| 2 | 提議同盟 | ❌ 雙獨立無效；玩家可能被收編；無自立選項 | ⭐⭐⭐ | 複雜邏輯（雙獨立判定、收編防護、自立選項） |
| 3 | 貿易 | ❌ 無選擇介面，直接自動執行 | ⭐⭐ | 選擇介面相對獨立，但基礎 |
| 4 | 要求納貢 | ❌ 只一次性 coin×0.1，無後果 | ⭐⭐ | 依賴攻擊威懾感（戰鬥後才有說服力） |
| 5 | 勒索 | ⚠️ 已修，但 NPC 無法拒絕 | ⭐ | 已修，調整 NPC 拒絕邏輯即可 |
| 6 | 招募 | ❌ STUB | ⭐⭐⭐ | 最後；涉及 subteam + 人物轉移 |

---

## Task 1: 攻擊（戰鬥 UI）

**優先度：P1**

**目標：** 實作戰鬥 UI，NPC 真實代打，戰後可掠奪資源

**依賴：** 無

**關鍵子任務：**
- [ ] 設計戰鬥介面（雙方血量、技能選擇、迴合制）
- [ ] NPC 戰鬥 AI（技能選擇邏輯、傷害計算）
- [ ] 戰後掠奪系統（自動計算戰利品、玩家選擇）
- [ ] 對話系統整合（戰敗後 NPC 反應、投降選項）

**交付：** 完整戰鬥流程無 crash，測試 10+ 場戰鬥

---

## Task 2: 提議同盟

**優先度：P2**

**目標：** NPC 自主判定同盟，防止玩家被收編，提供自立選項

**依賴：** Task 1（攻擊/威懾感）

**關鍵子任務：**
- [ ] NPC 獨立判定邏輯（威望、實力、互信）
- [ ] 玩家獨立判定邏輯（收益 vs 風險）
- [ ] 收編防護（玩家可拒絕成為 subteam）
- [ ] 自立選項（leader 可帶人脫隊）
- [ ] 同盟狀態管理（協議、違約、終止）

**交付：** 6 種同盟結果都能發生，無強制收編

---

## Task 3: 貿易

**優先度：P3**

**目標：** 玩家可瀏覽 NPC 物品清單，選擇交易或拒絕

**依賴：** 無（可獨立實作）

**關鍵子任務：**
- [ ] NPC 物品清單 UI（分類、數量、品質）
- [ ] 玩家選擇介面（篩選、數量調整）
- [ ] 價格計算（NPC 貪心度、關係影響）
- [ ] 交易確認與執行

**交付：** 3+ NPC 貿易無 crash，合理價格

---

## Task 4: 要求納貢

**優先度：P4**

**目標：** 定期納貢（週期性）、NPC 感受到威脅時願意納貢、不納會受懲罰

**依賴：** Task 1（攻擊威懾感）

**關鍵子任務：**
- [ ] 納貢週期系統（NPC 記住上次納貢時間）
- [ ] 威脅計算（基於戰鬥勝率、隊伍規模）
- [ ] 拒絕後果（玩家可強制掠奪 or 宣戰）
- [ ] 長期關係衰退

**交付：** 20+ tick NPC 主動納貢且會拒絕

---

## Task 5: 勒索（調整拒絕邏輯）

**優先度：P5**

**目標：** NPC 在某些條件下可拒絕勒索

**依賴：** 無（現有系統基礎）

**關鍵子任務：**
- [ ] 拒絕條件判定（NPC 實力接近、有同盟支持、high loyalty）
- [ ] 拒絕反應（對話、威脅、逃跑、戰鬥）
- [ ] 失敗後果（NPC 仇恨值上升、聯合抵抗）

**交付：** NPC 能成功拒絕勒索，玩家面臨後果

---

## Task 6: 招募

**優先度：P6（最後）**

**目標：** NPC 可加入玩家 team，轉移至 subteam，帶走背包

**依賴：** Task 1, 2（同盟相關）

**關鍵子任務：**
- [ ] 招募條件判定（忠誠度、關係、team 空間）
- [ ] NPC 人物轉移（從 NPC team 移出、加入玩家 subteam）
- [ ] 背包轉移（equipped + inventory 隨人轉移）
- [ ] 脫隊風險（低忠誠度可能逃脫）

**交付：** 招募 3+ NPC 進 subteam，無人物遺失

## 測試檢查表

- [ ] 所有 6 種行動都有對應 UI
- [ ] 每種行動至少測試 5 次無 crash
- [ ] NPC 行為不是直接 script outcome，從 values/stress/loyalty 計算
- [ ] 20+ tick headless test 無異常
- [ ] 玩家隊伍成員不會無故脫隊
