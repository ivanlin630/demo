## §1b ★★★「存活」必須四分（blueprint 裁 2026-09-04；★聚合掩蓋結構是本週核心教訓）
```
★穩定        —— 資源成長、決策有 committed
★瀕死        —— ★★【判準（systems 定 2026-09-05）】：**窗內曾出現 `food_days < 1`（或 food == 0）而【最終存活】**
                 ⇒ ★不是「看起來很危險」，是【曾經觸底 ＋ 活到最後】兩個條件同時成立
★★卡在單一迴圈 —— ★★★【判準（systems 定 2026-09-05）】：**同一個 option 連續贏 ≥ N 次決策，
                 而該隊【資源沒有下降】** ⇒ 兩個條件缺一不可（★只有「一直贏同一個」＝可能是正確的持續行為；
                 ★★加上「資源沒下降」才排除「它正在解決問題」）；**N 由實測分布定，不先手填**
★死（含空殼）—— 團滅、或 pop_end=0 而未 extinct
⇒ ★★★「非存活率 46.2%」這一個數字,拆開是四種完全不同的處境,而其中【兩種是活著但卡住】
⇒ ★而這一格是【卷面規則】不是 code 改動 ⇒ 不需解凍、不影響同源
```
