## §1 一條規則

> **每一段只能是「規則／概念」或「證據／紀錄」之一。**
> **證據不與規則同居，只留一行指標。**

判準（機械可判）：**這句話三個月後還會不會是真的？**
- 會 → 規則／概念
- 不會 → 證據／紀錄

⚠ **例外：立法署名不算紀錄。** 「★執行失敗反饋鐵律（用戶立法 2026-08-21）」的日期是**誰在何時裁的**，是規則權威的一部分，**留**。
（第一版判準「帶日期＝紀錄」就是栽在這裡——會把憲法的署名整批誤刪。）

## §2 同一個病，三個粒度

| 粒度 | 形狀 | 例 | 好不好抓 |
|---|---|---|---|
| **檔** | 整個檔都是紀錄 | `status/*.status.md` | 最好抓（已停更中） |
| **段** | 整段是盤點／診斷 | `game-design` 的「路線圖總覽」「接線現況」 | 好抓 |
| **★段內** | **規則 2 行 + 佐證 29 行** | `invariants` 幾乎每一段 | **幾乎抓不到** |

### 為什麼段內混住最難察覺

`invariants.md` 我試了兩把自動尺，都失敗：

```
關鍵字行計數        →  6%   ← 假低：血證是十幾行敘事，只有一行寫「血證」
標題帶證據標記的段  → 24%   ← 也低：多數段的標題是【規則名】，血證藏在段內
人工讀一段          → 1:15  ← 真值
```

**每一段看起來都是規則**（標題是規則名），只是每段拖著一條 8–15 倍長的尾巴。
⇒ 所以它長到 824 行都沒人喊停 —— **它不像紀錄，它像 65 條規則。**

### 動機是對的，位置是錯的

寫的人剛痛過，**怕未來有人不知道代價就推翻規則**，所以把證據釘在規則旁邊。
⇒ **解法不是「別寫血證」**（那會丟掉防護），是**血證有自己的家、規則留一行指標**。

## §3 為什麼恰好是這兩份最肥

`invariants.md`（全六角色讀）和 `00_roles.md`（全六角色讀）**是唯二的全員必讀**。

> **一份 doc 被越多人讀，就越會變成傾倒場。**
> 想讓所有人看到某條規則 → 塞進全員必讀最快。

佐證：
- `invariants` 收了 **126 行量測紀律**（該在 `03b_measurer`）＋ **46 行流程紀律**（該在 `01_architect`）

★ **藍圖沒有專屬 doc，所以它的規則只能塞進共讀脊椎，六個角色每次 compact 一起付錢。**

## §5 附帶必要：讀單只能有一份

現在「角色該讀什麼」有**兩個 owner**，而且已 drift：

```
00_roles.md:153（導覽表）  系統 = 00 + 01 + 流程 owner 全 doc（02-08）
session-role.sh（CTX）     系統 = CLAUDE.md + 00_roles + 01_architect
session-role.sh:80         「先重讀你那格 docs（照 00_roles 導覽表）」  ← 自己把讀者導回導覽表
```

三個角色讀到不同答案（系統導覽表多 2.6×／實作 hook 多 3×／量測員導覽表多 1.6×）。

**⇒ 留 hook（實際被注入的），導覽表改成一行指標：「你那格由 SessionStart hook 注入，以 hook 為準」。**

**同時修兩個具體錯**：
1. `CLAUDE.md:52`「`invariants.md` ★ 跨系統規則（**每 session 開頭讀一次**）」→ 改指 **§0 條文（150 行）**
2. hook 叫實作「重讀**感知鐵律段**」，但 `invariants.md` **沒有這個標題**（概念散在「決策讀 belief 非真值」「★決策模型：感知→腦→行為」）⇒ agent 只能整檔讀。**分級後給它一個真實存在的錨。**

**★補一個反向的漏**：`09_exam_gate.md`（長考閘，89 行，活的、重要）**hook 一個角色都沒指名**。
⇒ 各角色 doc 開頭加「**觸發式必讀**」：
```
01_architect.md 開頭：
  ★ 要開大考前 → 必讀 09_exam_gate.md
  ★ 要動信箱機制 → 必讀 07_mailbox_trigger.md
```
**開場不付錢，觸發時一定被指到。**
