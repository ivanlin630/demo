## ★時長現實（用戶戳，重校尺）：目前設計時長 1~2 代人
多世代的東西 out-of-horizon，別替錯尺設計：
- **燒不到（defer / timescale-gated，時長拉長才解鎖，接時間統一 wave TimeScale）**：文化漂移分化（隔離→分化要幾十代）、外戚累代養主張/王朝樹、宗教長期分裂演化。
- **窗內就 fire（1~2 代的真 payoff，聚焦這些）**：單次繼位爭奪（多源正統撞）、天命侵蝕（幾件敗仗/饑荒就崩）、靜態文化背景製造斷層、聯姻外交鍵 + 一代後代。

## 1. 性別（結案）
- `PersonData.sex` 欄位已在但惰性。**只具名有意義、無行為分工、純血脈標籤**（守憲法：不 gate 戰鬥/勞動）。匿名層續用 `anon_female_ratio` 算 mass。
- 用途＝下游地基：聯姻（血脈合併）+ 繼承（後代帶雙親血脈）。具名層繁殖＝異性配對→生具名後代（parent 血脈邊，走 RelationGraph），區別現有「匿名晉升 named」（晉升無血脈，王朝戲要真血脈）。
- 關係本身性別盲（友誼/結盟/仇＝既有 feud/protect/gratitude）；只「生育/血脈」用異性標籤。
- 延後：繼承看不看性別＝**文化變數**（父系/母系/性別盲隨文化，見正統）；後代先**成年具名**，childhood 老化後補（`age` 欄在，`project_population_fixes` open item）。

## 2. 聯姻（深版 A，但 1~2 代下薄化）
- 引擎化（憲法）：提親/納/拒都引擎秤（需聯盟×血脈聲望×人格）；拒婚＝可為 casus belli/feud 種子。
- 人格長策略：野心家廣聯姻、信義高守盟、信義低先婚後叛、貪婪為嫁妝。
- 兩排牙：①外交鍵（在世＝聯盟/NAP，毀婚盟成本 >> 毀普通約，信義 gate + feud）②血脈鍵（後代雙血脈→登記跨團繼承主張）。
- **背叛但保主張**（反派 CK 招，傾向採用：主張是血脈事實、不因道德蒸發）——**但 1~2 代下跨團主張罕見晚窗才成熟（對方絕嗣），保當種子非主引擎**。窗內聯姻主要價值＝外交鍵 + 血脈斷層戲。

## 3. 身份 = 一組可增減的親疏環（registry 可擴充）
配對親疏＝各環距離加總；要加面向＝加一環，不重寫（承綜合發展模型的 registry 直覺）。**全是外交 utility 加權，非行為閘**——好戰頭人照樣打教友，人格仍主宰，身份只染權重。

- **模型＝離散 tag 排多邊形，環上距離＝親疏，對角＝極端敵對**（用戶定：讀法 A + 多邊形幾何）。同頂點=最友、相鄰=輕微、對角=勢不兩立。
- **文化＝多環**：社會結構 / 習俗 / 生活方式（游牧/農耕/商業）各一親疏環。1~2 代下**靜態多樣背景**（不漂移，靠初始各 region 不同製造斷層：同文化易盟、跨文化摩擦、跨文化聯姻後代繼承規則撞）。
- **語言＝特殊，不是親疏環，是溝通層**：語言不決定愛不愛你，決定**聽不聽得懂**。騎訊息系統：同語言→傳播乾淨；異語言→失真/傳不到/誤解（接核心命題「傳播困難→資訊碎裂」+ 技能=理解）。方言=小障礙，全異語言=大障礙。異語言不必互恨，但溝通成本高→信任慢建、易誤會=另一種疏遠。

## 4. ★宗教 + 正統 = 天賦神權脊椎（本輪關鍵收斂）
**宗教＝pick（schism-tree，特殊），正統＝衍生 mandate-belief（非 pick），宗教授予正統。**

- **宗教不是平環，是分裂樹**（用戶史實直覺：不要 N 個平等神，要「同一宗教不同分支 + 頂多兩三宗教」，符 HRE 天主教分裂 / 五代佛道儒）：1~2 根宗教，各根下分支（正統/改革/異端派），距離=樹距離。
- **正統＝「這統治者有沒有天命/神授」的 followers 信念**（非挑的環）。宗教環 sanction 統治者→跟主流信仰關係好=天命強→宗教與正統咬合。
- **天命會失**（承 game-design「天命失」）：敗仗/饑荒/天災=天怒徵兆→mandate-belief 崩→叛亂有理；勝→鞏固。隨事件更新（騎 belief-store point 7 message→belief 橋）。
- **異端>異教（表現非寫死，用戶要求）湧現自兩環交互**：敵意≠純宗教樹距離；額外的毒來自**正統競爭**——同根異支雙方都自稱「真神授/真正統詮釋」→爭同一批信眾的正統權→正統環對撞→切齒；異根異教各拜各的不搶你天命→冷淡。∴ 異端切齒 = 宗教近 × 正統爭，乘出來非硬寫加成。（十字軍打自己人、天主 vs 新教、遜尼 vs 什葉。）
- **接①造謠**：「他失了天命/神棄之/偽稱神授」=侵蝕 mandate 的假 claim=資訊戰打正統，命題閉環。

**多源正統收進天賦神權**：血脈/義子/軍功/推舉**不是四個獨立源，是四種爭同一個天命的說法**——血脈嗣「聖裔承天命」、篡位強人「我勝即天命轉移」（五代）、受祝福者「神職加冕」（HRE 教皇）、眾將擁立「眾意即天意」。繼位爭奪=followers 信哪套 mandate 論證→內戰/分裂。

## 5. ★軍閥怎麼發揮（用戶顧慮，關鍵解）：權力 ≠ 正統
天命是「權力的穩定劑」，不是「掌權的門票」。
- **權力**=真實武力（軍閥有這個，與天命無關）→照樣引擎奪權（殺正主坐上位），mandate 非前提。武力奪來的起手天命低。
- 低天命+高武力=坐得上、**坐不穩**（叛亂/背叛/挑戰者不斷→五代短命朝）；高天命+高武力=穩。
- 軍閥的戲=**奪權後拼命把武力煉成天命**（連勝→「天命轉移」回溯神聖化 / 脅迫神職加冕 / 聯姻立血脈），趕在下個強人幹掉他前。罕見補成功=開創長朝、打破循環那個。
- **權力先動、信念後補，落差=不穩定窗=動盪 payoff。** 全湧現：軍閥照引擎奪權、followers mandate-belief 照 belief-store 隨勝負/加冕/血脈更新、跌破挑戰者就反。零腳本。軍閥=引擎，天命=耐久度與悲劇。

## 憲法/鐵律對齊（貫穿全維度）
- 全 belief 層（正統/宗教/文化=感知信念非客觀 stat）→ 騎 belief-store（在建）。
- 身份=外交 utility 加權非行為 override；繼位/叛亂=followers 引擎決策（mandate-belief vs 挑戰者 vs 自利+人格），非 scripted event。
- 接既有：③內政 coup/exile（軍事強人源已在）、RelationGraph（血脈/婚姻/feud 邊）、①造謠（打正統）、訊息系統（語言溝通層）。
