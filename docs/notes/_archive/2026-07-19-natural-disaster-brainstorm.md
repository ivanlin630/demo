# 天災（維度7）brainstorm — 未來 arc 停車筆記

> 藍圖×用戶 brainstorm 2026-07-19（無信箱藍圖 session，純未來願景）。**非現在派工**。存 `notes/`（不碰 canonical、不發 handback）。observe-gated + **序 gated（要乾淨經濟基線才 legible，見下）**。接 [[2026-07-19-identity-dynasty-legitimacy-brainstorm]]（天命/正統）。

## 定位＝C：物質×信念的橋（用戶定）
天災站憲法「允許側」（世界規則＝作者寫世界，NPC 照引擎回應逃/遷/搶/祈/怪罪，非腳本）。世界已有饑荒基線壓力，∴ 天災的新價值**不是「更多死」**，是：
- **外生 wildcard**：隨機外來衝擊（非管理不當），世界現壓力全內生（戰/economy），天災補外生。
- **物質×信念雙打（獨有味）**：一場災**同時毀糧（物質）+ 蝕天命（信念）**。不接天命就浪費那條線。

## 每場災＝雙效
- **(a) 物質損害**（糧/人/資源，localized）：騎 resource/pop 系統。
- **(b) 天命衝擊**（該頭人 mandate-belief 蝕）：騎 belief-store mandate。

## ★核心＝天命衝擊「被頭人回應中介」（非自動扣分，天災的真戲）
- 災來 → mandate 崩不崩，看頭人怎麼應（引擎決策：救災/囤積/棄逃——慈悲責任→救、貪婪→囤）。
- **救得好→mandate 撐住甚至升**（「他帶我們熬過饑荒」）；囤/逃→崩。
- ∴ **天災＝統治壓力測試，不是骰子。天命由此「掙來」非白給。**
- **文化中介**：虔誠文化怪罪狠、務實文化只遷徙（接身份環）。
- **接①造謠**：敵手放「天罰偽王！」放大 mandate 侵蝕＝資訊戰騎天災。
- **★接軍閥煉金**：剛奪權軍閥碰饑荒管得好＝又一條武力煉天命的路（加在連勝/加冕/聯姻旁）；弱主碰災→mandate 崩→被推翻。**災＝正統戲上演的舞台。**

## 物質側＝localized → 遷徙/難民
localized 災（如某區產量下降）→ 難民逃向無災區 → 遷徙/抱團/搶掠壓力（接絕境經濟）。

## 動盪迴路
災 →（物損 + 天命跌）→ 頭人應對失敗 → 叛亂/篡位；應對成功 → 挺過測試、鞏固。全湧現：災＝世界規則，頭人回應＝引擎決策，followers mandate-belief＝belief-store 隨**觀察到的回應**更新。零腳本。

## 規模＝registry + ~3 原型（用戶同意）
不鎖數字，做 registry：每災＝一個「物質效果 profile」，**天命/mandate 機器全共用**（回應中介/掙天命/造謠放大不分災種）。加災＝加 entry。
物質效果聚成 ~3 原型（差別在引擎回應真的不同）：

| 原型 | 例 | 打什麼 | 回應差異 |
|---|---|---|---|
| **① 慢產量下降** | 旱/枯萎病 | 糧**生產**逐步降 | 慢擠壓→遷徙 |
| **② 急庫存/人損** | 洪/震/火 | 存糧/人/設施**驟失** | 急衝擊→救災 scramble |
| **③ 瘟疫** | 疫病 | 殺**人**、**傳染**、不碰糧 | 完全不同：隔離 vs 逃、**騎同格傳播（像訊息蔓延）** |

超過 3＝這 3 原型的風味皮（蝗=①變體、山火=②變體）。

**序：**
1. **先做 ①產量下降**（用戶指定的 canonical 例，最乾淨、最好示範 C 橋）。
2. 成了加 **③瘟疫**（差異最大、複用同格傳播、回應完全不同）。
3. **②急損**看世界缺不缺那味再加。
∴ 機器做一次、災先上 1 種、長到 ~3 原型、之後全皮。不前置塞 5 種。

## ★★序 gated + 給主藍圖 economy arc 的旗（本輪重要副發現）
- **天災要乾淨經濟基線才 legible**：現在世界 buggy-hungry，加「產量下降災」分不清**災餓 vs bug 餓**。∴ 天災**排在 framework 清完 + 真 economy 讀出來之後**（基線健康，「這區本來吃得飽、災來才餓」才成立）。
- **★「餓世界」是疑似 part-bug、非定案設計（用戶戳「能種田為啥餓」，藍圖認同）**：`恆-hungry→永建農` 補丁閘（已修）、供給牆早破（has_facility 恆1→31%、goods 18x、Manufacture 700x、隊真會生產）、剩 28% doom 故意還沒當真稀缺（god-view 髒 + stall-gap bug 汙染，framework 先清才讀真 economy）。→ **「餓世界」＝診斷進行中的暫時標籤，非世界設計前提。**
  - **★連帶旗（給 economy arc）**：絕境經濟/抱團/收留 look-before-leap 那些設計，部分是**對著可能被閘餓出來的世界過度擬合** → framework 清完須**重驗還需不需要**。此旗屬主藍圖 economy arc，非天災 arc，但本輪挖出，記此供 resurface。
