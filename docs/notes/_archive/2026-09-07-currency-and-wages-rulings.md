## §1 礦總量有限（用戶裁定）＋三幕結構

**裁定：礦總量有限。**
⚠ HOW 缺口（轉 systems）：現行 code **無儲量遞減**——`tile.resources["ore_gold"]` 只在 world-gen 寫入（5–30），全庫無扣減點（兩路窮盡搜索：`tile.resources` 全寫入點＋ore 減法語彙，零命中）。礦有限裁定 ⇒ 需要儲量計數器（採集遞減）。

```
第一幕 金潮   礦豐、貨幣化擴張（薪資/市場剛上），錢追著經濟跑
第二幕 漸緊   成本錨調節＋儲量遞減，錢荒零星、囤積成戲
第三幕 錢荒   礦竭＋死錢池累積 → 通縮質地 → 信用內生（A2 開題）
```

**歷史課（為什麼一直挖礦沒通膨）——四機制，對照 sim**：
①**成本錨**（通膨→挖礦不划算→自動減產；供給內生）→ ★待驗：coin 在引擎裡有沒有邊際遞減（`marginal_economy` 對貨有，coin 未查）——**有＝無限泉也自穩；沒有＝接線缺口**
②流量/存量比極低 → 可量（⑨創世存量＋`mint_coin` ledger）
③持續漏損（磨損/沉船/首飾/貿易外流）→ sim 只有死錢池一種（`abandoned_coin`/`offmap_extinct_coin`＝埋藏失傳的類比）
④經濟成長＋貨幣化擴張吃掉新供給 → 正在發生
反例即規則：西班牙白銀/羅馬摻假/曼薩穆薩——流量暴增就通膨。

## §2 金本位的必要性 ＝ 信任的 bootstrap

金本位 vs 信用本位的差別**不是材質，是信任來源**：金＝信物理（零信任貨幣，陌生人唯一能用的錢）；信用＝信人（需要「認得誰欠誰＋違約有後果」的社會基礎設施）。
開局世界信任趨近零 ⇒ **金本位不是選擇，是信任真空期的唯一解**。跳過第一幕，信用沒有出生理由（硬塞＝腳本化違憲）。
歷史上信用不是換掉金，是**架在金上**——A2 命名「第二階段」正確。

**貨幣必要性（對照量測）**：解雙重巧合（`buy_no_want: 2,248` ＝以物易物稅的屍體）／唯一無倉容上限的資產（`sell_storage_full`/`buy_carry_full`＝實物財富被物理封頂 ⇒ **規模經濟需要 coin**）／價格的可傳播語言（n 個價 vs n²交換比 ⇒ L2 情報的前提）／薪資（歷史上發餉就是鑄幣普及的第一驅動力）／全經濟唯一守恆量（CoinAudit 架構依賴）。
誠實邊界：純以物易物世界能跑，只是**地方性、巧合性、封頂**——恰是本專案量測史上的舊世界（供給牆時代）。必要性相對於願景（規模/貿易網/情報套利）。

## §3 A2 信用本位定稿（用戶裁定：範圍）

**★範圍＝勢力間＋商團間，不及僱傭層。** 理由：
①對下的「欠」已有載體——**怨/忠誠就是員工的應收帳款**，疊 ledger＝同一件事記兩份
②信用需要**對等執行力**（能斷貿易/砸信譽/開戰才叫債權人）；員工只有怨＝壓迫關係非金融關係
③「誰能欠」＝**明天還在＋討得回** ⇒ 定居的據點、有 seat 的政權、有信譽的商團；流浪團付現

**分兩幕**：
- **商團信用先**——需求已量到：`arb_kill_nostock: 1,795,597`（看得見套利、沒本錢吃）＝貿易信用的歷史起點（匯票）。A2 開題第一個客戶已排隊。
- **勢力信用後**——朝貢欠繳（tribute 已存在）/贖金分期（A5 俘虜「贖」）/戰債。⚠ 依賴：違約戲（討債開戰）需要戰爭動詞 ⇒ **天然排在戰爭之路重啟後**。

**前置**（planning-closeout 已記）：脊椎估值前瞻（債＝未來請求權，B5 缺口）。
**觸發機械化**（取代「感覺通縮了」）：板價中位數連跌 N 窗＋成交量萎縮＋mint 未停（排除「沒人採礦」）＋死錢池佔比未暴增（排除「戰爭凍幣」——那該用搶劫解不該用信用解）→ 掛 defers token。
**白撿閉環（進 A6 設計輸入）**：戰爭凍結 coin（死錢池）＝製造通縮；consolidation 搶劫＝**唯一的貨幣再流通政策**。戰爭同時製造病和藥，湧現不用設計。（留問 systems：`abandoned_coin` 可不可拾？可拾 ⇒ 死城=金礦=拾荒者與盜匪之戲。）

## §4 薪資雙層制（用戶裁定，四輪收斂）

**撤回記錄**（各被用戶擊落，理由要留）：
- 實物工資 ✗——匿名生存已由吃團糧涵蓋；named 要個人糧倉＝大改
- 入帳制 ✗——**帳需要明天還在的債務人**，分團/叛亂/滅團每條都是特例，零特例法淹死；戰團經濟史也站這邊（即時分贓、欠餉即譁變）
- 完全豁免 ✗——白嫖忠誠＋可被 game（先花光＝策略性貧窮免罰）

**★定稿：雙層制**

```
匿名層  供養制。糧＋安全＝義務底線，失守→morale/叛亂。薪資非必要
        （anon 池降為可選士氣加成，HOW 歸 systems）
記名層  薪資制。coin 現結；有名字的人有 values/goals——野心是要付錢的。
        付不出→忠誠流失→離團/拒晉升/被挖走（★離心非叛亂）
        ⇒ 無幣村結構性封頂於小規模：匿名吃飽穩定、named 只剩領主至親、長不大
        ——不叛亂不爆炸，商路/礦帶 coin 進來才解鎖成長層
例外    關係貨幣：主從記憶免薪（code 已有 `_has_master_memory` skip）；血緣免薪 ← B1 接
        ★免要求 ≠ 不能給（用戶補裁）：領主想付照樣可付、照樣買忠誠——恩義免義務，不封賞賜
富村    overpay bonus 保留 → 忠誠緩衝＋搶人籌碼
叛亂    保留給供養失敗與不公（有錢不餵人＝暴君戲）
後續    人才被薪資吸走（勞動市場遷移）＝湧現版，掛條件不現在做；
        「看到別村發錢薪才怨」← L2 情報（與經濟階級筆記同觸發）
```

**壯大鏈**：分團要領袖、委任要心腹、擴張要軍官＝全走記名 ⇒ **壯大的燃料是 named，named 的燃料是 coin** ⇒ coin 是成長層的專屬貨幣（金錢必要性的最後一顆牙）。

**現況 bug 座實（轉 systems 修法）**：
```
salary_system: paid = salary * budget_ratio      # 無幣村 ratio=0
  LoyaltyBank.adjust(p, -(1-ratio)*SALARY_LOYALTY_PENALTY, "underpay")  # 滿額扣
  if budget_ratio < 1.0: UnrestBank.add(team, 1, "salary")              # +1/輪
SALARY_INTERVAL = 7 日
```
⇒ 結構性無幣村＝每 7 天全員滿額扣＋unrest 永動——**地理被定罪成治理失敗**，且懲罰正落在市場可達性最差的村。
**修法方向**：named underpay → 忠誠流失（個體、導向離團），unrest 從薪資摘鉤、歸供養失敗；匿名薪資懲罰移除、morale 錨定供養。

## §5 待驗（量測員/查證票，四項）

1. **coin 邊際遞減**在不在決策引擎（成本錨成立與否——決定無限泉會不會自穩，礦有限只是加第三幕）
2. 慢性減薪現行下游全貌（忠誠回復/unrest 衰減速率 vs 7 日懲罰節奏——決定 §4 修法急迫性）
3. `anon_treasury = 0` 長期效應
4. named 忠誠流失速率 vs 離團閾值（雙層制下「封頂」是漸進失血還是斷崖）
