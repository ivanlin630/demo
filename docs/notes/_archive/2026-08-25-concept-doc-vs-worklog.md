## §4 常設規則（一句話，機械可判）

> **要寫「現在到哪了」的東西，就不屬於概念 doc。**
> 判準＝**這句話三個月後還會不會是真的**。

★ 好處：**寫的人當下就知道自己違規**，不用等 review。

去處對照：

| 內容 | 去哪 |
|---|---|
| 為什麼這樣設計／高層模型／裁定與其署名 | 概念 doc ✅ |
| 現在到哪了／盤點／arc 進度 | `progress.md` |
| 什麼壞了／診斷／真根 | `known_issues.md` |
| 被新法取代的舊設計 | `docs/archive/`（原地留一行指標） |
| 量到的數字 | 量測紀錄；**概念 doc 不抄數字進來** |

⚠ 最後一條同時解掉 `stale-claims` 的膨脹疑慮：
概念 doc 裡「含會過期數字」的行目前共 **161 行**（game-design 64／invariants 48／person 23／team 14／world 9／mechanism-intents 3）。

⇒ **`stale-claims` 的正確角色不是「幫數字加標籤」，是「偵測概念 doc 裡出現了不該在那的數字」。**
