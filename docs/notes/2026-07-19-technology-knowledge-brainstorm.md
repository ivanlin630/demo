# 技術/知識（C：技術附身於有技之人）— 未來 arc 停車筆記

> 藍圖×用戶 brainstorm 2026-07-19（無信箱藍圖 session，純未來願景）。**非現在派工**。存 `notes/`。observe-gated（部分 timescale-gated）。接 [[2026-07-19-bonds-and-character-arcs-brainstorm]]（師徒羈絆）、[[2026-07-19-info-warfare-verbs-brainstorm]]（竊技）、[[2026-07-19-long-range-planning-brainstorm]]（means-end 求知識）。

## 重定向：不做科技樹，做「知識即資訊」
- **技術「進步」（發明/科技樹）＝多世代 timescale-gated** → 1~2 代看不到發明火藥，**排除**。
- 窗內 + 命題契合的是**知識＝不均分布的資訊/能力**（同受霧/不對稱/稀缺）。

## 技能 vs 技術（不同軸，用戶戳「不相等」）
- **技能＝做多好**（個人執行力，已在、隨用長、隨人死）。
- **技術＝能做啥**（配方/上限，可傳可失）＝**新概念，與技能不同軸**。

## ★裁定＝C：技術附身於有技之人
- 技術是真的「能做啥」上限（配方分**基礎 vs 需技術**幾層）——與技能不同軸、真實存在。
- **但技術非憑空群體 boolean，是「附身在懂它的人身上」**：一群「有冶金」＝因為它**有懂冶金的匠人**。
- **有技之人＝技術載體**：靠他們**教（師徒羈絆）/被擄（擄匠）**傳；**最後載體無徒而死＝失傳**。配方分層存在，但「擁有技術」＝「擁有懂它的人」。
- ＝技術真實且 character-embodied（活在人身上）、騎技能+羈絆、無憑空科技樹。**技能＝執行，技術＝那些人身上帶的配方；擄匠＝擄技術，大師死絕＝失傳。**

## 教/偷要時間——時間成本是 feature 非麻煩
- **教＝學徒期**（多-tick）：騎已有 skill 成長 + 師徒羈絆（大師教→徒技能加速長向那技術）。
- **偷＝間諜 op**（多-tick + 風險）：騎 偵查/潛行 + 資訊四動詞；被抓＝失敗+後果。
- 兩者＝長程計劃 means-end（缺知識的群慾求→追師/竊/征服，跨 tick 拼）。
- **★關鍵：時間成本正是知識「稀缺/失傳/值得偷」的原因。** 瞬傳→到處擴散永不失傳沒人偷→零戲；慢傳→留原地集中、大師教到一半死＝傳承失敗悲劇、偷比學快、值得藏。時間生失傳/藏/竊的戲。

## 真前置：設施/物品補最小技術分層（用戶戳「目前無技術之分」）
- 現在 workshop=workshop、item 有 grade 欄但**無 knowledge-gated 分層** → 知識無處掛、「會冶金」沒機制表現。
- **最小前置（非科技樹）**：少數 craftable 分知識門檻（基礎兵器人人做、上等兵器需冶金；基礎設施誰蓋、高階工坊/冶爐需技術）。**幾層就夠**，讓知識＝「能做出更好的東西」。

## 戲（全 window-fit + 命題化）
失傳的技藝（大師死傳承斷）/藏技行會（知識壟斷）/技術竊取（間諜偷冶金＝資訊動詞用在知識）/擄匠（征服奪知識，連俘虜道德）/授技結盟（傳授鞏固聯盟）。

## 憲法乾淨
知識＝資訊/能力附身於人（騎 info-system/belief + skills + 師徒 bond，非腳本科技樹）。缺某知識的群慾求→means-end（找師/竊/征服）→引擎決策，非腳本 tech-unlock。registry 一維（發展 registry「未來加技術」）。
