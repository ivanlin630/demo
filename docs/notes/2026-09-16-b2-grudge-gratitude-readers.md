## §1 裁定

### 寫入（匿名層照舊走 UnrestBank，匿名不落單）
1. 重徵 → `extorted`（表已有，接線）
2. 供養失守／求救不應 → 怨（新 type `neglected`，嚴重度介於 extorted 與 looted）
3. 施捨／救援 → `kindness`（寫入者已在，加呼叫點）

### 疊加與淡忘
- **同類疊＝飽和疊加** `1−(1−舊)(1−新)`：小怨累積會爆、單次大怨直接高、永不破 1、順序無關、零常數。取代 max；既有「厭煩疊加」（特別稅計次）併入。
- **異類（恩 vs 怨對同一人）並存，不淨值**。「救命恩人殺了我兄弟」是戲，淨值＝0 沒戲。
- **淡忘走事件不走時鐘**：消耗邊的事件（見下）為主；被動淡忘＝**人格化速率**（義氣高恩記久、好戰高／慎重低怨記久）。
- **禁**：全域半衰期常數、硬到期刪邊、恩怨同速率。

### 行動＝秤上多選項（不是「報不報」二元）
對同一個人的選項，各自讀兩條邊＋人格＋處境（實力比、缺不缺他、戰時否），每次重估：

| 選項 | 讀什麼 | 消耗邊？ |
|---|---|---|
| 復仇（攻擊） | feud、實力比、好戰 | 消耗怨 |
| **被動**（冷淡→加價→拒賣→不救，連續量） | feud，成本≈0——**弱者的出口**，沒有它弱者有怨等於沒怨 | 否 |
| 無 | 兩邊低／慎重高 | 否 |
| 報恩（援助、折價、優先成交、替他打） | gratitude、義氣 | 消耗恩 |
| 和解（賠禮＝offer，對方秤決定收不收） | 自己是加害方、對方 feud 高、需要對方 | 對方收下才消耗其怨 |
| **勾銷**（一筆勾銷，心裡的事，單方面） | 兩邊都高且相當、慎重／義氣中等、需要對方或實力相當 | **兩邊一起消耗** |
| 抹黑（傳聞） | feud、打不過又不想沉默 | 掛觸發（資訊戰動詞） |

**唯一要釘死的規則**：消耗邊的是事件（報恩／復仇／和解／勾銷），被動與無不消耗。

### 四種結局全是路徑，不是人格查表
| 結局 | 怎麼長出來 |
|---|---|
| 恩仇都報 | 報恩先贏→消耗恩→下次重估怨獨大→復仇（或反序：先殺再厚葬） |
| 擇一 | 一個贏、另一邊留著，之後人格淡忘或新事件翻案 |
| 都不報（兩清） | 勾銷贏→兩邊消耗 |
| 都不報（擱著） | 被動→兩邊都留著；他再犯或再施恩，帳翻出來 |
人格只調權重，不寫結局；同一個人今天勾銷、明天他再搶一次就復仇。

### 讀者接線（三個，序）
1. **離心路徑**：記名者對領主 feud → 離團 util ↑；gratitude → 留下／免薪（④關係貨幣已裁）。
2. **交易逐方估值**：對方領主是我 feud 對象→加價／拒賣；gratitude→折價／優先。與軍票 trust 同形（per-party 進 `trade_valuation`）。順手砍 `npc_ai_system.gd:176` 的 0.003 常數。
3. **求助對象**：`_find_aid_target` 已有 rep 項，加 gratitude +／feud −。
- `vendetta_target` 三硬門檻 → util 項（補丁閘去除，讀 gratitude 與處境）。
- 舊 `p.relations` 淨值標量 → 廢（讀者一律讀邊）。

## §2 複雜度（用戶問）
規則少結局多。真新增：三寫入呼叫點、一行飽和疊加、四處消耗邊、一個淡忘函數、兩個估值 term、一個 option、一函數改寫、一個刪除。**零新判斷器，減一個補丁閘。**
唯一風險＝六選項人格權重成調參面：權重由人格值推導不手填；每格床要能紅。

## §4 驗收床（每格能紅）
1. 同一重徵序列：義氣高 vs 低 ⇒ feud 強度分化
2. 十次小重徵 ⇒ feud 累積到可觸發被動拒賣（max 版永遠不到）
3. 有怨的弱村 ⇒ 對加害者拒賣樣本；對第三方照賣（對照）
4. 恩怨並存 ⇒ 至少各一個「先報恩後復仇」與「勾銷」樣本（B 片）
5. 賠禮 offer 被收 ⇒ feud 降；被拒 ⇒ 不降
