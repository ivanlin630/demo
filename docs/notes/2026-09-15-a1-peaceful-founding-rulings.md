## §1 裁定

1. **三層照 code 走**：聚落 → 勢力 → 國。野心階梯兩個台階可演（先拉幫結派、再稱王）。
2. **立國＝最低門檻＋過秤**（防「沒事就立國」噪音）：
   - 門檻＝**結構事實，不是數字**：有據點／有記名班底（心腹、軍官至少各一）／不隸屬他國（臣屬者先叛離，那是另一把秤）。世界答得出的不手填。人口、財富進 util 不進門檻。
   - 秤＝`:1692` 那道閘改成 means-end 秤上的選項，與**臣服現有國／維持獨立**並列——三選項同一把秤就是野心階梯。真防呆＝另外兩個有真 util，不是冷卻。
   - 舊三常數不丟、改身份：野心＝driver（人格）、統領＝成功機率估計、readiness＝代價項。與勢力層 `:54` 同形。
3. **零特例含玩家**：`player_command_system.gd:402 establish_faction` 現也是 fiat；門檻三事實對玩家同樣生效，玩家只是自己當秤。

### 承認
他國秤上「承認／不承認」。不承認⇒打你正當性高、你的票在他境內 trust 起手低。承認＝外交籌碼可交換。

### 降階
不寫規則。成員走光⇒勢力散；國滅⇒回勢力／聚落⇒成員各自上「立國／臣服／獨立」秤⇒戰國分裂連鎖。同一秤反向跑。

## §4 驗收床（兩端都要能紅）
「從不立國」與「人人立國」是同一個病的兩端（守衛母體恆空／恆滿）。四格：
1. 野心高／低同處境 ⇒ 立／不立各有樣本
2. 立國後被提防**真發生**：鄰國 threat belief 升＋有攻擊樣本
3. 正統債真發生：起手低忠誠→有叛離樣本
4. 門檻真擋：不隸屬／無班底者從不出現在候選
