## §1 方案採納（四點全對齊憲法）

金幣＝普遍接受性非固定購買力／收不收由 NPC 從經驗＋傳聞判斷（＝既有 belief 管線＋known_reputations，進秤的選項非新判斷器）／不做全球匯率、NPC 不知總發行量／濫發走「發行→世界狀態→經驗→信用認知→行為」不走通膨公式。

**它順手解掉兩個卡點**：
- A2 對脊椎前瞻估值的依賴——「大家都收」是學來的信念，不是折現計算 ⇒ **勢力信用幕不用等脊椎**（商團貿易信用仍要）
- 入帳制被砍（債務人不延續）——軍票是**持票人債**（bearer note），票跟人走，分團不分帳。**不是入帳制，是它的反面。**

## §2 三處補強

1. **★錨＝發行者回收義務**：勢力用自己的票收稅／朝貢／賣貨。沒有它，「別人會收」的網路信念**冷啟動不了**。這是接受性的地板，其他信念疊其上。
2. **觸發歸位**：勢力**缺金發不出餉**才印票 ⇒ 軍票＝對錢荒的反應＝第三幕；給通縮觸發一個具體消費者。
3. **⚠ 待裁：士兵領票算不算「現結」**（貼著「僱傭層永遠現結、欠款不及員工」那條線）。影子傾向相容：當場拿到票＝現結，票值不值錢是持票人的資訊問題；發票餉的忠誠效果 × 收薪者對票的 trust，不信票＝覺得沒領到薪→走離心路徑，零 ledger。**用戶未表態。**

## §3 通膨（用戶裁：要連續，不要二元懸崖）

```
trust[NPC][票] ∈ [0,1]   ← 真信念：經驗＋傳聞更新
估值 ＝ 面值 × trust      ← 進既有 trade_valuation，軍票當一種貨估值，零新系統
```
「我收但要 20 張不是 10 張」自然長出；每個 NPC 各有隱含率，**沒有世界數字**。二元＝trust∈{0,1} 是特例，連續是通式（更少特例）。

| trust 來源 | 機制 |
|---|---|
| 親身經驗 | 拿票去買，對方要價／拒收 |
| 回收經驗 | 繳給發行者有沒有按面值收（＝錨） |
| 傳聞 | 「東市不太收甲票了」走 message 傳播 ＝ **L2 情報** |
| 距離 | 離發行者近 trust 高（回收可達），遠則折價——**地理梯度湧現** |

**濫發螺旋（無公式）**：缺金→印票發餉→票變多→持票人找下家難→要價經驗差→trust 滑→要更多張→更急脫手→…；發行者回收能力是唯一實體地板，超過它螺旋自啟。惡性通膨＝領主人格（貪婪/絕境）決定鏈的結果，非系統判定。

**貨幣史四幕**：金潮 → 漸緊 → 錢荒發票 → **濫發票通膨**。
**紅線**：trust 不得是發行量的函數（那是偷渡的全球匯率）。
**玩家看到**：要價變多＋記憶裡「某市拒收甲票」的傳聞——零自動總結（C1 一致）。

## §4 匿名層與買人心

- **匿名池維持 coin-only，票不入**。匿名不交易（吃團糧、不逛市場），票進池唯一去路＝領主徵用回來＝自己的 IOU 繞回自己＝零。
- **匿名可發薪（coin）**：供養＝義務、薪資＝加分項——進 `anon_treasury` 積蓄池＝領主危機緩衝（可徵用）；不發不罰、發了有賞。
- **買人心走「票→貨→供養」或「票→記名→流通」**。直接發票給匿名＝禁——它會製造「用廢紙買到忠誠」的漏洞；票沒人收就買不到糧就買不到人心，**紙不能直接換忠誠**的防呆天然成立。
- 軍票只對「會拿去花的人」有意義：記名層持有／團庫 `team.resources[甲票]`。

## §5 勢力滅亡與票的生命週期

```
發行   缺金 → 印（材料+設施）→ 團庫／記名持有
流通   trust 估值進 trade_valuation；傳聞傳 trust；地理梯度
回收   繳稅/朝貢/買勢力貨 → ★銷毀（正常匯；發行>回收才叫濫發）
死亡   勢力亡→回收錨消失→trust 隨【消息傳播】歸零
       ★消息沒到的偏鄉還在收；先知情者可把票倒給不知情者＝核心迴路第 5 條「利用無知」
       觀察窗（征服者可承接）→ 過後搬 defunct 帳（顯性 sink，同 offmap_extinct_coin 慣例）
征服   據點易主＝接收經濟體（已裁）的子案：承接舊票（買前朝人心最便宜）vs 拒收（怨落自己頭上）
       ＝征服者人格秤上的選項，非系統規則
匿名   不入
```
**稽核式（票版 CoinAudit）**：每發行者 `issued == redeemed + outstanding + defunct`——系統可稽核、NPC 看不到 outstanding，兩層分開。

## §6 物理（用戶問：票占空間重量嗎）

**不占，票＝coin 類**：零重量、無倉容上限、不腐壞。兩軸分開：
- 估值軸：票「當一種貨」進 trade_valuation（面值×trust）
- 物理軸：走 coin 的 carry/vault 豁免路徑，`coin` 單 key 擴成一組 key（`coin`/`甲票`/`乙票`）
零重量正是紙幣本質：金的上限是礦，**紙的上限是 trust**——沒有物理擋濫發，所以才會通膨。

## §8 續場裁定（2026-09-09 下午，用戶裁）

| # | 裁定 | 形狀 |
|---|---|---|
| 1 | **士兵領票＝現結**（§2-3 收） | 票當場到手＝現結；票值＝持票人資訊問題走 trust。忠誠效果＝既有 underpay 路徑，ratio 餵「實領估值／應領」 |
| 2 | **記名收票零評估、只讀 trust** | `trust[NPC][票]` 是 belief 欄位，發餉當下只查表不算；trust 動在之後花／繳回的經驗與傳聞。零新判斷器 |
| 3 | **印票＝財政秤上的選項，多面向** | 與「欠餉／徵匿名池／賣庫存／裁軍」並列。util 讀：缺口、離心成本、**領主自己對票會不會被收的 belief**、自己 outstanding vs 回收底氣、物理前提（紙／鑄坊）。人格 modulate。**不得算通膨預測公式** |
| 4 | **只勢力發票；商團走雙邊帳** | 票＝不記名持票人債／帳＝記名雙邊債，兩軸正交（媒介 vs 付款時點） |
| 5 | **錨＝`trust[發行者][自己的票] ≡ 1`**（定義非特例） | 我的 IOU 回到我手上＝抵債，面值。⇒ 任何跟發行者的交易自動回收銷毀，**不需要稅／朝貢機制**，也**砍掉「回收政策」決策**（§1 說的「回收義務」就是這條）。貪婪表現在濫發不在拒收；領主沒貨可賣⇒兌不到⇒trust 靠經驗滑 |
| 6 | **初始 trust 承自對發行者的信任** | 發票＝領主一句話（message，origin=領主）；兵的初始 `trust[票]`＝他對領主的既有信任（忠誠／known_reputation）。不設常數。忠誠低的軍隊印票立刻炸＝合理 |
| 7 | **票不預設暫用／長期** | 同一套規則兩條軌跡：守紀律（發≈收、錨持續行使、活著）⇒ trust 貼 1＝事實紙幣經濟；貪婪⇒四幕。發行選項對**任何支出**開放（發餉、買貨、蓋設施），不只發餉——trust 高了拿紙買東西最誘人＝濫發誘因在此 |
| 8 | 劣幣驅逐良幣＝湧現 | 雙方各有 trust，我的 < 你的 ⇒ 我用票付金留著。逐方估值就長出來，不寫規則 |

### 用票還債／grievance／協商（賒帳延後，但形狀先釘）
- 還款＝offer，債主算 `N × 面值 × trust[債主][票]`；≥債清、＜債只清那部分、拒收全額續欠。雙方帳可不同（認知非真相）＝恩怨源。
- 缺口→債主 grievance＋雙邊信譽掉。**沒有「武力強」特例**：強弱只改變債主秤上有哪些選項（弱：認賠／斷賒／傳話；強：＋武討＝grievance 驅動 raid／＋把票倒回發行者逼兌）。
- 債務人事前 util 讀 belief-threat ⇒ 金還強者、紙還弱者，欺軟怕硬湧現。
- **grievance 不是雙方都知道**。債務人只從三管道拼：offer 回覆（部分收帶「餘 70」）／債主主動催（秤上可選說或不說，悶著＝突襲討債）／傳聞與威脅感知。
- **協商＝一回合 offer**，多回合＝之後再出價湧現，**不做談判狀態機**。
- ⚠ HOW 待查（systems）：現行交易回覆有沒有「部分接受＋餘額」形狀，還是收／拒二元。

## §9 賒帳：DEFERRED（用戶裁 2026-09-09「先不做」）

**形狀留檔**：記名團級雙邊債 `{債主,債務人,金額(coin),到期,來源}`；範圍勢力↔商團／商團↔商團／勢力↔勢力；債主秤「現結賣／賒帳賣（加價）／不賣」、債務人秤「現結／賒／印票／不買」；**無利息**，成本＝成交時加價（由債主違約預期推出，非常數）；違約不強制扣押、不自動罰；分團債留母團、滅亡→defunct、征服者可承接；稽核 `簽==清+outstanding+defunct`。

**為什麼不做**：解的是「有貨沒錢」（以物易物已在）；票已解錢荒發餉；現在瓶頸是分配撮合；它是唯一讓債務**跨團傳染**的機制，多一個世界級風險源換不到現在缺的。

**做了會不會變賒帳經濟**：會，除非三個煞車是真值（禁 cap 常數）：
1. **賣方自己要現金**——雇員薪資只能現結（已裁）⇒ 賣方每期需 coin ≥ 餉 ⇒ 賒出去的貨換不到餉。最硬的一條，薪資裁定送的。
2. 曝險——債主讀自己 outstanding。
3. 加價——有 coin 的買方現結更便宜。
正確湧現＝金潮現結為主、錢荒賒帳為主。每期都賒⇒不是設計錯，是 util 沒讀到三值⇒dump per-option util。

**觸發**：量到「雙方都有貨、一方缺 coin、以物易物配不上⇒交易流失」達看得見的量。前置：債務人側要「coin 流感官」（糧流感官同型，非脊椎全套）；債主側信譽×還款 belief 就夠。

## §10 續場補漏

- **礦枯竭**：我說「code 無扣減」是錯的，見 `2026-09-09-retract-ore-depletion-gap.md`。剩的是量測票（三幕能否在可玩時距內走到錢荒），不擋票。
- **板撮合要走估值不走裸 coin 比**（HOW 標）：板單以 coin 計價，買方拿票來，GATE-B 若直接比 coin 數就永遠配不上。必須過 `trade_valuation`。
- **玩家動詞**：市場四件套外加 `印票`／`發票餉`（領主身份）進 player_reachable 票；板面板顯示「此攤收哪些票、折多少」＝對方回覆帶的資訊。
- **床形狀**（缺陷變對照）：錢荒起手局（庫 0、餉到期、有鑄坊）× 兩人格 ⇒ 絕境印／保守不印各一格；濫發 vs 守紀律 ⇒ trust 滑／撐住各一格。四格都要能紅。驗「四幕能發生」不驗「必發生」。
- **刻意不做（掛觸發）**：偽鈔、兌金窗口、利息、談判機、賒帳。
- **序**：票 coin 類 key＋估值 → 財政秤加「印票」 → trust 進 belief＋傳聞 hook → 玩家動詞 → 床。
