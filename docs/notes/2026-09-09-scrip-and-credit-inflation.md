## §1 方案採納（四點全對齊憲法）

金幣＝普遍接受性非固定購買力／收不收由 NPC 從經驗＋傳聞判斷（＝既有 belief 管線＋known_reputations，進秤的選項非新判斷器）／不做全球匯率、NPC 不知總發行量／濫發走「發行→世界狀態→經驗→信用認知→行為」不走通膨公式。

**它順手解掉兩個卡點**：
- A2 對脊椎前瞻估值的依賴——「大家都收」是學來的信念，不是折現計算 ⇒ **勢力信用幕不用等脊椎**（商團貿易信用仍要）
- 入帳制被砍（債務人不延續）——軍票是**持票人債**（bearer note），票跟人走，分團不分帳。**不是入帳制，是它的反面。**

## §2 三處補強

1. **★錨＝發行者回收義務**：勢力用自己的票收稅／朝貢／賣貨。沒有它，「別人會收」的網路信念**冷啟動不了**。這是接受性的地板，其他信念疊其上。
2. **觸發歸位**：勢力**缺金發不出餉**才印票 ⇒ 軍票＝對錢荒的反應＝第三幕；給通縮觸發一個具體消費者。
3. **⚠ 待裁：士兵領票算不算「現結」**（貼著「僱傭層永遠現結、欠款不及員工」那條線）。影子傾向相容：當場拿到票＝現結，票值不值錢是持票人的資訊問題；發票餉的忠誠效果 × 收薪者對票的 trust，不信票＝覺得沒領到薪→走離心路徑，零 ledger。**用戶未表態。**

## §3 通膨（用戶裁：要連續，不要二元懸崖）

```
trust[NPC][票] ∈ [0,1]   ← 真信念：經驗＋傳聞更新
估值 ＝ 面值 × trust      ← 進既有 trade_valuation，軍票當一種貨估值，零新系統
```
「我收但要 20 張不是 10 張」自然長出；每個 NPC 各有隱含率，**沒有世界數字**。二元＝trust∈{0,1} 是特例，連續是通式（更少特例）。

| trust 來源 | 機制 |
|---|---|
| 親身經驗 | 拿票去買，對方要價／拒收 |
| 回收經驗 | 繳給發行者有沒有按面值收（＝錨） |
| 傳聞 | 「東市不太收甲票了」走 message 傳播 ＝ **L2 情報** |
| 距離 | 離發行者近 trust 高（回收可達），遠則折價——**地理梯度湧現** |

**濫發螺旋（無公式）**：缺金→印票發餉→票變多→持票人找下家難→要價經驗差→trust 滑→要更多張→更急脫手→…；發行者回收能力是唯一實體地板，超過它螺旋自啟。惡性通膨＝領主人格（貪婪/絕境）決定鏈的結果，非系統判定。

**貨幣史四幕**：金潮 → 漸緊 → 錢荒發票 → **濫發票通膨**。
**紅線**：trust 不得是發行量的函數（那是偷渡的全球匯率）。
**玩家看到**：要價變多＋記憶裡「某市拒收甲票」的傳聞——零自動總結（C1 一致）。

## §4 匿名層與買人心

- **匿名池維持 coin-only，票不入**。匿名不交易（吃團糧、不逛市場），票進池唯一去路＝領主徵用回來＝自己的 IOU 繞回自己＝零。
- **匿名可發薪（coin）**：供養＝義務、薪資＝加分項——進 `anon_treasury` 積蓄池＝領主危機緩衝（可徵用）；不發不罰、發了有賞。
- **買人心走「票→貨→供養」或「票→記名→流通」**。直接發票給匿名＝禁——它會製造「用廢紙買到忠誠」的漏洞；票沒人收就買不到糧就買不到人心，**紙不能直接換忠誠**的防呆天然成立。
- 軍票只對「會拿去花的人」有意義：記名層持有／團庫 `team.resources[甲票]`。

## §5 勢力滅亡與票的生命週期

```
發行   缺金 → 印（材料+設施）→ 團庫／記名持有
流通   trust 估值進 trade_valuation；傳聞傳 trust；地理梯度
回收   繳稅/朝貢/買勢力貨 → ★銷毀（正常匯；發行>回收才叫濫發）
死亡   勢力亡→回收錨消失→trust 隨【消息傳播】歸零
       ★消息沒到的偏鄉還在收；先知情者可把票倒給不知情者＝核心迴路第 5 條「利用無知」
       觀察窗（征服者可承接）→ 過後搬 defunct 帳（顯性 sink，同 offmap_extinct_coin 慣例）
征服   據點易主＝接收經濟體（已裁）的子案：承接舊票（買前朝人心最便宜）vs 拒收（怨落自己頭上）
       ＝征服者人格秤上的選項，非系統規則
匿名   不入
```
**稽核式（票版 CoinAudit）**：每發行者 `issued == redeemed + outstanding + defunct`——系統可稽核、NPC 看不到 outstanding，兩層分開。

## §6 物理（用戶問：票占空間重量嗎）

**不占，票＝coin 類**：零重量、無倉容上限、不腐壞。兩軸分開：
- 估值軸：票「當一種貨」進 trade_valuation（面值×trust）
- 物理軸：走 coin 的 carry/vault 豁免路徑，`coin` 單 key 擴成一組 key（`coin`/`甲票`/`乙票`）
零重量正是紙幣本質：金的上限是礦，**紙的上限是 trust**——沒有物理擋濫發，所以才會通膨。
