# 第四輪試玩：你可能會遇到的已知問題

> 這份清單跟著修復一起更新：每修好一項、合併進主線的同一次提交就改這裡那一行（系統負責）。
> 回饋怎麼分流：畫面／按鍵／提示句的問題 ⇒ 直接開票；世界行為的問題 ⇒ 先對照這份，已列的不另開，沒列的進觀察輪分類。
> 最後更新：2026-10-07（起草）

| 你會看到的 | 為什麼 | 哪張票在修 | 修好之後 |
|---|---|---|---|
| 用 `python tools/play.py` 玩時，按了推進鍵（x／Space）畫面上的時間沒變，要再按一次才看到上一步的結果 | 畫面在推進真正跑完之前就先送出來了，永遠落後一步 | 端到端驗收票（同一支函式一起修） | 按下推進鍵後，回來的畫面就是推進之後的樣子。★上幾輪你遇到的「按了沒反應、再按一次才動」「待辦數對不上」可能有一部分就是這個——不是你看錯（修好後這一列標「已修」保留不刪） |
| 隊伍走路很慢，平地、山地、森林看起來差不多慢 | 疲勞只會累積不會恢復，幾天後所有隊都被壓到最慢那一檔，地形的差別被蓋掉 | 疲勞票（疲勞依活動恢復＋「休息」選項） | 沒在趕路或做工時會恢復；休息過的隊走得快，地形快慢看得出差別；你自己的隊也能下令休息 |
| NPC 隊伍說要「建設」，卻站在空地上不動，或一直沒蓋出東西 | 建設沒有綁定地點，隊伍不知道該去哪裡蓋 | 建設綁地點票 | 選了建設的隊會走回自己的據點去蓋；蓋不了時會說出原因（例如材料不夠多少） |
| 商隊走到市集後什麼都沒做，又在那裡待很久 | 到了市集沒有可成交的單時不算失敗、也不放手；自己的市集裡連別人的單都不能交易 | 貿易失敗票 | 沒得交易就當場放手並記得「這裡上次沒成」；在自己的市集也能跟別人的單成交 |
| 錢或貨顯示「待領」，隊伍站在市集上卻沒領回來 | 只有帶著貿易任務到市集時才會領，站著不動或做別的事時不會 | 到場即結清票 | 隊伍只要站上那個市集，自己的待領就立刻入帳 |
| 抽稅的訊息看起來都一樣，印的比率跟實際被拿走的對不上 | 居民稅、勢力貢、掠奪用了同一種說法；印的是調整前的比率 | 訊息名稱票（排在端到端驗收之後） | 訊息會說是哪一種（居民稅／勢力貢／掠奪）和實際比率；一毛沒收到時不再印「徵收 45%」 |
| 不是盟主的隊伍，也會向同勢力的人加抽一筆重稅 | 舊的「特別稅」誰都能抽、沒有宣戰也能抽、抽多少是寫死的比例 | 戰時徵用票 | 只有盟主、在缺戰爭經費時才能徵；抽多少看盟主的性格和對方的處境；對方可以拒絕，被抽狠了會記仇甚至脫離 |
| 隊伍做完一件事之後，有時發呆將近兩小時才動 | 每支隊的思考時間錯開排程，剛好排到後段時要等很久 | 思考節律票 | 任務結束後一小時內一定會重新決定下一步 |
| NPC 有時做出明顯不划算的事（例如去搶一個對它幾乎沒價值的目標、或放著明顯更好的選項不做） | 候選清單上的分數跟最後選的對不上，而紀錄沒說為什麼 | 挑選器一致票 | 選了低分選項時，紀錄會印出是哪一層加成讓它翻過去；印不出理由的情況會被當成錯誤另外修掉 |
| 有隊伍一直掛著賣不出去的糧，價錢也不降 | 自動掛賣看不到自己賣不掉 | 尚未開票（已記錄） | 暫時不會變 |
