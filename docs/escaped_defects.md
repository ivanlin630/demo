# Escaped Defects（逃逸缺陷 ledger）

> **定義**：用戶發現的任何問題=逃逸缺陷=流程事故。每筆立檔：哪層該抓而沒抓 → 補那層機器。
> **三層驗收鏈**（全綠才交付用戶）：①充足性閾值（帶分母的率 assert）②常駐漏斗（分階段轉化率回歸可見）③戲感審計（系統以觀者身分讀 default 世界流,統計唸成句子問怪不怪）。
> **承諾邊界**：湧現系統會出新型失誤;本制保證=**同類永不第二次**（每筆逃逸缺陷變一層機器）。
